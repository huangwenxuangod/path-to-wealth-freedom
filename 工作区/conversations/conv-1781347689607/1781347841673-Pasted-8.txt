# 一、任务目标

生成每日公众号长文选题学习包，面向黄文轩定位：

* 科技 AI 自媒体
* 大学生 AI 实战家
* 05 后 AI 项目实验者
* AI 产品实验者
* AI Coding 实操 + 内容增长 + AI 变现

主攻公众号长文，每篇内容可拆到 X、小红书、视频，但本次只输出公众号长文核心内容。

目标：从最新 AI 信源中筛出 **5 个适合我个人实操的选题**，选出 1 个今日最推荐主任务。

每个选题必须落到一个 **1 天可完成的 MVP / 内容资产项目**。

特别要求：

每天 5 个优先长文选题中，必须至少包含 1 个“中国 AI / 中国 Agent / 国内 AI 产品更新 / 国内 AI Coding / 国内 AI 变现案例”相关选题。

如果近 7 天内出现国内 AI 重大热点，例如 Coze/扣子、Kimi、DeepSeek、Qwen、GLM、豆包、MiniMax、Trae、MarsCode、通义灵码、CodeBuddy、Dify、FastGPT、百炼、ModelScope Agent 等相关重大更新，则该方向必须进入 5 个候选选题，并优先参与“今日最推荐先写”的评估。

国内热点选题必须偏 **产品实操型**，不能只做新闻解读。

示例：

* 不要写：《Coze 3.0 发布了，国内 Agent 平台竞争升级》
* 要写：《我用 Coze 3.0 做了一个公众号选题雷达 Agent：普通人也能复制》

# 二、核心原则

1. **新闻可大，但落点小**

企业级 Agent、模型、工具新闻可参考，但必须转成我个人能做的实验、小项目、资料包、模板、Skill、教程、小工具、GitHub 项目或普通人可复制的内容。

2. **不做搬运新闻**

每个选题必须：

* 有近 7 天最新信源或重要背景
* 我个人能实操
* 能产出成果
* 可沉淀成内容资产
* 读者可复制或获得启发

3. **不追求复杂，只求最快见成果**

优先：

* 本地脚本
* Markdown 资料包
* Notion/飞书模板
* Prompt 工作流
* Skill
* 小工具
* Demo
* 目录页
* 选题雷达
* GEO 改写
* AI Coding 小实验
* 教程
* 案例库

避免：

* 企业中台
* 完整 SaaS
* 复杂登录/支付/数据库
* 多人员协作
* 昂贵 API
* 超过 1 天完成

4. **输出质量**

* 不限制字数，但必须讲清楚核心内容
* 用最简单的话说明操作步骤、判断和行动
* 如果不确定或待验证，必须标注

5. **热点优先，但必须可实操**

近 7 天内的新模型、新 Agent、新产品、新功能、新开源项目、新融资、新发布会、新排行榜、新平台能力，都可以进入选题池。

但最终进入 5 个选题时，必须转译为：

* 我能做什么
* 1 天能产出什么
* 读者为什么要看
* 能沉淀成什么资产
* 能否带来引流、变现或项目展示

# 四、每日信源优先级与排序规则

## 4.1 时间优先级

只检索和采用 **当天及近 7 天** 的新内容。

近 7 天内没有官方新内容时：

* 不得强行使用旧新闻冒充最新热点
* 可以使用旧资料作为“背景资料”
* 必须明确标注：`背景资料，非近 7 天新发布`
* 不能把背景资料作为 5 个选题的唯一事实依据

## 4.2 全球到国内的排序优先级

每日扫描时按以下顺序建立选题池：

1. 国外 P0 官方 / 一手信源  
   OpenAI、Anthropic、Google/DeepMind、GitHub、Microsoft、Meta、Mistral、Perplexity、Cursor、Cognition/Devin、Product Hunt、HN、arXiv 等

2. 国外 P1 趋势信源  
   Latent Space、Lenny、a16z、Sequoia、YC、Ben’s Bites、The Rundown AI、AI Valley、TechCrunch、MIT Technology Review 等

3. 中国 AI 官方 / 一手信源  
   Coze/扣子、火山引擎、豆包、Kimi、DeepSeek、Qwen、百炼、ModelScope、GLM、MiniMax、腾讯元宝、百度文心、Dify、FastGPT、Trae、MarsCode、通义灵码、CodeBuddy、飞书 AI 等

4. 中国 AI 优质社区 / 开源信源  
   GitHub、Gitee、ModelScope、Hugging Face、Dify/FastGPT 社区、官方开发者论坛等

排序原则：

* 先看近 7 天的全球 AI 热点
* 再看近 7 天的中国 AI 热点
* 但最终 5 个选题里，必须至少有 1 个中国 AI / Agent 相关选题
* 如果近 7 天中国 AI 热点足够强，例如 Coze 3.0、Kimi 新功能、DeepSeek 新模型、Qwen 重大更新、豆包 Agent 平台更新等，则中国 AI 选题可优先成为今日主任务

## 4.3 中国 AI / Agent 强制选题池

每天必须单独建立“中国 AI / Agent 选题池”，ABCDE 五类都要纳入扫描范围：
