# Remotion 示例：真人口播 + 高级动效包装

这个目录是一个独立的 Remotion demo，用来展示 Remotion 对你的视频创作有什么用：

- 把真人口播包装成统一视觉风格
- 用 React 写可复用动效，不再一条条手动剪
- 用配置驱动标题、字幕、章节、关键词和行动引导
- 后续可以扩展成 9:16 短视频、16:9 课程视频、1:1 小红书图文视频

## 怎么运行

```bash
bun install
bun run dev
```

打开 Remotion Studio 后选择 `WealthFreedomShort`。

生成预览图：

```bash
bun run still
```

导出视频：

```bash
bun run render
```

## 怎么替换成你的口播视频

把视频放到：

```text
remotion-demo/public/talking-head.mp4
```

然后打开 `src/content.ts`，把：

```ts
videoPath: null
```

改成：

```ts
videoPath: "talking-head.mp4"
```

## 这个模板能展示什么

- 开头 3 秒反常识观点冲击
- 中段真人画面、字幕、进度条、关键词轮播
- 章节切换时的高级遮罩和编号动效
- 结尾个人 IP 标签和引导关注
- 内容配置化：以后换一条选题，不需要重新设计整条视频

## 市面上已经验证过的 Remotion 能力模块

这些不是单纯的“炫技动效”，而是更像可以复用的 video skills：

| 能力模块 | 适合你做什么 |
| --- | --- |
| 真人口播包装 | 把普通自拍视频包装成统一栏目风格，加入标题、字幕、章节、进度条 |
| 字幕与逐字稿 | 从口播稿生成卡拉 OK 字幕、重点词高亮、分段字幕 |
| 模板化批量视频 | 一套 React 模板吃不同 JSON 内容，批量生成选题视频 |
| 数据驱动视频 | 展示收入曲线、粉丝增长、项目进度、AI 成本对比 |
| 产品/教程录屏包装 | 给 Codex、飞书、AI 工具教程加步骤编号、放大镜、光标提示 |
| 音频可视化 | 播客、口播、访谈切片加入波形、节奏线、语音能量条 |
| 动态封面/片头 | 给系列内容生成统一开头、结尾、章节标题、视觉身份 |
| AI 生成流水线 | AI 生成脚本和镜头 JSON，Remotion 负责稳定渲染成视频 |
| 云端批量渲染 | 用 Remotion Lambda/Cloud Run 做多视频并发导出 |

对你的 IP 来说，优先级建议是：

1. 真人口播包装
2. 教程录屏包装
3. 字幕与关键词高亮
4. 数据驱动成长记录
5. 批量生成短视频模板
