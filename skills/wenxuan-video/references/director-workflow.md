# 导演式工作流

## 不是“分镜表填完就做动画”

知识片的导演任务是控制观众每一刻知道什么、看哪里、怎样把上一条信息接到下一条。分镜不必精细绘画，但必须明确知识目的、主体、变化和视点。禁止用一串“淡入、发光、旋转”代替叙事。

## A：研究、叙事与分镜

1. 确认用户实际要制作什么，例子不自动成为锁定参数。资料缺失但不影响初稿时明确假设；关键事实/因果不确定时先查一手来源。参考片按全片抽样和关键段密集抽帧分析。
2. 写一句观众问题、一句核心回答和一条贯穿全片的对象/变量。叙事可用“反常→机制→条件/反例→回到问题”，不是强制七幕公式。
   时长服务理解，不默认60秒；2—3分钟或更长可按必要解释展开。明确是什么与为什么，按需要选择例子、对比、类比、反例或过程演示。设计开头hook及其兑现，长片章节用新问题接力；不为固定时长删掉关键推理或灌水。
3. 正式分镜前选BGM并建立声音节奏图，读music-driven-editing.md；无音乐则记录用户选择。先写全片信息推进：每段提供哪条新信息，前段为什么引出后段，结尾怎么兑现开头。决定节奏后再编号镜头；章节/幕/场景/镜头不是同一个计数。
4. 视觉未知时先比较轻量风格卡。轻量分镜只需一表：时间、知识目的、主画面及前后状态、旁白/字幕、景别与机位、运镜动机及起终画面、转场衔接，以及音乐区间、目标声音事件与画面命中。每段一张草图够用时不追加复杂画板；变化难懂时补第二张。
5. 写“导演理由”：为什么近景/全景、观众先看什么、画面何时停住、下一镜如何承接。静止镜头也是设计选择。
6. 阶段A默认交付完整叙事＋分镜＋运镜分析，等待用户继续；全流程自主授权则先自检再进入B。审批状态写真实来源，不把模型自检记成用户已确认。

## B：动效设计在分镜之后

每镜围绕实际声音事件按“预备→运动→命中→余势与读取结果”分拍，必要时少量额外动作；先定义视觉变量，再给时间：对象/属性、开始/结束状态、触发事件、起止时刻、缓动、语义目的。

- 物体运动：顾客改道、路径延伸、数字变化，解释事件。
- 摄像机运动：改变观众的取景与关注范围，不改变知识变量。
- 特效：强调重要信息，不掩盖主体形状或制造虚假因果。

尽量错开镜头大幅运动与关键数据变化，数据读完再切。禁止所有对象同时飞入、背景不断转、人声/字幕/图表同时各讲一大段。不要用一切抖动/发光等同于戏剧性。

## 运镜分析：可执行的简版

| 方式 | 知识目的 | 常见失误 |
|---|---|---|
| 固定 | 稳定读数、比较、观察变化 | 因为怕简单而硬加摇镜 |
| 推近 | 从环境转到关键证据/局部机制 | 主体还没建立就快速推入 |
| 拉远 | 从局部事件揭示系统/网络 | 所有标签同时缩小至不可读 |
| 平移/跟随 | 保持连续对象，连接因果节点 | 方向颠倒、主体漂移出画 |
| 俯视 | 展示空间、流向和竞争范围 | 透视过斜导致关系难读 |
| 切镜/匹配转场 | 比较、转折、缩短无信息时段 | 每幕重置物体和空间导致断链 |

每次运动必须写：目的、开始看见什么、结束多知道什么、触发时机、持续时间、阅读停留、与下一镜共享的锚点。2D画面里的推近通常是视窗/缩放，不声称具有真实3D景深。

## C：低成本 Animatic

全片按时间串起来，用线框/草图/场景卡、粗镜头、占位字幕、BGM、计划音效及已有或临时旁白验证。此处就发现“看不懂”“太快”“结尾来不及”，成本比精制后返工低。

先听实际旁白并测量分段；草稿阶段只给估时与置信度，不说“文案已锁60秒”就真的60秒。字幕的阅读停留、镜头运动和信息变化都要在Animatic检查。用户选择逐张交付场景卡时按其节奏交付，避免未经确认一次性生成全部图。

## D–F：制作与导演验收

技术服务已确定的画面需求。先做代表段，再全片；用统一对象和视觉规则保证连续性。场景、动效、音频每次修改后复查邻接镜头，避免局部漂亮但全片不通。

导演验收四问：静音看能否读懂关键机制？只听能否跟上论证？音画对应是否同时发生？结尾是否准确回答开头？这四问是设计检查，不是学习效果实验证明。

## 用户参考例子的处理

用户给的“八幕”文本实际列7段、总60秒；先校正计数，不机械增加第8幕。最后6秒文字偏密的风险必须用真实旁白试读检查。其“品质可见”画面不自动等于完整柠檬市场机制，若真正讲逆向选择，应补信息不对称、买方报价与优质供给退出等逻辑。

这些是示例审阅方法，不把竖屏、60秒、红白配色、AI旁白或7张卡固化为本Skill默认输出。
