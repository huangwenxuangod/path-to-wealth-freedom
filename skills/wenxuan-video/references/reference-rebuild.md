# 参考重建：把外观翻译成设计约束

1. ffprobe 确认宽高、fps、时长、音轨、编码，记录 SHA256，保留原文件。完整时长必须来自文件而非印象。
2. 执行 analyze_reference.py：均匀抽帧、场景候选、联系表与声轨。均匀抽样覆盖全片，不叫“逐帧看完”。场景检测只找到突变，连续推镜中的语义换景仍需人工辨识。
3. 在最难段追加 0.2–0.5 秒密集抽帧；逐个判断主体轨迹、速度、缩放、遮挡、进退场和相机运动。
4. 建立视觉令牌：背景色/主色/语义色、线宽、地平线、主物体画面占比、字幕字高/字距/基线、光晕范围、明暗层级。参考字号换算成画面高度比例，不照搬绝对值到别的尺寸。
5. 把 observed / inferred / authored 三类分开：画面有透视线框是 observed；“用了 Blender”是 inferred；自写 Canvas 实现是 authored。
6. 同时间码对比关键帧并记录具体差距。构图错了先修构图，主体错了先修主体，不用增强 Bloom 掩盖形状差异。

只把参考截图用于分析，不塞回输出后宣称原创重建。纯复刻与“把别的选题做成相同风格”是不同任务，以用户要求为准。
