# 音频：前置驱动、分轨与清晰度

先读music-driven-editing.md：BGM在分镜前选定与分析，音效参与动作命中设计。以下为混音，不替代音乐化导演编排。

## 独立分轨

旁白轨、音乐轨、音效事件轨分别管理，原始 WAV/M4A 留存。旁白是主角；先把旁白调到舒适音量，再加低电平音乐，最后只在机制转折/重要出现放音效。字幕出现、每个节点点亮和每次镜头移动不必各响一次。

脚手架 AudioMix 提供可编辑旁白活动区间，在区间前后渐变压低音乐，并为音效设置独立增益。它使用时间区间 ducking，不是自动语音检测；区间应来自旁白实际分段。

经验起点而非验收真理：音乐处于人声下约 15–22 dB；重要音效约 0.1–0.4 秒；相邻事件避开密集重叠；总线真峰值留出余量约 -1 dBTP；最终目标响度按发布平台选择，LUFS/-1dBTP 不用音量百分比冒充。测量使用 FFmpeg ebur128=peak=true；sample peak 与 true peak 要分开。

## 只有混合音轨

先确认是否原片自带配乐/音效，不重复叠音乐。EQ、高低通、轻压缩改变整个混音；独立压低音效需要实际分轨或经复核的声源分离结果。声源分离容易伤辅音和氛围，先做短片 A/B 再处理全片。

丝路这次最终轻修使用 140 Hz 低架 -1.5dB、6kHz -2dB、1.2:1 轻压缩与限幅，收敛低频冲击和刺耳高频；较强高通/低通试验改变能量包络过大，已退回更轻的版本。此参数是该音轨的试验，不是通用处方。更换视频先测量再听 A/B；人声变薄、齿音模糊、音乐抽吸则退回更轻参数。

只改音频时用 FFmpeg `-c:v copy` 复用已渲染的视频码流，不重新跑全部画面。验证视频码流 hash 相同、音频时长/时间戳/声道正常。EQ 会改变相位，逐样本相关系数不等于听感或人声清晰度；用时序、能量包络、峰值测量辅助，主观听感仍需 A/B。
