# AI编程

## 一句话定义
AI 从「代码补全」进化到「全流程代理」，编程工作的本质正在被重新定义——开发者从「写代码的人」变成「指挥 AI 写代码的人」。

---

## 核心观点

### 技术层面
- **Agentic Coding 是颠覆性而非渐进式改进**。Apple 在 Xcode 26.3 中原生集成 Claude Agent 和 OpenAI Codex，GitHub 发布 Agent HQ，Cursor 以 $2B ARR、$50B 估值成为史上增长最快的 B2B 软件公司——三件事叠加标志着范式跃迁。
  (来源：[[热点雷达-20260509-AI-Agent-Vibecoding]])
- **三大技术支柱**：超长上下文理解（百万 Token 级）、MCP 工具调用协议、自主规划与验证循环（Plan Mode + 执行-验证-调整）。
  (来源：[[热点雷达-20260509-AI-Agent-Vibecoding]])
- **和 2024 年比提升幅度**：上下文长度 10-30 倍、代码准确率从 67% 到 92%+、端到端任务完成率从 <20% 到 60-75%。
  (来源：[[热点雷达-20260509-AI-Agent-Vibecoding]])

### 商业层面
- **Cursor 的商业模式验证**：不靠自研模型，靠极致产品体验（上下文理解、多文件编辑、Agent 模式自然切换），50-300 人做到 $2B ARR。
  (来源：[[热点雷达-20260509-AI-Agent-Vibecoding]])
- **变现地图清晰**：
  1. 个人开发者/大学生用 Vibe Coding 接单（案例：Anuj Bhalla 月收入 $15,000）
  2. 企业用 Agent 替代初级开发人力（Superhuman、Temporal 已采用）
  3. 编程教育从「教语法」转向「教思维」（Replit 5000万+用户）
  (来源：[[热点雷达-20260509-AI-Agent-Vibecoding]])

### 风险与局限
- **Token 成本随项目规模指数增长**：有开发者一个月账单高达 $3,731，远超订阅费。
  (来源：[[热点雷达-20260509-AI-Agent-Vibecoding]])
- **幻觉在复杂场景下依然致命**：7 起 Vibe Coding 生产事故，包括 150 万 API 密钥泄露、生产数据库被删。
  (来源：[[热点雷达-20260509-AI-Agent-Vibecoding]])
- **维护债务累积**：AI 生成的代码「能跑但看不懂」，3 个月后维护成本急剧上升。Forbes 直接标题：《Vibe Coding Will Break Your Company》。
  (来源：[[热点雷达-20260509-AI-Agent-Vibecoding]])
