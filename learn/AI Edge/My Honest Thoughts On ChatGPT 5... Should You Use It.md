# ChatGPT5 终于来了

从 GPT-4o 发布后，大家就盼了很久。这期间还出过不少小版本，其中 **o3** 曾是我最喜欢的模型（后面会说）。现在 o3 被砍掉了，我其实有点难过 —— 虽然 GPT5 和它很像，但对我个人需求而言，o3 在某些地方表现略好。OpenAI 现在把所有模型**全部整合**成了一个包。

你第一个明显的感受：**打开 ChatGPT，再也不用选模型了**。

过去一堆版本（4o、o3、4.1）把人搞晕。OpenAI 这次走**大众化商业路线**，全部统一成 GPT5。

App 里现在有三档：

1. **GPT5**（默认，基础版）
2. **GPT5 Thinking**（思考更深、回答更详尽，适合写作等）
3. **GPT5 Pro**（专业研究版）

Pro 回答速度明显更慢，但**智商最高**，适合：

- 复杂工作问题
- 高等数学
- 金融数据建模

日常使用 **GPT5 标准版足够**，复杂问题我会切 Thinking。

# 一、GPT5 相对旧模型的核心升级

## 1. 速度暴快

我对比了 GPT4 与 GPT5：

GPT5 **快 50%–70%**，且准确率更高。

比 o3 也快非常多（o3 经常很慢），质量持平甚至略好，耗时更短。

## 2. 基准测试成绩极强

解题、数学、代码、推理能力全面超越 o3 和 4o。

可以确定：**这是 OpenAI 史上最快、最聪明、最强的模型**。

## 3. 编码能力大幅提升

我只做了基础测试（Python、JSON、小型网页 / 移动端界面），结论：

- **幻觉（hallucinations）大幅减少**
- 准确率远高于 4o、o3

但我依然认为：**编码不如 Claude 4.1**，Claude 整体仍是编码最强。不同垂直领域可能有差异，程序员建议自己实测。

编码不是颠覆性革命，但**明显更好、更稳**。

## 4. 真正完整多模态（文本 + 图像 + 音频 + 视频）

这是体验上的大升级，OpenAI 明显在**讨好普通用户**：

- 拍张照片发过去 → 语音回答
- 上传文档保持上下文
- 不用切换模式、不会丢失记忆

一套聊天里**所有输入输出通吃**，对移动用户、语音用户非常友好。创意工作者会明显受益。

## 5. 图像生成提升有限

图像生成**没有质变**，显然不是本次重点。

速度略快，但和 Gemini、Grock 最新的视觉升级比，完全不算震撼。这部分大概率以后再补。

## 6. 隐藏小功能

- 内置**人格切换**、主题颜色
- 增强高级语音模式：对话更流畅、不卡顿、响应更快
- **深度应用集成**：Gmail、Google Calendar（对标 Gemini）
- 项目记忆、长期个人偏好记忆（官方说有优化，我用得还不够久暂不评价）

# 二、实话实说：失望与倒退的地方

GPT5 发布前**被吹得太神**，但实际落地后，很多人包括我都觉得：

**没有带来期待中的 “量子级跃迁”**，只是一套更工整、更快、更整合的套餐。

这一点直接反映在预测市场 **Poly Market** 上：

- OpenAI 八月前保持最强模型的概率 **暴跌至 20% 以下**
- 即将发新模型的 Google **暴涨至 80%+**

市场认为：GPT5 不够颠覆，守不住王座。

## 我的两个真实痛点

### 1. 免费联网数据抓取倒退（我最痛）

我大量用 AI 做**金融、加密货币、股市研究**。

o3 可以**免费直接抓取**各类财经、加密网站数据，自带集成与 API。

但 GPT5 **不再免费联网拉数据**，强制要求：

- 配置 JSON
- 跑 Python
- 手动填 webhooks

以前 o3 自动搞定的事，现在要自己配置，非常繁琐。

**手动配完 API 后，回答质量确实比 o3 / 4o 更好，但多了巨大摩擦成本。**

### 2. 模型灵活性消失

过去我可以自由切换：

- GPT-4o：简单文本
- o3：深度分析
- o3 Pro：研究
- 小模型：写作

每个模型**专精不同场景**。

现在全部大一统，对普通用户友好，但对**重度 AI 用户、研究者**很痛苦：**可定制性、可选择性大幅下降**。

我好几次下意识想切模型，才发现已经没了，说实话挺难受。

# 三、横向对比：GPT5 vs Claude / Grock / Gemini

## 1. vs Claude

- 编码：**Claude 依然更强**
- 如果你是 Claude 用户，**没有任何强理由换 GPT5**

## 2. vs Grock（尤其是 Super Grock）

- Grock 依然是**智商纸面最高**的模型
- **实时研究、新闻、市场催化剂、突发消息** → Grock 完胜
    
    GPT5 抓取实时新闻经常卡顿，Grock 依托 X 平台海量推文，实时性碾压。

## 3. vs Gemini

- Gemini **Google 生态集成依然最丝滑**（Gmail、Drive、Calendar、YouTube）
    
    GPT5 刚加上集成，但仍不如原生。

# 四、我以后怎么用这些模型？（真实习惯不变）

- **GPT5**：创意脑暴、通用对话、日常提示、轻度编码、基础研究 → 依然最强最顺手
- **Claude**：重度编码、长文本、文件、仪表盘、工程
- **Grock**：实时新闻、市场研究、突发信息
- **Gemini**：Google 全家桶、图像、YouTube 相关

**并没有因为 GPT5 而出放弃其他模型**。

---

# 五、最终 Verdict（总结）

- **单独看 GPT5**：它是**好模型**，也是**全球顶尖模型之一**，甚至可能是**对普通用户最友好的模型**。
- **但如果你期待革命性颠覆**：这次更新**让你失望了**。

它更快、更稳、更少幻觉、整合更优雅，但**没有摧枯拉朽超越竞品**。
