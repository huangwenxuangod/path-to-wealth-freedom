## 什么是 Obsidian？

Obsidian 本质上就是一款**笔记软件**，没什么神秘的。

区别在于：它不是桌面那种列表式文件夹，而是**自动生成思维导图（双向链接）**。

你可以像 Notion 一样点进单独页面，页面底部会自动关联其他相关页面。

这让你可以**直观看到不同信息之间的关联**。

比如我点「OpenClaw」，就能看到所有相关内容：我做过的视频、收藏的文章、X 上的攻略等，全部链接在一个库中。

想象潜力有多大：

- 个人生活库
- 创意灵感库
- 商业数据库
- 收藏库：文章、视频、推特、网页干货

只要格式正确（我会教你用 Claude Code 批量处理），它就会自动建立关联。

久而久之，你会搭建出**模仿人类大脑的知识网络**：大脑就是把不同记忆关联、形成模式，Obsidian 完全一样，而且可视化呈现。

你在使用 Claude Co-work / Claude Code 时，直接给 AI 开放这个文件夹（我的叫「My AI Brain」），AI 就相当于在**用你全部的私人数据做训练**。

它等于：**文件管理 + 笔记 + 思维导图 三合一**。

完美解决「反复给 AI 喂记忆」的问题。

我之前 Claude Code 教程里讲过**自进化记忆体系**，依然很强；

但叠加上 Obsidian，自动化再上一个台阶，能收录更多信息，AI 可检索的数据更多。

## 重要设置：Orphans（孤立文件）

Setting 里有个选项：`Orphans`。

指**没有和任何内容建立链接的孤立节点**。

比如我录入一条视频纯文稿，但没关联其他内容，就是 Orphan。

为了保持第二大脑整洁，我会**关闭 Orphans 显示**。

没有链接，说明你需要建立链接：

- 手动添加
- 或直接让 Claude Code 自动建立（它可编辑本地文件）

## 缺点：什么人不适合用？

1. 你更喜欢普通文件夹
2. 不想维护数据库（需要一点点额外工作）
3. 不是视觉化思考者，不需要看关联图

只用文件夹依然可以给 LLM 喂上下文，**Obsidian 不是必需品**。

替代方案：Notion、Google Sheets，搭配 API 接入 Claude Code 也可以。

Obsidian 只是**更新颖、更复利、更像人脑**的方案。
