# 如何从新手 → 高手：从「提示词玩家」变成「Agent 工作流使用者」

最大化 Claude 的核心，是**离开默认的 Chat 界面**（手机、电脑打开就是这个），转向两个核心功能：

1. **Co-work**（第二层）
2. **Claude Code**（第三层）

## 三个等级

- **Level 1：Chat**（普通对话）
- **Level 2：Co-work**（AI 助理）
- **Level 3：Claude Code**（AI 工程师）

### 先搞清楚：什么是 Co-work？

Chat 你肯定懂：就是对话、建项目、来回聊天。

Chat 很强，我上条视频也讲过用 Chat 生成 artifact 干活，但它有致命局限：

**不能自动执行、不能定时任务、不能像 Claude Code 一样搭建非 HTML 的真实系统。**

### Co-work vs Claude Code 核心区别

- **Co-work = 你的助理**
    
    可以读取、管理、编辑你**电脑本地文件夹**里的文件：
    
    - 读表格、改表格
    - 分析数据、统计
    - 读取文件夹内所有文件、总结、提炼规律
    

举个例子：

你想总结 20 条 YouTube 视频，找爆款规律 → 用 Notebook LLM / Glasp 下载所有字幕 → 放进一个文件夹 → Co-work 读取全部 20 个文件 → 用这批数据产出结果。

**最强点：Co-work 可以定时任务（Scheduled tasks）**

点 Scheduled → New Task，就能让它**夜间、定时、重复执行**。

比如：

> 总结我今日日历、未读邮件，标出紧急事项

可以设：每小时 / 每天 / 每周。

这就跳出了「每次都要发 Prompt」的模式，变成**真正的智能体自动干活**。

你还可以做：

- 每日自动市场报告
- 每日特定地区房产报告
- 每日手表收藏价值更新
- 任何定时自动化任务

Co-work 里还有 Ideas 板块，给你大量现成任务灵感。

一句话：**Co-work 是能帮你执行任务的助理。**

# 真正核心：文件夹搭建（高手与玩家的分水岭）

只有一个关键词：**Context（上下文）**

过去：你要在 Prompt 里塞大量上下文。

现在：**把所有上下文整理进文件夹，AI 自动读取，不用反复提示。**

你完全掌控记忆，记忆还会**自我更新、长期复利**。

就算以后换 LLM，你可以带着整个文件夹走，**所有积累不会丢失**。

**AI 时代的新玩法：从「提示词工程」转向「文件结构工程」。**

## 新建文件夹只需要 3 个核心文件

1. **instructions.md**（指令）
2. **memory.md**（记忆 = AI 的大脑）
3. **context-[你的领域].md**（战略 / 上下文）

### ① instructions.md（告诉 AI 怎么回应、怎么做事）

示例（我的 AI 内容助理）：

- 身份：AI Edge 频道内容助理
- 任务：整理选题、总结视频、格式化脚本
- 规则：语气直接、口语化、无废话、无 AI 腔
- **最重要一行（必加）：**
    
    > 当你学到我的偏好或工作流新信息，自动写入 memory.md
    

### ② memory.md（AI 的活大脑）

所有你纠正过的、偏好、习惯，都会**自动写进这个文件**。

比如：

- 我不喜欢用长破折号
- 我喜欢短句
- 我的输出格式

普通 Chat 是黑盒：你不知道它记了什么、忘了什么。

**memory.md 你可以随时打开、查看、手动修改。**

### ③ context-strategy.md（全局战略）

我的频道示例：

- 品牌定位：杠杆效率类频道
- 内容结构：75% 杠杆工具 + 25% 纪实
- 视频时长：15 分钟左右
- 更新频率：每周 3–4 条

当我的战略改变，**只改这个文件**，不用反复告诉 AI。

放到生意里同样适用：

- 产品流失率从 X 涨到 Y
- 未来 6 个月转型订阅制
- 新的目标客户

全部写进 context，AI 所有回答都会基于最新战略。
