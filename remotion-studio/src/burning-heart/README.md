# 不烧心时代 - 知识视频项目

## 项目概述

基于深度研究报告《隔壁的"烧心"店：为什么商家身边总在"刷新"卷价格的人？》创建的知识类视频。

**时长**: 2分30秒 (150秒)  
**BGM**: 不烧心时代.mp3 (29.65秒，循环5次)  
**分辨率**: 1920x1080 @ 30fps  
**总帧数**: 4500帧

## 场景结构

### 场景1: 开场钩子 (0-12s)
- **核心内容**: 模拟短剧画面，"隔壁刷新"现象定格
- **视觉**: 老店挂上"规矩不能坏"，隔壁突然亮起"降价"标语
- **钩子**: "隔壁是被谁召唤来的？"

### 场景2: 召唤机制 (12-37s, 25秒)
- **经济学概念**: 自由进入 (Free Entry)
- **核心逻辑**: 老店利润 = 市场入场信号
- **视觉**: 俯视街道，客流汇入→利润升高→新店出现
- **关键数据**: 利润数字动画、入场信号波纹

### 场景3: 贴脸开店 (37-62s, 25秒)
- **经济学概念**: 霍特林空间竞争 (Hotelling Model)
- **核心逻辑**: 共享客流收益 > 价格竞争损失
- **视觉**: 分屏对比实验 - 分散 vs 贴脸
- **修正标注**: d'Aspremont (1979) 对原模型的修正

### 场景4: 价格绞杀 (62-87s, 25秒)
- **经济学概念**: 伯特兰价格竞争 (Bertrand Competition)
- **核心逻辑**: 商品越像，价格越有杀伤力
- **视觉**: 价格对决，利润条被压缩，客流实时转移
- **动态数据**: 价格降低、客流变化、利润率压缩

### 场景5: 柠檬市场 (87-117s, 30秒)
- **经济学概念**: Akerlof柠檬市场 (1970)
- **核心逻辑**: 品质不可见时，市场奖励便宜
- **视觉**: 两碗面对比，购买前一样，购买后才知"烧不烧心"
- **破局提示**: 复购、口碑、明厨亮灶、食材溯源

### 场景6: 真相反转 (117-137s, 20秒)
- **核心信息**: 打破短剧二元对立
- **视觉**: 点击隔壁店，弹出三种可能性
  1. 偷工减料 (劣质食材)
  2. 效率更高 (规模采购)
  3. 亏损引流 (前期补贴)
- **金句**: "短剧说'守规矩者必胜'，经济学说'被看见的品质才必胜'"

### 场景7: 收尾 (137-150s, 13秒)
- **视觉**: 五个经济学概念卡片展开，形成知识地图
- **因果链**: 利润信号 → 贴脸进入 → 降价抢客 → 便宜胜出 → 谁停谁死
- **信息源**: Hotelling (1929), Bertrand (1883), Akerlof (1970), Van Valen (1973)
- **结束语**: 项目标题 + 副标题

## 设计系统

### 配色方案（深色系 + 高对比度）
- **背景**: #05070C (最深) → #1E2636 (五层表面)
- **文本**: #F1F0E8 (主) / #8A9099 (弱化)
- **强调色**:
  - 红 #E94235 (价格战/警告)
  - 青 #38BDF8 (数据/理性)
  - 绿 #6EE7B7 (品质/良心)
  - 黄 #FBBF24 (注意)
- **商家标识**:
  - 老店: #6EE7B7 (绿色 - 良心)
  - 隔壁: #E94235 (红色 - 价格战)

### 字体系统
- **正文**: Inter Variable, Noto Sans SC
- **等宽**: JetBrains Mono (经济学概念标注)
- **显示**: Plus Jakarta Sans (标题)

### 动画原则
- 使用 `interpolate` + `Easing` 实现流畅过渡
- 关键元素使用 `Easing.out(Easing.back())` 产生回弹效果
- 数字动画逐帧递增，营造真实感
- 粒子系统模拟客流汇聚

## 数据配置

所有参数通过 `data/burning-heart.json` 配置：

```json
{
  "originalStore": {"name": "老店", "price": 15, "cost": 9},
  "competitorStore": {"name": "隔壁", "price": 13, "cost": 8},
  "market": {
    "entryBarrier": "low",
    "customerSensitivity": 0.7,
    "qualityVisible": false
  }
}
```

## 制作流程

### 1. 预览
```bash
npm run dev
# 在浏览器打开 http://localhost:3000
# 选择 BurningHeartExplainer 组件
```

### 2. 渲染
```bash
# 快速预览（低质量）
npm run render -- BurningHeartExplainer --codec=h264

# 最终输出（高质量）
npm run render -- BurningHeartExplainer --codec=h264-mkv --quality=95
```

### 3. 调整参数
编辑 `data/burning-heart.json` 可实时调整：
- 店铺价格
- 市场参数
- 配色方案

## 技术特点

1. **完全数据驱动**: 所有视觉元素从 JSON 配置生成
2. **BGM循环**: Audio 组件 `loop` 属性自动循环播放
3. **响应式设计**: 使用 `clamp()` 实现流式字号
4. **Token系统**: 统一的设计令牌，保证视觉一致性
5. **TypeScript类型安全**: Zod schema验证所有输入

## 理论依据

基于五个经济学机制的嵌套分析：

1. **自由进入** (Free Entry) - 利润信号
2. **霍特林模型** (Hotelling 1929) - 空间竞争
3. **伯特兰竞争** (Bertrand 1883) - 价格战
4. **柠檬市场** (Akerlof 1970) - 信息不对称
5. **红皇后假说** (Van Valen 1973) - 相对竞争
