# Connected Workspace

视觉来源：平级 agent-ui-film 的六秒 HyperFrames 成片。新片为八秒，保留黑底、纸面资料、荧光绿 marker 与真实 Logo，增加流动光脉冲和状态响应。

背景 #090c0b；强调 #b5ff38；纸面/正文 #f1f0e8；深色表面 #1c2220；辅助文字 #aab4ad。字体为本地 Noto Sans SC 与 JetBrains Mono。

静态层级：标题 → 资料与产品 → 连接状态 → 结果。纸面与深面板形成材质对比，背景保持安静。光效仅用于扫描和传递，不持续旋转轨道或铺满粒子。

时间：0–1.4 秒建立，1.4–2.4 秒标题，2.4–3.6 秒扫描，3.6–5.2 秒连接，5.2–6.1 秒响应，6.1–8 秒阅读结果。

横屏 1920×1080，竖屏 1080×1920；默认 30fps，60fps 保持秒级时间。竖屏重排，预览缩放不改变逻辑画布。

资料内容是示意，不冒充真实产品截图或已执行的业务结果。产品 Logo 使用用户已有资产；中性 demo 使用原创图标。

验收：关键文字完整，光束端点贴合，信息主要区域不重叠，最后结果稳定可读；透明图层真正无背景。技术验证记录与审美结论分开。
