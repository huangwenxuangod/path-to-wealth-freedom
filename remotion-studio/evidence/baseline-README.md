# AI Motion Studio

面向 Codex 的 React 动画制作项目。当前阶段：调研与设计完成，运行工程和插件扩展待按方案实施。

推荐技术栈：Bun + TypeScript + React + Remotion + Tailwind CSS v4 + 官方 GSAP 集成。Magic UI 提供按需移植的视觉组件；Aceternity、React Bits、Motion Primitives 按具体镜头选择。

- [完整调研与实施方案](docs/RESEARCH_AND_PLAN.md)
- [来源、版本快照与证据等级](docs/SOURCES.md)

项目定位：一个工程生产多条参数化视频，积累镜头与动画语言；通过官方 Remotion Codex 插件和轻量项目规则完成创作。

首版交付目标：AgentWorkflow 基准片、BeamOverlay 透明素材、两组文案数据、横竖屏构图、确定性渲染验收。
