# V4：大字作为焦点，同一组对象完成接力

## 1080p 字号标准

|角色|字号|用途|
|---|---:|---|
|焦点关键词|140px|私人导师、教学助手、正向变革进入时|
|持续主标题|112px|重点讲解期间，不缩成小标签|
|关系图标题|90px|教育标题收拢后仍清晰可读|
|上下文短句|44px|每个学生、每位教师、同一份 AI|
|节点标签|36px|学生、教师；只解释节点身份|

以上为 1920×1080 合成画布字号，预览会随播放器等比缩放。编号不承担主信息，保持原大小；字幕与演讲不改。

## 连续性

风险大字缩成风险节点；两条防护对象收拢进入节点，风险转成盾牌，再转成 AI。学生与教师由同一 AI 分叉产生。讲学生时教师停靠变暗，讲教师时学生停靠变暗，最后两者回到同一分叉关系图。没有为每段重新生成一套图形。

标题先大后收，但收回后的标题仍保留 90px；教育大字期间 AI 节点让到下方，避免标题压住图标。结尾用“同一份 AI / 两种支持”两级排版，避免一行长句挤小。

纯函数 `flow-state.ts` 按秒生成位置、透明度与比例；连线端点直接取同一状态，保证拖动时间轴时关系一致。交接约 0.3–0.55 秒；未改变原视频速度和口播剪辑。

参考方向：[Material motion](https://m2.material.io/design/motion/understanding-motion/) 的对象关系与转场连续性。该链接是动效原则参考，不是观看外部成片的证据。

## 可调

在 Studio 继续调整四个标题、颜色、图层缩放与场景开始时间。字号标准在主组件顶部 TYPE 中；位置和阶段接力在 flow-state.ts 中。已有根组件默认值与用户调参保留。

学生与教师的介绍阶段也先以 112px 展示身份，导师／助手标题到来时，身份字才收为 44px 上下文，避免等待关键词期间只有小字。
