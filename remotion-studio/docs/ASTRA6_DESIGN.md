# Astra6 设计

36 秒，1920×1080，30fps。总述 6 秒；软件操作、工程执行、专业交付各 8 秒；总结 6 秒。最后 3 秒稳定。

冷白 #F5F7FA、白面 #FFFFFF、石墨 #17243A、说明 #526176、操作蓝 #2457E6、结果绿 #087F70。颜色只属于本片，不是品牌标准或全工程默认。

Noto Sans SC 承担中文，JetBrains Mono 只用于终端。总述居中，分述左论点/右工作对象，总结回收三种能力。Magic UI 的窗口、终端、数字和光束在实际镜头出现。所有运动来自 frame/fps。

素材受限时采用计划中约定的原创流程示意，并在片中注明。数字来自官方发布评估，同屏标注设置；没有独立模型能力实测。
