# Talking Head Design Lab
题材：Sal Khan TED2023，AI教育演讲原声片段；素材25.438–57.438秒，32秒。
视觉方向：深海蓝、暖纸白、柔和青色；编辑式信息图，真人与纸面UI相互让位。避免荧光描边、粒子、重复品牌底纹。
真实底板：TED原声与原片。文字翻译依据英文官方时间字幕，不沿用开头顺序错位的官方中文字幕。
原创图解：边界列表、技术→个性化支持→学习、私人导师聊天概念UI、教师支持任务。图解不冒充产品实录。
母版：人物右侧/左信息、全屏图解/原声小窗、人物右侧/左聊天UI、全屏双栏/原声小窗。
人物定制：全片同一个媒体元素，改变位置、尺度、遮罩圆角；无换脸，不声称完成抠像。原片人物自然换机位保留。
可调：data/talking-head.json及Studio props：颜色、文案、视频位置/缩放、图层位置/缩放、场景入口、全屏开关、字幕字号、音量、原片对照。
Magic UI: 使用既有video/animated-beam.tsx的确定性适配版本；MIT来源和许可沿用THIRD_PARTY.md。
Reusable brief: 将真人作为底板，先建立静态构图，再用对象状态变化解释关系。重点只有一个；卡片、字幕和脸部互不抢占。真实录屏与原创示意分开标注。
