# 全部了解 · Agent UI motion study

## Style Prompt
参考用户提供的黑底荧光绿信息图。1920×1080、6 秒、30fps。左侧真实语义的工作资料，右侧截图中产品 Logo，标题承担视觉中心。用纸张色文档与深色工作台形成材质对比，少量绿色只强调标题、连接与完成状态。输出透明 WebM 和黑底 MP4；静音，供剪映合成。

## Colors
- #090c0b：MP4 预览背景
- #b5ff38：唯一强调色
- #f1f0e8：文档纸张与正文
- #1c2220：深色面板
- #aab4ad：辅助文字

## Typography
中文使用本机 PingFang SC，项目打包可用中文字体。英文与数字使用本地 JetBrains Mono。标题 112px，主要资料标签 38–42px，辅助信息 24px。

## Composition
顶栏短标题和编号，中间左侧四种资料上下错落，右侧 Logo + 产品名称；标题在上方，四条绿色路径从资料区域外侧汇聚到产品。底部用短句承担结论。布局边界 x=140..1780, y=130..950。

## Motion
0.15–0.75s 建立画面；0.7–1.5s 强调资料；1.4–2.15s 标题和 marker；2.2–3.3s 路径汇聚；3.3–5.45s 阅读结果；5.5–6.0s 整体淡出。单一暂停 GSAP 时间轴，路径通过 dashoffset 控制，所有循环有限。

## What NOT to Do
不采用持续粒子、旋转轨道、发光背景、默认蓝紫渐变。资料示意不冒充真实软件截图。文档小字仅作质感，四类资料名称必须可读。保留原 Logo，不重绘品牌标识。
