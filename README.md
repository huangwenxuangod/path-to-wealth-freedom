## 💡 核心理念

### 1. 做 IP 的五道门槛
- **表达** —— 把认知翻译成内容的能力
- **持续** —— 拼的不是爆发力，是续航力
- **人格化** —— 让人记住你这个人，而不只是内容
- **暴露感** —— 敢拍、敢发、敢暴露真实现状
- **内耗感** —— 允许自己不完美，在质疑声里继续往前走

### 2. 一人公司自媒体创作系统（车干手册）
**叙事身份**：不是"成功的人在回望"，也不是"完全不知道该怎么办的新手"，而是**正在路上、有时在坑里、有时刚爬出来**的人。

**叙事公式**：我以为 → 结果发现 → 现在我觉得

**四个情绪缺口**（按优先级）：
1. ★★★★★ 焦虑：看别人成功，自己还在原地
2. ★★★★☆ 被说中：那个没人说透的委屈
3. ★★★☆☆ 逆袭爽感：反转带来的喘息
4. ★★☆☆☆ 执行困境：有想法卡住的羞耻

**三平台定位**：
- **X（推特）**：主攻阵地，流量引擎 —— 一句话到三段话，要密度不要长度
- **公众号**：深度沉淀，信任建立 —— 把碎片思考沉淀成有结构的真实复盘
- **小红书**：破圈入口，新增粉 —— 给还没开始、正在犹豫的人一个"原来可以这样"的视角

### 3. 100 天执行计划
- 目标从"做 IP"改成"**执行 100 天**"
- 每天 1 条，发完就算完成
- 用流程替代意志力

### 4. 内容创作 SOP
1. **观点前置** —— 主观表达，引起争议
2. **解释观点** —— 讲故事，自我暴露拉近距离
3. **价值输出** —— 学到了什么？怎么泛化到普通人？

### 5. 赚钱本质
**能让人主动掏钱给你的，只有资源差和信息差。**
- 资源差：时间、人脉、技术
- 信息差：认知差、行业秘密、非共识红利

### 6. 专注力管理（每日 SOP）
- **环境锚定**：固定工作位置 + Discord study together 摄像头 + 手机关机
- **目标设定**：每天 1 件最重要的事，10 字以内
- **1 小时循环机制**：更新目标（1分钟）→ 专注执行（50分钟）→ 短暂休息（7分钟）→ 隐性知识沉淀（2分钟）
- **兴趣延伸规则**：遇到感兴趣的内容先记录，下一个 1 小时块再研究
- **每日沉淀**：3 句话复盘 —— 最有效的专注动作、破坏专注的关键节点、明天需微调的 1 个细节

### 7. 灵感快速验证迭代方法论
- 所有产品（网站 / 插件 / APP / 实体）统一先用**H5 + 浏览器**做极简演示，仅展示几秒核心效果，**不完整开发**。
- 先做成交验证，不先做完整产品；国内优先用**闲鱼**直接交易，避开复杂流程。
- 实体类也可在闲鱼 PS 高价效果图，直接标价售卖（如 500 元），用效果图验证真实需求。
- 有人下单就快速铺货，没人买则直接验证该产品**无实际商业价值**，用最低成本完成市场测试。

### 8. X（推特）海外流量洼地（2026-04-07 新增）
- **X 现在是海外免费流量洼地**，先做蓝 V、高频发文涨粉
- 用流量链接线下生意和投资，再靠 AI + 团队放大
- 最终落地 B 端与实体变现，这是当下普通人最稳的出海 + 赚钱路径
- X 运营公式：**蓝 V + 按时出摊 + 长短文 + 蹭流 = 线下链接 + 商业变现**

### 9. 获客的关键：找对需求 + 私信获客（2026-04-07 新增）
**找需求（4个最小动作）**：
1. 刷动作：只看评论区，不看正文
2. 标记动作：复制带「想要」「怎么」「求助」的句子
3. 归类动作：给每句话加标签（想赚钱/想学习/想变美/想搞对象/想省事/想解决具体问题）
4. 统计动作：哪个标签出现最多，就是当前最刚需

**私信获客（5个最小动作）**：
1. 选人动作：看用户是否活跃、是否真实
2. 开口动作：「看你在找 XX，方便问下你主要想解决什么问题吗？」
3. 追问动作：「你现在最卡的是哪一步？」
4. 记录动作：把回答复制到对应需求标签下
5. 结束动作：「了解了，谢谢～」直接退出，不聊不推不转化

### 10. 滑梯效应：把启动阻力降到无限低（2026-04-07 新增）
- **核心理念**：最难的永远是「开始」那一瞬间，一旦真正迈出第一步，后续动作会像滑梯一样顺着惯性自然往下滑
- **极致微习惯化**：把任务缩小到荒谬的地步，只求「开始」不求完成（想健身→只穿上运动鞋；想写东西→只打开电脑）
- **5 分钟法则**：告诉自己「只做 5 分钟，随时可以停」，99% 的情况下做着做着就停不下来了
- **口诀**：阻力越低 → 启动越容易 → 惯性越强 → 完成越自然

### 11. 回归手写内容的反思（2026-04-07 新增）
- AI 写作、自动化运营如同流水，文章发出来后不会有任何记忆和知识内化
- 普通人应该做的不是 FOMO 跟上蒸馏 skills 的趋势，而是赶快积累自己的表达内核
- 如果连手写一篇文章、表达自己的观点都做不到，基于自己的语料库建 skills 又有什么用？
- **执行时最痛苦的肌肉，往往是锻炼效果最好的**
