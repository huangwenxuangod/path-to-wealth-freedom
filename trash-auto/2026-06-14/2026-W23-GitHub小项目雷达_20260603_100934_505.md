#### 项目类型

AI Agent / AI Coding / Coding Agent

#### 为什么值得看

这是本周最值得关注的"范式级"项目。Claude Code、Cursor、Copilot 都很强，但它们有一个共同问题：**封闭**。你想换个模型？只能用它支持的。你想加自定义功能？插件机制有限。你想看它是怎么工作的？闭源。

Pi 做的事很简单：**把 Claude Code 的核心能力拆成 5 个独立的 npm 包，全部开源**。

它的 5 个 npm 包分工明确：
- `@earendil-works/pi`：终端编程 Agent 主 CLI（对标 Claude Code）
- `@earendil-works/pi-agent-core`：Agent 运行时核心（可在自己应用里集成 Agent 能力）
- `@earendil-works/pi-ai`：统一多模型 LLM API（支持 25+ 厂商）
- `@earendil-works/pi-tui`：终端界面库
- `@earendil-works/pi-chat`：Web 聊天组件 + Slack 机器人

信号意义很大：AI 编程助手的"开源替代"时代正式到来。就像 VS Code 替代了 Sublime Text、Linux 替代了 Unix——开放生态最终会赢。

#### 为什么适合黄文轩

### 项目 2：oh-my-pi

#### 项目信息

- **项目名**：oh-my-pi (omp)
- **GitHub 链接**：https://github.com/can1357/oh-my-pi
- **Star 数**：5,700+
- **最近更新时间**：2026-05-30（持续活跃）
- **主要语言**：Rust（核心约 27k 行）
- **License**：MIT（基于 Pi 的 Fork）
- **一句话说明**：给终端 AI 编程 Agent 装上 IDE 级的代码智能——Hashline 编辑系统让 AI 编程成功率从 6.7% 跃升到 68.3%，支持 40+ 语言、LSP 集成、子 Agent 并行。

#### 项目类型

AI Coding / Coding Agent / CLI

#### 为什么值得看

这是本周最硬核的 AI Coding 基础设施项目。大多数 AI 编程工具的"编辑"环节其实很脆弱——模型生成 diff/patch 时，因为空格、缩进、上下文对不上而失败，触发大量无意义重试，烧 Token 又浪费时间。

oh-my-pi 用了一个非常巧妙的技术方案——**Hashline 编辑系统**：给每一行代码生成一个短哈希锚点，模型通过引用锚点来定位编辑位置，而不是复现原文。效果是炸裂的：

| 模型 | 效果 |
|------|------|
| Grok Code Fast 1 | 任务通过率从 6.7% 跃升至 68.3%（提升近 10 倍） |
| Gemini 3 Flash | 比 Google 自己的最佳实现还高出 5 个百分点 |
| Grok 4 Fast | 输出 token 减少 61% |
| MiniMax | 通过率翻倍 |

除了 Hashline，它还内置了**子 Agent 并行框架**（最多 100 个并发任务，git worktree 隔离）、**TTSR 时间旅行规则注入**（平时不占 context，只在模型要踩坑时才触发提醒）、**LSP 完整集成**（40+ 语言开箱即用）、**调试器驱动**（直接操控 lldb/dlv/debugpy）。

#### 为什么适合黄文轩

1. **AI Coding 实操者**：核心技术故事极其精彩，Hashline 的 10 倍提升天然适合写深度技术长文
2. **科技 AI 自媒体**：全网讲 AI 编程工具的人很多，但很少有人能讲清楚"为什么 AI 编辑代码总是失败"
3. **AI 产品实验者**：如果你也在用 Claude Code 或 Cursor，体验 oh-my-pi 就是体验下一代 AI 编程范式
4. **内容稀缺性**：Hashline 编辑系统的中文内容几乎是空白

#### 可执行边界判断

- **个人能跑**：✅ 一行命令安装（Windows PowerShell 支持）
- **企业权限**：❌ 不需要
- **昂贵 API**：⚠️ 需要模型 API Key（支持 40+ 厂商）
- **复杂部署**：❌ `irm https://omp.sh/install.ps1 | iex`
- **适合时间**：1 天可改造
- **最大风险**：Rust 生态对于不熟悉 Rust 的用户可能有编译门槛；Windows 支持仍在完善中

#### 最小运行路线

4. **最优改造**：**AI 编程工具编辑成功率评测系统**——标准化 20 个编程编辑任务，自动评测不同工具的编辑成功率。这是"文轩拆 AI 项目"栏目的完美素材。

- `deep-research`：多轮搜索 + 网页抓取 + 综合引用回答（对标 Perplexity 深度研究）

#### 项目类型
