Browser Agent / AI Agent

#### 为什么值得看

浏览器自动化是 AI Agent 的"最后一公里"。之前的 browser-use（95k stars）证明了需求存在，但它只是一个实验性项目。Stagehand 把浏览器自动化从"社区玩具"升级为"生产级 SDK"——内置自愈机制（网站 UI 变了自动适应）、动作缓存（重复操作不用再烧 Token）、混合模式（代码精确 + AI 灵活）。

信号意义：Browserbase 是一家拿了融资的企业级浏览器基础设施公司，Stagehand 是它开源的战略产品。当浏览器基础设施公司亲自下场做 Agent SDK，说明"浏览器 Agent"已经从概念验证进入工业化阶段。这不是又一个实验项目，是浏览器 Agent 赛道的 AWS 时刻。

MCP / Workflow / AI Agent 框架

- **一句话说明**：为 24/7 主动 Agent 设计的记忆框架——像文件系统一样管理 Agent 记忆，永久保存、跨会话、主动预判。

#### 项目类型

AI Agent / 记忆系统 / 基础设施

#### 为什么值得看

memU 把 Agent 记忆从"向量搜索"升级到了"文件系统"。这不是比喻——它真的把记忆组织成文件夹结构：`preferences/`、`relationships/`、`knowledge/`、`context/`。记忆可以浏览、挂载、交叉引用、导出备份，像一个真正的知识管理系统。

三个关键设计让它区别于所有其他 Agent 记忆方案：

1. **减少 90% Token 消耗**：通过缓存洞察和避免冗余 LLM 调用来降低长运行成本
2. **主动预判**：即使你不发指令，Agent 也能根据你的历史行为提前准备上下文
3. **记忆即文件**：所有记忆以 Markdown 文件存储，你完全拥有、可读可改、可备份

信号意义：Agent 记忆从"附加功能"变成了"基础设施"。当 24/7 在线 Agent 成为趋势（如 OpenClaw、memUBot），持久化、结构化、低成本记忆系统就是刚需。
