### v7 修复 "渐进空白" 问题（2026-06-21 18:36）

**触发**：用户截图反馈第 1 页完整、第 2 页只看到顶部、第 3 页之后完全空白。

**根因（不是 padding）**：

1. `.tpl-v6 .slide` 加 `justify-content:flex-start; align-items:stretch; width:100vw; height:100vh; box-sizing:border-box;`
2. `.tpl-v6 .slide>*:not(.slide-header):not(.cover-foot):not(.qa-body)` 加 `min-height:0;`

### v8 修复 \"渐进空白\" 真正根因（2026-06-21 19:00）

**触发**：用户截图证实 page 1 完整 + page 2-5 全空白（仅进度条）

**Puppeteer 实测真相**（用 chrome + puppeteer-core 跑）：
- Slide 0: position=relative, rect={x:0, y:0, w:1920, h:1080}    可见
- Slide 1: position=relative, rect={x:30, y:1080, w:1920, h:1080} viewport 外
- Slide 2: position=relative, rect={x:30, y:2160, w:1920, h:1080} viewport 外

**真正根因**（不是 padding 也不是 flex:1）：
1. v7 把 .tpl-v6 .slide{position:relative} 覆盖了 base.css 默认的 position:absolute; inset:0
2. base.css 默认 position:absolute; inset:0 让所有 slide 占满 viewport，靠 is-active 切可见性
3. v7 改成 relative 后，所有 slide 堆叠到 viewport 外（y=1080, 2160, ...）
4. 加上 opacity:0 默认 + 只有 is-active 才 opacity:1 → 第 2 页起看到空白

**核心洞察**：base.css 第 60-61 行注释明确说明：
```css
/* single-page standalone (used when a layout file is opened directly) */
body.single .slide{position:relative;width:100vw;height:100vh;opacity:1;transform:none;pointer-events:auto}
```
**只能用 class=\"single\" 才能改 position，且会破坏 runtime.js 的 is-active 切换**。**正确做法是不动 position**，只覆盖 layout 属性。

### v9 修复 page 6 矩阵竖排问题（2026-06-21 19:18）

**触发**：用户截图反馈 page 6 左侧轴标签"高频次 高痛感 / P0 / 完全忘了订阅存在 / P1 / 试了取消没成功"竖排了。

**根因**：原 HTML 是 `<span>单<br>次<br>痛<br>感</span>`，48px 列宽里每个 `<br/>` 强制换行 → 4 个字竖排 4 行。粗暴修复后用 `position:absolute + rotate(-90deg)`，结果 axis 列塌缩到 61px 高（absolute 把 ax-mid 取出 flex 流程）。

**3 次错误尝试 → 1 次正确方案**：
1. ❌ `<span>单<br>次...` —— 4 字竖排
2. ❌ `position:absolute + translate(-50%,-50%) rotate(-90deg)` —— axis 塌缩到 61px
3. ❌ `flex:1 + writing-mode:vertical-rl` —— axis 仍 102px
4. ✅ `display:grid + grid-template-rows:36px 1fr 36px + min-height:528px + writing-mode:vertical-rl` —— axis 528px ✅

**关键洞察**：writing-mode:vertical-rl 让 span 的"高度"变成旋转后的"宽度"——不会自动撑大父容器。**必须显式给 axis 加 min-height + grid-template-rows**。
