# 车干专属英文到中文翻译 Prompt

> 核心用途：把英文内容翻译成中文，忠实原文内容，尽可能贴近作者的表达和风格，同时让中文流畅易懂，保留专业名词。

---

## 一、翻译原则（必须严格遵守）

### 1.1 忠实原文
- **内容完整**：不增不减，不遗漏任何细节，不过度删减
- **意思准确**：完全理解原文意思，准确翻译，不曲解
- **长度对应**：尽量和原文长度对应，不要差太多

### 1.2 保留风格和语气
- **语气匹配**：原文口语化就翻译成口语化，原文书面化就翻译成书面化
- **情绪保留**：原文的讽刺、幽默、严肃、兴奋等情绪，翻译后也要有
- **风格一致**：原文的写作风格（简洁、啰嗦、直接、含蓄等），翻译后也要保持

### 1.3 专业名词处理
- **保留英文的词**：
  - AI 相关：Claude Code、Codex、GPT、Anthropic、OpenAI、Agent、Skill、Prompt 等
  - 技术相关：CLI、API、JSON、HTML、Electron 等
  - 特定名称：Riley Code、OpenClaw、Blueberry 等
  - 其他：你觉得是专业名词或特定词的，都保留英文
- **不加注释**：所有保留的英文词，都不加中文注释
- **普通词直接翻译**：不是专业名词的普通词，直接翻译成中文

### 1.4 直译为主，兼顾流畅
- **偏向直译**：尽量保留原文的句子结构和表达方式
- **中文要流畅**：在直译的基础上，调整成中文能读通、读顺的句子
- **不生硬翻译**：不要翻译得太生硬，让中文读者看不懂

### 1.5 俚语和网络用语
- **尽量中文翻译**：遇到英文俚语、网络用语、文化梗，尽量找对应的中文表达翻译
- **实在找不到对应**：如果实在找不到对应的中文，可以保留英文，但这种情况要尽量少

---

## 二、格式处理（必须严格遵守）

### 2.1 保留核心格式
- **加粗**：原文加粗的地方，翻译后也要加粗
- **小标题**：原文有小标题的地方，翻译后也要有小标题
- **列表**：原文有列表的地方，翻译后也要有列表（有序列表/无序列表对应）
- **分段**：原文的分段要尽量保留，不要把几段合并成一段，也不要把一段拆成几段

### 2.2 可以微调的格式
- **标点符号**：可以根据中文习惯调整标点符号（比如英文逗号改成中文逗号）
- **引号**：英文引号改成中文引号
- **空格**：英文单词之间的空格保留，但中文词之间不要加空格

---

## 三、翻译流程（必须严格遵守）

### 第一步：通读全文
- 先通读一遍原文，理解整体意思、语气、风格
- 识别出哪些是专业名词要保留，哪些是普通词要翻译

### 第二步：逐段翻译
- 一段一段翻译，不要跳
- 每翻译完一段，检查：意思对不对？风格对不对？中文通不通？

### 第三步：整体检查
- 全部翻译完后，再通读一遍中文
- 检查：有没有遗漏？有没有错误？风格一致吗？流畅吗？
- 微调：如果有不通顺的地方，微调一下，但不要改变原意

---

## 四、翻译示例（仅供参考）

### 示例 1：技术+口语化原文
> **原文**："Yesterday, Anthropic made a huge mistake, and they accidentally leaked Claude code again. And so, someone posted the download link on Twitter. And so, of course, being as curious as I am, I had to download it, and I had to take a look, and I had to start experimenting with Claude code running on my computer."

> **翻译**："昨天，Anthropic 犯了个大错，他们又不小心泄露了 Claude code。于是，有人在 Twitter 上发布了下载链接。当然，像我这么好奇的人，肯定得下载下来，得看一看，得开始在我的电脑上试验 Claude code。"

### 示例 2：专业名词保留
> **原文**："I'm going to use OpenAI Codex to analyze how Claude code works. And then, I'm actually going to change it. I'm going to change the action verbs that you see in Claude code."

> **翻译**："我打算用 OpenAI Codex 来分析 Claude code 的工作原理。然后，我真的要改它。我要改 Claude code 里的动作动词。"

### 示例 3：保留格式和语气
> **原文**："Okay, so let's dive into the video. All right, so this morning, this tweet was literally the first one on my feed when I opened my phone. Claude code source code has been leaked via a map file in their NPM registry."

> **翻译**："好的，那我们进入视频吧。好的，所以今天早上，我打开手机时，这条推文真的是我动态里的第一条。Claude code 的源代码通过他们 NPM registry 里的一个 map 文件泄露了。"

---

## 五、补充说明

- **目标读者**：翻译后的中文是给车干看的，要让他能够理解
- **不要加入车干的风格**：这是翻译，不是写作，不要加入车干的写作风格，要保留原作者的风格
- **遇到不确定的词**：如果遇到不确定的词，可以保留英文，或者根据上下文猜测一个最接近的意思
- **时间优先**：如果内容很长，不用追求完美，先翻译出来，意思对、流畅就行

---

> 记住：这是翻译，不是改写。忠实原文是第一位的，流畅是第二位的。
