> 这套提示词对准你工作流的三个卡点： 大纲没有情绪骨架 → 提示词A AI生成后语气太正式、AI味太重 → 提示词B 钩子不够狠需要返工 → 提示词C
> 
> 使用顺序：A → B → C → 发出去

---

## 底层逻辑：在用提示词之前先读这段

你的内容为什么现在没有流量？

不是因为选题不对，是因为你把**情绪写成了观点**。 观点可以被反驳，情绪只能被共鸣。 观点让人说"有道理"，情绪让人说"操这说的就是我"。

你的读者是谁？是那个打开手机刷X，看到同学进大厂、看到同龄人产品上线，然后默默关掉手机的人。他心里那句话从来没说出口：**"我是不是已经落后了？"**

你的任务不是教他，是帮他把这句话说出来。

说出来了，他转发。 没说出来，他划走。

**一句话总纲：找到缺口，戳准情绪，让他觉得你说的就是他。**

## 提示词 A：大纲生成提示词

**使用时机：** 有话题/选题之后，还没开始写，先跑这个提示词生成有情绪骨架的大纲。

**你要做的：** 把下面的提示词发给AI，把`[话题]`和`[我的个人经历/感受]`两个地方替换成你自己的内容。

---

```
你是我的内容大纲助手。我是一个05后金融科技大三学生，正在做AI变现和独立开发实践，在X/公众号/小红书上做内容。

我的读者画像：
- 和我同龄或稍大，在AI赛道想做点什么但总是卡住
- 最深的恐惧是：看别人成功，自己还在原地
- 最真实的状态：有想法，开了草稿，关掉了

我的内容风格：
- 不写教程，写"被说中了"的东西
- 口语化，短句，费曼原则（小孩能听懂才算真懂）
- 叙事视角：我就是那个读者，我也在坑里，我也在挣扎

我现在的话题是：[话题]
我的个人经历/感受是：[用一两句话说你对这个话题最真实的感受，越口语越好]

请帮我生成一个内容大纲，要求：

1. 大纲必须有情绪骨架，不是"第一点/第二点/第三点"的干货结构，而是情绪推进的叙事结构：
   - 情绪入场：一个让读者瞬间代入的场景或感受
   - 矛盾/卡点：那个没人敢说出来的真实处境
   - 转折/发现：我是怎么动的，或者我发现了什么
   - 落地/出口：一个读者今天就能用的结论，或一个开放性问题

2. 每个模块给我2-3个可以填的"情绪关键词"，不是内容，是情绪方向

3. 最后给我3个候选钩子（第一句话），要求：
   - 不超过25字
   - 直接戳那个"怕落后"或"卡住了"的情绪
   - 读完让人想继续看，而不是想点赞

4. 输出格式：大纲 + 情绪关键词 + 3个候选钩子
   不要给我正文，只给骨架
```

---

**用完提示词A之后你要做的事：**

从3个候选钩子里选一个，或者基于它改一个更狠的版本。 选完钩子，确认大纲的情绪走向对了，才进入提示词B。

## 提示词 B：初稿生成提示词

**使用时机：** 大纲和钩子确认之后，用这个提示词让AI生成初稿。

**核心目标：** 生成的初稿要能让你直接改，而不是重写。AI味要在生成时就压掉，不要等你改。

---

### B1：X推文版（金句/短帖）

```
你是我的X推文写手。你的任务是模仿我的写作风格，不是创作"AI风格内容"。

我的写作风格特征：
- 极短句，一句话不超过20字，能断开就断开
- 口语化，像我在跟朋友说话，不是在写文章
- 不用"首先/其次/最后"，不用"值得注意的是"，不用"综上所述"
- 不用感叹号堆砌热情，情绪藏在内容里不在标点里
- 费曼原则：初中生能看懂，不需要专业背景
- 我说话喜欢用"没办法""再逼我一次""就这样"这类口头禅

我的身份：05后，金融科技大三，在做AI实践，怕落后同龄人，所以逼自己动

我的选题/话题：[话题]
我的大纲：[把提示词A生成的大纲贴进来]
我选定的钩子（第一句话）：[你选定的钩子]

请帮我写一条X推文，要求：
- 总字数150-300字（适合X的长帖）
- 第一句话用我选定的钩子，一字不改
- 结尾必须有一个让人想评论或转发的问题/结论
- 读完之后让人觉得"这说的就是我"，而不是"这人懂很多"
- 全程用我的口吻，不是"内容创作者的口吻"

输出：直接给我正文，不要前言，不要"以下是内容"这类废话
```

---

### B2：公众号长文版

```
你是我的公众号文章写手。你的任务是模仿我的表达风格生成初稿，我来做最终修改。

我的写作风格：
- 开头不铺垫，直接从情绪最浓的那个场景切入
- 短句为主，每隔2-3句空一行，不写大段文字墙
- 口语化，像在跟一个认识的人说话
- 不用行业黑话，不用"赋能""生态""闭环"这类词
- 费曼原则：高中生能看懂，不需要AI专业知识
- 每隔一段要有一句可以单独截图的话（金句）
- 结尾不喊口号，给一个真实的"我接下来要做的事"

我的身份背景：05后，金融科技大三，做AI实践，用执行力对抗落后同龄人的焦虑

我的选题：[话题]
我的大纲：[提示词A生成的大纲]
我选定的钩子（开头第一句）：[你选的钩子]
目标字数：800-1200字

请生成初稿，要求：
- 严格按照大纲的情绪走向，不要自己加干货点
- 每个段落不超过100字，段与段之间空行
- 全文至少3处可以单独截图的金句，加粗标注
- 结尾最后一句话是一个开放性问题，邀请读者回复

输出：直接给初稿正文，不要注释
```

### B3：小红书短文版

```
你是我的小红书文案写手。

小红书的规则只有一条：第一句话不够狠，后面写得再好也没用。

我的风格：
- 口语化，真实，不精致，不"博主腔"
- 短句，每行不超过15字
- 每隔2行空一行，方便手机阅读
- 结尾给一个"你也可以"的出口，不是成功学鸡血

我的身份：05后大学生，在做AI变现，总是在卡住和继续之间反复

我的选题：[话题]
我的大纲：[提示词A的大纲]
我选定的钩子：[你选的钩子]

请生成小红书正文，要求：
- 总字数300-500字
- 第一句就是我的钩子，后面立刻展开，不要任何铺垫
- 中间有一个"我也是这样的"的共鸣点
- 结尾是"你也可以做到这一件事"的出口
- 配套生成标题：格式是"情绪词+关键词+感叹号或问号"，给我3个备选

输出：标题3个 + 正文，不要其他废话
```

## 提示词 C：钩子强化提示词

**使用时机：** AI生成初稿之后，你看第一句话觉得"不够狠"，用这个提示词专门强化钩子。

**为什么要单独一个提示词：** 钩子是你改得最多的地方。与其每次手动想，不如让AI批量生成，你来选最狠的那个。

---

```
我写了一条内容，但开头钩子不够强，我需要你帮我重新生成钩子。

我的内容主题：[一句话说主题]
目标读者的最深恐惧：看别人成功，自己还在原地，怕落后同龄人
我的叙事身份：我也在这个处境里，不是从外面教他们，是和他们站在一起

钩子的三个标准（必须同时满足）：
1. 不超过25字
2. 读完的第一反应是"这说的就是我"，而不是"有道理"
3. 制造一个让人必须往下读才能解决的信息缺口

以下是三种钩子类型，每种给我3个：

类型一：直接说出读者不敢说的话
（把那个憋在心里、没人敢承认的感受直接说出来）
示例格式："[一个具体的、让人羞愧或共鸣的内心独白]"

类型二：反常识断言
（说一个让人觉得"等等，为什么"的结论）
示例格式："[反直觉的结论]，但没人告诉你为什么。"

类型三：具体场景还原
（一个极度具体的场景，让人瞬间代入）
示例格式："[时间/地点]+[一个动作]+[一个感受]"

输出：三种类型 × 每种3个 = 共9个候选钩子
每个钩子后面加一句话说明：它戳的是哪个情绪缺口

我来选最狠的那个。
```

## 提示词 D：去AI味润色提示词

**使用时机：** 初稿生成后，感觉语气太正式、AI味太重，用这个提示词做整体润色。

**这是你改得最多的问题，专门给它一个提示词。**

---

```
我有一篇AI生成的初稿，需要你帮我把它改成我自己的语气。

我的语气特征：
- 短句。能断开就断开，一句话绝不超过20字
- 口语化。像跟朋友说话，不是在写文章
- 费曼原则：初中生能听懂。遇到任何术语，用一个生活化的比喻替换
- 不用这些词：首先/其次/综上/值得注意/不可忽视/赋能/生态/闭环/底层逻辑/顶层设计
- 不堆感叹号，情绪藏在内容里
- 我有一个口头禅语气：没办法、再逼自己一次、就这样、算了继续

改写规则（按优先级）：
1. 把所有超过20字的句子拆成两句
2. 把所有正式词汇换成口语词汇（例："实现效率提升" → "省了两个小时"）
3. 把所有"我们"换成"你"或"我"，不制造虚假的共同体感
4. 把所有列举结构（①②③）改成正常叙述，或保留但改成更口语的方式
5. 第一句话检查：够不够狠？如果不够，直接告诉我，我来改

这是需要润色的初稿：
[把AI生成的初稿贴进来]

输出：润色后的完整版本
同时在最后标注：你改动最大的3处是哪里，以及为什么改
```

## 提示词 E：跨平台改写提示词

**使用时机：** X上写完长文之后，要分发到公众号/小红书，用这个提示词做平台适配改写。

**你现在的问题：** 直接复制粘贴发，三个平台的内容几乎一样，没有做平台适配。这个提示词解决这个问题。

---

```
我有一条在X上发过的内容，需要改写成适配其他平台的版本。

我的X原文：
[把X原文贴进来]

改写规则：

【改写成公众号版本】
- 在X原文基础上扩写，加入更多个人故事和细节
- 总字数800-1200字
- 增加2-3处可以截图的金句（加粗）
- 结尾增加一个邀请读者评论的问题
- 语气比X版本稍微更完整，但依然口语化

【改写成小红书版本】
- 把X原文压缩到300-400字
- 第一句话要比X版本更狠，更直接戳感受
- 把所有长句拆成每行不超过15字的短句
- 结尾给一个"你也可以"的出口
- 同时生成3个标题备选：格式是"情绪词+关键词+感叹号/问号"

注意：
- 三个版本情绪核心完全一样，只是形式不同
- 不要在小红书版本里加公众号没有的新观点
- 公众号版本不是X版本的翻译，是它的扩展

输出：公众号版本 + 小红书版本（含3个标题）
```

## 完整工作流总览

```
有话题了
    ↓
运行提示词A（大纲+情绪骨架+3个候选钩子）
    ↓
你选钩子（或基于候选改一个更狠的）
    ↓
运行提示词B（对应平台：X/公众号/小红书）
    ↓
初稿出来了
    ↓
第一件事：看第一句话够不够狠
    → 不够狠：运行提示词C，换钩子
    → 够狠：继续
    ↓
第二件事：AI味重不重
    → 重：运行提示词D，润色
    → 不重：继续
    ↓

    → 要：运行提示词E
    → 不要：继续
    ↓
发布前自查7项（见手册第七章）
    ↓
发出去，不要改第八遍
```

## 判断内容好坏的三个标准

你说"看完之后还想再看一次的才是好文"。

这是最好的评判标准。但它太模糊，操作性不强。 用这三个更具体的标准代替：

**标准一：有没有一句话让你"停了一下"** 好内容里一定有一句话会让你在读的过程中停顿。那句话是金句。如果全文读下来没有停顿，这条内容的密度不够。

**标准二：读完你知道"他在说谁"吗** 你的读者读完应该知道：这条内容是写给"那种怕落后、卡住了、但还是想动"的人的。如果读完不知道这条在说谁，群体感不够强，传播力就弱。

**标准三：结尾有没有让你想做一件事** 好内容的结尾会让人想评论、想转发、想去试一件事。不是"受到了鼓励"，是"我现在想做这件事"。

## 禁止词清单

这些词出现在你的内容里，直接删：

|禁止词|替换方向|
|---|---|
|不是/而是/相反|直接说内容，不用序号|
|首先/其次/最后|直接说内容，不用序号|
|值得注意的是|删掉，直接说那件事|
|综上所述|删掉，结论直接说|
|赋能/生态/闭环|用具体动作替换|
|底层逻辑|说清楚那个逻辑是什么|
|不可忽视|删掉，重要的事自己会显现|
|我们|换成"你"或"我"|
|非常/十分/极其|删掉，用具体数字或场景替换|
|希望本文对你有帮助|这句话是内容死亡的标志，永远不要出现|
