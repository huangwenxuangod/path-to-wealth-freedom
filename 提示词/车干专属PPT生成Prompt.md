# 车干专属 PPT 生成 Prompt

> 核心用途：根据输入的内容（文章/长文本/主题/想法），自动选择合适的风格，生成有创意、独特排版设计的 PPT，同时提供详细的设计建议。

---

## Step 1 · 检查输入完整性

同时检查两项，缺哪项就提示哪项，两项都缺则一起提示：

### 【输入内容】
- **没有输入** → 提示："请把你要做成 PPT 的内容给我（文章/长文本/大纲/主题想法都行），我需要读懂内容才能生成 PPT。"
- **有内容** → 继续。

### 【个人偏好（可选）】
- **没有提到偏好** → 自动根据内容选择风格，不问用户。
- **有提到偏好** → 优先考虑用户偏好。

输入完整后，进入 Step 2。

---

## Step 2 · 深度内容分析（静默，不输出给用户）

分析内容时，必须精准判断内容类型和核心情绪，这直接决定风格选择。

### 分析维度：

#### ① 内容类型判断
- **知识分享/教学类**：AI 工具、技术教程、方法论
- **商业/创业类**：变现方案、商业模式、竞品分析
- **成长/思考类**：个人成长、反思总结、心理分析
- **深度拆解类**：案例拆解、现象分析、逻辑梳理

#### ② 核心情绪判断
- **理性/专业** → 适合极简风、现代商务风
- **科技/未来感** → 适合科技风、赛博朋克风
- **创意/活力** → 适合孟菲斯风、新粗野主义
- **高级/沉淀** → 适合侘寂风、瑞士国际主义

#### ③ 内容密度判断
- **高密度（干货多）** → 每页少字，重点突出
- **中密度（有干货有故事）** → 每页中等字数
- **低密度（故事/观点为主）** → 可以有较多文字，重点在排版

---

## Step 3 · 风格自动匹配（静默，不输出给用户）

根据内容分析结果，从以下风格库中自动选择最匹配的 1-2 种风格。

### 风格库（大语料库，详细描述）

#### 风格 A：科技未来风（适合科技/AI/创业类内容）
- **背景材质**：深色渐变背景 / 赛博朋克金属板 / 混凝土质感 / 科技网格纹理
- **色彩处理**：赛博霓虹高饱和（蓝紫渐变 / 青色高光）/ 双色调（深蓝底 + 亮青色）/ 科技感单色（深灰底 + 白色）
- **排版结构**：不对称布局 / 对角线构图 / 元素错位排列 / 科技感分割线
- **视觉元素**：等距像素风图标 / Flat UI 图标 / 3D 几何体 / 科技网格 / 电路板纹理
- **字体风格**：无衬线粗体 / 科技感数字字体 / 字重对比强烈
- **每页文字量**：1-3 句话，重点突出
- **风格 DNA**："赛博朋克金属板 × 不对称布局 × 霓虹高饱和"

#### 风格 B：极简高级风（适合知识分享/成长思考类内容）
- **背景材质**：纯色平涂 / 微水泥质感 / 极简直白 / 低饱和灰底
- **色彩处理**：单色调 / 低饱和莫兰迪 / 高对比黑白 / 双色调（米白底 + 深灰字）
- **排版结构**：三分法构图 / 黄金分割 / 孤岛留白 / 瑞士国际主义网格 / 居中对齐
- **视觉元素**：极简线条图标 / 几何图形 / 大量留白 / 细线条分割
- **字体风格**：优雅无衬线 / 字重统一 / 字间距宽松
- **每页文字量**：1-3 句话，重点突出
- **风格 DNA**："极简留白 × 瑞士国际主义 × 低饱和莫兰迪"

#### 风格 C：创意孟菲斯风（适合活力/创新/年轻向内容）
- **背景材质**：纯色平涂 / 孟菲斯几何底纹 / 波点纹理 / 彩色网格
- **色彩处理**：孟菲斯原色系（亮黄 / 亮红 / 亮蓝 / 亮绿）/ 高饱和撞色 / 多色渐变
- **排版结构**：孟菲斯网格 / 放射状发散 / 元素重叠 / 不对称平衡
- **视觉元素**：孟菲斯几何图形 / 波点 / 波浪线 / 粗线条 / 手绘涂鸦风
- **字体风格**：粗体手写感 / 装饰性字体 / 字重对比强烈
- **每页文字量**：1-5 句话，可多可少
- **风格 DNA**："孟菲斯原色系 × 放射状发散 × 几何图形重叠"

#### 风格 D：新粗野主义（适合深度思考/商业拆解类内容）
- **背景材质**：粗纹理纸张 / 混凝土质感 / 胶片颗粒 / 折皱纸底
- **色彩处理**：复古 CMYK 偏色 / 单色调 / 高对比黑白 / 双色调（米黄底 + 黑字）
- **排版结构**：新粗野主义网格 / 倾斜排版 / 元素错位 / 大字号标题
- **视觉元素**：粗糙线条 / 手绘草图风 / 拼贴元素 / 像素风图标
- **字体风格**：粗体无衬线 / 打字机字体 / 手写感字体
- **每页文字量**：3-5 句话，中等密度
- **风格 DNA**："混凝土质感 × 新粗野主义网格 × 打字机字体"

#### 风格 E：侘寂沉淀风（适合成长反思/深度沉淀类内容）
- **背景材质**：侘寂纹理 / 手工纸质感 / 微水泥 / 自然纹理
- **色彩处理**：日系清冷低饱和 / 单色调 / 大地色系 / 低对比度
- **排版结构**：大量孤岛留白 / 不对称平衡 / 自然流动 / 三分法
- **视觉元素**：自然材质纹理 / 极简线条 / 植物元素 / 手绘感图标
- **字体风格**：优雅宋体 / 细体无衬线 / 字间距宽松
- **每页文字量**：1-3 句话，重点突出
- **风格 DNA**："侘寂纹理 × 孤岛留白 × 日系清冷低饱和"

## Step 4 · PPT 结构设计（静默，不输出给用户）

根据内容自动设计有创意的 PPT 结构，每页都有独特的排版设计。

### 核心结构框架（创意设计，不是经典结构）

#### 封面页
- 超大字号标题
- 独特排版（居中/偏左/偏右/对角线）
- 风格 DNA 视觉元素
- 副标题（小字）

#### 目录页（可选）
- 极简目录，不是传统列表
- 用数字或图标代替项目符号
- 独特排版

#### 内容页（每页都有独特设计）
- 核心观点前置（超大字号）
- 独特排版（不对称/倾斜/网格/重叠）
- 视觉元素辅助（图标/图形/纹理）
- 每页只讲 1-3 个点
- 风格 DNA 贯穿始终

#### 金句/总结页
- 超大字号金句
- 大量留白
- 极简设计
- 风格 DNA 视觉元素

#### 结尾页
- 简单一句收尾
- 个人品牌元素（如果有）
- 风格 DNA 视觉元素

---

## 补充说明

- **根据内容灵活调整**：不是每一页都严格按模板，根据内容特点设计独特排版
- **每页都要有创意**：避免每页都一样，每一页都有独特的设计
- **风格统一但不单调**：风格 DNA 贯穿始终，但每一页有变化
- **重点突出**：核心观点、金句一定要突出，用超大字号、特殊排版
- **留白很重要**：不要塞满内容，大量留白更高级

---

> 记住：PPT 的核心不是"好看"，而是"清晰传达" + "独特风格"。
