# 财富自由之路 (Path to Wealth Freedom)

> **"用 AI + 自媒体，倒逼自己成长，毕业前赚 100 万"** —— 一位大学生的真实成长记录。

这是黄文轩用于 AI 内容生产、AI 选题研究、Prompt/Skill 资产沉淀、AI 产品实验和自媒体增长的个人工作区。

没有废话，只有**真实的思考 (Thoughts)**、**可落地的行动 (Actions)** 和**拿到的结果 (Results)**。

## 文件整理规则

| 文件类型 | 存放位置 |
|---------|---------|
| 当前使用的内容 | 内容/ |
| 可复用资产 | 内容/资产/ |
| 数据文件 | data/ |
| 图片和视频 | 素材/ |
| 历史内容 | 归档/YYYY-MM/ |
| 无用文件 | trash-auto/YYYY-MM-DD/ |

- 不直接永久删除文件

---

## 使用注意

- 根目录只保留入口文档和核心配置
- 散落文件会被自动归档
- 代码项目核心文件不会被自动移动
- trash-auto 内文件需要定期人工确认后再清理
