# Astra × 贪吃蛇：实时性缺口

## Style Prompt
43 秒、1920×1080、30fps 的编辑式科技短片。视觉只使用墨黑、暖白、雾灰与极淡鼠尾草绿；把「快速移动的贪吃蛇」与「缓慢的 Agent 感知—计算—指令闭环」做成一组不断错位的时间图。画面像一份冷静的技术调查档案：超大中文结论、窄体英文编号、细线、真实截图、扫描框和时间标尺。用克制的方向推移与柔焦转场表达系统延迟，不使用炫技式粒子。

## Colors
- `#0B0C0C`：主背景 / 墨黑
- `#F0EFE8`：主文字 / 暖白
- `#A9ADA8`：辅助信息 / 雾灰
- `#C9D0C2`：唯一强调色 / 淡鼠尾草
- `#252826`：深灰面板 / 结构层

## Typography
- 中文：`Noto Sans SC`，标题 82–150px，正文 30–46px
- 英文与数字：`IBM Plex Mono`，编号与时间码使用等宽数字

## Composition
七幕横向短片。每幕至少包含背景结构、主要结论、数据或示意第二焦点。左上角贯穿章节编号，右下角贯穿 00:50→01:33 时间码。真实贪吃蛇截图与 ARC-AGI-3 图表均来自文章素材；其他控制循环、速度差与静态/动态对照使用 SVG/CSS 信息图。

## Motion
主转场为横向推移与轻微柔焦交叉；主题切换使用竖向推移。每幕先建立标题，再进入数据/图形，最后保留阅读停顿。贪吃蛇移动采用有限次数的 stepped 位移；Agent 循环以 1.6–2.4 秒完成一轮，刻意与蛇的 0.18 秒节拍错位。所有运动确定性、可 seek、无无限循环。

## What NOT to Do
- 不使用蓝紫渐变、霓虹发光、粒子星空或玻璃拟态。
- 不把截图铺满当作唯一画面，必须保留编辑式信息层级。
- 不伪造实时操作成功；结论明确指向高频控制闭环的短板。
- 不在非最终幕提前淡出内容；转场本身承担离场。
- 不用小号网页正文堆砌全文，字幕按语义切成短句。
