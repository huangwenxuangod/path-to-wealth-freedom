# Hyper Studio Pilot
12 秒 / 1920×1080 / 30fps。主题：从素材到成片。
## 视觉
暖白 #f3f0e8、墨黑 #171d20、砖红 #b83225。中文 PingFang SC，英文同字体。大号编辑式排版、细网格与宽留白。尾镜用深色底与暖白字，红色只在暖白上使用。
## 镜头
0–3.5s：FROM MATERIAL。官方 HyperFrames 标识，巨大中文标题“让素材，成为镜头。”，右边真实旧片画面以小幅倾角展开。
3.5–8s：编辑台向左推入，展示真实旧片画面、镜头编号和三段节奏条。3.8s 建立、5.1s 推进、6.4s 停留，指示线与音效对齐。
8–12s：暖白平面向上离开，深色结尾“下一条，开始。”，落在 HYPER STUDIO 品牌字上。11.5s 整体淡出。
## 限制
不采用粒子、随机数、无意义眩光；清晰字幕和真实内容优先。镜头转换用 GSAP transform。音效为本地合成 click/chime，无旁白和音乐。
