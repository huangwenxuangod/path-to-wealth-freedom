# 云屿村 · Cloud Isle

一座浮在云海上的小岛，十二个村民按作息过完一天。纯代码构建：没有模型、贴图、字体或音频文件，
所有几何体、颜色、纹理都在运行时生成，three.js 以经典脚本内置（`src/vendor/three.classic.js`，
r160.1，MIT）。

## 交付物

- `index.html` — 48 秒合成（HyperFrames），同时也是可独立播放的网页
- `renders/cloud-isle_1080p.mp4` — 1920×1080 / 30fps / 48s 成片（1440 帧，80.6 MB，CRF 16）
- `snapshots/` — 逐时段校验帧

## 校验记录

- `npx hyperframes check`：0 error / 0 warning（lint、runtime、layout、motion 全过）
- `ffprobe`：h264 / 1920×1080 / 30fps / 1440 帧 / 48.000s
- `blackdetect`：无黑帧
- 独立播放：`file://` 直接打开 `index.html` 可正常出画（1 秒无 `hf-seek` 时自动切 rAF）
- 渲染耗时：high 质量 1 分 56 秒（截图捕获 · 硬件 GPU）

## 时间

全片 48 秒是一条连续镜头，没有剪辑点。光照与作息都由 `t` 直接求值：

| t | 段落 | 太阳高度 |
|---|---|---|
| 0–8 | 破晓，云海泛金，鸟群掠过 | 0.05 → 0.3 |
| 8–18 | 苏醒，炊烟、开门、上工 | 0.3 → 0.75 |
| 18–30 | 白天，集市、打水、农活；镜头压低靠近广场 | 0.75 → 0.98 |
| 30–39 | 午后收工，人群向篝火聚集 | 0.98 → 0.3 |
| 39–44 | 日落，逆光剪影，窗光逐户亮起 | 0.3 → −0.2 |
| 44–48 | 夜，篝火与萤火虫，星空 | −0.2 → −0.45 |

## 村民作息

每人一张停靠表（到达/离开时刻），中间的空档就是走路。全部是查询，不是模拟：

```
阿禾（农夫）  家 → 农田 → 集市 → 农田 → 篝火 → 家
石根（农夫）  家 → 农田 → 水井 → 集市 → 篝火 → 家
老周（木匠）  家 → 谷仓 → 钟楼 → 集市 → 篝火 → 家
阿海（渔夫）  家 → 码头 → 集市 → 篝火 → 家
麦娘（面包师）家 → 面包坊 → 集市 → 篝火 → 家
金满（商人）  家 → 市集（整日上午到黄昏）→ 篝火 → 家
阿锦（织工）  家 → 市集 → 篝火 → 家
风伯（磨坊主）家 → 磨坊 → 水井 → 集市 → 篝火 → 家
恒公（老人）  家 → 钟楼 → 水井 → 集市 → 篝火 → 家
小满 / 小豆   孩子：水井、农田、广场追逐
阿岩（农夫）  家 → 农田 → 谷仓 → 集市 → 篝火 → 家
```

姿态由活动类型解析求值（走、锄地、售卖、挑选、打水、钓鱼、搬运、围坐、追逐），
起停处用 0.4 秒混合回站立姿态，避免跳变。

## 天空

- 天穹是 shader：高度渐变 + 日轮 + 日晕 + 星点
- 云海：2600 个手绘云团拼出的云毯（运行时 canvas 生成），加 150 片朝向相机的水汽、24 朵地平线积云
- 大气色标按太阳高度插值（7 个关键点），从深夜到正午

## 命令

```powershell
# 预览（Studio）
npx hyperframes preview --background --port 3010

# 校验
npx hyperframes check

# 成片
$env:HYPERFRAMES_BROWSER_PATH='C:\Program Files\Google\Chrome\Application\chrome.exe'
npx hyperframes render . --output renders/cloud-isle_1080p.mp4 --quality high --fps 30 --crf 16
```

本机注意：官方 headless-shell 会崩（exit 3221225595），渲染必须用 `HYPERFRAMES_BROWSER_PATH`
指向本机 Chrome；WebGL 画面走截图捕获通道（`screenshot capture · hardware gpu`）。
