## 四、卡密 vs 权益（交付模式二分）

店铺把商品拆成「卡密 250 / 权益 134」，不是随便分，是两种商业逻辑：

| 维度 | 卡密（250） | 权益（134，代充/直充） |
|---|---|---|
| 形态 | 一串码 / 账号密码，批量导入 | 视频会员 / 订阅 API 直充 |
| 交付 | 付款即发码，无后续 | API 直充，1–3 分钟到账，自动续费 |
| 库存 | 依赖卡密池，占"货" | 免卡密，不囤货，占"支付通道+人力" |
| 利润 | 毛利高、可铺量 | 服务费溢价（官价 +10~20%） |
| 风险 | 发货不退、掉线不质保 | 需 24h 风控切流，封号按天退 |
| 示例 | 激活码、成品号 | ChatGPT Plus 代充、Claude 代充 |

**分开计数的原因**：两者交付、库存、利润、售后逻辑完全不同，混计会扭曲库存结构与毛利分析。卡密是"标品货架"，权益是"订阅服务"。

## 五、占位零库存 SKU 策略

`Windsurf(0)`、`苹果 Apple ID(0)` 上架零库存，是虚拟资源店近乎必做的"齐全心智"货架策略：
- 建立一站式信任、降低跳出
- 向上游探价、试探需求
- 同类店（JY 小店、芒果商城）普遍用"更多品类敬请期待"占位

⚠️ 平台机制注记：链动小铺库存=0 时系统默认自动下架/转预售（防超卖是核心风控）。所以"长期展示 0 库存"实际靠「预售」状态实现，而非硬挂 0 库存商品。

本店能跑通全类目，底层是链动小铺这套 SaaS 在托：

| 能力 | 说明 | 对集合店的价值 |
|---|---|---|
| 0 元入驻 | 手机号+实名，10 分钟开店，无保证金执照 | 起步成本≈0 |
| 资金直清 | 买家付款直达商家微信/支付宝，不经平台 | 不抽成、不冻资金（vs 传统代收型抽 10~30%） |
| 卡密自动发货 | Webhook 回调 → 7.2 秒发货 → 异常自动退款重发 | 7×24 无人值守 |
| 货源代发 | 对接上游 API / 克隆店铺一键铺货 | **零库存运营**，不囤货不砸手里 |
| USDT 收款 | 支持加密货币 | 海外/加密社群生意的支付通道 |
| 两级分润 | 一级 10~15%、二级 3~5% | 推广者愿意推，自来水裂变 |

**核心结论**：链动小铺 = 「自动发货发卡网 + 社交裂变分销 + 货源代发」SaaS。最大卖点 = 资金直清 + 两级分润 + 零库存代发，对虚拟商品卖家极友好。

⚠️ 平台风险：其"推荐新商家拿 30 天流水 1.5% 分红 + 无限级裂变"叙事游走传销红线（刑法 224 条之一：三级以上 + 拉人头 + 入门费）。合规做法是只设两级、以真实交易为底线。

## 十一、对车干的落地启示

把本店当成"专业属性效应"的参考答案，对照你自己的业务：

1. **先做入口，不是先做货源**
   本店 0 元入驻、货源代发、不囤货。你做游戏账号/AI 资源，也别先砸钱囤货，先跑通"一个入口覆盖某赛道全链路"的页面，用分销代发验证需求。

2. **类目要铺"上下游闭环"，不是堆数量**
   学它的三层结构：本体层（核心账号）+ 配套层（接码/邮箱/卡）+ 占位层（证明齐全）。你做游戏账号，配套层就是"代练/饰品/代充/区服卡密"，让用户买完号能直接玩。

3. **占位 SKU 是心智投资，不是库存负担**
   零库存上架冷门类目，补全"我什么都有"的感知。但前提：基础交付不能崩，否则齐全变负分。

4. **流量端先于一切**
   内容钩子（专业感）→ 活码规避限流 → 私域沉淀 → 两级分润裂变。先让别人看见你，品牌认知是被看见后才建立的，不是产品做完自动生成。

5. **合规红线必须避开**
   本店踩的"境外账号"合规雷区，你做游戏账号也要注意：账号买卖在国内有法律天花板，代练/饰品/代充合规空间更大。别碰号池/盗卡类高危。

6. **卡密 vs 权益分账**
   标品货架（卡密）走量赚毛利，订阅服务（权益）走服务费溢价+复购。两种逻辑分开运营、分开看数据。
