# 主动验证需求 SOP

> 核心命题：**主动不是社交行为，是验证行为。**
> 你主动发内容、主动问大佬、主动 DM、主动求反馈——**都是为了拿到真实世界的付费信号**。
> 失败不是被拒绝，是一直在脑子里验证，没有真实反馈。

---

## 一、底层原理 5 条

### 原理 1：创业闭环 = Offer × Leads × Money Models

Alex Hormozi 三本书合起来就是你做任何项目要跑通的三件事：

```
Offer   → 你到底卖什么？（产品/内容/服务）
Leads  → 谁会看到你？（流量/触达/曝光）
Money  → 怎么持续收钱？（变现/订阅/分账）
```

**你卡在主动 = 卡在 Leads + Validation**——你缺的不是"卖什么"，是"怎么让别人看见你、怎么验证他们愿不愿意付钱"。

### 原理 2：Wrong Target Customers 是最常见的死法

用户觉得"有意思" ≠ 愿意付费。
用户愿意试试 ≠ 愿意买。
用户说"不错" ≠ 这是生意。

**伪信号**：点赞、收藏、转发、说"支持"、说"想用"。
**真信号**：付钱、留下邮箱、预付、转发给同类、忍受麻烦。

### 原理 3：主动 = 验证，不是求认可

| 旧认知（错） | 新认知（对） |
|------------|------------|
| 主动是社交行为 | 主动是验证行为 |
| 主动是求人脉 | 主动是求付费信号 |
| 主动是暴露自己 | 主动是测试市场 |
| 主动是"我厉害了" | 主动是"我需要真实反馈" |

### 原理 4：4 层验证 = 兴趣 → 痛点 → 行为 → 付费

大多数人死在第 3 层和第 4 层。

```
Layer 1 兴趣：你会不会看？
Layer 2 痛点：你现在有没有这问题？
Layer 3 行为：你为它花过钱/时间吗？
Layer 4 付费：你愿意现在付 29.9 元吗？
```

越往下越真实。**不问到第 4 层 = 没验证**。

### 原理 5：被拒绝 ≠ 失败，没验证 = 失败

| 真失败 | 假失败 |
|--------|--------|
| 主动问了 100 次，0 个付费信号 | 不敢主动，脑子里想了 1 个月 |
| 发了 1 个 demo，被骂产品差 | 没发 1 个 demo，怕被骂 |
| DM 30 个创始人，0 回复 | 没 DM 1 个，怕被忽略 |

**真正的浪费不是被拒绝，是永远在脑子里"自嗨验证"。**

## 二、4 层验证法详解

### Layer 1：兴趣验证（最弱）
**问法**：
- "你觉得这个方向有人想看吗？"
- "你会感兴趣吗？"
- "这个有意思吗？"

**能得到的反馈**："好像有人看" / "挺有意思" / "挺有想法"
**真实度**：⭐☆☆☆☆（最弱）
**陷阱**：80% 的"好像有人"等于 0 个人。

### Layer 2：痛点验证
**问法**：
- "你现在有没有这个问题？"
- "你最头疼的是什么？"
- "你为这个事花过多少时间？"

**能得到的反馈**："是啊我也愁" / "我没遇到过" / "我也不确定"
**真实度**：⭐⭐☆☆☆
**陷阱**：说有 ≠ 有，但比 Layer 1 强。

### Layer 3：行为验证
**问法**：
- "你为这个问题花过钱/时间吗？"
- "你买过什么相关产品？"
- "你为它做过什么？"

**能得到的反馈**："我去年买过一个 199 元的课" / "我天天在 B站搜"
**真实度**：⭐⭐⭐☆☆
**陷阱**：过去买过 ≠ 现在会买你。

### Layer 4：付费验证（最强）
**问法（直接给钱）**：
- "你现在愿意付 9.9 元预订吗？"
- "29.9 元资料包你买吗？"
- "199 元的服务你现在下单吗？"

**能得到的反馈**：
- 强信号：直接付 / 留下邮箱 / 转账
- 弱信号：说"再考虑" / "等做好了再说"
- 假信号：说"等你做出来" / "我支持你"
**真实度**：⭐⭐⭐⭐⭐
**陷阱**：要设计"小金额 + 即时"才能拿到真信号。

## 三、DM 主动触达 4 字段记录法

**每次主动发出去之前，先填这 4 个字段**：

| 字段 | 含义 | 示例 |
|------|------|------|
| **触达对象** | 谁 | Manus 创始人肖弘 |
| **我发了什么** | 内容 | "5 天体验 Manus + 漫剧 demo" |
| **结果** | 反馈类型 | 已读未回 / 简单回复 / 有效反馈 |
| **下一步** | 行动 | 不用管 / 改一句话 / 过几天再发 / 换人 |

**不写"我是不是很丢脸"这种人格判断**——只记数据，不做审判。

## 四、付费验证的 5 种设计（可直接用）

### 设计 1：朋友圈/X/小红书"29.9 元预订"
```
我最近准备做一个「大学生 AI 项目实战」系列。
不是讲概念，而是每天拆一个普通人能做的 AI 小项目：
怎么找选题、怎么做 MVP、怎么发内容、怎么尝试变现。

想问一个真实问题：
如果我把这些内容整理成一个资料包（5 部分）：
1. AI 项目选题库
2. 每个项目的一天 MVP 步骤
3. 内容发布模板
4. 变现路径
5. 实操复盘

你会愿意付 29.9 元买吗？
不愿意也可以直接说，我想听真实反馈。
```

### 设计 2：知识星球 99 元早鸟价
```
3 天内付 99 元入星球的，享终身 6 折续费。
3 天后恢复 199 元。
限制前 100 名。
```

### 设计 3：1 对 1 咨询 199 元
```
提供 1 次 30 分钟的"AI 项目实战方向诊断"。
不画饼，只给 3 个可执行的下一步。
只接 10 个名额，付完即止。
```

### 设计 4：9.9 元预订第一版
```
如果你愿意付 9.9 元预订第一版资料包，
我会发你 1 份"未完成版"，让你帮我看看缺什么。
预订款全部抵正价。
```

### 设计 5：免费 + 押金验证
```
免费看完整资料，但需要预付 30 元押金，
看完后写 1 条反馈（≥ 50 字）即退还。
用押金筛出真有意愿的人。
```

## 五、30 天主动验证 SOP

### 第 1 周：建验证资产
```
□ Day 1-2：写 1 份 30 秒自我介绍（电梯演讲版）
□ Day 3：列 30 家目标公司 + 30 个潜在用户名单
□ Day 4-5：发出 1 条"29.9 元付费意愿测试"朋友圈/X/小红书
□ Day 6：分析反馈，统计"愿意付 / 不愿意 / 不回复"比例
□ Day 7：周复盘，调整表达
```

### 第 2 周：打 10 家 AI 公司
```
□ 每天 5 条评论 + 1-2 条私信
□ 每天 1 个 30 分钟 demo 推进
□ 每天必填 4 字段记录
□ 周日 21 点周复盘
```

### 第 3 周：打 10 个潜在用户
```
□ 找 10 个"看起来会需要 AI 项目实战包"的人
□ 1 对 1 私聊 30 分钟
□ 用 4 层验证法问 4 个问题
□ 收集 5 个 Layer 4 真信号
```

### 第 4 周：交付 + 沉淀
```
□ 给 5 个 Layer 4 真信号用户交付第 1 版（哪怕 1 个 PPT）
□ 写 1 篇"30 天主动验证复盘"长文
□ 公开复盘"我问了 100 个人，5 个愿意付钱"
□ 把 SOP 反哺下一轮
```

### 30 天最低成本动作
> **即使今天不想 DM，至少要做 1 件事：**
> 1 条真实评论 + 1 条 4 字段记录。
> 30 分钟能完成，**1 天都不能断**。

## 六、风控 4 件套（防止半途而废）

### 风控 1：每日最低成本动作
30 分钟（评论 + 记录），不断更。

### 风控 2：每周"小赢"仪式
每周日 21 点，公开 1 条"这周我赢了 X"推文。

### 风控 3：30 天 milestone 卡点
```
第 7 天  至少发出 1 条付费验证测试
第 14 天 至少拿到 1 个 Layer 3 信号
第 21 天 至少拿到 1 个 Layer 4 信号
第 30 天 至少交付 1 次 + 1 篇复盘文
```

### 风控 4：30 天后兜底
```
30 天后没拿到 Layer 4 信号？
→ 检查 3 个问题：表达错 / 客户错 / 产品错
→ 表达错 → 找 1 个 mentor 帮你看表达
→ 客户错 → 换梯度（找更精准的人）
→ 产品错 → 重新做 4 层验证
```

## 七、3 句话结论

1. **主动不是社交，是验证。** 你主动不是为了求认可，是为了拿付费信号。
2. **不问到 Layer 4 = 没验证。** 兴趣、痛点、行为都太弱，只有"愿不愿意付钱"才是真信号。
3. **被拒绝 = 数据，没验证 = 失败。** 你主动 100 次被拒 100 次，你也赢了 100 个真实反馈。
