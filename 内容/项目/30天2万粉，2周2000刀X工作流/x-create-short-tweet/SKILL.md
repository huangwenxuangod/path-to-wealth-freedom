# 文章拆短推

给一篇文章，提取核心观点，每个观点用 3 种人性视角写成可直接发布的短推（100-280字）。

---

## 流程

```
Step 1: 获取文章路径 → 读取全文
Step 2: 提取独立观点（5-8个）
Step 3: 展示观点列表，等用户选
Step 4: 每个选定观点 × 3 个人性视角写变体
Step 5: 保存到 ~/xiaomu-x-creator/tweets/
```

---

## Step 1: 获取文章

如果用户没给路径，问一句：
```
给我文章路径，我帮你拆成短推
```

拿到路径后读取全文。

---

## Step 2: 提取观点

从文章中拆出独立观点。**萃取的是观点，不是信息。**

什么算观点：
- 一个判断（"X比Y重要"）
- 一个方法论（"我做事的原则是……"）
- 一个反常识洞察（"大多数人以为X，其实是Y"）
- 一段可复用的经历（"做了X → 发生了Y → 说明Z"）
- 一个态度/价值观宣言

什么不算：
- 纯事实搬运
- 没有立场的信息罗列

每个观点记录：
```
- 观点内核：一句话
- 原文位置：大致在文章哪个部分
- 推特潜力：独立拿出来能不能站住？开口大不大？有没有反常识？
```

---

## Step 3: 选题确认

展示观点列表（表格），附带推特潜力星级和推荐理由。
给出 Top 3 推荐。

**等用户选定再进入下一步。**

用户说"都要"或"你选" → 按推特潜力排序，取 top 3。

---

## Step 4: 写短推变体

### 4.1 人性视角发散

每个选定观点，从以下触发点中选 3 个最适合的视角：

| 触发点 | 驱动力 | 适合的观点类型 |
|--------|--------|---------------|
| 焦虑 | 怕落后、怕错过 | 趋势判断、能力要求 |
| 优越感 | 想证明自己比别人看得深 | 反常识洞察、方法论 |
| 损失厌恶 | 怕失去已有的 | 正在犯的错、隐性代价 |
| 好奇 | 想知道别人不知道的 | 内幕、拆解、真相 |
| 贪婪 | 想要捷径/杠杆 | 方法论、效率技巧 |
| 嫉妒 | 为什么别人行我不行 | 个人经历、成功路径 |
| 恐惧 | 害怕被淘汰/替代 | 行业变化、技术冲击 |
| 归属感 | 想找到同类 | 价值观宣言、身份认同 |

同一选题的 3 个变体必须面向不同读者心理。

### 4.2 初稿（正向写完）

先按观点自然展开写完整条，不强求第一句就炸。

**结构：**
- 总长度：100-280 字
- 开头：自然进入
- 中间：具体事实/经历/对比支撑
- 结尾：一句锋利的判断收尾
- 数据密度 <= 2

**格式规则：**
- 换行即标点：裸换行 > 句号
- 冒号换行：解释说明不用冒号，直接另起一行
- 「」强调 > ""
- 「」左右不挨标点
- 能砍就砍
- 直奔核心

**语言规则：**
- 接地气的具体类比 > 泛泛而谈
- 金句要锋利直接，不留余地
- 洞察融入叙事语气
- 内容要硬，表达要人
- 底层欲望要显式命名
- "我"的声音：加入第一人称判断

**禁止：**
- AI味总结句（"这不是X问题，是Y问题"）
- "不是X而是Y"对举模板腔
- "你有没有想过"共情型问句开头
- 空洞的鸡汤收尾
- 括号补充说明
- 句号结尾
- 冒号做解释说明
- 描述型开头
- 结尾互动 CTA
- 政治/军事/地缘/民族宗教/中美体制对比

### 4.3 开头重铸

初稿写完后，对每条逐条执行：

1. 从正文（尤其中段和结尾）圈出 2-3 个候选钩子：最炸裂的事实、最浓的情绪、最锋利的反转
2. 选最强的一个提到第一句，重铸前 2 句，顺一遍后续段落
3. 亲历性校验：引用非亲历信息时标明来源，禁止把二手信息写成第一人称亲历

**开头铁律：**
- 第一句直接甩最炸裂的事实/情绪/反转
- 不要用"我"开头
- 第一句单独成行，后面空一行
- 第二句才是"我"的第一人称切入

**自检清单：**
- [ ] 第一句是炸裂事实/情绪，不是铺垫？
- [ ] 第一句没用"我"开头？
- [ ] 第一句单独成行 + 后面空一行？
- [ ] 第二句是第一人称具体细节？
- [ ] 二手信息有来源标注？
- [ ] 数据密度 <= 2？

任何一项不过 → 重铸，不放行。

---

## Step 5: 保存

输出为 md 文件，路径：`~/xiaomu-x-creator/tweets/{日期}-短推变体-{主题关键词}.md`

**frontmatter：**
```yaml
---
title: 短推变体-{主题关键词}
status: draft
created: YYYY-MM-DD
tags: [推特, 短推, 观点萃取]
summary: 从{文章名}萃取N个选题，共M条短推变体
source: {文章路径}
---
```

文件内容包含：
1. 每个选题的观点内核
2. 3 个视角的短推正文
3. 每条标注激发的人性触发点

---

## 注意事项

- 观点不够（少于 2 个有推特潜力的）时如实告知，不硬凑
- 用户确认选题后才写推文
- 从文章拆出的观点要能独立站住，不能依赖原文上下文
