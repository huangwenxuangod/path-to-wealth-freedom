## 使用建议

### 场景 1：找 SaaS 方向（接单 / 副业 / MVP）
→ 打开 `每日SaaS产品创意雷达/` 最新 1 篇 → 看 "今日最推荐立即做的 1 个项目" + "3 小时低门槛项目" → 选 1 个 → 用 Claude Code / Cursor 跑 1 天 MVP。

### 场景 2：找 Side Project / GitHub 复刻
→ 打开 `GitHub小项目雷达/` 最新 daily 或 weekly → 看 "今日最推荐先跑" → fork 仓库 → 读 README → 跑 Demo → 改造成自己的小项目。

### 场景 3：学方法论 / 增长策略
→ 打开 `方法论拆解/` → 选 1 篇 → 提炼 3 条可迁移原则 → 套到当前在做的小项目上。

### 场景 4：写公众号长文
→ 跨子目录组合素材：SaaS 找选题灵感 + GitHub 找实操素材 + 方法论找框架 → 用 `车干专属写作AI Prompt` 写长文 → 拆 X / 小红书 / 视频。
