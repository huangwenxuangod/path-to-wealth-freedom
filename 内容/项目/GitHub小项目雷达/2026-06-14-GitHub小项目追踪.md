#### 项目类型

AI Agent / Autonomous Agent

#### 为什么值得看

在 LangChain、AutoGen 越来越臃肿的背景下，HuggingFace 反其道而行之——smolagents 核心代码只有 1000 行。它的爆款逻辑是：

1. **"Code Agent" 是新范式**：让 LLM 直接写 Python 代码作为动作，而不是 JSON 工具调用。这在 GAIA 基准上比传统 tool-calling 提升明显
2. **HuggingFace 官方背书**：背后是整个 transformers 生态，模型、工具、Spaces、Hub 一站式打通
3. **Modality-agnostic**：text、vision、video、audio 统一一套 API
4. **MCP 协议原生支持**：通过 `Tool.from_mcp` 一行代码接入 MCP server
5. **安全沙箱**：内置 E2B、Blaxel、Modal、Docker 沙箱，code execution 不烧本地机器

27.8k stars + 1047 commits + 半年内发到 v1.26.0，说明这个项目不是昙花一现，是 HuggingFace 重点投入的 Agent 基础设施。
