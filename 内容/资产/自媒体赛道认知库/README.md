# 自媒体赛道认知库

这里用于存放「自媒体新热点领域雷达」自动化任务生成的长期研究报告。

定位：每天沉淀一个新兴内容赛道，把平台流量、用户心理、商业变现、AI 放大空间和个人可执行动作整理成可复用资产。

## 入库规则

- 雷达报告命名：`认知雷达-YYYYMMDD-领域关键词.md`
- 社媒短稿放入：`传播草稿/`
- 每篇报告都应保留信源、案例、风险边界和个人行动地图
- 后续可同步到飞书知识库「无限学习」

## 使用方式

- 找公众号选题：优先看「为什么现在火」和「平台内容玩法」
- 找副业机会：优先看「金钱流向图」和「变现模式拆解」
- 找 AI 产品方向：优先看「AI 介入现状与可能性」和「个人开发者机会」
- 做复盘：按领域标签、平台、变现方式、AI 介入环节回看
