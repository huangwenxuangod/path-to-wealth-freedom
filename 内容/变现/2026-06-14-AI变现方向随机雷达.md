## 3. 今日筛出的 3 个 AI 变现方向

### 方向 1：Claude Code Skills 定制开发 + Skill Marketplace 出货

- **它是什么**：基于 Anthropic Agent Skills 规范，开发并出售"针对特定工作流"的 Claude Code Skill（如小红书爆款拆解 Skill、公众号选题 Skill、独立项目雷达 Skill），通过 GitHub 仓库 + claudeskills.info 等 marketplace + 公众号评测栏目三渠道分发
- **为什么最近值得看**：Anthropic 官方文档把 Agent Skills 作为一级公民（信号 1）、Claude Code 年化 ARR 据报道达 $2.5B（信号 2，待独立验证）、claudeskills.info/agent37.com/agensi.io 等市场基础设施已现雏形（信号 3-5），是 2026 H2 平台窗口期
- **AI 替代了什么工作**：替代"懂 Claude Code + 懂 prompt 工程 + 懂工具链整合"的工种；用户不需要从 0 拼工作流，直接装一个 Skill 就行
- **谁可能付钱**：① 独立开发者和小团队（省时间）② 内容创作者/小红书博主（提效）③ 中小企业主（套现 Claude 能力）④ AI 工具推广者
- **现有案例/信号**：platform.claude.com Agent Skills 官方文档、claudeskills.info（marketplace 雏形）、agent37.com"30 Skills Worth Hosting and Selling"、agensi.io Plugin Marketplace Guide、buildtolaunch.substack.com 第三方评测
- **我能怎么低配复刻**：3 个 Skill 起步：① 小红书爆款拆解 Skill ② 公众号选题生成 Skill ③ 独立项目每日雷达 Skill（GitHub Trending 摘要 + 评测）
- **3 小时版本**：挑 1 个最熟的场景（小红书爆款拆解），1 小时写 SKILL.md + 1 小时录 3 分钟演示视频 + 1 小时发 GitHub + 小红书 + X
- **1 天验证 MVP**：完成 3 小时版本，再补 1 个"安装使用教程"公众号长文 + 1 张小红书引流图 + 1 个 Reddit r/ClaudeAI 投递
- **内容怎么写**：发"我为什么做这个 Skill → 解决什么痛点 → 怎么用 → 真实案例 → 安装步骤"，叙事性 + 截图驱动
- **怎么变现**：早期免费（GitHub 拉粉）→ 单 Skill 付费 $5-19 → 套包 $49-99 → 企业定制 1v1（$200-1000）→ Gumroad/Lemon Squeezy 上架
- **怎么引流**：公众号长文教程 + X build in public + 小红书"AI 工具推荐" + GitHub README SEO + Reddit r/ClaudeAI + 即刻中文社区
- **可沉淀资产**：Skill 资产本身（可开源可卖）+ GitHub `claw-xuan/claude-skills` 仓库 + 公众号"Ship of the Week"栏目 + 评测数据库 + 教程
- **反直觉认知**：Skill 真正稀缺的不是 .md 文件（复制门槛低），而是"配套数据集 + 配套使用模板 + 持续更新 + 作者信任"；纯卖文件会被复制，含数据/评测/教程的有护城河
- **风险和不确定性**：① 平台规则可能收紧（Skill 审核）② 竞品涌入快（半年内必内卷）③ 收入数据缺乏第三方验证（待验证）④ 复制门槛低 → 需做"作者品牌"护城河
- **状态分类**：**现在我能做**（核心路径 1 天可跑通）
- **适合黄文轩程度**：★★★★★（完美匹配"05 后 + AI Coding 实操 + 自媒体"三角身份）
- **接入哪个任务系统**：内容/文章（公众号长文）+ 提示词/（Skill 模板库）+ GitHub 仓库 + 内容/变现（每日雷达）+ 内容/选题（栏目化）

### 方向 2：AI 简历/求职 Skill（面向 2026 届校招）

- **它是什么**：针对大学生/应届生求职场景，把"中文/英文简历润色 → JD 匹配 → 模拟面试 → Offer 复盘"做成 AI 工作流（Claude Skill + 小红书爆款模板 + 免费引流课）
- **为什么最近值得看**：知乎 2026 届 AI 求职工具大横评出现（信号 10）、CSDN/gitcode 2026 简历制作工具实测、OfferShow 等老牌工具开始加 AI 模块；2026 校招规模大、付费意愿强
- **AI 替代了什么工作**：替代"求职教练 1v1 改简历"（500-2000 元/次）的基础版、替代"职业咨询 30 分钟 200 元"的入门版
- **谁可能付钱**：① 2026 届/2027 届应届毕业生（刚需）② 海归求职（英文简历需求）③ 跨专业转码/转商学生（场景化改写）④ 在职想跳槽者
- **现有案例/信号**：知乎《2026 届应届生 AI 求职工具大横评》、CSDN/gitcode《2026 简历制作工具深度实测》、Kickresume/Rezi/Teal 等海外 SaaS、OfferShow AI 简历模块
- **我能怎么低配复刻**：1 个"AI 简历 + 模拟面试"Skill + 1 套小红书爆款笔记模板（10 篇） + 1 份免费引流课"AI 求职 7 步法" + 1 份付费 Prompt 模板包
- **3 小时版本**：搭 1 个 Claude Skill"输入简历+目标 JD → 输出定制化润色版"（1h）+ 录 3 分钟演示视频（1h）+ 发小红书/知乎/即刻（1h）
- **1 天验证 MVP**：完成 3 小时版本 + 写 1 篇公众号长文"我用 Claude 改完简历，3 天拿到 5 个面试"+ 设计 1 张小红书引流图 + 在评论区引导"扣 1 帮你改"
- **内容怎么写**：标题"用 Claude 改完简历，3 天拿到 5 个面试"；重点写"具体 prompt + 改前后对比 + Offer 截图"；小红书形式"3 张图 + 1 段文字"易爆
- **怎么变现**：① 小红书 9.9-29.9 资料包（简历模板+Prompt）② 公众号引流到 99-299 元"AI 求职训练营" ③ Skill 49-99 美元在国际 marketplace ④ 1v1 简历润色 99-199 元/份
- **怎么引流**：小红书"求职"细分关键词（CV/简历/校招/实习/AI 改简历）+ 知乎回答"AI 工具横评"问题 + 公众号 SEO（"AI 简历"竞争低）+ 大学生群裂变
- **可沉淀资产**：Prompt 模板（10 套简历场景）+ 小红书爆款拆解 + "2026 AI 求职工具评测"白皮书 + Skill 资产 + 100 个真实改简历案例库
- **反直觉认知**：付费用户不是"找不到工作焦虑的人"，而是"已经在投简历、有 offer 焦虑、需要快速优化"的人；真正愿意付钱的是有"具体场景"的人（商科转码/海归/985 冲刺大厂）
- **风险和不确定性**：① 合规风险（不能宣传"保 Offer"）② 平台限流（小红书对"求职""Offer"敏感）③ 同行复制快 ④ 需保护用户隐私（简历数据）
- **状态分类**：**现在我能做**（内容引流）+ **需要积累资源**（1v1 服务需要先有案例）
- **适合黄文轩程度**：★★★★★（大学生身份既是用户也是内容生产者）
- **接入哪个任务系统**：内容/文章 + 提示词/ + 内容/变现 + 内容/资产（案例库）+ 公众号长文

### 方向 3：GEO/AI Search 优化内容栏目 + 自测小工具

- **它是什么**：① 教品牌/独立开发者/创作者如何让自己的内容被 ChatGPT/Claude/Perplexity/Gemini 等 AI 搜索引擎引用；② 做一个免费的 GEO 自测小工具（输入网址 → 输出 AI 引用概率 + 改进建议）
- **为什么最近值得看**：Lumar、Botify、optimizegeo.ai、LLMrefs 等专业平台涌现（信号 11-12），4-Pillar GEO Framework 已成共识；传统 SEO 流量正在被 AI Search 截流
