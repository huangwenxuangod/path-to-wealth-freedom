## 3. 今日筛出的 3 个 AI 变现方向

### 方向 1：Claude Code Skills / Plugins 打包销售
* **它是什么**：把"场景化的 Claude Code SKILL.md / 插件包"（如自媒体选题 Skill 套装、跨境选品 Skill、大学生 AI Coding 学习路径 Skill）作为数字商品在 Gumroad / 飞书 / 公众号小程序 / GitHub Sponsors 销售。
* **为什么最近值得看**：Anthropic 2026 上线第三方 Skills marketplace，Claude Code 在中文圈（05 后 / 大学生 / 自媒体）渗透率快速上升，但**真正垂直、可直接拿来用的 Skill 包**几乎空白。
* **AI 替代了什么工作**：
  1. 写"选题清单 + 标题模板 + 内容结构"的人
  2. 写"工作流自动化脚本 + 提示词模板"的人
  3. 写"跨境 / 简历 / 副业"垂直资料的"资料贩子"
* **谁可能付钱**：
  * 大学生 / 研究生（AI Coding 学习路径 Skill、毕业设计 Skill）
  * 自媒体博主（选题 Skill、爆款拆解 Skill）
  * 跨境小老板（选品 Skill、Listing 改写 Skill）
  * 中小创业者（"AI 搭子"全套）
* **现有案例 / 信号**：
  * ClaudeMarketplaces.com 出现第三方上架（链接：https://claudemarketplaces.com/）
  * jeremylongshore/claude-code-plugins-plus-skills 仓库
  * Firecrawl 2026 best Claude Code skills 集合
  * "How to Monetize SKILL.md Skills as a Developer — 2026 Guide"（agensi.io）
* **我能怎么低配复刻**：
  1. 选 1 个最熟悉的场景（如"小红书爆款拆解"或"AI Coding 入门"）
  2. 写 3-5 个 SKILL.md + 配套的 prompts/ scripts
  3. 用 README + Demo 视频 包装，挂在 GitHub + 飞书云文档
  4. 公众号 / 小红书发"使用教程"引流
* **3 小时版本**：
  * 选定 1 个垂直场景（30 分钟）
  * 写 3 个 SKILL.md + 1 份 README + 1 个录屏 demo（2 小时）
  * 同步发 1 条公众号 + 1 条小红书介绍（30 分钟）
* **1 天验证 MVP**：
  * 上线 Skill 包 1.0（GitHub + 飞书文档）
  * 发 1 篇深度长文（"我为什么做这套 Skill"）
