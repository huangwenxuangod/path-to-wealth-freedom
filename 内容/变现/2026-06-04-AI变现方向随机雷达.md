## 3. 今日筛出的 3 个 AI 变现方向

### 方向 1：AI Coding Agent 工作流模板 / Skill 包

- **它是什么**：针对 Cursor、Codex/ChatGPT、Claude Code 等 AI Coding 工具，开发「开箱即用」的 Skill 包、工作流模板、/loop 配置、角色插件配置。卖给非技术知识工作者和中小团队——他们想用 AI Coding 降本增效，但不知道怎么配置。
- **为什么最近值得看**：Codex 与 ChatGPT 合体（6/3），知识工作者在 Codex 中占比 20% 且增速是开发者 3 倍。Cursor 3.6 推出 /loop、Auto-Review、Shared Canvas。GitHub 上 Taste-Skill（2.4K stars）证明「AI Skill」是独立品类。非技术人涌入 AI Coding，但缺「说明书」。
- **AI 替代了什么工作**：AI 替代了「手动学习工具配置」和「反复试错 prompt」。Skill 包把最佳实践打包成可复用的产品。
- **谁可能付钱**：非技术创业者、独立开发者新手、中小企业运营/市场团队、想转型 AI 的产品经理、大学生做项目。付费意愿参考：Cursor Pro $20/月有人付 → Skill 包 $9-29 一次性或 $5-10/月订阅合理。
- **现有案例 / 信号**：Taste-Skill（GitHub 2.4K stars）、Cursor 官方 Skills marketplace 正在酝酿、Codex 合作伙伴生态（Wix/Replit/Lovable/Figma 等正在接入）、OpenAI 计划允许合作伙伴直接在 Codex 和 ChatGPT 中创建部署插件。
- **我能怎么低配复刻**：我是 AI Coding 实操者，日常就在用 Cursor 和 Claude Code 做项目。把我实际使用的 prompt、工作流、skill 配置整理成模板包。从自己踩过的坑和最优配置中提炼。
- **3 小时版本**：整理 5 个我自己日常用的 Cursor/Claude Code Skill 配置，打包成一个 Notion 页面 + GitHub repo，写清楚每个 skill 的用途、配置方法、适用场景。发小红书/GitHub/X。
- **1 天验证 MVP**：完成 5 个 Skill + 1 个视频教程（YouTube Shorts/小红书），上架 Gumroad $9。同时在 X/小红书发 Build in Public 内容。核心指标：Gumroad 是否有浏览量、是否有 1 单付费。
- **内容怎么写**：公众号长文《Codex 杀进 ChatGPT，普通人怎么用？我整理了 5 个开箱即用的 Skill》。小红书拆成 5 条笔记（每个 Skill 一条）。YouTube Shorts：30 秒演示一个 Skill 的效果。
- **怎么变现**：卖 Skill 包（$9-29 一次性）、卖订阅型 Skill 库（$5-10/月）、做 Cursor/Codex 配置咨询服务（$50-200/次）、企业团队配置服务（$500-2000/团队）。
- **怎么引流**：GitHub 开源 repo（SEO + 开发者社区）、小红书 Build in Public（公开收入数据和开发过程）、X 发开发日记、Product Hunt 上架。
- **可沉淀资产**：Skill 模板库（可迭代成长期付费产品）、Cursor 最佳实践教程（可扩展成小课）、Notion 配置手册、GitHub 开源项目（作品集）。
- **反直觉认知**：大部分人觉得「做 Skill 包太简单，没人会付钱」。但 OpenClaw 第一名 MRR $55K 只做「1 分钟帮你安装」——信息差和执行差本身就是产品。知识工作者不会也不愿花时间研究配置，他们愿意付 $9-29 省 2-3 小时。
- **风险和不确定性**：OpenAI/Cursor 可能官方推出 Skill marketplace 改变分发格局（但也是机会——提前卡位成为早期创作者）；Skill 包容易复制，需要持续迭代和品牌化；付费意愿需要真实验证。
- **状态分类**：现在我能做
- **适合黄文轩程度**：极高（9/10）。我的 AI Coding 实操者定位天然契合。日常就在用这些工具，内容本身就是产品素材。
- **接入哪个任务系统**：每日公众号选题、GitHub 小项目雷达、内容资产沉淀、7 天公开挑战

### 方向 2：MCP Server 开发 + 上架变现

- **它是什么**：开发 MCP（Model Context Protocol）Server——连接 AI 助手（Claude/ChatGPT/Cursor）与外部工具/API 的标准化接口。上架 MCP Marketplace 通过 License Key 收费。
- **为什么最近值得看**：MCP Marketplace 是目前唯一支持完整创作者变现的 MCP 平台（Stripe Connect、85/15 分账）。其他所有目录都是免费列表。竞争极低——整个生态处于「谁先上架谁先占坑」的阶段。Anthropic Claude Opus 4.8 完成 Super-Agent 基准，意味着 AI Agent 能力大幅提升，对 MCP Server 的需求将爆发。
- **AI 替代了什么工作**：MCP Server 替代了「手动在多个工具间切换」和「人工 API 调用」。让 AI 直接操作 Notion、Google Drive、Slack、数据库等。
