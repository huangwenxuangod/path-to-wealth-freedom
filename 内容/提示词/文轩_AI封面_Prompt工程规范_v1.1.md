# 文轩 AI 封面 Prompt 工程规范 v1.1（Search-First 真实参考版）

> 核心升级：**先搜索，再设计；先找真实，再让 AI 生成。**
>
> 目标不是做一张“看起来像 AI 生成的高点击封面”，而是做一张：
>
> **真实人物 + 真实品牌资产 + 真实产品内容 + 真实场景参考 + 一个强动作 + 一组克制标题**
>
> 最终观感应该接近：**真实创作者拍摄素材 + 真实产品展示 + 真实背景 + 轻后期设计**。

---

# 0. v1.1 最重要的更新

v1.0 的重点是：

- 真人主体
- 单场景
- 少元素
- 一个核心物件
- 有梗动作
- 大标题

v1.1 在此基础上新增一个最高优先级原则：

> **不要直接凭想象生图。先搜索真实世界的参考资产，再设计。**

以后每次设计封面，在真正调用图像生成之前，必须先完成一个小型 Reference Research。

必须优先搜索三类东西：

1. **真实场景图**
2. **真实产品 / 品牌图标 / UI**
3. **同赛道优秀封面图**

必要时再搜索：

4. **动作参考图**
5. **服装 / 灯光 / 摄影构图参考**
6. **产品官方页面 / 发布页 / 品牌规范**

只有完成搜索后，才进入设计。

---

# 1. 为什么“先搜索”是 v1.1 的核心

AI 封面最容易出现的问题，不是“不会画”，而是：

- 场景是 AI 凭空想象的
- 图标是假的
- 产品 UI 是假的
- 人物动作像模板
- 背景像 3D 样板间
- 色彩像“AI 认为的高点击封面”
- 所有元素都“差不多对”，但没有一个是真的

最终结果就是：

> **技术上完整，观感上很假。**

所以 v1.1 的方法反过来：

> **真实世界负责提供素材语言，AI 负责组合、重构和强化。**

不是让 AI 自己从零发明一切。

---

# 2. Search-First Reference Research 流程

以后每次让我设计封面，优先按照以下流程。

---

## Step 1：先拆主题

先把视频内容拆成四个问题：

1. 这期视频的对象是什么？
2. 最值得点进去的冲突是什么？
3. 最应该被看见的主体是什么？
4. 什么真实场景最适合承载这个故事？

例如：

### 主题
Codex 配置不再卡手机验证

### 拆解
- 对象：Codex / ChatGPT
- 冲突：原本卡验证，现在解决了
- 真人主体：我本人
- 核心物件：电脑
- 产品内容：真实 ChatGPT / Codex 标识
- 场景：真实、干净的工作桌 / Home Office

---

# 3. 搜索真实场景图

## 3.1 为什么必须搜

不要直接写：

> “生成一个高级办公室”

因为模型会自动生成最典型的 AI 办公室：

- 蓝灯
- 绿植
- 完美桌面
- 虚假的景深
- 不真实的家具组合

正确做法是先搜索：

- real home office photography
- clean workstation photography
- developer desk setup
- modern home office natural light
- Gatsby mansion exterior photography
- yacht deck sunset photography
- estate terrace real photography

然后从真实照片里提炼：

- 光线方向
- 家具密度
- 材质
- 景深
- 色温
- 相机高度
- 背景留白

---

## 3.2 真实背景参考的筛选标准

选参考图时优先：

- 像真实摄影，不像渲染
- 光源合理
- 材质自然
- 不过度装饰
- 主体区域有留白
- 视觉层级简单
- 背景能被一眼识别

不要选：

- AI 感明显的参考图
- 过度豪华
- 太多灯带
- 赛博朋克
- 高饱和 HDR
- 细节特别杂

---

## 3.3 场景搜索优先级

### 教程 / 工具类
优先：
- home office
- real desk
- clean room
- developer workstation
- creator studio

### 探索 / 全解类
优先：
- ship deck
- lighthouse
- harbor
- library
- observatory
- map room

### 商业 / 成果 / 掌控类
优先：
- estate
- mansion entrance
- terrace
- executive office
- elegant lobby

---

# 4. 搜索真实图标、Logo 和产品内容

## 4.1 原则

如果封面中出现：

- ChatGPT
- OpenAI
- Codex
- Claude
- 豆包
- Cursor
- Gemini
- 其他产品

不要让模型自己“画一个差不多的”。

必须优先搜索：

1. 官方网站
2. 官方品牌指南
3. 官方产品页
4. 官方 App Store / 产品截图
5. 官方博客 / 发布页

---

## 4.2 品牌图标处理原则

> **真实标准图标 > AI 重绘图标**

要求：

- 不拉伸
- 不随意改变结构
- 不自创类似版本
- 不乱加纹理
- 不把标准 Logo 变成奇怪 3D 雕塑
- 如果需要实体化，也要保持核心识别结构

例如 OpenAI 的官方品牌指南明确强调：
- 标识比例不要随意更改
- 不要擅自加效果
- 不要使用未经批准的变体
- 标识应保持清晰空间

因此以后看到用户给出的真实 Logo，应尽量以它为参考，而不是重新“想象”它。

---

# 5. 搜索真实产品 UI / 内容

如果电脑、手机、平板出现在画面中，屏幕内容是非常重要的“真实性锚点”。

不要生成：

- 假代码
- 假按钮
- 无意义卡片
- 看起来像 SaaS 模板的 UI
- 奇怪拼写

应该先搜索：

- 产品官网
- 官方帮助文档
- 官方发布页
- 官方产品截图
- 用户真实操作截图

然后决定：

> **屏幕到底应该显示什么。**

屏幕内容可以简化，但不能假。

---

# 6. 搜索优秀封面图

## 6.1 搜索目的

不是照抄别人的设计。

而是观察：

- 主体占比
- 人物大小
- 标题位置
- 动作方向
- 背景复杂度
- 产品如何展示
- 文字与人物的关系

重点分析的是：

> **结构，而不是装饰。**

---

## 6.2 优先搜索同赛道创作者

例如：

- AI 教程
- AI Coding
- AI 工具
- 产品测评
- Agent
- 编程教程
- 科技解释

优先看：

- 有真人的封面
- 单主体
- 一个产品
- 少量标题
- 动作强
- 手机缩小后仍然清楚

---

## 6.3 搜索封面时问的 6 个问题

看到参考封面后，必须先分析：

1. 谁是第一主体？
2. 主体占画面多少？
3. 动作是什么？
4. 产品如何进入画面？
5. 标题占多少空间？
6. 缩小后还剩什么？

---

# 7. “参考包 Reference Pack”规范

每次正式生图前，尽量建立一个小型 Reference Pack。

建议包含：

### A. 人物参考
- 我的真实照片
- 真实脸型
- 当前发型
- 当前服装

### B. 动作参考
- 一张真实人物动作图
- 重点参考手势、身体方向、神态

### C. 产品参考
- 官方 Logo
- 官方图标
- 官方 UI / 产品截图

### D. 场景参考
- 一张真实摄影背景图
- 用来参考材质、灯光和空间结构

### E. 封面结构参考
- 一张同赛道高点击封面
- 只参考构图逻辑

理想状态：

> **不要让一个参考图承担全部任务。**

而是：
- A 决定脸
- B 决定动作
- C 决定产品
- D 决定背景
- E 决定封面结构

---

# 8. 新的封面生成总公式

v1.1 的最终公式：

> **真人主体 × 真实动作参考 × 真实产品资产 × 真实背景参考 × 单场景叙事 × 克制标题**

进一步压缩：

> **真实素材做骨架，AI 做整合。**

---

# 9. 真人主体规范

主体必须优先是我本人。

要求：

- 保留真实脸部辨识度
- 保留真实肤质
- 保留合理毛孔和皮肤细节
- 不要网红脸
- 不要过度磨皮
- 不要脸型漂移
- 不要不必要换装

如果我给了衣服参考：

> **默认衣服不变。**

除非我明确要求角色化换装。

---

# 10. 动作规范

动作不是装饰。

动作的目的：

> **告诉观众应该看哪里。**

优先：

- 拿电脑往镜头前展示
- 托着产品
- 指向屏幕
- 递给观众
- 展示结果
- 邀请式伸手

人物动作最好来自真实照片参考。

如果找到了真实动作图：

> **保留动作骨架，换成我的脸 / 身份。**

不要让模型凭空生成标准：
- 张嘴
- 指向
- 两眼瞪大

这种典型 AI thumbnail pose。

---

# 11. 核心物件规范

每张图一个核心物件。

例如：

- 电脑
- 手机
- 豆包图标
- ChatGPT 图标
- 地图
- 机器人

不要一张图里同时：

- ChatGPT Logo
- Codex Logo
- 手机
- 电脑
- 代码窗口
- UI 卡片

核心原则：

> **宁愿一个东西放大，也不要五个东西都出现。**

---

# 12. 真实背景规范

背景可以有设计，但必须满足：

- 看起来像真实摄影
- 光源合理
- 材质真实
- 空间比例合理
- 背景不抢主体
- 不过度完美

推荐 Prompt 关键词：

```text
real photography
natural ambient light
believable interior
realistic material texture
documentary-like environment
clean real workspace
subtle depth of field
authentic room proportions
```

避免：

```text
futuristic
cyberpunk
neon
ultra epic
glowing everywhere
fantasy office
CGI showroom
```

除非视频主题本身就需要。

---

# 13. 标题规范 v1.1

文字仍然必须吸睛，但不能成为“AI 感来源”。

原则：

- 只有标题
- 2～5 个中文字优先
- 黄白搭配
- 加粗词用黄色
- 非加粗 / 次级部分用白色
- 字体厚实但自然
- 轻微倾斜
- 浅阴影
- 少量描边
- 不要巨大 3D extrusion
- 不要强 glow
- 不要高光塑料字

标题应该：

> **像真人创作者后期加上去的。**

而不是：

> **像 AI 自动生成模板里的字。**

---

# 14. 色彩规范

v1.1 的目标不是“炸”。

目标：

> **真实 + 清楚 + 有一点强化。**

推荐：

- 饱和度略降低
- 对比度中等
- 人脸曝光自然
- 物件稍亮
- 背景稍暗 / 稍虚
- 标题保持高识别

避免：

- 海水蓝过饱和
- 天空蓝过饱和
- 皮肤过亮
- RGB 颜色全满
- 高 HDR
- 黑位死黑
- 高光爆白

---

# 15. 画幅规范

以后只允许：

- **3:4**
- **4:3**
- **16:9**

禁止使用其他比例。

### 3:4
适合：
- 竖版平台
- 人物 + 电脑 / 手机
- 人物展示产品

### 4:3
适合：
- 人物 + 产品
- 教程封面
- 中等横向空间

### 16:9
适合：
- B站
- YouTube
- 横版大场景
- 冒险型 / 叙事型封面

---

# 16. v1.1 标准工作流

## Phase 1：Research

### 1. 搜产品
- 官方网站
- Logo
- 官方 UI
- 官方产品截图

### 2. 搜场景
- 真实摄影
- 同场景环境
- 光线参考

### 3. 搜动作
- 真实人物
- 手势
- 姿势
- 镜头透视

### 4. 搜封面
- 同赛道
- 高点击
- 单主体
- 清楚标题

---

## Phase 2：Analysis

把搜索结果拆成：

- 人物参考
- 动作参考
- 产品参考
- 背景参考
- 构图参考

然后问：

> 最终封面只留下什么？

---

## Phase 3：Reduction

强制删除：

- 多余 UI
- 多余 Logo
- 小字
- 装饰卡片
- checklist
- 多余人物
- 第二个场景
- 第二个产品

最终尽量只留下：

> **人 + 一个物件 + 一个动作 + 一个背景 + 一组标题**

---

## Phase 4：Generation

只有在 Reference Pack 确定后才生成。

生成 Prompt 必须明确：

- 参考谁的脸
- 参考哪张动作
- 使用哪个真实产品标识
- 参考哪类真实背景
- 标题写什么
- 比例是什么

---

## Phase 5：Reality Check

生成后先不要看“好不好看”。

先问：

1. 这像真人吗？
2. Logo 是真的吗？
3. 产品像真的吗？
4. 背景像真的地方吗？
5. 动作像真人会做的吗？
6. 有明显 AI 生成痕迹吗？
7. 缩小后主体还明确吗？

如果其中 2 项明显失败：

> **不要继续堆后期，重新生成。**

# 17. v1.1 通用 Search-First Prompt

```text
先不要直接生成图片。

先围绕这期视频主题做 Reference Research。

请主动搜索并整理以下参考：

1. 与主题相关的官方产品图标 / Logo / 品牌资产
2. 官方产品界面、官网截图或真实内容
3. 适合本期故事的真实摄影场景图
4. 与我想要的动作类似的真人姿势参考
5. 同赛道优秀封面图，用于分析主体比例、标题排版和构图

搜索后不要机械复制参考图。

先提炼：
- 真人主体应该怎么站
- 手势应该怎么做
- 核心物件是什么
- 背景应该是什么
- 产品应该显示什么真实内容
- 标题应该放哪里
- 哪些元素应该删除

然后再生成封面。

最终要求：

【人物】
必须是我本人，保持真实脸型、五官、发型、肤质和身份辨识度。
不要塑料磨皮，不要陌生 AI 脸。

【动作】
优先参考真实人物照片中的动作。
动作必须自然、有叙事功能、能引导观众看向产品。

【产品】
必须优先参考真实官方图标、真实品牌资产和真实产品界面。
不要擅自重绘假 Logo。
不要生成无意义假 UI。

【背景】
必须参考真实摄影场景。
背景要像一个现实中真正存在、真正可以拍摄的地方。
自然灯光、真实材质、合理空间比例。
禁止泛滥的赛博朋克、霓虹灯和虚假 CGI。

【构图】
只保留：
一个人物
一个核心物件
一个真实场景
一组主标题

【标题】
只出现主标题。
黄白配色：
强调词黄色，普通词白色。
字体厚实、易读，轻微倾斜。
阴影浅，描边克制，不要强烈 3D 和发光。

【视觉】
realistic photography,
natural skin,
real product assets,
believable environment,
clean creator thumbnail,
subtle depth of field,
controlled contrast,
restrained saturation.

吸睛来自：
真人 + 动作 + 清楚主题 + 真实产品

而不是：
高饱和 + 发光 + 特效 + 元素堆积。

【画幅】
只能使用：
3:4
4:3
16:9
根据平台和构图选择其中一个。
```

# 20. v1.1 最终判断标准

一张图合格，不是因为：

> “AI 生成得很漂亮。”

而是因为：

> “如果没人告诉我，我会以为这是创作者真的拍了一张照片，然后设计师做了少量后期。”

最终标准：

### 看人
像真人。

### 看产品
像真的产品。

### 看 Logo
像真的 Logo。

### 看背景
像真的地方。

### 看动作
像真的动作。

### 看标题
像真人后期加上去的。

### 看整体
吸睛，但不假。

# 21. 最终一句话原则

> **先搜索真实世界，再让 AI 重组真实世界。**

以及：

> **封面可以是 AI 生成，但绝不能让“AI 生成感”成为封面的第一印象。**
