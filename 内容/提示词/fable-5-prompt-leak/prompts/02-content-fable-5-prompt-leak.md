# Prompt 02 · 是什么

## 内容定位
- **核心**：Claude Fable 5 系统提示词到底是什么？
- **4 个数据模块**：
  - 30,000 token
  - 72 章节
  - 18 工具 JSON Schema
  - 「出厂设置说明书」
- **金句**：「不是道德宣言，是操作指南」
- **氛围**：报纸版面感、严肃、信息密度

## 完整 Prompt

```text
A bold screen-print style editorial knowledge card, portrait 3:4 aspect ratio, dramatic duotone limited color palette of crimson red (#DC143C) and deep navy black (#0D1B2A) on warm cream paper background (#F5E6D0).

The composition is structured as a 2x2 grid of data modules in vintage newspaper layout style, with thin crimson divider lines. Each module contains a large bold condensed number in crimson:
- Top-left: "30K" with small label "TOKEN"

- Bottom-right: "1" with small label "FILE"

Above the grid, the title in bold navy condensed sans-serif: "不是道德宣言" with a crimson strikethrough line, followed by "是操作指南" in larger crimson text below.
```
