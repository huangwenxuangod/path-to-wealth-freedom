# 文轩 AI 封面 Prompt 工程规范 v1.0

> 目标：建立一套可长期复用的 AI 自媒体封面设计方法，让每张封面都保持 **真人主体、单场景、少元素、有梗动作、强标题、低 AI 感** 的统一视觉语言。

---

# 1. 核心设计原则

## 1.1 封面的本质

封面不是视频摘要，也不是功能说明页，更不是“把所有信息都塞进去”的宣传海报。

封面的任务只有一个：

> **在 0.5 秒内，让观众看到一个明确的人、一个明确的动作、一个明确的物件，并产生“为什么会这样？”的点击欲。**

因此，所有封面优先服从以下公式：

> **真人主体 + 单一场景 + 一个核心物件 + 一个有梗动作 + 一组主标题**

进一步压缩：

> **一个人 + 一个场景 + 一个动作 + 一个物件 + 一组标题**

---

# 2. 我的封面审美 DNA

## 2.1 真人主体优先

默认第一主体必须是我本人。

要求：

- 保留真实脸部辨识度
- 尽量保持真实肤质，不要塑料磨皮
- 不要把人物改造成陌生网红脸
- 不要让产品、图标、UI 抢过人物
- 人物要占据足够大的画面比例
- 人物最好是半身或近景，确保缩略图状态下仍能识别

默认优先级：

1. 我本人
2. 一个核心产品 / 图标 / 道具
3. 场景背景

---

## 2.2 单一场景

一张封面只讲一个视觉故事。

推荐场景：

- 船头 / 甲板 / 灯塔 / 海面
- Gatsby 风格庄园 / 豪宅 / 庭院
- 干净办公工位
- 夜景 / 晚霞 / 海港
- 大型会议室 / 高级工作空间
- 具有明确情境的现实空间

禁止：

- 多场景拼贴
- 左边一个 UI、右边一个产品、中间一个人物
- 大量浮动卡片
- 太多标签、气泡、清单
- 同时塞多个产品

---

## 2.3 一个核心物件

每张封面只保留一个辅助主物件。

例如：

- 手机
- 豆包图标
- Claude / ChatGPT / Cursor 图标
- 地图卷轴
- 船舵
- 笔记本电脑
- 机器人
- 某个 App UI 设备化实体

核心要求：

> **物件必须足够大、足够清楚，并和人物动作发生关系。**

优先关系：

- 托着它
- 指向它
- 递给观众
- 拿着它展示
- 与它互动
- 把它当“宝物 / 工具 / 结果”呈现

---

## 2.4 动作必须有梗

我不喜欢“普通站着”。

动作必须承担叙事功能。

推荐动作：

- 伸手邀请
- 指向
- 托举
- 举起展示
- 递出
- 船长式掌控
- Gatsby 式自信举杯 / 邀请
- 轻微夸张的惊讶
- “你来看这个”的动作
- “这个就是答案”的动作

动作要求：

- 有故事感
- 有视觉引导
- 有一点夸张
- 但不能像标准 AI thumbnail 模板动作
- 不能太机械
- 手势和脸部情绪要一致

---

## 2.5 标题规则

封面只保留主标题。

不要：

- 副标题
- 解释性小字
- checklist
- 功能列表
- UI 内文字
- 对话气泡
- 额外说明

标题建议：

- 2～5 个中文字最佳
- 或 1～3 个英文词
- 放顶部
- 粗体
- 黄 + 白 为主
- 黑色粗描边
- 可轻微倾斜
- 有一点动势，但不要夸张 3D

推荐结构：

- 左黄右白
- 上黄下白
- 产品名黄、结果词白
- 主体词白、冲突词黄

示例：

- 豆包 工作
- 豆包 打工
- Astra 全解
- Claude Code
- AI 打工
- 真能干活？

---

# 3. 视觉风格

## 3.1 真实感优先于“AI 感”

我不喜欢“AI 一眼生成”的效果。

尤其避免：

- 皮肤过度磨皮
- 人脸过亮
- 高饱和蓝紫色
- 过强边缘光
- 过度锐化
- 过强 HDR
- 塑料材质
- 背景过于完美
- 所有元素都同时发光
- 过于赛博朋克

正确方向：

> **像真人拍摄出来的一张戏剧化照片，再加少量后期设计。**

推荐视觉关键词：

- realistic photography
- cinematic realism
- clean composition
- natural skin texture
- soft cinematic lighting
- subtle depth of field
- slightly moody
- restrained saturation
- controlled contrast
- editorial YouTube thumbnail

---

## 3.2 色彩控制

默认不要太亮。

推荐：

- 整体略深
- 中等对比度
- 饱和度适中
- 背景颜色退后
- 人脸和核心物件更亮
- 标题保持高识别

避免：

- 满屏霓虹蓝
- 荧光绿
- 过亮红
- 所有物件都加 glow
- 过度渐变

原则：

> **主体亮，背景静。**

---

# 4. 场景设计逻辑

在生成封面之前，必须先把视频主题压缩成一个“故事瞬间”。

## 4.1 从内容命题到画面

### 示例：豆包工作

错误思路：

> 豆包 + checklist + 写方案 + PPT + 数据分析 + 文案 + UI + 图标

正确思路：

> 我托着豆包图标，像展示一个“真的能替我工作”的新工具。

### 示例：Astra 贪吃蛇

错误思路：

> Astra logo + browser + score + benchmark + snake + failed

正确思路：

> GPT 变成贪吃蛇，狠狠撞墙。

### 示例：Claude Code 全解

错误思路：

> Claude logo + terminal + code + UI + 说明

正确思路：

> 我站在船头，手持“Claude 地图”，像带观众探索一个未知世界。

---

# 5. 标准封面生成流程

每次生成封面时，严格按照以下步骤。

## Step 1：定义点击钩子

先回答：

> 这期视频最值得点进去看的点是什么？

不是完整标题，只要一个核心冲突。

示例：

- 豆包真的能工作
- Astra 竟然翻车
- Claude Code 一次讲懂
- 手机也能开发 APP
- AI 可以替我干活

## Step 2：压缩成一个场景

把命题变成一个视觉瞬间。

问：

> 如果只能用一张照片表达，这一幕应该是什么？

## Step 3：确定真人主体

明确：

- 必须是我
- 使用我提供的人脸参考
- 保持真实五官
- 保持穿着要求
- 决定动作
- 决定神态
- 决定人物占比

## Step 4：确定一个辅助主物件

只留一个。

## Step 5：确定动作关系

人物必须和物件产生关系：

- 指
- 托
- 拿
- 递
- 展示
- 操控

## Step 6：确定背景

背景只负责承载故事。

## Step 7：确定标题

只有标题。

## Step 8：控制风格强度

主动降低：

- 饱和度
- 对比度
- 发光
- AI 感
- 过度磨皮

## Step 9：加入禁止项

Prompt 中必须明确告诉模型不要什么。

## Step 10：做缩略图检查

缩到手机屏幕大小以后，只应该剩下：

- 我
- 动作
- 一个物件
- 标题

如果还能看到很多小信息，说明太复杂。

# 6. 标准 Prompt 模板

## 6.1 通用封面 Prompt

```text
设计一张高点击 YouTube / B站 AI 内容封面。

整体方向：
这不是复杂海报，而是一张“真人电影瞬间 + 大标题”的高 CTR 缩略图。
画面必须只围绕一个场景、一个真人主体、一个核心物件展开，元素极少，主体极强，缩小到手机屏幕后仍然一眼能懂。

【真人主体】
主体必须是我本人。
严格保留我提供的人脸参考中的五官、脸型、发型与辨识度。
保持真人摄影感和自然皮肤质感，不要过度磨皮，不要改变成陌生网红脸。
人物必须是画面第一视觉中心，采用近景或半身构图，占据画面约 40%～60%。

【人物动作】
人物不能只是站着。
设计一个夸张但自然、有梗、有叙事功能的动作。
可以参考：指向、托举、递出、展示、邀请、伸手、掌控。
手势必须清楚地引导观众看向核心物件。
神态自然、有轻微戏剧性，不要标准 AI thumbnail 式夸张表情。

【核心物件】
全画面只保留一个核心辅助物件。
物件要大、清楚、有存在感，并且与人物动作直接互动。
不要同时出现多个产品、多个 UI 或多个图标。

【场景】
只使用一个明确、干净、有电影感的现实场景。
背景必须服务于人物和核心物件，不允许抢主体。
背景有空间感，但信息量低。
可使用：船头、甲板、豪宅、庄园、办公区、海港、夜景、晚霞、高级工作空间等。

【标题】
只保留顶部主标题。
除了主标题以外，画面中不要出现任何其他文字。
标题控制在 2～5 个中文字，或 1～3 个英文词。
使用超粗黑体，黄色 + 白色，粗黑描边。
标题可以有轻微倾斜感和动势，但不要复杂 3D。
标题必须在缩略图状态下仍然非常清楚。

【视觉风格】
真人摄影感优先。
cinematic realism, realistic photography, natural skin texture, clean composition, restrained saturation, medium contrast, subtle depth of field, soft cinematic lighting.
整体色调略深，适度降低饱和度和对比度，不要过亮。
让人物和核心物件更清楚，背景适当虚化和退后。

【禁止项】
不要多余文字。
不要副标题。
不要小字。
不要 checklist。
不要 UI 卡片。
不要气泡。
不要功能列表。
不要多人物。
不要多个产品。
不要背景过杂。
不要满屏粒子。
不要赛博朋克霓虹感。
不要塑料人脸。
不要过度锐化。
不要 HDR 过强。
不要高饱和。
不要太亮。
不要让画面一眼看出是 AI 生成图。
```

# 7. 豆包工作专用 Prompt

```text
设计一张“豆包工作”主题的高点击 AI 自媒体封面。

【核心概念】
这张图表达的不是“豆包有哪些功能”，而是：
“我发现豆包真的能替我工作。”

【画面结构】
一个真人主体 + 一个豆包核心物件 + 一个现实场景 + 顶部标题。
不要增加任何其他信息。

【人物】
人物必须是我本人。
严格保留我的真实脸部辨识度。
保持真实皮肤纹理和自然五官。
人物为画面第一主体，半身或近景。
人物表情自然、自信、略带“发现好东西”的感觉。

【动作】
动作必须有叙事性。
优先使用：
- 单手托着豆包图标
- 伸手把豆包递向观众
- 手掌向上托起豆包
- 指向豆包
- Gatsby 式轻微自信邀请动作

动作可以略夸张，但必须自然。

【豆包物件】
豆包图标作为唯一辅助主体。
图标要大、清楚、有实体感。
可以轻微悬浮在手掌上。
不要把豆包图标做成过度发光的科幻物体。
不要增加其他功能卡片或 UI。

【背景】
背景采用干净、有高级感的现实环境。
推荐：
- Gatsby 风格豪宅 / 庄园
- 高级办公空间
- 干净户外露台
- 夜色豪宅庭院

背景要轻微虚化，信息量低，不能抢主体。

【标题】
顶部只显示：
“豆包 工作”

“豆包”使用黄色超粗字体。
“工作”使用白色超粗字体。
粗黑描边。
标题有轻微倾斜和动势。
除了这四个字，不允许出现任何其他文字。

【视觉控制】
整体稍微偏深。
降低对比度和饱和度。
不要太亮。
不要满屏蓝光。
保持真实摄影感。
保留自然皮肤质感。
不要强烈 AI 味。

【禁止】
不要 UI。
不要 checklist。
不要小字。
不要气泡。
不要副标题。
不要多个图标。
不要复杂背景。
不要人物换装，除非另有明确要求。
不要把我变成陌生人。
```

# 8. 冒险型封面 Prompt

适合：Claude Code、AI Agent、全解、探索类视频。

```text
设计一张高点击“探索 / 全解”型 AI 视频封面。

画面必须像一个电影故事瞬间。

人物主体必须是我本人。
保留真实脸部辨识度和自然肤质。

人物位于一个明确的冒险场景，例如：
船头、甲板、海港、灯塔、远景海面。

人物动作必须有故事性：
掌舵、指向前方、拿地图、递出地图、邀请观众跟随。

只保留一个核心物件，例如：
地图卷轴 / 产品图标 / 一个实体化 AI 标志。

背景必须干净、有空间感，不要堆太多装饰。

顶部只保留主标题。
标题采用黄白超粗字 + 黑描边。
不要其他任何文字。

整体视觉风格：
realistic cinematic thumbnail,
natural skin texture,
slightly dramatic,
controlled contrast,
moderate saturation,
clean background,
strong subject separation.

不要：
多余小元素、功能列表、UI 卡片、过度发光、过度赛博感、AI 塑料脸。
```

# 14. 标题视觉规范

默认标题设计：

- 字体：超粗黑体
- 字重：Heavy / Black
- 主色：黄色 + 白色
- 描边：黑色粗描边
- 阴影：轻微
- 位置：画面顶部
- 字数：2～5 个中文字
- 角度：轻微倾斜，约 2°～8°
- 不使用小字号辅助文案

推荐配色：

```text
黄色：#FFD400 / #FFC800
白色：#FFFFFF
描边：#000000
```

# 15. 出图前检查清单

## 主体

- [ ] 我本人是不是第一视觉中心？
- [ ] 人脸是否真实？
- [ ] 人物够大吗？
- [ ] 动作有故事吗？

## 场景

- [ ] 是否只有一个场景？
- [ ] 背景是否干净？
- [ ] 背景是否抢主体？

## 元素

- [ ] 是否只有一个核心物件？
- [ ] 有没有无意义的小元素？
- [ ] 有没有多余 UI？

## 文字

- [ ] 是否只有标题？
- [ ] 标题是否足够大？
- [ ] 是否 2～5 字？
- [ ] 有没有多余小字？

## 风格

- [ ] 是否太亮？
- [ ] 是否太饱和？
- [ ] 是否 AI 感太强？
- [ ] 皮肤是否塑料？
- [ ] 是否像真实封面而不是 AI 海报？

## 缩略图测试

缩小以后，应该只剩：

> **人 + 动作 + 物件 + 标题**

如果缩小后仍然有大量信息需要阅读，就需要继续删元素。

# 16. 最终一句话原则

> **不要让 AI “设计一张丰富的封面”，而要让 AI “拍出一个有梗的真人故事瞬间，再只加一个大标题”。**

这就是整套封面 Prompt 工程的最高优先级。
