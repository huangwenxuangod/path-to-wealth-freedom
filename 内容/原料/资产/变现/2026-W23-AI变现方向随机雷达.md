## 3. 筛出的 10 个 AI 变现方向

---

### 方向 1：RedSkill — 在小红书卖 AI Skill

- **它是什么**：小红书 AI Skill 分发平台，类似 AI App Store。创作者上传 Skill（AI 能力模块），用户在笔记中一键安装使用
- **为什么最近值得看**：5 月 24 日上线，话题 160 万浏览，关联笔记 600+。已有 3 个真实案例突破 10 万+ 销售额。内测期竞争极小
- **谁可能付钱**：家长（教育）、懒人（自动化）、玩家（娱乐）、求职者（提效）、自媒体人（内容工具）
- **AI 替代了什么工作**：外教、记账员、编剧、网申填写、内容策划
- **已有案例 / 信号**：14 万+ 英语 Skill、40 万+ 记账 Skill、3000+ 份文游指令
- **我能怎么低配复刻**：选一个高频小痛点 → 写 SKILL.md → 发笔记挂 RedSkill
- **1 天验证 MVP**：做 1 个 Skill → 发 2 篇笔记 → 看 24 小时数据
- **可能的变现方式**：卖 Skill（数字商品）、社群（Skill 交流）、教程（教别人做 Skill）、代做 Skill 服务
- **可沉淀资产**：Skill 文件、笔记内容、用户社群、产品方法论
- **反直觉认知**：卖得最好的不是技术最酷的 Skill，而是解决「懒」的——用户不是买技术，是买「不用动脑」
- **风险**：内测期未开放官方付费；平台可能调整策略；3 个月内竞争会急剧升温
- **状态分类**：现在我能做
- **是否适合黄文轩**：⭐⭐⭐⭐⭐ 极适合

### 方向 2：Claude Code 中文 Skill 教程 + 资料包

- **它是什么**：Claude Code 是 Anthropic 的 Agent 编程工具，生态在 GitHub 霸榜，但中文资料空白
- **为什么最近值得看**：Anthropic 首次盈利的驱动力就是 Claude Code（$2.5B run-rate）。GitHub 前十有七个 Claude Code 生态项目，中文社区零系统教程
- **谁可能付钱**：中国开发者、AI Coding 初学者、企业技术团队
- **AI 替代了什么工作**：代码审查、bug 修复、文档生成、测试、Git 操作、重构
- **已有案例 / 信号**：claude-howto 33K stars；everything-claude-code 185K stars；superpowers 195K stars
- **我能怎么低配复刻**：写公众号长文 + 配套 Skill 文件 + Prompt 模板集
- **1 天验证 MVP**：一篇公众号推文 → PDF 资料包 → 小红书 3 篇笔记
- **可能的变现方式**：免费长文引流 → 付费资料包 → 咨询服务 → 企业培训
- **可沉淀资产**：公众号长文、PDF 资料包、Skill 合集、Prompt 模板、GitHub 仓库
- **反直觉认知**：中文资料少不是因为需求小，是因为大部分 AI 博主还在追热点。生态空白 = 先发优势
- **风险**：需要 Claude 付费 API（用户成本）；中国市场可能被国产替代；资料更新频率要求高
- **状态分类**：现在我能做
- **是否适合黄文轩**：⭐⭐⭐⭐⭐ 极适合

### 方向 3：GEO 优化 — AI 搜索时代的内容创作者必修课

- **它是什么**：GEO（生成式引擎优化），让内容被 AI 搜索引用。市场规模 480 亿元
- **为什么最近值得看**：Gartner 预测 2028 年传统搜索下降 50%+。个人创作者比企业更需要 GEO——没有品牌背书，只能靠被 AI 引用获取流量
- **谁可能付钱**：中小企业、个人创作者、营销人员、知识付费用户
- **AI 替代了什么工作**：传统 SEO——从争关键词排名变为争 AI 引用位置
- **已有案例 / 信号**：IDC 白皮书；GEO 优化页面 AI 引用率高 35%+
- **我能怎么低配复刻**：写 GEO 优化指南系列，面向个人创作者而非企业 SEO
- **1 天验证 MVP**：一篇公众号文章 → 小红书 3 篇碎片化笔记 → 观察需求反馈
- **可能的变现方式**：资料包 → 付费社群 → 小课 → 企业咨询
- **可沉淀资产**：公众号系列、GEO 优化清单模板、资料包、方法论
- **反直觉认知**：自媒体人比企业更需要 GEO，因为 AI 搜索是新的流量入口
- **风险**：AI 引用机制不透明，优化效果难量化；用户认知度低
- **状态分类**：需要积累资源
- **是否适合黄文轩**：⭐⭐⭐⭐ 适合

### 方向 4：中文 AI 代写服务（公众号 / 小红书 / LinkedIn）

- **它是什么**：用 AI Agent 帮创始人/高管批量生成社交媒体内容，海外已验证月入 $5K-20K
- **为什么最近值得看**：海外模式已验证（12 个客户 × $1500/月），中文版尚未规模化。中国创始人/高管对内容代写需求大，但缺少 AI-native 服务商
- **谁可能付钱**：创业公司创始人、VC 投资人、企业高管、知识 IP、自媒体人
- **AI 替代了什么工作**：内容策划、初稿撰写、发布排期——替代了内容助理 90% 的工作
- **已有案例 / 信号**：Indie Hackers $18K/月案例；国内「内容代运营」市场庞大但偏传统
- **我能怎么低配复刻**：先自己用 AI 写公众号（已经验证）→ 把这套流程产品化 → 服务 2-3 个客户测试
- **1 天验证 MVP**：把自己的 AI 写作工作流整理成服务页 → 在小红书/LinkedIn 发「帮创始人写公众号」的帖子 → 看咨询量
- **可能的变现方式**：月度订阅服务（￥2000-5000/月/客户）、代写单篇、写作工作流模板
- **可沉淀资产**：AI 写作 Skill、服务 SOP、客户案例、公众号长文
- **反直觉认知**：AI 代写不是「让 AI 全自动写」，而是「AI 70% + 人工 30% 审核润色」，客户买的是「不用自己动脑」和「质量担保」
- **风险**：客户获取是瓶颈（不是产能）；内容质量难以规模化；可能被视为「洗稿」
- **状态分类**：需要积累资源（需要客户）
- **是否适合黄文轩**：⭐⭐⭐⭐ 适合，但需要先验证客户获取

### 方向 5：小红书中长视频 AI 创作

- **它是什么**：小红书未来投入 500 亿流量倾斜中长视频，AI 合规标注不影响曝光。用 AI 生成脚本 + 配音 + 画面，抓住平台流量红利
- **为什么最近值得看**：中长视频推荐时效 90 天（普通笔记 7 天），蒲公英分成计划即将上线（播放量持续分成）。平台级红利，不是小风口
- **谁可能付钱**：不直接付钱——先做内容涨粉，再通过商单、分成、引流变现
- **AI 替代了什么工作**：脚本写作、配音、画面生成、字幕制作、剪辑
- **已有案例 / 信号**：小红书官方公告 500 亿流量计划；AI 合规标注不影响曝光
- **我能怎么低配复刻**：用 AI 写脚本 + AI 配音（VoxCPM2）+ AI 生成画面 + 剪映合成
- **1 天验证 MVP**：做 1 条 AI 中长视频（5-10 分钟，AI 工具测评或教程类）→ 发布 → 看 7 天数据
- **可能的变现方式**：蒲公英分成、品牌商单、引流私域、知识付费
- **可沉淀资产**：视频内容、AI 视频制作工作流 Skill、教程
