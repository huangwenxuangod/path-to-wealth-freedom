## 正文（选项B版本，298字）

Apple刚把Claude和OpenAI Codex塞进了Xcode 26.3。

不是插件，是原生集成。意思是：你描述需求，AI自己拆任务、改代码、跑测试、修bug——以前要一个月的功能，现在可能一个下午。

Google一个Principal Engineer说，Claude Code 1小时干完了他们团队12个月的活。虽然被质疑是demo不是生产代码，但10倍提效在特定场景下是真的。

更疯的是Cursor：50个人，3年，ARR干到20亿美元，估值500亿美元。史上增长最快的B2B软件公司，没有之一。

但别急着高潮。

我扒了7起AI写代码导致的事故：150万API密钥泄露、生产数据库被删、BBC记者电脑被黑。Vibe Coding产出的代码能跑，但3个月后你自己都看不懂。

所以我的判断是：AI不会取代程序员，但「会审AI代码的人」会取代「只会手写代码的人」。

翻译成人话：你可以让AI写，但你必须能一眼看出它哪行在作死。

## 正文（选项B版本，295字）

Cursor最近惹众怒了。

$20/月的Pro不够，还要推$200/月的Ultra。更过分的是——你自己买的Claude API Key，在Cursor里只能聊天用，Tab补全和Agent功能强制锁死在他们自己的模型上。

开发者不是傻子。5月5日，一个叫Kilo Code的开源插件登顶Product Hunt日榜第一。

核心卖点就三个：
1. 完全免费开源，代码全透明
2. 500+模型随便换，Claude、GPT、DeepSeek、甚至本地模型都行
3. 最新v7支持多Agent并行——同时开5个AI程序员，各自在独立分支写代码，互不干扰

实测效果：我一个微服务重构任务，5个Agent并行跑了6小时，完成了原本3天的工作量。

成本呢？按OpenRouter的零加价定价，6小时高强度使用大概花了$8。Cursor Pro一个月$20只能一个人用，这个$8是按实际用量付的。

不是Cursor不好，是当开源追上功能+打出价格差的时候，闭源的压力就来了。
