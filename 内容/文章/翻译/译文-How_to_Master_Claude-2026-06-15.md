## 一、理解 Claude

### 三层模型

在讲怎么精通 Claude 的具体步骤之前，你得先搞清 Claude 到底怎么运转，再把脑子里那套旧的"AI 用法"换掉。

Claude 有三个"层次"。

- **第一层**：Claude Chat（网页基础界面，也就是大多数人在用的那个）
- **第二层**：Claude Cowork（替你把活干完）
- **第三层**：Claude Code（替你把东西造出来）

Claude 真正的力量在第二层和第三层。

![Image](https://pbs.twimg.com/media/HKTMvU7boAAT1rB?format=jpg&name=large)
*第二层和第三层*

也就是说，你得把思路从"靠提示词的 AI"（第一层）切换到"Cowork 和 Claude Code 里的代理式 AI 系统"（第二层和第三层）。

![Image](https://pbs.twimg.com/media/HKTM85zacAAS3js?format=jpg&name=large)
*提示词 vs 代理*

从现在开始，你每次做事都得问自己两个问题：

1. 我要完成的任务是什么？
2. 怎么用 Cowork 和 / 或 Claude Code 把这个流程自动化？

这套框架才是你真正开始"把生活自动化"的方式——它会把你从那种"一条条提示词打过去、活还是得自己干"的孤立状态里拉出来。这就是"第一层"。

这块讲完，咱们就下潜到第二层和第三层——Claude 真能把你生活改个底朝天的地方。

## 二、Claude Cowork

### 两大功能：Scheduled Tasks + Dispatch

前面说过，Claude Cowork 是 AI 代理真正替你把活干完的地方。

Cowork 有两个关键功能能帮你把活真正做完：

**1. Scheduled Tasks（定时任务）**

Cowork 的关键在于它能自主地跑任务，不用你每次想要个结果时都重新提一遍提示词。

也就是说，代理可以反复访问你桌面上的文件夹、扫描你的浏览器 / 各种连接器，等等。

举个例子：每天早上扫一遍你的 Gmail 收件箱，9 点给你出份日报；每天下午 5 点生成一份当日工作小结；每小时整点出一份新闻简报。

![Image](https://pbs.twimg.com/media/HKTNFaTbwAAIih9?format=jpg&name=large)
*定时任务*

你可以在 Claude 桌面 App 里这样部署：Cowork → Scheduled Tasks。

如果你一时想不到 Cowork 能拿来做啥，Anthropic 内置了一个"Ideas（灵感）" tab，里面全是 Cowork / Scheduled Tasks 的真实用例，可以直接逛。

![Image](https://pbs.twimg.com/media/HKTNKfqaMAAngWe?format=jpg&name=large)
*灵感*

**2. Dispatch**

第二个，Claude Dispatch。

这是让你用手机跟 Cowork 通讯、从任何地方给 Cowork 派活的功能。

## 三、Claude Code

### 入门：Claude Code 桌面端

现在讲第三层：Claude Code。

这一层是真正让 AI 帮你"造东西"的地方。

比如：自定义工具、自定义脚本、看板、应用。

我个人喜欢直接在桌面 App 里访问 Claude Code。

### 关键：文件夹搭建（让 Claude 长期记住关键信息）

AI 最大的一个问题，是很难给它持续提供对的上下文。

LLM 经常忘事——它们留不住你的所有偏好，或者最后只记住些不重要的东西。

这一节我就教你怎么把桌面文件夹搭好，把这些问题全解决，让 Claude 真的记住那些该记的。

关键是这套文件夹搭法你也能套到别的 LLM 上，以后换模型时不用反复加上下文或者重新打提示词。

**新建一个文件夹，然后建下面这三个 markdown 文件：**

**1. Instructions.MD** — 告诉模型"该怎么表现"

```
Folder Setup
One of AI's biggest issues is that it can be hard to provide it with the right context over time.
LLMs often forget things, don't retain all your preferences, or end up remembering irrelevant things.
In this section, I'm going to show you how to properly set up your desktop folders to eliminate all these issues and have Claude remember what actually matters.
You can plug this folder setup into other LLMs, which eliminates the need to re-prompt or re-add context whenever you switch models.
Start a brand new folder, and build these three markdown files:
Instructions. MD - tells the model how to act
```

注意 Instructions.MD 的最后一句："Update Memory.MD with my preferences over time."（随时间把我的偏好更新到 Memory.MD）

这句非常关键——它就是让 Claude 给你建一份"持续滚动更新的记忆日志"的那条命令。

**2. Memory.MD** — Claude 的"大脑"，会随时间持续更新

```
Example:

## Preferences（偏好）
## Corrections（纠错）
## Patterns（模式）
## Decisions（决策）
```

只要你在 Claude Code 里说"别再用破折号了"这种话，它就会按你 Instructions.MD 里写好的规则，自动把你的偏好更新到 Memory.MD 里。

然后你就可以把这份 Memory.MD 拿去给任何 LLM 或者 Claude Chat 用，啥都不用重新解释——做大项目时非常好用。

看到这，希望你开始感受到这套系统的威力。

**3. Context.MD** — 总纲领 / 任何模型需要的上下文

这个 markdown 文件放什么完全看你具体项目，下面是我给 AI Edge 内容策略写的 .MD 例子：

```
* AI EDGE - CONTENT STRATEGY
#a Positioning（定位）
Al leverage authority. Not news, not tool reviews. Personal transformation + leverage with occasional documentary stakes.
#* Content Barbell（内容杠铃）
- 75% Leverage Lane（借力赛道）:systems/playbooks that create outcomes (money, time, advantage)
- 25% Documentary lane（纪录赛道）:cinematic stakes about AI trajectory, always ending with "what to do"
# Style（风格）
- 8-15 min max
- Fast first 7 seconds
- Open Loops + payoffs
- Outcome-driven, not tool-driven
- Simple frameworks, examples, steps you can apply today
#* Formats（形式）
- Anchor videos（主推视频）:fully edited, 3-4 per week
- Raw/lightly edited（原片/轻度剪辑）:2-3 per week
- Every video needs:title options, outline, hook variations, retention notes, editor notes
```

**总结一下文件夹这套东西：**

第一，你要 Instructions.MD，告诉 Claude 该怎么表现。
第二，你要 Memory.MD，告诉 Claude 你的偏好。

![Image](https://pbs.twimg.com/media/HKTODcsagAAKzTV?format=jpg&name=large)
*记忆 hack*

第三，你要 Context.MD，放具体上下文。

**这套搭法能搭出来的东西：**

把这套系统搭起来，本质上是给自己建了一个自动化闭环：

Cowork 里跑日常任务 → Cowork 里识别模式 → Claude Code 里搭成系统 → Cowork 里这个任务跑得更快更好。

![Image](https://pbs.twimg.com/media/HKTOJPAbIAA-ESj?format=jpg&name=large)
*高手循环*

### 整套系统的效果

这套搭法直接把你从"第一层 Claude 用户"（就是那种不停在 Claude Chat 里反复打提示词的人）拽出来，变成真正在管自动化工作流的高阶玩家。
