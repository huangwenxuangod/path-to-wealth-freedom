## 1. MiniMax Sparse Attention

![Image](https://pbs.twimg.com/media/HKu_ynzWwAAvghM?format=png&name=large)

超长上下文已经成为智能体、代码库级别推理、多模态工作流和持久化记忆的核心需求，但稠密 Softmax 注意力机制仍然让百万 token 级别的部署成本高得离谱。MiniMax Sparse Attention（MSA）的解法是在分组查询注意力（GQA）之上引入块级稀疏性，配一个轻量级路由分支，让每个查询组只关注真正需要的键值块。

- **双分支注意力设计：** Index Branch 对整个因果上下文打分，独立为每个 GQA 组挑出 Top-k 键值块；Main Branch 则只对这些选中的块执行精确稀疏注意力计算。
- **硬件感知实现：** 论文将稀疏模式与 GPU 核函数协同设计，使用无 exp 运算的 Top-k 选择和 KV-outer 稀疏注意力，在块粒度访问下提升张量核心利用率。
- **规模化加速效果显著：** 在一个 1090 亿参数的原生多模态模型上，MSA 在 1M 上下文长度下将每 token 注意力计算量压缩 28.4 倍，同时保持与 GQA 持平的性能。配套的 GPU 核函数在 H800 上实现了 14.2 倍预填充加速和 7.6 倍解码实际时钟加速。
- **为什么值得关注：** 长上下文只有"能便宜地跑起来"才有实际价值。MSA 的可贵之处在于机制简洁、直接训练进生产规模的模型、开源推理核函数，并驱动了已发布的 MiniMax-M3 模型。

[论文](https://arxiv.org/abs/2606.13392) | [推文](https://x.com/MiniMax_AI/status/2065436935188058208)

## 2. Self-Harness

![Image](https://pbs.twimg.com/media/HKu_9jyWAAAq8bf?format=png&name=large)

大多数智能体脚手架（agent harness）都是人工手搭一次就冻住了，底层模型迭代多少次它都一动不动。这篇论文提出 Self-Harness：让 LLM 智能体自主改进它自己的运行脚手架——包括提示词、工具、记忆和围绕基座模型的编排逻辑——全程不需要人工工程师介入，也不依赖更强的外部智能体。因为每个模型的失败方式都不一样，Self-Harness 会挖出这些模型特有的弱点，并把它们转化成具体可执行的脚手架修改，而不是泛泛的改进建议。

- **三阶段自改进循环：** 先跑 Weakness Mining（把执行轨迹聚类成模型专属失败模式），再跑 Harness Proposal（针对这些失败生成多样且最小化的修改方案），最后跑 Proposal Validation（修改方案必须通过 held-in 和 held-out 集上的回归测试才被接受）。
- **跨基座模型持续增益：** 在 Terminal-Bench-2.0 上，所有被测模型的 held-out 通过率均有提升。MiniMax M2.5 从 40.5% 升至 61.9%，Qwen3.5-35B-A3B 从 23.8% 升至 38.1%，GLM-5 从 42.9% 升至 57.1%。
- **弱点直接变修改：** 不是追加一堆通用指令，而是把每个观察到的失败模式，精准转化为对记忆、工具或提示词的定向修改，最高相对提升幅度达 138%。
- **为什么值得关注：** 模型越来越多，迭代越来越快，为每个模型手动调一套脚手架根本跑不过来。Self-Harness 证明脚手架本身可以自适应，让"冻住的脚手架和它包裹的模型之间的差距"不再是无解的问题。

[论文](https://arxiv.org/abs/2606.09498) | [推文](https://x.com/omarsar0/status/2064429834999304247)

## 3. Agents' Last Exam

![Image](https://pbs.twimg.com/media/HKvAAPHWoAAex8F?format=jpg&name=large)

来自 Berkeley RDI 的 Agents' Last Exam（ALE）是一个"活着的"评测基准，衡量的不是智能体能不能在学术测试上拿高分，而是能不能干有经济价值的真实工作。它由 250 多名行业专家共同搭建，将 1000 多个可验证任务映射到美国联邦职业分类体系，覆盖 13 个行业集群下的 55 个子领域。每个任务都有客观可核查的结果，没有主观人工打分，而且任务池会随着新工作流的接入持续扩充。

- **根植于真实职业：** 任务参照 O\*NET 和 SOC 2018 定义，覆盖非体力劳动行业，刻意瞄准智能体真正会被部署的专业工作流，而不是谜题型问题。
- **三档难度分级：** 任务分为 Near-Term（近期可用）、Full-Spectrum（全谱）和 Last-Exam（终极考试）三档，让基准既能追踪近期的实用性，也能覆盖那些高难度多步骤任务的长尾。
- **远未饱和：** 最难档的平均全通过率只有 2.6%，即便是 Codex + GPT-5.5 这样的强配置，在最简单档得分也低于 50%，在最难档低于 10%。
- **为什么值得关注：** 在现有基准上刷高分并没有转化为有经济意义的实际部署。ALE 把评测的锚点换成"可验证、由专家策划的真实工作"，给出一个随智能体进步而持续移动的靶子，不容易被刷穿。

[论文](https://arxiv.org/abs/2606.05405) | [推文](https://x.com/dair_ai/status/2062916866235068607)

## 4. How AI Agents Reshape Knowledge Work

![Image](https://pbs.twimg.com/media/HKvAC3vWEAEHAkc?format=png&name=large)

这篇经济学论文基于 Perplexity 的大规模生产数据，研究从对话式助手向自主智能体的转变如何重塑知识工作。它从自主性、效率、任务范围三个维度，对比了 Search（对话式助手）与 Computer（通用智能体系统）。论文的框架是一个成本结构模型：智能体的固定成本和委托成本更高，但每步边际成本更低——所以只要任务足够复杂，智能体就能胜出。

- **自主性在实践中的真实面貌：** Computer 每次会话平均完成约 26 分钟的自主机器工作，Search 只有约 33 秒；每次查询的不满意率，智能体低 55%，为 1.3%，Search 为 2.9%。
- **效率提升巨大：** 在匹配任务上，Computer 将完成时间从 269 分钟压缩到 36 分钟，时间缩短 87%，相对于人工配合 Search 的方式成本降低约 94%。
- **任务范围向上跃迁：** 智能体处理的查询认知复杂度更高——71% 是抽象或非常规任务（Search 为 53%），创造性工作的比例是其两倍，且任务本身会跨职能边界打包多个相互依赖的子任务。
- **为什么值得关注：** 数据支持一个清晰的预测：随着委托的固定成本下降，智能体会把"负担得起的价值边界"推向更高价值的多步骤知识工作——这也正是增长最快的方向，研究期间采用量达到第一周的 84 倍。

[论文](https://arxiv.org/abs/2606.07489) | [推文](https://x.com/omarsar0/status/2064076252584222933)

## 5. Agentopia

![Image](https://pbs.twimg.com/media/HKvAK4oXAAAt262?format=png&name=large)

Agentopia 是目前最有野心的智能体社会测试床之一——这篇 79 页的论文把 100 个 LLM 智能体扔进一个持久化世界，让它们在模拟的 10 年里生活、建立关系、追逐目标。相比之前以"天"为粒度的研究，时间跨度拉长了几个数量级。除了观察涌现的社会行为，作者还把模拟过程作为训练信号，通过拒绝采样让模型向反映人类幸福感的"生活奖励"靠拢。

- **长时程是设计目标：** 早期智能体社会研究以天为单位运行，Agentopia 把每个世界的模拟时长拉到十年，让那些只在长时间尺度下才会出现的无脚本社会策略和人际动态浮出水面。
- **把模拟变成训练信号：** 生活奖励指标被用来微调更具人格化特征的模型，而且这些改进能迁移到模拟之外的下游角色扮演基准，不只是在沙盒里有效。
- **量化提升：** 经过训练的智能体在 CoSER Test 整体性能上提升了 15.6%，其中拟人化（Anthropomorphism）提升最大，达 23.7%，角色忠实度（Character Fidelity）提升 16.4%；受到 24.2% 更多同伴尊重，被 15.9% 更多同伴喜欢。
- **为什么值得关注：** 一次 10 年、100 个智能体的运行，消耗了 567,000 次 LLM 调用、共 137 亿 token。这个规模本身就是一个声明——智能体研究正在往"活着的、持续学习的种群"方向走，它既是研究对象，也是训练数据来源。

[论文](https://arxiv.org/abs/2606.07513) | [推文](https://x.com/dair_ai/status/2064075015960875347)

## 6. The Geometry of On-Policy Distillation

![Image](https://pbs.twimg.com/media/HKvAOJaXYAAnm7A?format=jpg&name=large)

在线蒸馏（On-Policy Distillation，OPD）已成为今年讨论最热的后训练方案之一，但大多数时候它都被当成一个黑盒——夹在监督微调（SFT）和强化学习（RL）之间，说不清是什么。这篇论文把它拆开看，从参数几何的层面分析 OPD 如何改变模型权重，并论证 OPD 不是 SFT 和 RLVR（带可验证奖励的强化学习）的中间地带，而是一种性质独特的更新。

- **更新更少的权重：** 和 SFT 相比，OPD 的更新只影响少得多的参数，且基本绕开了权重空间中的主导主成分方向——这在一定程度上解释了它的样本效率优势。
- **早期子空间锁定：** OPD 的累积更新在训练早期就快速收敛到一个窄小的低维子空间，而不像 SFT 那样扩散到多个方向。
- **那个子空间功能自足：** 把训练限制在这个早期形成的子空间内，OPD 的性能完全保留，但 SFT 会明显退化——这说明这个小子空间真的承载了有效信号，不是什么统计噪声。
- **为什么值得关注：** 弄清楚 OPD 在权重空间里动了哪里，就能把一个"流行但没人真正懂"的方法变成有机理可循的东西——更容易推理、更容易与其他目标结合，也可以有意识地改进，而不是靠试错碰运气。

[论文](https://arxiv.org/abs/2606.07082)

## 7. Lookahead Sparse Attention

![Image](https://pbs.twimg.com/media/HKvAQ9mWYAAxsly?format=png&name=large)

长上下文解码的瓶颈在 KV 缓存——每多一个 token，缓存就长一点，到了极端上下文长度，内存很快就被它吃光。这项工作（以 DeepSeek-V4 为旗帜）提出 Lookahead Sparse Attention（LSA）：不存完整的 KV 缓存，而是预测未来解码真正需要哪些上下文，只保留那些"对查询有价值"的块。

- **学出来的轻量索引器：** 不是把所有东西都留着，而是用一个小索引器主动挑出对后续生成重要的 KV 块，让物理缓存保持精简，同时不丢掉模型后面会用到的信息。
- **骨干网络解耦训练：** 训练策略让索引器可以独立训练，不用加载完整的骨干模型，大幅降低了把这个机制嫁接到大模型上的成本。
- **大幅压缩缓存，精度不降：** LSA 把物理 KV 缓存压缩到全上下文基线的 13.5%，同时平均精度反而微升 0.6%；在 50 万 token 上下文下，KV 缓存开销压缩超过 90%，推理稳定性不受影响。
- **为什么值得关注：** 超长上下文正在成为区分"玩具 Demo"和"真正可用系统"的关键，而内存就是那堵墙。预测你需要什么上下文，而不是把所有的都留着——这是一条真实硬件预算内就能落地的长上下文解法。

[论文](https://arxiv.org/abs/2606.09079)

## 8. Latent Spatial Memory

视频世界模型在长时程一致性上一直很难做好，因为显式 3D 记忆通常需要跑一个代价高昂的像素空间循环。Mirage 换了个思路：把场景信息直接存在扩散模型的潜空间里，通过深度引导的反投影和潜空间变形来维持持久化的空间记忆。和显式 3D 记忆基线相比，这个方法端到端生成速度最高快 10.57 倍，内存占用低 55 倍，长时程空间一致性也有所改善。

[论文](https://arxiv.org/abs/2606.09828)

## 9. The Consistency Illusion

多智能体辩论通常用"智能体最终是否达成共识"来评判，但这篇论文指出：输出层的一致可以掩盖推理过程中的深层分歧。作者将智能体的推理轨迹和决策抽象为两个维度（推理相似性 × 结论一致性）上的四种状态，并识别出"分歧式一致"——不同路径走到相同答案。在 600 个内容审核样本中，分歧式一致出现了 118 次，和真正分歧状态之间的 Cohen's d 为 0.80，区分相当清晰；基于这套状态分类做路由，在标记高分歧案例时也优于纯基于分歧的方法。

[论文](https://arxiv.org/abs/2606.04223) | [推文](https://x.com/dair_ai/status/2064395355220029696)

## 10. Beyond Scalar Rewards

奖励模型通常把一个判断压缩成单一标量，但这篇论文认为人类偏好用分数分布来表达更准确，并提出 Z-Reward：在打分前先把推理过程内化成一个预测分布。具体做法是用大型视觉语言教师模型完成推理密集型判断，再蒸馏到小学生模型里高效部署——270 亿参数的教师模型人类偏好准确率达到 89.6%，90 亿参数的学生模型以 88.6% 的成绩几乎追平。用作强化学习信号时，相比监督学习基线，净偏好提升 41.3%，超过 GRPO 等其他奖励方法。

[论文](https://arxiv.org/abs/2606.09076)
