# 第一部分：完整中文翻译

## 开场

如果你在用 ChatGPT、Claude、Claude Co-work 或 Codex，但不知道怎么用 agent 做营销——你来对地方了。我整个创业公司都跑在 Codex 里面，用的是 GPT 5.6，他们新出的模型，能力接近 Claude Fable，基本上什么活都能干。今天和我一起的是 Vashall，我的联合创始人，他正在从软件工程师转型做营销。所以今天我要给他演示 Codex 里面 9 个最重要的工作流，这些工作流帮我用 agent 做营销。

在正式讲工作流之前，我想先给观众快速解释一下 Codex 是什么。左边这里是对话列表，我们也可以把对话组织成项目。比如这个是 Agent Native 播客的项目，我所有关于这个播客的对话线程都在这里。点开其中一个，就会在这里显示。然后这里是 agent 对话区，我正在和 agent 做的东西会显示在这里。你可以去 Codex 里面，让它帮你做基本上任何知识工作类的任务，也可以让它创建一个 app。

——你经常用 Codex，也用 Claude Code 吧？

——对，主要是写代码。

——主要是写代码。但你正在转向营销，因为营销现在是瓶颈。

——做营销的增量价值确实比继续做工程更高。我们已经有 Fable 在 24/7 运行了，团队能做的越来越多。

——我现在就有 Fable 在另一个房间里跑着。

## 工作流 1：抓取所有社交媒体内容

第一个营销工作流：抓取所有平台上的社交媒体内容。我有一个 skill，可以输入 `/scrapecreators`，然后说："请找到 Instagram 上的创作者 Callaway。我很喜欢他的社交媒体内容。把他过去几个月最好的 10 个视频抓下来，我要转录稿和原始视频，然后把它们放到一个新的 Notion 数据库里。数据库先放在 Archive 文件夹下面，这只是测试用的。然后我还想让你告诉我，为什么他作为一个短视频创作者这么有效。"

然后直接发送。这个任务不需要用最高配，我用 5.6 soul（他们最大的模型），用 medium 推理强度。我发现用 medium 的话，你的额度能撑很久。这是个大模型就能搞定的任务，直接发出去就行。

大概等 2-3 分钟，它会去抓 Callaway 在 Instagram 上的所有视频。

——太棒了，这个 skill 是你自己做的吗？

——对，这是我用 ScrapeCreators API 做的 skill。它找到了 Callaway 在 Instagram 上的认证主账号。这里说："10 个原始视频已下载到本地，10 个转录稿已成功获取。我在当前 Archive 页面下创建了测试数据库。现在正在上传 MP4 文件并逐条写入记录。"

所以它基本上是在创建一个他内容的数据库，我们就是在抓取。我待会儿会讲到，下一个 skill 我会把 Callaway 的内容转化成一个单独的 skill，这样我就能随时调用他那种优质的脚本风格。

目标就是：你把这些 skill 组合起来用——找创作者、学习他们怎么说话，然后调整你自己的脚本风格和整个流程。

说到底，AI 写内容脚本之所以差，是因为代码好坏很容易验证——app 能跑就行，很确定性。但内容是主观的。正因为如此，过去 3 年 AI 虽然变聪明了很多，但写内容的能力并没有提升。不过，AI 非常擅长复制——给一个范例，找其中的模式，然后基于这些模式创作内容。所以你唯一需要做的，就是给它好的范例。这就是我们在这里做的事：给 AI agent 一个数据库或 API，让它需要创作类似某个人的内容时，就能直接去找到好的范例。

——对，而且这也让你能把自己的品味放进去。

——你看！搞定了。它去了 Instagram，找到了他最新的视频，有评论数、视频时长精确到秒、Instagram reel 的点赞数。这是脚本内容："这家中国公司 ByteDance 正式发布了 Seed Dance 2，这可是个大事。" 这些细节。我们刚看了他的视频，他非常有节奏感，脚本写得特别好——实际上这就是他内容的核心。如果你做内容或者做营销，你要注意这一点。

现在他所有视频都抓好了，放在 Notion 数据库里，我们可以直接在 Codex 里面打开 Notion。

——太酷了。

——看这个，这是原始视频文件。它抓取并下载了，然后上传到了 Notion。如果你是视频剪辑师，这个功能特别有用——比如你要做合集视频，或者像我们的剪辑师 Leo，他经常需要找 B-roll 素材。你可以在 YouTube 上说"去找瑞士的视频"或者"去找 Alex Hormozi 的视频"，它能实际拉取视频，搜索视频里某个特定片段，比如"找 Alex Hormozi 在户外走路的片段"，然后你就能拿到一个 B-roll 片段，用在你做的关于 Alex Hormozi 的视频里。对视频剪辑师来说这非常有用。如你所见，这简直太有用了。我们什么都能抓，全平台通用。

## 广告插播：Riley Brown Agent + Chorus 平台

顺便说一下，这个视频里提到的每一个 skill 都可以在描述栏的链接里找到。我还放了很多额外的 skill。你也可以雇佣 Riley Brown agent——这是我一直在做的一个 agent。点"hire agent"，就能立刻把这个 agent 加到你的 iMessage 里。然后 agent 会自动启动，你就能直接给它发消息了。你可以发"Hello Riley agent, what skills do you have?"，agent 就会回复你，给你一个联系人卡片，列出所有技能。

如果你要换模型，可以发 `/model`，这在 iMessage 里就能用。会给你所有可选的模型，你可以说"switch to Fable"，它就切换到 Claude Fable 5。这个 agent 免费试用，你可以用到所有最好的模型，100% 免费。我用 Chorus 做的，Chorus 是我们过去 3 个月在开发的平台，想做一个开放的 agent 平台——你可以用任何模型、连接你所有的工具，加到 iMessage、Slack 和其他任何平台上。免费试用，链接在描述里。

## 工作流 2：把任何创作者变成一个 Skill

第二个最有用的 Codex 营销 skill：把任何创作者变成一个 skill。

我在同一个对话里继续。我用 WhisperFlow 说："我需要你做更多研究。找出他频道上互动量最高的 10 个非赞助视频，上传到数据库刷新一下。然后把所有他表现最好的视频变成一个 skill，叫 'Callaway top performing'。这样我以后任何时候都能用这个 skill 写他风格的内容。"

现在 Codex 开始干活了——去找他表现最好的视频，然后在 Codex 里创建文件，以后我输入"Callaway top performing"就能用他的声音写内容。

——就这么简单？

——对，就这么简单。任何垂直领域的任何创作者都能这么做。

——它一直抓到了 2023 年。

——它说："完整历史拉取范围比第一次测试广泛得多。正在翻阅该账号的归档记录，一直追溯到 2023 年。这样更早的爆款也能公平竞争。我会保留每个被排除的赞助/推广帖子的证据。" 所以它在过滤掉所有赞助内容，因为赞助帖子可能是被投流推上去的，不是真实互动。我们要的是高质量的、真实的脚本。赞助帖不应该算在里面。

好了，现在我们有视频了。看，这些全部都有超过 1000 条评论。现在我们有了所有视频，这些都是保证是他最好的内容。而且这是他早期的风格，太疯狂了。

——这是刚出的。微软刚发布了他们的 Excel。

——对，我记得这个视频爆了。现在它更新了数据库，正在创建我们可以用的 skill。搞定了——它创建了一个叫"Callaway top performing"的 skill。

现在如果我们按 Command+N 开一个新对话，输入"Callaway top performing"。看到了吗？然后我说："我想写一个关于 Anthropic 发布的 JSpace 新闻的脚本。他们发布了一个很酷的东西，我觉得有点难懂。Callaway 擅长用简单的方式解释事情，同时又让人觉得紧迫和酷。请用他的声音写一个脚本，写 3 个版本。"

这里的核心就是：那些文件只是我们抓取的转录稿。但重点是——我不需要自己去收集信息，不需要手动写他的脚本或者做任何额外的事。我只需要说"去找他、变成 skill"，然后用 skill 去干活。

——用 skill 去干活。

——看！搞定了。我来用 Callaway 的风格读一下："Anthropic 刚刚在 Claude 的大脑里发现了一个隐藏的工作空间。"

——这个钩子太好了！真的非常好。

——"而且最奇怪的是，没有人编程它。"

——"没有人编程它。他们叫它 JSpace。"

——Callaway 每个视频都这么干。这完全是他的语气。"Anthropic 刚刚创建了接近测谎仪的东西给 AI 用，叫 J Lens。"

——有趣。他们确实有这个。对。

——我试了不同的角度，但说实话我觉得第一个版本真的很好。以上就是怎么把任何创作者变成一个 skill。

## 工作流 3：抓取竞品广告

第三个最有用的 Codex 工作流和 ScrapeCreators 很像——抓取广告。

每次说这个 skill 的名字都觉得怪，因为这是个教育视频，但这个工具叫 Foreplay。Foreplay 只是一个公司名，他们做了一个有用的工具，可以抓取所有曾经创建过的广告。

我可以输入 `/foreplay API`，然后立刻抓取任何竞品的广告。你想抓的内容可以是静态广告也可以是视频广告，都能下载视频或图片，也能下载转录稿。但你拿不到投放数据——那些是内部数据，比如 ROI、ROAS 之类的。但我们可以用「广告运行时长」作为代理指标。如果一个广告跑了 9 个月，大概率他们花了很多钱维持它，原因肯定不简单。

我经常做的一件事——这个 skill 的一部分如果你下载了的话，我的 agent 会自动做——就是："请抓取我的竞品 quad.ai、Perplexity、ChatGPT 和 Replit 运行时间最长的广告。放在 Notion 数据库里，先放 Archive 文件夹下测试。我要所有信息，想看看哪些广告表现好。在 Notion 数据库里加一个文本字段，分析每个广告为什么表现好。每个广告都要有一个文档解释原因。请创建这个数据库。还有什么需要加的？可能也要原始文件。每个竞品我要 top 5 视频广告和 top 5 静态广告。确保视频只限英文。"

这个 prompt 会跑一会儿，大概 3-4 分钟。其实我先停一下，既然它要做跨大量数据的分析和模式识别，我把推理强度调到 extra high。就让它跑，我们需要更智能的分析。这可能会让它花更长时间，但没关系。我们要知道这些广告为什么表现好，这样我们才能做出一样好的。

——有道理。

——好了，搞定了。这个跑了 10 分钟，是个大任务。有分析步骤，我用了 extra high，所以会消耗更多 token。如果你是 20 美元/月的计划，这种 prompt 可能只能跑几次。但数据库做好了。右键打开浏览器看看。它甚至有 CTA 字段——"注册"或"安装移动 App"。这里有 Replit、ChatGPT、Perplexity、Claude。原始创意素材在这里，点开看看。这是什么？看起来是静态广告。我们让它抓 5 个静态的。

——这个应该是个视频。

——对。你可能正坐在一个能赚钱的想法上。"用普通的文字，我只需要打出我想要的……然后我就去忙别的了。"

——等等，我之前见过这个广告。看到实际表现好的广告感觉很奇妙。

——对，这是品牌建设类型的。好了，我们有了所有这些广告。你知道在前 AI 时代，收集这些东西要多久吗？我们就这样搞定了。"这个 offer 很具体，截止日期制造紧迫感，生日框架让促销感觉像庆祝而不是打折。" 它不仅抓取了数据，还分析了每个视频。所以可能花了这么久。它得分析每个视频。

——对，可能还要拿转录稿，思考为什么。

——看，如果回到表格开头，CTA 一直到最后面。对，有 CTA——比如"注册"或"了解更多"。你可以问："这里有 20 个竞品，我只要找表现最好（运行时间最长）的、CTA 类型是移动 App 下载的广告。" 就能全部找到。

## 工作流 4：Paper + Firecrawl——把广告素材变成自己的

好，静态广告我想多说两句。这里应该有 25 个静态广告，但我现在要做的是把所有静态广告放到 Paper 上——一个 AI 原生版 Figma。然后我们把我们的品牌放到这些静态广告上，基本上就是把它们当作我们自己广告的模板。

"请把所有静态广告放到我现在的 Paper app 上。" 这是一个 bonus skill，叫 Paper MCP，让我能连接到 Paper（基本上就是 Figma）。跑一下。我这边已经打开了 Paper，命名为"ads"。然后 Codex 就会控制 Paper，把静态广告放上去。

看，你能看到 AI 在这个画板上工作，因为有个小图标。还有个小动画，我很喜欢。这里分了"static ad swipe file - Claude / Perplexity / ChatGPT / Replit"。

——你能看到它在实时添加。

——对，实时添加，超级有意思。

——太酷了。

好了，广告都放上去了。说实话我更希望它只放静态素材本身，不需要整个框架。但没关系，这是基于 HTML 的，我可以直接选中素材。我们待会儿要做的是把这些广告换成我们自己的品牌。

然后我突然想到一个很酷的工作流——我现在是现场想到的："请用 Firecrawl 去 chorus.com，找到落地页，把整个页面抓下来，放到 Paper 画板上，放在这些广告旁边。这样我就能有我们的品牌素材，和这些静态广告放在一起，然后把竞品品牌替换成我们的。把整个页面放在那里，然后把页面上的所有单独素材放到另一个 frame 里。一个放 Chorus 网站，一个放网站素材。"

——这是真实的工作流程，人们日常工作中真的会这么做。

——对，我确实是现场想到的。本来只想展示抓广告素材，然后突然想到：我不想把它们放在 Notion 数据库里，那不是我的创意流程。我要放在 Figma 上。然后我意识到：好的，我们要把这些换成 Chorus 的品牌素材。那怎么把品牌素材弄到画板上？对了，我们可以用 Firecrawl 抓取网站然后放上去。

等几分钟，这需要一点时间，因为它要抓整个网站。但最终会放到画板上，就放在广告旁边。

看！它创建了两个新画板——"Chorus Website Reference"和"Chorus Asset Library"。它把整个落地页完美地拉了下来，放到画板上。这太疯狂了。说实话我之前做过视频里提到的所有其他 skill，但这真的是我第一次在 Paper 里面试这个，所以我玩得很开心。

这里有 logo、word mark 和 icon，非常酷。还有更多——哇。

——还能选中里面的元素。

——它还在工作！这里有 26 个源文件、专门 agent。这非常 Figma。

现在我们抓取了所有素材。Paper 有内置的图片生成功能，你可以直接把图片拉出来，复制粘贴到外面。这些是我想要复制的。我们可以选品牌的部分——比如拿 word mark，拿这个小图标。你就是在做一个 mood board，把所有想用的素材放在一起。

然后我可以选中这些元素，说："我需要给 Chorus 创建一个新广告。我给了你 logo、word mark 和一张整体品牌截图。这允许你创建自定义 agent 来帮你工作。我要你把 Replit 的排版替换成 Chorus 的广告。用好的文案。OpenAI image 2 就够用了，可以用真实的文案，它能生成一堆素材。"

——哇，它做了一个。

——好了，我们有了"Chorus AI employees that do your work. Create custom AI employees that handle tasks, projects, and entire workflows." 你可以看到它用和 Replit 那个广告非常类似的方式组织了内容。现在你可以继续调整了。

这只是我想到的一个点子。比如我们想复制这个 Replit 的广告，我可以用 Pro 版，选中这些元素说："请改这个。保持人物不变，背景不变，把 logo 换成我放在下面的那个。然后让它说 Chorus 而不是 Replit。文案改成：'Built a $100,000 agent for $50'。除了颜色改成 Chorus 品牌色之外，其他什么都不改。"

然后你就能一批一批地生成。它们开始出现在这里了。看这个："Build a $100,000 agent for $50. Built with Chorus." 搞定了。

我们拉取了所有表现最好的广告，然后把品牌替换成了我们的。我们会原封不动用这个吗？不会，我们会改更多。但重点是：这让你找到最好的广告范例，然后给你大量创作广告内容的灵感，这正是你要做的——你要大量实验广告。

——而且在 Paper 里你也可以修改 prompt，让它做完全不同的变体，可以实验。如果你用了这个，在评论区告诉我，我很想知道你的工作流程，因为这是我在 Paper 里第一次做这个。

## 工作流 5：社交媒体排期发布

下一个有用的 Codex skill 涉及社交媒体发帖排期。我有一个 skill 叫 Buffer Publisher。我可以把我们在 Paper 上创建的帖子粘贴进来："我实际上想把这条作为 Instagram 帖子发布。也帮我排到 Buffer 上。"

这个不需要用好的模型，这是相对简单的任务——放图片、用 API 发出去。直接跑。排在 Instagram 和 LinkedIn 上，用 Buffer。Buffer 是一个社交媒体管理工具。

哦，它说："请发送文案和期望的日期时间。" 好提醒。做成草稿吧。文案写："I can't believe he built a $100,000 agent for $50. Oh my god 😱"

有意思的是你可以用之前提到的 ScrapeCreators skill 来找文案灵感——"请用 ScrapeCreators 找 Instagram 上的 Greg Eisenberg，看看他的文案风格。我非常喜欢他的文案。用他的风格写一条文案，然后排成草稿，把草稿链接发给我。"

90 秒后搞定了。右键在浏览器打开。我们有一个加到 Buffer 的帖子，可以看到完整内容。素材在里面了，已经准备好了。我说了要创建草稿，所以还没实际排期，但我可以让它"排到下周三"，它可能会先走个审批流程，问我确认文案，我说好的，就真的排好了。我不用再想这件事，直到在 feed 上看到它。

——太棒了。看那条文案的语气。

——"a doctor built a $100,000 AI agent for $50" 这就是 Greg Eisenberg 写文案的风格。这就是怎么把 ScrapeCreators 和 Buffer Publisher 结合使用。这让社交媒体排期变得容易多了，你都不用离开 Codex。

还有一点，如果你喜欢发 Twitter，也可以用 Typefully。我们公司实际上管理着 7 个 Twitter 账号，都通过 Typefully。你可以登录多个账号，直接排期 Twitter 帖子。如果你只关注 Twitter，这是 Buffer 之外的另一个选择。

## 工作流 6：Google Drive 管理

下一个 skill 不那么视觉化但更实用——Google Drive skill。

在营销中，特别是你拍了大量内容的时候，Google Drive 很重要。我们这个视频是分段拍的，对吧？所以有视频文件夹、又一层文件夹、整个层级结构。我有一个 skill 叫 Agent Native Drive，里面有一个文档，告诉 agent 深度分析文件夹的模式。还有一个文档告诉 agent 文件夹是怎么组织的。这个 skill 指向一个主文件夹，叫"Agent Native"。

——它会重新组织你的 Drive 吗？会清理吗？

——我可以说："我实际上 2 个月后要和 Gary Vee 做一期播客。请给他创建一个文件夹，创建一个视频文档，写一个 hook，确保看看这个文件夹里其他文档来了解我在 Agent Native 用过什么样的 intro，然后列出几个可以问他的问题。创建所有需要的文件，给我链接。"

我不需要明确说"给我链接"——因为这是 skill 的一部分：每当它创建或编辑文档/文件夹时，总是提供链接，让我能立刻在 Codex 里打开。

好了，搞定了。50 秒就创建了一个稍短版本的 hook。它非常擅长控制 Docs 和 Drive。

## 工作流 7：日历链接排期

下一个 skill 我认为是我杠杆率最高的 skill 之一，因为我在做播客，想请到高质量嘉宾。

一种方式是发日历链接给他们。但不同情况不同对待——如果是我现在感兴趣的话题，可能只想在未来几周内约；如果是常青话题，可能想约 2 个月以后；如果他们要做产品发布，可能想约 2 个月后。所以我想能发给他们一个自定义日历链接，让他们选择不同的日期。

我有一个 skill 叫 Cal.com。Cal.com 没有在 Codex 里有官方插件，但设置方法很简单：去 cal.com 拿 API key，粘贴进来，说"创建一个完全控制 cal.com 的 skill"，一分钟后就好了。

比如说我要给 Shaquille O'Neal 发邀请——我要和他聊 AI。

"我要在播客上和 Shaquille O'Neal 聊 AI，但这个播客我需要时间准备。所以可用日期只限周二和周四的排期，但只有 9 月和 10 月可用。创建一个文档，写 intro。给我草拟一封带 Cal.com 链接的邮件。"

——所以你要给 Shaq 发你的自定义日历链接？

——对。它会读取我的自定义日历链接，默认是周二周四中午到下午 5 点。但我可以让它编辑成只在特定日期范围内可用。

——这个 skill 的酷之处在于你可以把自己的偏好放进去，它就会按照你的偏好创建新的日历链接。

——对，100% 有用。一分钟搞定了。我们有了邮件草稿，主题"Agent Native Podcast"。内容："Hey Shaq, I would love to have you on my channel for a conversation about AI." 然后这里有链接。我们可以在浏览器打开，看到可用时间——8 月没有，看下个月。9 月和 10 月有。11 月没有。它创建了一个自定义链接，日期完美。

## 工作流 8：邮件草稿

最后一个 skill，对我来说实际上是最有用的。它可能看起来不起眼，你必须实际体验一段时间才能理解它有多有价值。

我们刚才只是创建了一个草稿，但我不能直接编辑它。我只能说"改这个词、改那个词"，或者复制出来改。很烦。

但我可以说："请找到你认为最匹配 Shaq 的邮箱。如果有公开的联系邮箱，就用那个。创建一个实际的 Gmail 草稿。"

这会在 Gmail 上创建一封草稿邮件，然后发给我一个草稿链接，我可以编辑并发送。而且这不是一次一封——我可以对收件箱里任意多的邮件做这件事。

看，它找到了："我找到了一个比通用基金会邮箱更好的联系人——Drew Russo at Better Collective Playmaker，Shaq 当前大型播客背后的媒体集团。地址是公开的。"

这就是这个 skill 做的事——它发给我一个链接，59 秒后我就能点开。因为我已经登录了 Gmail，直接打开。现在我不用在 Codex 里看了，可以直接编辑发送。这在群发邮件时特别有用——你想 CC 四个人，AI 擅长搜你的邮箱找出该 CC 谁。

但更厉害的是批量处理。你可以让 Codex 分析你所有邮件，找出需要回复的，全部草拟好，发给你链接。

"请找到过去两个月里所有向我推销产品的邮件。礼貌但带点花样地拒绝——'我先不用了'，然后话锋一转：'你想试试我们的产品吗？' 给他们我们产品的链接，尽量有说服力，让他们真的想用。所有这些都要草稿链接，不管多少封。"

好了，5 封回复。它翻了我们所有邮件。看这封："有人推荐了一个 AI 面试工具叫 Talia。嘿，感谢联系，Talia 看着不错，但我先不试了。不过——剧情反转——你想试试我们的产品吗？"

——太好了。

看下一封："感谢跟进，这个 demo 令人印象深刻，但我先不试了。让我反转一下剧本——"

——为什么要反转剧本？[笑]

——这个转变确实有点怪。好吧，这封我要发。

这就是我处理邮件的方式——批量处理。特别是创作者行业，你经常要联系创作者，可以个性化邮件然后批量创建草稿，你的工作就是最后检查草稿确保没问题。你可以快速过一遍。

而且它会越来越像你说话，因为你的 agent 会保留关于你的记忆。如果它反复犯同一个错误，你可以说"请更新 email draft skill，以后不要说这个或那个"，它就会记住。

## 核心观点

Riley Brown 的核心论点非常明确：**AI agent 不只是写代码的工具，它是营销操作的指挥中心。** 整个视频的底层逻辑是——把营销工作拆解为可重复的流程，每个流程封装成一个 Codex skill，然后用 agent 自动执行。

## Riley 的方法论精华

### 1. "先手动做一次，再变成 skill"
Riley 反复强调的模式：先在 Codex 里手动完成一个任务，然后把整个流程封装成一个 skill，以后用名字调用。这让 Codex 从"聊天窗口"进化成"操作系统"。

### 2. "给 AI 好的范例，而不是让 AI 从零创作"
这是整个视频最重要的洞察。AI 写内容差的根本原因是内容是主观的，没有明确的"对错"。但 AI 擅长模式识别——给它 10 个 Callaway 的爆款视频脚本，它就能写出类似风格的脚本。

### 3. "模型选择要匹配任务复杂度"
- 简单任务（如 Buffer 排期）→ medium 推理强度
- 复杂任务（如广告分析+模式识别）→ extra high 推理强度
- Riley 的经验：medium 能让额度撑更久，extra high 会消耗更多 token

### 4. "skill 组合使用"
Riley 最大的杠杆来自于把多个 skill 串联起来：
- ScrapeCreators 抓内容 → 变成 skill → 用 skill 写脚本
- ScrapeCreators 抓 Greg Eisenberg 的文案风格 → 用于 Buffer 帖子的文案
- Foreplay 抓广告 → Paper 放素材 → Firecrawl 抓品牌素材 → 生成自己的广告

### 5. "现场即兴发现工作流"
最有启发性的一幕是 Riley 在演示过程中即兴想到了 Paper + Firecrawl 的组合工作流。他说"我是现场想到的"——这说明当你熟练掌握这些工具后，组合使用的方式会自然涌现。

- "这个 skill 是你自己做的吗？" → 引出 ScrapeCreators API 的解释

# 第四部分：9 个工作流详细步骤拆解

## 工作流 1：抓取所有社交媒体内容

### 目标
从任何社交平台抓取任何创作者的内容（视频、转录稿、互动数据），存入 Notion 数据库。

### 前提条件
- Codex 账号（ChatGPT Plus 或以上）
- ScrapeCreators API key（免费 100 credits 起步）
- Notion 账号已连接到 Codex
- 已安装 ScrapeCreators skill

### 具体步骤

**Step 1：安装 ScrapeCreators skill**
```
在 Codex 中输入：
"请帮我创建一个使用 ScrapeCreators API 的 skill，
用于抓取社交媒体内容。"
```
或者从 ScrapeCreators 官网获取现成 skill（支持 Claude Code、Cursor、Codex）。

**Step 2：发起抓取请求**
```
/scrapecreators

请找到 Instagram 上的创作者 Callaway。
我很喜欢他的社交媒体内容。
把他过去几个月最好的 10 个视频抓下来，
我要转录稿和原始视频，
然后把它们放到一个新的 Notion 数据库里。
数据库先放在 Archive 文件夹下面。
然后告诉我，为什么他作为一个短视频创作者这么有效。
```

**Step 3：选择模型和推理强度**
- 模型：GPT-5.6（"5.6 soul"）
- 推理强度：medium（简单抓取任务不需要最高）
- 理由：medium 能让额度撑更久，这个任务足够直接

**Step 4：等待 2-3 分钟**
Agent 会自动：
1. 调用 ScrapeCreators API 找到创作者认证账号
2. 下载 10 个视频的原始 MP4 文件到本地
3. 获取 10 个视频的转录稿
4. 在 Notion 创建数据库（含字段：评论数、视频时长、点赞数、脚本内容等）
5. 上传 MP4 文件到 Notion 记录
6. 分析创作者为什么有效

**Step 5：查看结果**
- 在 Notion 数据库中查看所有视频数据
- 在 Codex 内直接打开 Notion 预览
- 可直接下载原始视频文件用于剪辑

### 进阶用法
- **视频剪辑师找 B-roll**：在 YouTube 上搜索特定场景（如"Alex Hormozi 在户外走路"），自动拉取视频片段
- **跨平台抓取**：支持 Instagram、TikTok、YouTube、X、LinkedIn、Facebook、Reddit 等 27+ 平台

## 工作流 2：把任何创作者变成一个 Skill

### 目标
从创作者的爆款内容中提取风格模式，封装成一个可重复调用的 skill，让 AI 能模仿该创作者的风格写内容。

### 核心原理
**AI 不擅长从零创作内容，但擅长从范例中复制模式。** 给它好的范例，它就能产出好的内容。

### 具体步骤

**Step 1：在同一个对话中继续**
不需要开新对话，直接在抓取内容的对话里继续。

**Step 2：发起深度研究请求**
```
请做更多研究。
找出他频道上互动量最高的 10 个非赞助视频。
上传到数据库刷新一下。
然后把所有他表现最好的视频变成一个 skill，
叫 "Callaway top performing"。
这样我以后任何时候都能用这个 skill 写他风格的内容。
```

**Step 3：Agent 自动执行**
1. 拉取创作者完整历史内容（可追溯到 2023 年）
2. 过滤掉所有赞助/推广帖子（因为这些互动可能是投流推的，不真实）
3. 保留每个被排除帖子的排除证据
4. 按互动量排序，选出 top 10
5. 在 Codex 中创建 skill 文件（本质上是这些视频的转录稿集合）

**Step 4：在新对话中使用 skill**
```
Command+N 开新对话
输入：Callaway top performing

然后输入任务：
"我想写一个关于 Anthropic 发布的 JSpace 新闻的脚本。
他们发布了一个很酷的东西，我觉得有点难懂。
Callaway 擅长用简单的方式解释事情，
同时又让人觉得紧迫和酷。
请用他的声音写一个脚本，写 3 个版本。"
```

**Step 5：审查和选择**
- AI 会基于创作者的转录稿模式生成多个版本
- 选择最合适的版本使用
- Riley 的经验：Callaway 的风格特点是用"钩子"开头（如"Anthropic 刚刚在 Claude 的大脑里发现了一个隐藏的工作空间"），然后制造紧迫感

### 关键细节
- **过滤赞助内容**：赞助帖的互动数据可能被广告投放扭曲，必须排除
- **历史深度**：让 agent 回溯到 2023 年，确保更早的爆款也能参与排序
- **skill 本质**：就是一个包含优质转录稿的文件，但 AI 能从中提取风格模式

## 工作流 3：抓取竞品广告

### 目标
抓取竞品在 Meta/TikTok/Google 广告库中运行时间最长的广告，分析为什么有效，存入 Notion 数据库。

### 核心原理
**广告运行时长 = 广告效果的代理指标。** 如果一个广告跑了 9 个月还在运行，大概率 ROI 不错——没人会亏钱维持一个无效广告。

### 具体步骤

**Step 1：发起抓取请求**
```
/foreplay API

请抓取我的竞品 quad.ai、Perplexity、ChatGPT 和 Replit
运行时间最长的广告。
放在 Notion 数据库里，先放 Archive 文件夹下测试。
我要所有信息，想看看哪些广告表现好。
在 Notion 数据库里加一个文本字段，
分析每个广告为什么表现好。
每个广告都要有一个文档解释原因。
请创建这个数据库。

还要原始文件。
每个竞品我要 top 5 视频广告和 top 5 静态广告。
确保视频只限英文。
```

**Step 2：选择模型和推理强度**
- 这个任务需要跨大量数据做分析和模式识别
- Riley 先用了默认设置，然后停下来调到 **extra high**
- 理由：需要更智能的分析来判断广告为什么有效

**Step 3：等待 10 分钟**
Agent 会自动：
1. 调用 Foreplay API 抓取每个竞品的广告
2. 按运行时长排序
3. 下载视频和静态广告的原始文件
4. 获取每个广告的转录稿
5. 分析每个广告为什么有效（文案、CTA、紧迫感、框架等）
6. 创建 Notion 数据库（含字段：品牌、广告类型、CTA、运行时长、原始素材、分析文档）

**Step 4：查看分析结果**
数据库包含：
- 广告分类：Replit / ChatGPT / Perplexity / Claude
- CTA 字段：如"注册"、"安装移动 App"、"了解更多"
- 原始创意素材：可下载的视频和图片
- 分析文档：每个广告为什么有效（如"这个 offer 很具体，截止日期制造紧迫感，生日框架让促销感觉像庆祝而不是打折"）

**Step 5：按需筛选**
可以进一步细化请求：
- "只找 CTA 是移动 App 下载的广告"
- "只找视频广告"
- "只找特定时间段运行的广告"

### 关于 Foreplay 工具
- Chrome 扩展：一键保存 Facebook/TikTok/Instagram 广告库中的广告
- Spyder 模块：24/7 自动跟踪竞品广告，每次有新广告就通知
- Discovery 库：超过 1000 万个广告的社区数据库
- AI 简报生成器：从竞品灵感自动生成脚本和故事板
- 广告不会消失：即使品牌停投，Foreplay 也会永久保存

## 工作流 4：Paper + Firecrawl——把广告素材变成自己的

### 目标
把抓取的竞品静态广告放到设计画板上，抓取自己品牌的网站素材，然后用 AI 把竞品广告替换成自己的品牌广告。

### 这是最具即兴创造性的工作流
Riley 在录制过程中现场想到了这个组合——把 Foreplay 抓的广告放到了 Paper 画板上，然后又想到用 Firecrawl 抓自己的品牌网站素材。

### 具体步骤

**Step 1：把静态广告放到 Paper 上**
```
请把所有静态广告放到我现在的 Paper app 上。
```
- 需要已安装 Paper MCP skill
- Paper 是一个 AI 原生的 Figma 替代品（代码原生 HTML/CSS 画板）
- Agent 会自动在 Paper 上创建画板并添加广告素材
- 可以实时看到 AI 在画板上工作的动画

**Step 2：（即兴步骤）用 Firecrawl 抓品牌网站**
```
请用 Firecrawl 去 chorus.com，
找到落地页，
把整个页面抓下来，
放到 Paper 画板上，放在这些广告旁边。

把整个页面放在一个 frame 里，
然后把页面上的所有单独素材放到另一个 frame 里。
一个放 Chorus 网站，一个放网站素材。
```
- Firecrawl 会抓取整个网站，包括所有图片、logo、文字
- 输出为 Markdown 和素材文件
- Agent 自动在 Paper 上创建两个新画板："Website Reference" 和 "Asset Library"

**Step 3：在 Paper 上组装素材**
- 从 "Asset Library" 画板中选出需要的品牌素材（logo、word mark、图标等）
- 复制粘贴到广告旁边，创建一个 mood board
- Paper 支持直接选中元素

**Step 4：用 AI 生成自己的广告**
```
我需要给 Chorus 创建一个新广告。
我给了你 logo、word mark 和一张整体品牌截图。
请把 Replit 的排版替换成 Chorus 的广告。
用好的文案。
OpenAI image 2 就够用了，
可以用真实的文案，它能生成一堆素材。
```
- AI 会参考竞品广告的布局和风格
- 用你的品牌素材替换竞品元素
- 生成文案和视觉

**Step 5：精细化调整**
```
请改这个。
保持人物不变，背景不变，
把 logo 换成我放在下面的那个。
让它说 Chorus 而不是 Replit。
文案改成："Built a $100,000 agent for $50"。
除了颜色改成 Chorus 品牌色之外，其他什么都不改。
```
- 可以逐个元素精细控制
- 可以批量生成多个变体
- Paper 内置图片生成，可以直接修改

### 关于 Paper 工具
- **代码原生画板**：每个元素都是真实的 HTML/CSS，不是私有格式
- **MCP 支持**：24 个双向工具，AI agent 可以直接读取和写入画板
- **内置 AI**：图片生成、背景移除、矢量化
- **Copy as React**：设计可以直接导出为生产可用的代码
- **当前状态**：公共 Alpha 阶段，免费使用

### 关于 Firecrawl 工具
- **开源**（GitHub 111.7K stars）
- **MCP 服务器**：可连接到 Claude、Cursor、Codex 等
- **能力**：搜索网页、抓取页面、批量抓取、结构化数据提取、页面交互（点击、填表）
- **性能**：P95 延迟 3.4 秒，覆盖 96% 的网页
- **Agent 友好**：提供 Skill、CLI、MCP 三种接入方式

## 工作流 7：日历链接排期

### 目标
创建自定义的 Cal.com 日历链接，限定特定日期范围，然后草拟邀请邮件。

### 场景
不同嘉宾需要不同的排期策略：
- 热门话题嘉宾 → 未来几周内约
- 常青话题嘉宾 → 2 个月后约
- 产品发布嘉宾 → 配合发布时间约

### 具体步骤

```
去 cal.com 获取 API key
在 Codex 中粘贴 API key
输入："创建一个完全控制 cal.com 的 skill"
```
一分钟后 skill 就创建好了。

**Step 2：发起请求**
```
我要在播客上和 Shaquille O'Neal 聊 AI，
但这个播客我需要时间准备。
所以可用日期只限周二和周四的排期，
但只有 9 月和 10 月可用。
创建一个文档，写 intro。
给我草拟一封带 Cal.com 链接的邮件。
```

**Step 3：Agent 自动执行**
1. 读取现有 Cal.com 排期设置（默认周二周四中午到下午 5 点）
2. 修改可用日期范围（限制为 9-10 月）
3. 创建自定义日历链接
4. 创建文档并写 intro
5. 草拟邀请邮件

**Step 4：验证日历链接**
- 在浏览器打开链接
- 确认可用日期正确（8 月无、9-10 月有、11 月无）

**Step 5：发送邮件**
- 邮件草稿包含自定义日历链接
- 可以直接在 Codex 内编辑后发送

### 关于 Cal.com
- **开源**：可自托管，也可用云端
- **免费计划**：无限日历连接、无限活动类型、无限预订
- **API 优先**：比 Calendly 更开发者友好
- **API 认证**：只需 API key，不需要 OAuth
- **API 版本**：不同端点需要不同的 `cal-api-version` header

## 工作流 8：邮件草稿批量处理

### 目标
让 agent 分析收件箱，找出需要回复的邮件，批量草拟回复，生成 Gmail 草稿链接供人工审核发送。

### Riley 认为"最有用"的 skill

```
请找到你认为最匹配 Shaq 的邮箱。
如果有公开的联系邮箱，就用那个。
创建一个实际的 Gmail 草稿。
```
- Agent 会在互联网上搜索公开联系方式
- 找到最合适的联系人（不是通用邮箱，而是具体的人）
- 在 Gmail 创建实际草稿（不是在 Codex 里写文本）
- 返回一个 Gmail 草稿链接

**Step 2：打开草稿**
- 点击链接直接在浏览器打开 Gmail
- 因为已登录，草稿直接可用
- 可以编辑后发送
- AI 擅长找出该 CC 谁

**Step 3：批量处理**
```
请找到过去两个月里所有向我推销产品的邮件。
礼貌但带点花样地拒绝——"我先不用了"，
然后话锋一转："你想试试我们的产品吗？"
给他们我们产品的链接，尽量有说服力。
所有这些都要草稿链接，不管多少封。
```

**Step 4：批量审核**
- Agent 返回多个草稿链接
- 逐个打开审核
- 可以快速过一遍，发送或修改
- Riley 的经验：一次处理了 20 封

**Step 5：持续优化**
```
如果 agent 反复犯同一个错误：
"请更新 email draft skill，
以后不要说这个或那个。"
```
- Agent 会记住你的偏好
- 草稿会越来越像你说话的风格
- 可以持续训练 skill

### 核心价值
- **时间杠杆**：20 封邮件的回复从几小时变成几分钟审核
- **个性化**：agent 可以根据邮件内容个性化回复
- **品控**：草稿模式让你始终有最终审核权
- **记忆**：agent 保留你的邮件风格记忆，越用越准

### 典型应用场景
1. **批量拒绝推销 + 反向推销自己的产品**（Riley 的演示场景）
2. **批量联系创作者**：用 ScrapeCreators 抓创作者内容 → 个性化邮件 → 批量草拟
3. **客户跟进**：分析收件箱找出需要跟进的邮件
4. **群发邮件**：AI 找出该 CC 的人

## 对车干的启示

这个视频的核心方法论和车干的"流量打法"高度契合：

1. **内容即产品**：Riley 的方法论本质上是"用 AI 把内容生产效率拉满"——抓取优质内容、学习风格、批量生产、自动发布。这正是车干"内容第一位"策略的技术实现。

2. **0 元路径**：所有工具都有免费额度或免费计划。Codex 包含在 ChatGPT 订阅中，ScrapeCreators 免费 100 credits，Paper Alpha 免费，Cal.com 免费计划无限使用。组合起来的成本极低。

3. **联盟打法的技术基础**：工作流 3-4（抓竞品广告 → 换品牌 → 发布）直接可用于联盟营销——抓取同类产品的爆款广告，换成你的联盟链接和品牌素材，排期发布。

4. **AI = for money**：Riley 的方法论不是炫技，而是每一刀都砍在"省钱省时间"上。用 AI agent 替代人工完成抓取、分析、创作、排期、邮件处理——这就是 10 倍提效搞流量。

5. **双账号模型的技术支撑**：ScrapeCreators + Buffer/Typefully 的组合可以管理多个账号的内容生产，支撑车干"产品号 70% + IP 号 30%"的双账号策略。
