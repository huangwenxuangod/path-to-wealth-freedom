# 文稿→选题 自动化工作流方案

## 工作流概述

将你认为有价值的视频/文章逐字稿，自动转化为飞书多维表格中的选题记录，包含逐字稿原文、AI提炼的选题方向、以及你需要采取的具体行动。

## 完整流程图

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  用户收集素材    │────▶│  放入指定目录    │────▶│  定时任务触发    │
│ (视频/文章链接) │     │ 内容/逐字稿/*.md │     │  每日固定时间    │
└─────────────────┘     └─────────────────┘     └────────┬────────┘
                                                         │
                              ┌──────────────────────────┘
                              ▼
                    ┌─────────────────┐
                    │  1. 读取逐字稿   │
                    │  2. AI分析提炼   │
                    │  3. 生成选题方向 │
                    │  4. 生成行动建议 │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ lark-cli写入     │
                    │ 飞书多维表格     │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │  用户每日查看    │
                    │  选题库，决策    │
                    │  执行/放弃/暂缓  │
                    └─────────────────┘
```

## 飞书多维表格结构设计

### 表格名：选题库

| 字段名        | 字段类型 | 说明            | 示例值                  |     |
| ---------- | ---- | ------------- | -------------------- | --- |
| **标题**     | 单行文本 | 文稿原标题或自定义标题   | "张雪峰谈高考志愿的3个真相"      |     |
| **逐字稿**    | 多行文本 | 完整原文内容        | (完整Markdown)         |     |
| **核心观点**   | 多行文本 | AI提炼的3-5个核心观点 | 1. 信任溢价>信息差...       |     |
| **选题方向**   | 多行文本 | 5-10个可能的选题角度  | 1. "为什么家长愿花2万买志愿..." |     |
| **我需要做的事** | 多行文本 | 具体可执行的行动建议    | 1. 打开省考试院官网...       |     |
| **状态**     | 单选   | 当前处理状态        | 待处理/已确认/进行中/已完成/放弃   |     |
| **优先级**    | 单选   | 执行优先级         | 高/中/低                |     |
| **来源链接**   | 链接   | 原始视频/文章URL    | https://x.com/...    |     |
| **来源类型**   | 单选   | 内容类型          | 视频/文章/播客/论文/报告       |     |
| **创建时间**   | 日期时间 | 自动填充          | 2026-05-10 14:30     |     |
| **选题领域**   | 单选   | 内容领域          | AI/教育/商业/科技/生活       |     |
| **预估工作量**  | 单选   | 完成选题所需时间      | 1小时/半天/1天/3天/1周      |     |
| **记录ID**   | 单行文本 | 飞书记录ID（脚本回填）  | recxxxxxxxx          |     |

## AI分析Prompt（核心）

当定时任务触发时，AI执行以下分析：

### 输入
- 逐字稿全文（Markdown格式）
- 来源信息（URL、作者、平台）

### 分析步骤

**Step 1: 核心观点提取**
- 提炼文稿中最有价值的3-5个核心观点
- 每个观点用一句话概括，附原文支撑句
- 标注哪些观点是「反常识」的

**Step 2: 选题方向生成**
- 基于核心观点，生成5-10个可能的选题角度
- 每个选题包含：
  - 标题（带认知钩子）
  - 内容角度（这个选题从哪个切入点展开）
  - 目标受众（谁会对这个选题感兴趣）
  - 传播平台建议（小红书/即刻/公众号/知乎）
  - 预估数据表现（基于同平台同类内容的历史表现）

**Step 3: 行动建议生成**
- 针对每个高优先级选题，生成3条具体可执行的行动建议
- 必须具体到：打开哪个网站、搜索什么关键词、联系哪种人、看什么报告
- 标注哪些行动可以立即执行（5分钟内），哪些需要准备

**Step 4: 质量自检**
- 检查选题是否与近7天已产出内容重复
- 检查选题是否有可落地的AI结合点或商业洞察
- 检查选题是否匹配你的IP定位（05后大学生AI实战家）

## 技术实现

已创建两个脚本，风格与 `sync-to-feishu.sh` 保持一致：

### 脚本1：初始化多维表格

`scripts/init-feishu-base.sh` —— 首次使用执行一次，创建Base和表格结构。

```bash
# 创建Base和表格（可选指定飞书文件夹）
./scripts/init-feishu-base.sh [folder-token]

# 执行后会输出 Base Token，保存到环境变量
export FEISHU_BASE_TOPIC_TOKEN="Bascnxxxxx"
```

### 脚本2：同步逐字稿到多维表格

`scripts/sync-to-feishu-base.sh` —— 将单份逐字稿写入飞书。

```bash
# 用法
./scripts/sync-to-feishu-base.sh <逐字稿文件> [base-token] [table-name]

# 示例
./scripts/sync-to-feishu-base.sh "内容/逐字稿/某大V视频-20260510.md"
```

### 方式一：纯定时任务Prompt（推荐）

直接在牛马AI的定时任务面板中创建，无需额外脚本。AI自动读取逐字稿、分析、写入飞书。

**Prompt内容见下方「定时任务Prompt全文」。**

### 方式二：Shell脚本 + 定时任务

适合批量处理或集成到其他工作流。脚本已准备就绪，配置好环境变量即可使用。

### 飞书CLI命令速查

```bash
# 创建Base
lark-cli base +base-create --name "选题库" --folder-token <folder-token>

# 查看Base信息
lark-cli base +base-get --base-token <base-token>

# 列出表格
lark-cli base +table-list --base-token <base-token>

# 创建表格（带字段）
lark-cli base +table-create --base-token <base-token> --name "选题库" \
  --fields '[{"name":"标题","type":1},{"name":"逐字稿","type":19}]'

# 插入记录
lark-cli base +record-upsert --base-token <base-token> --table-id "选题库" \
  --json '{"标题":"测试","逐字稿":"内容","状态":"待处理"}'
```

## 定时任务Prompt全文

```
【角色设定】
你是「选题雷达」——一个专门分析X/Twitter大V和科技领域优质内容，并生成可执行选题的AI助手。
你的目标：把用户收集的逐字稿（主要来自X/Twitter AI/科技大V），变成飞书多维表格里的结构化选题资产。

【输入】
用户会将逐字稿以Markdown文件形式提供给你，文件路径为：内容/逐字稿/*.md
文件命名规范建议：YYYY-MM-DD-来源-作者-标题.md
文件内容包含：标题、来源链接（如有）、完整逐字稿文本。

【内容领域聚焦】
- 主要来源：X/Twitter AI/科技领域大V
- 核心领域：AI工具实战、AI商业变现、科技趋势、信息差套利、个人IP/自媒体
- 你的IP定位：05后大学生AI实战家 —— 用AI搞钱、提效、建立壁垒的真实记录

【执行流程】

Step 1: 读取并理解
- 读取指定目录下最新的一份逐字稿（按文件修改时间排序）
- 如果当天没有新文件，则任务结束，记录"今日无新素材"
- 理解文稿的核心主题、作者意图、关键论据
- 标注作者身份（X大V名、粉丝量级、领域标签）

Step 2: 深度分析（必须全部完成）

2.1 核心观点提取
- 提炼3-5个最有价值的核心观点
- 每个观点格式：
  - 观点摘要（15字以内）
  - 详细阐述（50-100字）
  - 原文支撑句（直接引用）
  - 是否反常识（是/否）
  - 与你IP的关联度（高/中/低，为什么）

2.2 选题方向生成（至少5个，侧重AI+大学生视角）
每个选题必须包含：
- 标题（带认知钩子，适合小红书/即刻传播）
- 内容角度（从哪个切入点展开，区别于原文，必须加入你的大学生/AI实战家视角）
- 目标受众（具体人群画像，如"想用AI搞副业的大学生"）
- 推荐平台（小红书/即刻/公众号/知乎/视频号/X）
- 预估互动量（高/中/低，附理由）
- AI结合点（这个选题怎么用到AI工具，或AI如何改变这个领域）

2.3 行动建议生成（至少3条，具体到工具/网址/人名）
- 必须具体到：打开哪个网站/APP、搜索什么关键词、看什么报告、联系哪种人
- 标注执行难度（5分钟/30分钟/半天/1天）
- 标注是否需要AI工具辅助（如需，指明具体工具：Claude Code/ChatGPT/Perplexity/Midjourney等）
- 给出"今天可以做的第一件事"和"本周可以验证的假设"

Step 3: 写入飞书多维表格
- 使用 lark-cli base +record-upsert 命令
- Base Token: 从环境变量 FEISHU_BASE_TOPIC_TOKEN 读取
- Table ID: 选题库
- 写入字段：
  - 标题：文稿原标题
  - 逐字稿：完整原文（前30000字符）
  - 核心观点：分点文本
  - 选题方向：分点文本
  - 我需要做的事：分点文本
  - 状态：待处理
  - 优先级：AI根据内容质量自动判断（高/中/低）
  - 来源链接：如有
  - 来源类型：文章（或根据内容判断）
  - 选题领域：AI工具/AI商业/科技趋势/个人成长/自媒体（自动判断）
  - 预估工作量：1小时/半天/1天/3天/1周（自动判断）
  - 创建时间：当前时间

Step 4: 输出确认
- 告诉用户：今天分析了哪篇素材、作者是谁、生成了几个选题、写入了飞书
- 给出推荐优先级最高的1个选题，附理由（为什么适合你的IP、为什么现在做）
- 给出"今日金句"：从逐字稿中提炼一句最有传播力的话
- 询问用户：是否有选题需要调整优先级？是否需要展开某个选题的深度研究？是否需要生成小红书/即刻版本的草稿？

【质量标准】
- 选题必须与你（大学生AI实战家）的IP定位匹配，禁止纯搬运
- 必须有你的独特视角：大学生怎么做？AI怎么加速？个人开发者怎么切入？
- 每个关键判断必须有原文支撑
- 行动建议必须具体到URL或工具名
- 选题必须包含可落地的AI结合点或商业洞察
- 禁止生成"AI可以颠覆一切"这类空泛选题

【自检清单】
- [ ] 是否提炼了3个以上核心观点？
- [ ] 是否生成了5个以上选题方向？
- [ ] 每个选题是否有明确的内容角度和AI结合点？
- [ ] 行动建议是否具体到工具/网址/人名？
- [ ] 是否与近7天已有选题重复？
- [ ] 是否成功写入飞书多维表格？
- [ ] 是否给出今日金句？
```

## 配置步骤（按顺序执行）

### 1. 初始化飞书多维表格（只需执行一次）

```bash
# 执行初始化脚本，创建Base和表格结构
./scripts/init-feishu-base.sh [folder-token]

# 脚本会输出 Base Token，例如：
# export FEISHU_BASE_TOPIC_TOKEN="Bascnxxxxx"
```

**如果没有 folder-token**：省略参数，Base会创建在你的飞书个人文档根目录。

**如何获取 folder-token**：打开飞书云文档，进入目标文件夹，从URL中复制 `fldxxxxx` 部分。

### 2. 设置环境变量

将脚本输出的 `FEISHU_BASE_TOPIC_TOKEN` 添加到环境变量：

```bash
# 添加到 ~/.bashrc 或 ~/.zshrc
echo 'export FEISHU_BASE_TOPIC_TOKEN="你的BaseToken"' >> ~/.bashrc
source ~/.bashrc
```

**Windows用户**：在系统环境变量中添加 `FEISHU_BASE_TOPIC_TOKEN`。

### 3. 创建逐字稿目录

```bash
mkdir -p "内容/逐字稿"
```

### 4. 创建定时任务

在牛马AI定时任务面板中创建：

- **名称**：选题雷达-每日扫描
- **时间**：每天 21:00
- **重复**：每日
- **Prompt**：粘贴上方「定时任务Prompt全文」

### 5. 日常使用

- 看到X/Twitter好内容 → 转逐字稿 → 保存到 `内容/逐字稿/YYYY-MM-DD-来源-作者-标题.md`
- 每晚21:00定时任务自动扫描 → AI分析 → 写入飞书多维表格
- 次日早上打开飞书 → 查看选题库 → 决策执行/放弃/暂缓

### 补充：手动同步单份逐字稿

如果定时任务之外想手动同步一份：

```bash
./scripts/sync-to-feishu-base.sh "内容/逐字稿/2026-05-10-x-某大V-标题.md"
```

## 注意事项

1. **逐字稿来源**：视频可用飞书妙记/通义听悟/Whisper转文字；文章直接复制或 `lark-cli` 网页转Markdown
2. **Base Token安全**：不要提交到git，使用环境变量或本地配置文件
3. **字段类型**：飞书多维表格字段类型编号：1=文本，3=单选，5=日期，15=链接，19=多行文本
4. **内容长度**：逐字稿可能很长，写入时截断到20000字符以内
5. **重复检测**：AI会自检近7天选题，但建议飞书表格里也加一列「素材哈希」做去重
