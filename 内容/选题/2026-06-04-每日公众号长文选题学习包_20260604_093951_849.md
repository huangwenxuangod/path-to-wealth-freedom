### 可复用标题结构

- **「我用 X 做了一个 Y：Z 小时，普通人也能复制」** — 个人实操 + 时间承诺 + 降低门槛
- **「X 发布了，但我只关心一件事：能不能帮我省钱/省时间」** — 热点 + 实用判断
- **「X 被砍了/涨价了，我找到了 Y 个替代方案」** — 冲突 + 解决方案
- **「X 个月从零到月入 X：一个普通人的 AI 变现复盘」** — 时间线 + 真实数据
- **「别再 X 了，试试这个 Y 方法」** — 否定旧认知 + 给出新方案

- **冲突型**：`「Claude Code 被踢出 $20 套餐后，我找到了零成本的替代方案」`

### 选题 1：我用 Coze 3.0 搭了一个公众号选题雷达 Agent：1 小时，零代码，普通人也能复制

- **推荐标题**：《Coze 3.0 刚上线，我用 1 小时搭了一个公众号选题雷达 Agent——零代码、免费、可复制》
- **一句话观点**：扣子 3.0 的多人多 Agent 协作 + 行业技能包，让普通人也能用 AI Agent 搭建自己的内容生产工作流，而不只是"用 AI 写文章"。
- **为什么适合黄文轩**：AI Coding 实操 + 内容增长 + AI 变现三合一。既有技术含量（Agent 搭建），又能直接服务于公众号内容生产，还能写成教程型长文。
- **类别**：Agent / 工作流自动化 / 中国 AI
- **是否中国 AI / Agent 选题**：✅ 是。本周最重磅中国 AI 事件。
- **可执行边界**：
  - ✅ 扣子 3.0 已全量上线（桌面端 + 网页端 + 手机端），免费可用
  - ✅ 内置自媒体行业技能包，无需从零搭建
  - ✅ 支持 ClaudeCode 一键接入，可用更强模型
  - ❌ 不涉及企业级多人员协作场景
  - ❌ 不做深度编程开发，只做工作流编排
- **强制学习清单**：
  1. 扣子 3.0 项目空间与 Agent 创建机制
  2. 扣子工作流画布（触发器 → 节点 → 输出）
  3. 联网检索插件 + 大模型节点组合
  4. 自媒体行业技能包加载
  5. 输出格式化为公众号选题表格
- **核心概念**：
  - **Agent 团队**：扣子 3.0 核心理念不是"一个万能 Agent"，而是"多个专业 Agent 协作"
  - **项目空间**：Agent、任务、文件在同一个项目中共享上下文
  - **行业技能包**：自媒体/法务/金融/医疗等预训练模板，降低搭建门槛
- **长文主线 / 骨架**：
  1. **开场钩子**：Coze 3.0 发了，最大的变化不是 UI，是"Agent 可以组队了"
  2. **为什么之前不行**：单个 Agent 做选题 = 每次都要从头说一遍需求
  3. **3.0 做了什么改变**：项目空间 + 多 Agent + 行业技能包 + 桌面端
  4. **实操：搭建选题雷达 Agent**（分步截图 + 解释每一步为什么这样做）
  5. **效果展示**：输入一个领域 → 输出 5 个选题的完整表格
  6. **和手动找选题的区别**：效率对比、质量对比
  7. **还能做什么**：扩展到小红书选题、视频脚本、GEO 改写
  8. **结尾**：这个 Agent 可以导出分享，读者扫码就能用
- **文章血肉提示**：
  - 每个步骤配截图（扣子 3.0 界面）
  - 写出"为什么这样设计工作流"而非"点这里点那里"
  - 展示至少 3 次不同输入（AI Coding / AI 变现 / AI 自媒体）的输出结果
  - 对比：用这个 Agent vs 手动找选题，节省多少时间
- **变现 / 引流方式**：
  - 文末提供 Agent 分享链接（扣子支持一键分享）
  - 引流到公众号：「关注后回复"选题雷达"获取 Agent 模板」
  - 后续可打包成「自媒体 Agent 工具箱」（含选题雷达 + 标题生成 + 排版助手）
  - 可录制成视频发 B 站 / 小红书

### 选题 2：Claude Code 被踢出 $20 套餐后，我用 Codegraph + 免费工具搭了一套零成本 AI 编程工作流

- **推荐标题**：《Claude Code 开始收 $100/月，我用一个开源工具把 AI 编程成本砍到了零》
- **一句话观点**：AI 编程工具正在从「一刀切订阅」走向「按量付费 / 高门槛」，但开源社区已经给出了零成本的高效替代方案。
- **为什么适合黄文轩**：AI Coding 核心定位 + 成本敏感（大学生友好） + 开源工具实操 + 「省钱」天然高点击。
- **类别**：AI Coding / Vibe Coding
- **是否中国 AI / Agent 选题**：否
- **可执行边界**：
  - ✅ Codegraph 开源免费，本地运行，无 API 费用
  - ✅ Claude Code 现有 Pro 用户暂不受影响（可用于对比）
  - ✅ 可搭配 CodeBuddy Code（免费）做国内直连方案
  - ❌ 不做全量工具横评，只做「零成本方案」专题
- **强制学习清单**：
  1. Claude Code 定价变化时间线
  2. Codegraph 原理：预索引代码库 → 减少 Token 消耗
  3. Codegraph 安装与配置
  4. Claude Code + Codegraph 组合使用
  5. 国产免费替代：CodeBuddy Code CLI
- **核心概念**：
  - **预索引知识图谱**：提前分析代码结构，AI 编程时不用每次都读全部文件
  - **Token 经济学**：为什么「少发工具调用」比「选更便宜的模型」更省钱
- **长文主线 / 骨架**：
  1. **冲突开场**：Claude Code 从 $20 一刀切到 $100/月起跳，发生了什么
  2. **为什么 AI Coding 越来越贵**：Agent 跑几个小时，推理成本是补全的几百倍
  3. **Codegraph 是什么**：预索引代码结构 = 少读文件 = 少消耗 Token
  4. **实操：搭建 Codegraph + Claude Code 零成本方案**（安装 + 配置 + 效果对比）
  5. **国产替代**：CodeBuddy Code（免费 + 国内直连 + CLI 形态）
  6. **三种方案成本对比表**：Claude Code 原生 / +Codegraph / CodeBuddy Code
  7. **结论**：不是不能用 AI Coding，是要学会"省着用"
