## 4. 今日 5 个优先长文选题

### 选题 1：GitHub 把 AI Coding 的“沙盒+委派”做出来了，我顺手给自己做了一套任务委派板

#### 一句话观点

AI Coding 真正开始实用，不是因为模型更会写代码，而是因为“先沙盒、再委派、再验收”的流程终于变得清晰了。

#### 为什么适合黄文轩

你不是职业后端团队负责人，你更适合写“我如何把 AI Coding 从好玩变成可交付”。这个题能同时展示你的 AI 产品理解、工作流设计能力和最小项目落地能力。

#### 这个选题属于哪类

AI Coding / Vibe Coding

#### 可执行边界判断

- 我个人能做：能。
- 是否需要企业权限：不需要，做的是个人版任务委派板和安全清单。
- 是否需要昂贵 API：不需要。
- 是否需要团队：不需要。
- 是否能用普通账号 / 本地脚本 / 简单页面 / 公开资料完成：能，用 Markdown、表格、GitHub issue 模板思路就能完成。
- 1 天内能完成到什么程度：能完成一份委派板模板、一张安全清单、一篇长文。

#### 强制学习清单

- 看懂 GitHub 关于 third-party coding agents 的安全校验是什么意思
- 看懂 Agent tasks REST API 代表的任务委派形态
- 理解 cloud sandbox 和 local sandbox 各自适合什么任务
- 总结哪些任务适合异步扔给 AI，哪些必须人盯着
- 给自己的 AI Coding 流程拆出“任务输入 / 验收标准 / 风险点”
- 把这些内容写成一页模板

#### 必须搞懂的概念

- 沙盒：先让 AI 在隔离环境里跑，降低直接污染主仓库的风险。
- 任务委派：不是聊天，而是把一个明确任务异步丢给 agent 去做。
- reasoning level：同样一个任务，给模型更高思考预算，通常更稳但更慢。
- 验收标准：AI 不只是生成了结果，而是结果能被你检查。

#### 长文主线：我要怎么学，怎么把学到的东西填进文章

- 开头钩子：你可能已经让 AI 写代码了，但真正卡住你的不是“它写不出来”，而是“我不敢把任务真的交给它”。
- 我今天要先学什么：先把 GitHub 最近 7 天和 AI Coding 直接相关的 changelog 扫完，只摘“跟个人工作流有关系”的点。
- 我学的时候要记录什么：每个更新分别解决什么问题，是效率问题、风险问题，还是任务编排问题。
- 我需要做哪一个最小实验：做一张“AI Coding 任务委派板”，包含任务名、输入上下文、禁止操作、验收标准、交付格式。
- 实验过程里要截图 / 记录哪些证据：GitHub changelog 页面、你自己的模板截图、你怎么把一个真实任务填进模板。
- 哪些内容适合写成“我踩的坑”：过去直接把模糊任务扔给 AI，得到的结果难验收；没写清验收标准，导致返工。
- 哪些内容适合写成“普通人可复制步骤”：任何人都可以先用 Markdown 做任务委派板，不用等 API 权限。
- 哪些内容适合写成“我的判断”：未来比“模型谁更强”更重要的是“谁的任务工作流更顺”。
- 哪些内容适合写成“变现启发”：这套板子未来可以延伸成“AI Coding 代搭流程模板”“AI 协作 SOP 包”。
- 文章结尾应该引导读者做什么：先拿自己一个最小项目，按这张板子试一次 AI 委派。

### 选题 5：看完“Is Grep All You Need?”，我给自己做了一张 AI 研究流程卡

#### 一句话观点

很多人以为 AI 研究就是多搜、多贴、多总结，但真正决定质量的，是你先怎么找、再怎么筛、最后怎么交给模型。

#### 为什么适合黄文轩

你每天都在做选题、研究包、资料整理，这个题能直接作用到你的日常工作流，也能和公众号长文主业务强绑定。

#### 这个选题属于哪类

GEO / SEO / AI Search

#### 可执行边界判断

- 我个人能不能做：能。
- 是否需要企业权限：不需要。
- 是否需要昂贵 API：不需要。
- 是否需要团队：不需要。
- 是否能用普通账号 / 本地脚本 / 简单页面 / 公开资料完成：能，做的是研究流程卡和实验记录。
- 1 天内能完成到什么程度：能做一份研究流程卡和一篇长文。

#### 强制学习清单

- 论文到底比较了什么
- grep retrieval 和 vector retrieval 的差别
- harness 为什么会影响结果
- 你的选题研究流程里哪些步骤更像 grep，哪些更像语义搜索
- 什么时候该先精确搜，什么时候再让模型总结
- 怎么把流程写成给自己能每天复用的卡片

#### 必须搞懂的概念

- grep retrieval：更偏精确匹配、关键词定位。
- vector retrieval：更偏语义相似匹配。
- harness：Agent 调用工具、读取结果、组织上下文的那套外壳。
- agentic search：不是一次搜索，而是“搜索 + 读结果 + 再继续找”的循环。

#### 长文主线：我要怎么学，怎么把学到的东西填进文章

- 开头钩子：我以前以为研究能力差是因为我没找到更强的 AI 搜索工具，后来发现很多时候只是搜索顺序错了。
- 我今天要先学什么：把论文摘要里的核心结论看懂，不延伸过度。
- 我学的时候要记录什么：它比较了哪些 retrieval 策略、在什么条件下 grep 更好。
- 我需要做哪一个最小实验：做一张“个人研究流程卡”，把选题研究分成精确检索、扩展检索、模型归纳、证据回填四步。
- 实验过程里要截图 / 记录哪些证据：论文摘要、你做的流程卡、你用今天选题包做的一次流程示例。
- 哪些内容适合写成“我踩的坑”：一上来就让模型总结，结果来源松、证据弱。
- 哪些内容适合写成“普通人可复制步骤”：先精确找原始事实，再交给模型归纳。
- 哪些内容适合写成“我的判断”：AI 搜索工具越来越多，但研究顺序比工具名更重要。
- 哪些内容适合写成“变现启发”：能沉淀成研究 SOP、选题服务、资料包生产流程。
- 文章结尾应该引导读者做什么：下次研究一个话题，按你的流程卡走一遍。
