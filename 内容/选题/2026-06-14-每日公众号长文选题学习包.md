### 选题 1：Kimi Work + Claude Code 双 Agent 协作实操——300 个 Agent 一起干活是什么体验

- **推荐标题**：`我把 300 个 Kimi Agent 拉进 1 个工作流，13 小时没人管，它自己写完了`
- **一句话观点**：Kimi Work 300 子 Agent + 13 小时连续编码的真正用法不是"看酷炫 demo"，而是"和 Claude Code 组成双 Agent 协作"——一边拆任务、一边写代码、一边质检，这是 2026 年 6 月国产 Agent 真正"1 人 = 1 团队"的最强信号。
- **为什么适合黄文轩**：
  - "AI Coding 实操者 + AI 项目实验者"标签需要持续"第一手实测"国产 Agent
  - 300 Agent 概念是 2026 年 6 月最震撼的国产 AI 叙事点，比单纯测模型更有"内容资产溢价"
  - "双 Agent 协作"是可沉淀方法论，可复用为内部 SOP / 资料包 / Skill
- **类别**：Agent 工作流自动化 + AI Coding
- **是否中国 AI / Agent 选题**：是 ✅（Kimi Work 是月之暗面 Moonshot 国产产品）
- **可执行边界**：
  - 在：注册 Kimi Work 申请内测 → 拆解 1 个真实项目（个人博客 / 数据处理脚本 / 知识卡片生成器）→ 配置双 Agent 协作（Kimi 拆任务 + Claude Code 写代码）→ 记录 13 小时过程
  - 不在：底层模型架构分析、商业化路径分析、企业级部署
- **强制学习清单**：
  1. 阅读 Kimi K2.6 与 Kimi Work 官方介绍（moonshot.ai / kimi.com）
  2. 申请 Kimi Work 内测权限（如未开放则使用 Kimi K2.6 公开 API 模拟 Agent 协作）
  3. 复盘 Claude Code 6 月最新功能（Subagents、Plugins、Hooks）
  4. 学习 MCP（Model Context Protocol）基础，能让 Claude Code 调用本地工具
  5. 设计 1 个 13 小时可完成的双 Agent 协作场景
