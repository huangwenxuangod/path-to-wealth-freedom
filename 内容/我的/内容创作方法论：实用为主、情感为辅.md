# 内容创作方法论：实用为主、情感为辅

> 记录时间：2026-09-16

## TLDR（太长不看）

- 在公司做任何事都是为了自己考虑；第一个做的是自动化验证转发机器人，体现产品思维 = 实用主义（有用的才用，没用的不用，要看到隐藏的痛点再做）
- 后续链路：广告逻辑、官网维护/开发、销售推送通知 → 最新用 MCP 把业务串在一起 → 补数据、补库存、补销售数据，通过 API 抓到一起存
- 存到一起的原因：把数据用 AI 串起来，得出正确结论 / 自动化结果——做出来很多事、写对了就是有价值
- 对内容创作者来说：要创作他们愿意看、想要看的；实用为主，情感为辅（主实用、偏情感）
- 实用价值：把信息提炼成"下一步你可以做什么来提升自己"，给出引导动作；让人明确知道下一步做什么，跟着一步一步做就能拿到结果和收获
- 情感价值：看完"卧槽好有用，收藏一下"；或者作为引路者/探路者分享踩过的坑，狠狠共情
- 我的角色：实用偏情感——主实用、辅感受，提供实用价值
- 做法：每一步拆到最细、流程拆到最清晰；先讲清楚做什么、怎么做（主要功能），可以带文笔和感悟（辅情感），但中间过程必须完整过一遍

## 原文

我在这家公司里面做任何的事情，其实都是为了自己考虑。其实第一步，当第一步进来的时候，我就开始去想。我第一个做的事情是一个自动化的验证转发的机器人。这件事情实际上很能体现我的产品思维，就是实用主义。就是什么叫实用主义？就是说有用的东西我才用，没用的东西我就不用了。要看到里面隐藏的痛，然后再去做。

然后接下来第二个也是类似的，比如它的广告的逻辑，还有一些官网的维护啊、官网的开发，包括销售，对吧？销售推送通知，其实也是和这些强相关的。同时最新的就是 MCP，通过做 MCP 类似的业务把这些东西都串在一起，然后现在又是在补数据、补库存，然后销售相关的这些数据，把它们通过 API 的方式抓到一起，去存在一起。

那为什么要存在一起呢？其实我们要想清楚，就是说我们存在一起的原因是，我想要把通，把这些数据通过 AI 去串在一起，得出一个正确的结论，或者说得到一个自动化的结果。那我们通过这样的方式，其实做出来了很多事情。写的是对的，就是有价值的。那我们就可以去说，哦，是的，没问题的，就是这样做的。那很多时候，他是不是真的这样问，其实不重要。对于他们来说，我们要的是一个结果。

对于我们内容创作者来说，其实那个时候我们要创作出他们愿意看、他们想要看的，就是很实用主义的事情。你本身不能给别人带来太多情感价值的情况，只能主实用偏情感。就是实用肯定是要为主的。就比如说你不是在每天推一个什么消息告诉别人发生了什么事，这只能算一种摘要；但是如果你把这种东西提炼成一个有用的价值，就是从这件事情之中，你下一步可以去做什么来提升你自己。哦，这就是一个引导的动作。那我们就可以通过这样的方式去让他们感受到：你这样去做，那就是实用的价值。下一步，很明确的知道下一步我要做什么，你跟着我一步一步做，你就能拿到结果、拿到收获去提升。

那什么是情感价值呢？就是看完之后，卧槽，好有用啊，我收藏一下，这是他妈的情感价值。还有一些情感战意，就是说我告诉了你一些，你看他大号里，或者说我踩了坑，对吧？我是一个引路者、探路者的角色。我踩到了这些坑，然后我觉得，我操，我为什么会踩这些坑呢？我当时也不知道，对吧？然后我分享，狠狠地共情了，这种感觉就是情感，然后分享出来。同样其实就算是这样的事情，你也会像一个故事一样，就是听完了，我操，共情了，很感动。然后虽然说它没什么用，就是它以情感为主，胡说嘛，对吗？胡说，就是一个小红书的博主，他也没什么用，但是听完了，你会觉得很有共情感。然后你觉得虽然没什么用，但是它是有价值的。

那我的角色，我肯定是一个实用偏情感，就是主实用、辅感受的人。我要提供的是价值，就是实用的价值。那在这种情况下，我一定是要把每一步拆到最细，流程拆到最清晰。那感悟那些也无所谓，对吧？你可以在后面加，就是辅情感；但是前面的介绍啊、告诉别人做什么呀、怎么去做啊，这些就是主要的功能，一定要先讲清楚。你可以带着一些文笔啊什么之类的，这都无所谓，但是一定要把中间的过程完整地过一遍，这个很重要。
