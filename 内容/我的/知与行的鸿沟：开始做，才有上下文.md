# 知与行的鸿沟：开始做，才有上下文

> 2026-09-17 · 口述思考存档 · 飞书原文：https://iigf5k70ohp.feishu.cn/wiki/RRRAwsQAMitpBjkvbp8cyrgWnmn

所以他们总是说，世界上的大部分人就是草台班子。因为我真的，但是想做到他们那样的水平，其实是有难度的。你知道认知到这和你执行到那，其实是有很大的鸿沟。就相当于说，你会说，哦，我知道 Codex 很牛逼，但是你真的会把 Codex 拿出来做成一个教程，做成一个分享给别人看吗？你愿意这样做吗？

同样的道理，为什么别人比你赚得多，别人比你优秀得多？不是因为他真的比你懂得多——当然他也可能真的比你懂得多，因为他做了。开始做了这件事情，他不可避免就要了解更多的上下文，更多跟 AI Agent 相关的上下文，所以他会比你懂得更多。

那举个例子，比如说 Codex，你知道它是个 Agent，你知道你能跟它对话，但是你知道它还有什么功能吗？你有去探索和摸索过吗？因为你想要讲出更多的内容，从 Codex 上挖掘更多的东西，你就不可避免的要深入的研究它，而不是就是泛泛的跟它聊天、跟它对话之类的那些功能。这些都是基本中的基本了。

那对于我们来说，实际上是类似的。我们要研究一个东西，必须要 deep dive in it。我们天生的作为一个创作者，上下文就是要比别人的长，我们就是要 100% 中的 80% 都是在研究，20% 才是在干什么？才是在输出，输出出来成什么内容？就是精华的内容。

天生是这样的。所以说费曼原理，费曼原理它最好最好的应用场景就是内容创作，就是做内容创作。这也可能是我最喜欢的一种方式。从现在开始吧，做研究，反正闲着无聊，做一做。

那为什么之前不做呢？因为之前没有做那种硬的约束。这点还看咸鱼的监督打卡，还是本质有用的。比跟同学监督有用的多，因为他不会每天提醒，那也没有人的压力，没有社交上的压力。你说其实没有说很害怕这种曝光、社交啊，哎呀，但是我很害怕什么？我很害怕的是我坚持不下来，然后没办法打破那种尴尬期，awkward time。这是我最大的问题。

但现在我觉得就还好，对吧？你就越多越好，觉醒，淡定，有前进。你对于内容的理解，不断地尝试。继续往下面做就行了，根本不需要担心的。没什么值得担忧的，一直 keep going 就行。最害怕的就是你不做，这是我最害怕的。你只要开始做了，我觉得一切就还好，真的就其实还好。

你说我真的太贪心了，反而导致了，这个结果，哎，确实不好。
