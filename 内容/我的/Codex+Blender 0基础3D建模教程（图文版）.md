## 一、效果先看：Codex+Blender 能做出什么

Codex+Blender，是怎么搭建出类似这样、这样、还有这样的效果的？先看两个真实案例，感受一下它的上限。

**案例1**：GPT-6 Astra 在 Blender 中复刻旧金山艺术宫，暖光夜景倒映在水面，氛围静谧，原推浏览量 260 万。（来源：Sharif Shameem 推文，2026-09-04）

**案例2**：把一张蒸汽火车的旧图纸丢给 Astra，它在 Blender 里重建出 3295 个可编辑的精细模型对象，几何结构美观。（来源：Tom Krcha 推文，2026-09-04）

> 这两个案例想说明一件事：3D 建模的门槛正在被 AI 拉平——你不需要会建模，只需要会说需求。

## 二、准备工作：装好 Codex 和 Blender

作为一个 Blender 纯新手，怎么从 0 到 1 通过 Codex 实现 3D 建模自由。看完这篇，你也可以搓出自己的第一个 3D 建模。

正式开工前，先准备好两个老朋友：**Codex** 和 **Blender**。

> 💡 **找不到 Blender 也不用担心：** 直接在 Codex 里输入「帮我下载和安装好 blender。」，它就能帮你把 Blender 自动下载、安装、启动好（实测用时 1 分 25 秒，安装 Blender 5.2.1 LTS 并验证启动）。

### 认识一下 Blender 界面

Blender 就是一个帮助你进行 3D 建模的软件，打开之后会看到正中间放着一个盒子（Blender 5.2.2 界面，中间默认有一个立方体 Cube）。

可能看到这么多复杂的按键和设置，很多人就晕了。但是没关系——我们可以通过**对话的方式**让 Codex 直接操作 Blender 帮我们建模，你不需要学会任何一个按键。

## 三、安装 Blender MCP：搭起 Codex 和 Blender 之间的桥

要让 Codex 能直接操作 Blender，需要先安装一个 **Blender MCP**——它相当于 Blender 和 Codex 之间的桥梁，装上之后 Codex 才能调用 Blender 的建模功能。

在 Codex 里输入：「帮我安装和下载 blender 的 mcp，搜索」

安装完成后可以看到：MCP 服务端已启用、Codex 状态 enabled、握手测试成功、可用工具 26 个。这一步是关键，装上之后 Codex 就"会"操作 Blender 了。

### 第二步：退出重启 Codex，正式开始建模

重启之后，我们只需要向 Codex 讲清楚我们需要的是什么，它就能够理解并搭建起来。

先来一个最简单的场景——生成一个红色的小球。输入：「blender mcp 创建一个红色金属球体，放在坐标（0，0，2），添加地面和三点灯光。」

大概过了 8 分钟，直接创建成功了。Codex 生成了红色金属球体（坐标 0,0,2、金属度 0.92、粗糙度 0.16）、地面，以及 KeyLight、FillLight、RimLight 三点灯光，还自动调整了相机。

作为练手之作，整体的效果还是很不错的。整个过程甚至不需要你自己打开 Blender 操作，说一句话，它帮你建模、打光、摆相机、出渲染。

## 四、总结：从 0 到 1 的完整路径

| 步骤 | 做什么 | 提示词 / 操作 |
| :--- | :--- | :--- |
| 1 | 安装 Blender | 「帮我下载和安装好 blender。」 |
| 2 | 安装 Blender MCP（桥梁） | 「帮我安装和下载 blender 的 mcp，搜索」 |
| 3 | 退出重启 Codex | 让 MCP 生效 |
| 4 | 用一句话描述需求 | 「blender mcp 创建一个红色金属球体，放在坐标（0，0，2），添加地面和三点灯光。」 |
| 5 | 等待 Codex 建模 + 渲染 | 全程无需自己打开 Blender 操作 |

## 这件事真正重要的地方

这样的玩法可能会颠覆整个 3D 建模行业的工作方式——以后一个好看的建模，可能不再需要一个个手搓，而是一个好的 prompt 就能直接生成。

> 3D 建模的门槛正在从"会建模"变成"会描述"：你说得清需求，AI 就能把模型做出来。对零基础的新手来说，这是前所未有的机会。

这套"Codex 会操作软件 + MCP 搭桥 + 一句话生成"的组合，不只适用于 Blender——凡是需要专业软件的场景（设计、剪辑、表格、开发），都在被同样的逻辑重写。
