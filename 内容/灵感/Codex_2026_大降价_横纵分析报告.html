一、一句话定义

OpenAI 在 2026-04-02 把 Codex 从「按消息/按 PR 算钱」改成「按 token 积分算钱」，并把 ChatGPT Business 座位价从 $25/月砍到 $20/月。表面是降本让利，本质是「计价单位」和「价格档位」被整个赛道重新校准的信号弹。

二、纵向分析：从 2021 老 Codex 到 2026 改价

2.1 产品身份辨析：三次「Codex」是三个东西

要讲清这次改价，必须先把「Codex」这个名字在五年里被复用三次的事说清楚。

  • Codex v1（2021 模型）：GPT-3 在 159GB GitHub Python 代码上微调出的模型。代表是 code-davinci-001/002 和 code-cushman-001。它驱动了最初的 GitHub Copilot，也是 ChatGPT 的直系祖先。2023-03-23 被 OpenAI 正式废弃。
  • Codex v2（2025 Agent）：2025-04-16 开源的 Rust 终端 agent（Codex CLI），同月还上线了 chatgpt.com/codex 里的云端 Codex Agent（基于 codex-1 模型）。这次的 Codex 不是一个模型，是一个 agent 框架。Apache 2.0 开源，活跃至今。
  • Codex v3（2026 模型回归）：从 2026-02 的 GPT-5.3-Codex 起，Codex 第三次成为 OpenAI 代码专用模型的名字。callback 到 2021 战略。

用户说的「Codex 大降价」，指的是 Codex v2 这条产品线（即 2025-04 那个 Agent），改的是它的计费模型，不是换了个底层模型。danielvaughan.com 2026-04-11 的总结很到位："The name 'Codex' has returned — not as a model, but as an autonomous coding agent. [...] After three years of the 'generalist is good enough' strategy, OpenAI returned to code-specialised fine-tuning with GPT-5.3-Codex."

2.2 阶段一：老 Codex 时代（2021-2023）

故事要从 2021 年讲起。

那年 7 月，OpenAI 发了 Codex 的论文（arXiv:2107.03374），把 GPT-3 的 12B 版本在 159GB Python 代码上微调，HumanEval 上做到 28.8% pass@1。这是 AI 写代码这件事第一次有了「专门为此训练」的模型。

2021-08-10，code-cushman-001（~2.5B）和 code-davinci-001 通过 API 私有 beta 发布。同期 GitHub 用它做了 Copilot 的代码补全引擎。2022 年 code-davinci-002 发布（更大上下文、更好指令遵循），然后就成了 GPT-3.5 的底座。

再到 2022-11-30，ChatGPT 发布。它用的 GPT-3.5，直接源自 code-davinci-002。换句话说，老 Codex 是 ChatGPT 的爹。

但 OpenAI 做了一个决定：2023-03-23，正式废弃了 code-davinci-002 和 code-cushman-001 的 API。理由是「GPT-3.5-turbo 在代码任务上已经够用，不需要专门的代码模型」。老 Codex 时代结束。

这一步决策在当时看是合理的。GPT-3.5-turbo 跑代码任务比 code-davinci-002 还便宜、还快，专门维护一个代码模型显得浪费。

但 OpenAI 当时不会想到，这次「去 Codex 化」会埋下后面 2026 改价的所有伏笔。

2.3 阶段二：通用模型主导的「去 Codex 化」时期（2023-2024）

2023-03-14，GPT-4 发布。HumanEval 67%，比老 Codex 强了 2 倍多。OpenAI 内部越来越确信「通用模型做代码足够好」的判断。

之后两年，OpenAI 一路在通用模型上加码：

  • 2023-11-06：GPT-4 Turbo preview（128K 上下文）
  • 2024-04-09：GPT-4 Turbo GA
  • 2024-05-13：GPT-4o（90.2% HumanEval，5× 更快，50% 更便宜）
  • 2024-07-18：GPT-4o mini（87.2% HumanEval，取代 GPT-3.5-turbo）
  • 2024-09-12：o1-preview + o1-mini 发布，首个「推理模型」，o1-preview 92.4% HumanEval

这一阶段，OpenAI 的战略是清晰的：通用模型在所有维度上超越专用模型。代码只是众多能力之一。

与此同时，竞品的「代码专用化」路线已经悄悄开始。Anthropic 在 2023 年起就坚持以 Constitutional AI 路线做安全 + 推理，并在 2024-2025 年初靠 Claude 3.5 Sonnet 在代码任务上拿到 90%+ HumanEval，吃下了一大波企业付费用户。

更关键的是，Anthropic 在 2024 年底发布了 Claude Code——一款终端 AI 编程 agent。它一开始只对 Max 档用户开放，但因为终端体验极好（直接在 shell 里跑、读 git diff、写 commit message），很快成了独立开发者圈的事实标准。

OpenAI 看到 Claude Code 吃下市场的反应是迟缓的。直到 2025-04 才下场。

2.4 阶段三：Codex v2 回归 + Agent 化（2025-04 ~ 2025-12）

2025-04-14，OpenAI 一次性发了 GPT-4.1 系列（1M 上下文、SWE-bench Verified 54.6%）、o3 和 o4-mini。

2025-04-16，Codex CLI 开源（Apache 2.0，Rust 写），与 o3、o4-mini 同日发布。Greg Brockman 在社交媒体力推。OpenAI 官方称它是「a coding agent that runs in your terminal」。

Simon Willison 同日评价（Prompt engineering is so weird，2025-04-16）把它定位为「OpenAI 版的 Claude Code」，但特别强调开源这个差异点。他同时吐槽 macOS 沙箱（sandbox-exec）实现「under-documented」，Linux/Windows 沙箱文档不足。

Codex CLI 首发时的产品决策有几个值得展开的：

第一，选了「开源」路线，与 Anthropic 闭源形成对比。 这不是 OpenAI 一贯的风格。它愿意把核心 agent 开源，赌的是开发者会围绕它建生态，类似 VS Code 反超 Sublime 的路径。

第二，Codex 这个名字被有意回调。 OpenAI 在 system prompt 里特别叮嘱「不要把你跟 many moons ago 的老 Codex 模型搞混」——这是一个有意的命名策略，把「做代码的 OpenAI 品牌」重新捡起来，即使这次它是 agent 不是 model。

第三，发售价定得很克制。 CLI 本身免费开源，但调用模型需 ChatGPT 订阅（Plus $20 或 Pro $200）或 API key。没有 free tier。codex-mini-latest（默认模型，o4-mini 基础）：$1.5 input / $6 output per 1M tokens，缓存 75 折。

第四，沙箱实现粗糙。 macOS 用系统自带的 sandbox-exec，但没怎么写文档；Linux/Windows 直接裸跑。这是个安全隐患，也是为什么 Simon Willison 同日发的博客会专门提。

紧接着一个月，2025-05-16，OpenAI 又发了云端 Codex agent（基于 codex-1 模型，o3 的代码特调版），接入 ChatGPT 侧边栏。首发 tier：Pro、Business、Enterprise；Plus 6-3 才开放。云端 agent 对订阅用户「前几周免费」，之后将限速 + 灵活按需付费。

2025-09-15，GPT-5-Codex 发布——这是 Codex v2 第一次「自带专用模型」。SWE-bench Verified 和大型仓库重构都超标准 GPT-5；支持 7+ 小时独立工作。

到 2025 年底，Codex App（桌面）推出，Codex 整体从研究预览转正（GA）。Ars Technica 2025-12-12 报道了一个有意思的细节：「The vast majority of Codex is built by Codex」——Codex 在用 Codex 写自己。

2.5 阶段四：Codex v3 模型回归 + 2026 大降价（2026-01 ~ 2026-06）

2026-02-05，GPT-5.3-Codex 发布。56.8% SWE-bench Pro，77.3% Terminal-Bench 2.0，agentic 任务比前代快 25%。Codex 这个名字第三次成为模型名前缀，callback 到 2021 战略。

2026-03-18，GPT-5.3-Codex 成为 Copilot 首个 LTS 模型（支持到 2027-02-04）。这是给企业客户的信心背书。

2026-03-05，GPT-5.4 发布（57.7% SWE-bench Pro，1M 上下文，128K 最大输出）。

2026-04-02，🔥 核心事件：大降价。

WinBuzzer 2026-04-04 的报道给出了改价细节：

"On April 2, 2026, we updated Codex pricing to align with API token usage, instead of per-message pricing. This change was applicable to new and existing Plus, Pro, ChatGPT Business and new ChatGPT Enterprise plans."

具体改了什么：

  • 计费单位：从「N credits per message」改成「credits per 1M tokens」，分 input、cached input、output 三档
  • ChatGPT Business 座位价：$25 → $20（-20%）
  • 新档「Codex-only seat」：纯按量、无限速
  • 新工作区促销：$100/user 信用（最多 $500），4 月 30 日到期
  • 触发因素（OpenAI 公开说）：Codex 达到 200 万周活用户后，按次计费已无法准确反映实际 token 消耗

OpenAI 2026-04-09 顺势推出 $100/月 ChatGPT Pro 新档。5× Plus 的 Codex 额度。直接对标 Anthropic 2025 年底推出的 Claude Max 5x（$100/月）。

2026-04-16，OpenAI 又搞了一场大升级：「Codex for (almost) everything」。包括后台操作 Mac（多个 agent 并行）、内置浏览器、Memory（预览）、Image 生成（gpt-image-1.5）、90+ 新插件、主动建议、长期自动化。同期 Anthropic 也在推 Cowork + Claude 远程控制 Mac，TechCrunch 标题就是："OpenAI takes aim at Anthropic with beefed-up Codex"。

2026-04-23，GPT-5.5 发布（代号 Spud，SWE-bench 88.7%，幻觉减少 60%）。同日 token-based 定价扩展到所有现有 Enterprise 套餐（Edu、Health、Gov、ChatGPT for Teachers）。

2026-06-14（调研日），Codex CLI 最新版本 v0.139.0，累计 837 个 release，90.9k stars，13.4k forks，96% Rust。

几个具体例子：

例子 1：Plus 用户做 1 个 cloud task（GPT-5.3-Codex）
- 改前：扣 ~25 credits
- 改后：实际 token 决定。假设任务 50K input + 5K output，缓存命中 80%：
- Input: 40K × (43.75/1M) = 1.75 credits
- Cached Input: 10K × (4.375/1M) = 0.044 credits
- Output: 5K × (350/1M) = 1.75 credits
- 合计 ~3.5 credits（改前的 14%）
- 含义：轻量任务大幅便宜，小任务用户获益。

例子 2：Pro 用户做大仓库 refactor（GPT-5.5，跑 7 小时）
- 改前：可能按「local task × N 个」算，几百 credits
- 改后：假设累积 1M input + 200K output，缓存命中 50%：
- Input: 500K × (125/1M) = 62.5
- Cached Input: 500K × (12.5/1M) = 6.25
- Output: 200K × (750/1M) = 150
- 合计 ~219 credits
- 含义：重型用户成本基本持平，无显著爆涨。

例子 3：企业按 seat vs 按量
- 改前：Business $25/seat × 100 人 = $2,500/月
- 改后：
- 方案 A：Business $20/seat × 100 = $2,000/月（降 20%）+ 超量按 token 买
- 方案 B：50 个 standard seat（$20）+ 50 个 Codex-only seat（按量）+ $500 促销 credit
- 典型企业总成本降 20-40%

例子 4：个人用户，Plus → Pro（新）
- 改前：Plus $20 月费 + 经常爆 Codex 限额
- 改后：
- $100 Pro：5× Plus Codex 额度（直接对标 Claude $100 档）
- $200 Pro：20× Plus 额度
- 个人重用户成本约 +$80-180/月，但额度充裕，无频繁限速。

2.7 决策逻辑：为什么是 2026-04-02，不是更早也不是更晚

这一节是整个纵向的精华——OpenAI 为什么选这个时点改价？

三个原因叠加在一起：

第一，Codex 200 万周活 + 6× 增长。 2026-01 起到 4 月，Codex 企业用量 6× 增长，年化收入 $1B+（WIRED 数据）。按消息计费已经不能反映真实的 token 消耗。计费单位已经「扭曲」了真实价值。如果不改，OpenAI 自己都不知道用户付的钱覆盖了多少算力成本。

第二，Anthropic Claude Code Max 5x 已经把 $100 档立住了。 2025 年底 Anthropic 推出 Claude Max 5x（$100/月），迅速吸走一批原本用 ChatGPT Pro $200 的重度用户。OpenAI 必须有个对标档——但单纯复制 $200 档对标没意义，$100 才是市场真正空缺的中端档。

第三，Codex-only seat 是一个「让企业不全部压在主套餐上」的产品创新。 之前 Business $25/seat 的问题在于「我有一半开发者是偶尔用 Codex 的，给他们 full seat 不划算」。Codex-only seat 让你给这批「偶尔用」的开发单独买按量额度。本质是「池化信用」的变体——微软后来在 2026-06 用「Copilot Enterprise 池化信用」证明这是 CFO 唯一能接受的 AI Coding 采购方式。

而 4 月这个时点也卡得刚刚好：GPT-5.3-Codex（2026-02）和 GPT-5.4（2026-03）刚铺完，模型阵容最齐；GPT-5.5（2026-04-23）正好在改价三周后接上，让新计费体系「第一个能用的最强模型」就是 GPT-5.5，制造一波关注。

换句话说，2026-04-02 是产品（Codex 跑通）、市场（中端档缺口）、对手（Anthropic Max）三件事同时撞在一起的窗口。 OpenAI 没理由再等。

三、横向分析：AI Coding 工具定价图谱

3.1 赛道的五种定价范式

2026 H1，AI Coding 工具的定价可以分成五种范式：

  1. 按月订阅（平价，$10-20）：Cursor Pro $20、Cursor Business $40、Claude Pro $20、GitHub Copilot Pro $10、Codex Plus $20、Windsurf Pro $15
  2. 按月订阅（信用池）：Cursor/Copilot/Codex 信用额——全部在 2025 H2 ~ 2026 H1 切到 token 计量
  3. 按 token（API 模式）：Aider、Cline、Continue、OpenHands 等开源 CLI 工具
  4. 按结果/任务（outcome-based）：Devin ACU（每 Compute Unit）、Factory（按 PR）
  5. 席位打包（企业）：GitHub Copilot Enterprise、Tabnine Enterprise、Windsurf Enterprise

范式 1 和 2 的边界在 2025 年底开始模糊——Cursor、Codex 这些表面是订阅的，本质已经在用 token 计量信用了。

范式 4（按结果）是最有想象力的，也是最不被 CFO 接受的。Devin 的 ACU 账单经常超出预算 2-3 倍，2026 H1 已经有多家企业退回按席位采购。

3.3 按月 vs 按 Token：两种范式的优劣

按月订阅：
- 优点：用户成本可预测，公司收入稳定
- 缺点：公司侧不可控——重度用户用得越多，公司成本越高但收入不变
- 用户视角：「我每月花 $20 心里有底，但不知道用得值不值」
- 公司视角：「我卖一个月就收一个月，但用户用爆了反而亏钱（罕见但有）」

按 token 计量：
- 优点：成本与使用量挂钩，对公司侧完全可控
- 缺点：用户难以预测——「一次会话花多少 token」对普通用户是黑盒
- 用户视角：「我怕爆量，但也不知道什么算爆量」
- 公司视角：「我赚的是用得多的用户的钱，但失去的是怕爆量的用户」

OpenAI 这次改价的本质是「按月 + 按 token」的混合模式：保留 Plus/Pro 订阅（用户可预测）作为入口，订阅内的实际消耗按 token 计量（公司侧可控）。这其实是 Cursor 2024 H2 就开始做的模式，OpenAI 2026 H1 才追上。

更深一层：这次改价新增了「Codex-only seat」按量档，本质是给「偶尔用 Codex」的开发单独买按量额度，避免企业主套餐被「轻度用户」拖高单价。这跟微软 2026-06 在 Copilot Enterprise 推的「池化信用」是同一个思路——大企业的 AI Coding 采购模式，正在从「按席位包月」转成「订阅+池化信用」。

3.4 三档价格对齐的真相

$20 / $100 / $200 三个档位，Cursor、Copilot、Codex、Claude Code、Windsurf 五家集体对齐。这不是巧合。

这是市场对「个人 / 重度个人 / 多 agent」三档用户群的价格发现。

$20 档：覆盖 80% 轻度用户。功能克制，主要服务「一周用几次做点小活」的场景。

$100 档：2024 年底前几乎不存在。Anthropic 2025 H1 推出 Max 5x 时，押的就是「中度全职用户」这个空缺——他们觉得 $20 不够用、$200 太贵，每月愿意付 $100 的人是真实存在的。OpenAI 2026-04 跟进 $100 档，验证了 Anthropic 的判断。

$200 档：重度用户/多 agent 并行。Anthropic 2024-12 推出 Pro $200，OpenAI 跟 $200 Pro，Cursor 跟 Ultra，5 家全在 $200 档有产品。这是「有真实需求但只能容纳 5-10% 头部用户」的档位。

这个三档结构会成为 2026-2027 年的行业公约数。任何新进入者都会按这三档定价，超出这个区间的要么死（太贵卖不动），要么亏（太便宜活不下去）。

四、横纵交汇洞察

4.1 历史如何塑造了当下的竞争位置

回到纵向时间线，再看今天的竞争格局，会发现一切都不是偶然。

OpenAI 的「去 Codex 化」（2023-2024）让它在 2025 H1 的 AI Coding 工具赛道上慢了一拍。 Claude Code 2024 年底就上线了，OpenAI 2025-04 才用 Codex CLI 跟上。这一拍慢的代价是——2025 全年 ChatGPT Pro $200 的销量基本被 Claude Max 5x $100 抢走了一大半。这就是为什么 2026-04 的改价必须同时做两件事：（1）把 Codex 计费从「按消息」改成「按 token」对齐赛道；（2）推出 $100 Pro 档补回中端档缺口。

反过来，Anthropic 的「不专门做代码模型」（2023-2024）让它在 2025 H2 后的代码任务上一直靠通用 Sonnet 顶。 2025-09 OpenAI 推出 GPT-5-Codex 时，Sonnet 4.5 在 SWE-bench Verified 上落后了 5 个百分点（89% vs 94%）。到 2026-02 GPT-5.3-Codex 发布，差距拉到 10+ 个百分点。Anthropic 直到 2026 H1 才回过味来，开始在内部推专门的代码模型——但发布节奏已经慢 OpenAI 一拍。

Cursor 的「编辑器 + 信用池」模式在 2024 H2 已经被验证可行，但 2025 全年都没做出真正的差异化。 它的护城河是「编辑器集成度」（Composer 体验、Tab 补全），但底层模型始终是「Claude + OpenAI + 自研小模型」的混合。2026 H1 Cursor 面对 Codex 改价 + Claude Max 加码的双重夹击，它的生存策略大概率是「强化 Composer 的多 agent 能力」+「绑死在企业合规」。

4.2 竞品的纵向对比

把 Codex、Claude Code、Cursor、Copilot 也放到时间线上对比，会发现四家走出了四条完全不同的路：

时间 OpenAI Anthropic Cursor GitHub Copilot
2021-2022 Codex 模型首发 → Copilot 用它 — — Copilot 首发用 Codex
2023-2024 通用模型化（去 Codex 化） Claude 3 / 3.5 起势 Composer 起步 跟随 OpenAI 模型
2025 H1 Codex CLI 开源（4-16） Claude Code 闭源发布 Composer 1.0 Copilot Workspace
2025 H2 GPT-5-Codex 专用模型 Claude Max 5x $100 档 Ultra $200 档 微软协议谈判
2026 H1 改价 + Codex-only seat Max 20x + Cowork Ultra 加 agent 池化信用 + 2026-06 叫停 Claude Code

核心差异：
- OpenAI：技术领先（专用模型 + 算力），但产品节奏慢（2025 才跟上 Agent 化）
- Anthropic：产品体验领先（Claude Code 终端体验），但模型能力被 OpenAI 反超
- Cursor：编辑器体验领先（Composer），但模型和技术都依赖第三方
- GitHub Copilot：生态领先（绑定 GitHub），但创新能力最弱

4.3 优势与劣势的历史根源

OpenAI 今天的优势，根源在 2021-2022 的早期 Codex + GitHub Copilot 合作。那时候 OpenAI 跟 GitHub 合作让 Codex 引擎被几百万开发者用上，OpenAI 积累了「AI Coding 该长什么样」的第一手数据。这份数据是 Anthropic、Cursor 都没有的。

OpenAI 今天的劣势，根源在 2023 年的「去 Codex 化」决策。当时 OpenAI 砍了代码专用模型，把所有资源投向通用模型，结果在 2024-2025 年 AI Coding agent 化浪潮里慢了 6-12 个月。这是「通用模型为王」假设在代码领域被证伪的代价。

Anthropic 今天的优势，根源在 2023 H2 的「坚持闭源 + 端到端优化」。Claude 3 / 3.5 / 4.x 的代际跃迁节奏比 OpenAI 慢，但每代都做到了「安全 + 推理 + 代码」三件套的稳定。这让它在企业市场（特别是金融、医疗、政府）拿到大批长合同。

Anthropic 今天的劣势，根源在 2024-2025 年「不愿做代码专用模型」。Claude Code 2024 年底发布时，跑的是通用 Sonnet 4.5，没有 code-specialized fine-tune。这让 Anthropic 在 SWE-bench 类代码任务上一直落后 OpenAI 5-10 个百分点。

Cursor 今天的优势，根源在 2023-2024 年「押注编辑器体验」。Cursor 把 VS Code fork 后做了大量编辑器集成优化（Composer 体验、Tab 补全、Codebase Indexing）。这是 OpenAI/Anthropic 都不可能短期复制的工程壁垒。

Cursor 今天的劣势，根源在 2023-2024 年「不自研模型」。Cursor 始终依赖 OpenAI + Anthropic 的 API 调模型，没有自研模型的能力。这意味着任何 OpenAI/Anthropic 推出自己的 IDE 集成（Codex App、Claude Code 桌面版），都在侵蚀 Cursor 的护城河。

剧本 A：最可能（60% 概率）—— 三档价格公约数被锁死，「订阅+池化信用」成企业默认

  • 2026 H2 ~ 2027 H1：所有企业采购都从「按席位包月」转成「订阅+池化信用」——微软已经用 Copilot Enterprise 证明这是 CFO 唯一能接受的 AI Coding 采购方式
  • 2027：OpenAI 推出 GPT-6 系列，Codex 改价模式被进一步推广到所有 ChatGPT 内部工具

  • 2026 H2：微软把 GitHub Copilot 整合进 Microsoft 365 全家桶（Word、Excel、Outlook、Teams），给企业「买 Office 送 Copilot」的捆绑价

剧本 C：最乐观（15% 概率）—— 出现「AI Coding 工具的 Linux 时刻」

  • 2027 H1：开源 AI Coding agent 工具（Cline、Continue、Aider）爆发，吞掉 30%+ 市场份额
  • 2027 H1：「订阅+池化信用」模式在中小企业和独立开发者中被开源工具挤压
  • 2027 H2：OpenAI/Anthropic 必须开源模型或大幅降价才能保住份额——AI Coding 工具的定价从「$20-200/月」降回「$0-50/月」

4.5 写给车干（文轩）的实战判断

最后这节单独写给你。作为「毕业前靠 AI + 技术 + 自媒体赚 100 万」的大学生车干（你自己定的目标），这次 Codex 改价对你的实战有什么指导意义？

第一，个人订阅档位怎么选？

按月成本 $20 的 Plus 适合你现在的状态（轻度使用），但你迟早会跑重项目（黑客松、Side Project、内容创作的素材处理），到时 Plus 会爆额。直接上 $100 Pro 5x 是性价比最优解——比你单独买 Plus + 偶尔 API 更划算。$200 Pro 20x 现阶段不要碰，那是给「同时跑 5+ agent」的人准备的。

第二，企业/团队/客户开发怎么用？

如果未来你接外包单（公众号文章里你已经写过 Cockpit Tools 多账号管理），给客户做开发时需要 Codex 的高额度，直接配 API key 按 token 走——成本清晰、可预测、可以给客户报实价。不要在订阅里算账，容易爆。

第三，自媒体选题怎么蹭？

这次改价 + GPT-5.5 发布 + $100 Pro 档推出，是一个完整的「AI Coding 工具定价权正在被重新校准」的故事。你可以从这几个角度写：

  1. 「Codex 改价后个人/企业成本对比实测」（带真实账单截图，结构化表格）

  3. 「为什么 AI Coding 工具都在做池化信用」（产品策略分析，连接微软 Copilot）
  4. 「$100 Pro 档值不值：5 个重度使用场景实测」（深度评测）

每个角度都能写一篇长文，且每篇都有真实数据支撑（OpenAI 官方 rate card + WIRED 数据 + 用户社区声音）。

第四，长期资产怎么沉淀？

这次研究本身就是一份「AI Coding 工具定价知识库」——把它放到 内容/项目/方法论拆解/ 目录下，未来每次 OpenAI/Anthropic 调整定价，你都可以更新它。这会变成你 AI Coding 赛道认知的「母版本」。

最后，最关键的一个判断：

2026 H1 的这次改价，本质是 OpenAI 把 AI Coding 赛道的「定价权」从「公司单方面定」转成「公司 + 市场 + 对手」三方博弈。这次三方博弈的均衡点就是 $20/$100/$200 三档。所有玩家——OpenAI、Anthropic、Cursor、Copilot、Windsurf——都在往这个均衡点靠拢。

未来 12 个月，看新进入者能不能打破这个三档公约。看开源模型能不能把价格打到 $0-50。看「按结果计费」能不能在企业市场找到落脚点。

这三件事的进展，会决定 2027 年 AI Coding 赛道是「继续按月订阅主导」、「按 token 直购主导」、还是「按结果计费主导」。
