# 03. AI 漫剧 / 短剧 产业链与玩家图谱

> 上游 IP 库 → 中游 工具+制作 → 下游 平台+投流+变现

## 产业链全景

```
【上游：IP 版权方】
  ├─ 阅文集团（10 万部 IP + 亿元基金）
  ├─ 番茄小说（字节系，IP 库最大）
  ├─ 知乎（盐言故事 IP）
  ├─ 七猫（百度系）
  ├─ 漫画公司（快看、腾讯动漫、有妖气）
  └─ 原创作者（独立编剧）

【中游：技术工具 + 内容制作】
  ├─ 基础大模型
  │   ├─ 视频：可灵(快手)、即梦(字节)、Veo3(Google)、Vidu(生数)、Sora2(关停)
  │   ├─ 图像：Midjourney、GPT-image 2.0、SD、Flux
  │   └─ 音频：ElevenLabs、智声、Suno、ChatTTS
  ├─ 全栈平台
  │   ├─ 剧火 AI（Seedance 2.0）
  │   ├─ 次元神笔（中文在线）
  │   ├─ 漫剧助手（阅文）
  │   ├─ NOVA AI（山海星辰，"一人剧组"）
  │   └─ OpenClaw（多 Agent 协作）
  ├─ 头部内容方
  │   ├─ 酱油动漫（《洪荒：代管截教》）
  │   ├─ 星火动漫
  │   ├─ 麦芽传媒（生态合作）
  │   ├─ 山海星辰（StardustTV）
  │   └─ 万兴科技（"剧本广场"）
  └─ 中小团队（90%）
      └─ 3-5 人作坊，主题材、爆款率极低

【下游：分发平台 + 投流 + 变现】
  ├─ 国内分发
  │   ├─ 字节系：红果短剧（1.4 亿月活）+ 红果漫剧 APP + 抖音 + 番茄
  │   ├─ 快手系：可灵 AI + 磁力聚星
  │   ├─ 百度系：柚漫剧 + 七猫漫剧
  │   ├─ 长视频：爱奇艺漫剧频道、腾讯视频火龙漫剧
  │   └─ 网文系：阅文 ToonScroll（海外）
  ├─ 海外分发
  │   ├─ ReelShort（枫叶互动，中文在线系）
  │   ├─ DramaBox（九州文化）
  │   ├─ NetShort、GoodShort、FlickReels
  │   ├─ TikTok（2026Q1 AI 短剧分成 200 万美元）
  │   └─ YouTube、Instagram Reels、Facebook
  ├─ 投流渠道
  │   ├─ 国内：巨量千川、磁力金牛、快手粉条
  │   └─ 海外：Meta Ads、Google Ads、TikTok Ads、Snapchat
  └─ 变现
      ├─ IAP（29%）：用户付费解锁
      ├─ IAA（71%）：广告分账
      ├─ 抖音 S+ 级：75 万保底 + 3 万/分钟
      └─ 海外：订阅 + 单集付费 + 广告
```

## 头部玩家（按梯队）

### T1：平台巨头（3 家）

| 公司 | 核心动作 | 投入 |
|------|---------|------|
| **字节跳动（红果+抖音+番茄）** | 红果 1.4 亿月活，5 亿真人扶持，红果漫剧独立 APP（2025.11） | 月内容预算 3 亿+ |
| **阅文集团** | 10 万 IP + 亿元基金 + ToonScroll 海外 + 漫剧助手 AIGC 工具 | 亿元级 |
| **快手** | 可灵 2.5 Turbo 漫剧优化 + 8 亿分账计划 + 单项目最高 50 万现金 | 200 亿美元估值 |

### T2：上市公司（4 家）

| 公司 | 核心动作 | 投入 |
|------|---------|------|
| **中文在线** | FlareFlow（3300 万+ 用户）+ 次元神笔 + 港股上市 | 75% 募资 |
| **昆仑万维** | "剧启 AI"计划 + 海外发行 + 自研视频模型 | 百万美金级 |
| **掌玩（听花岛）** | FlickReels + 下一代 Netflix 计划 | 10 亿级 |
| **点众科技** | 双 10 亿全球 AIGC 计划 | 1.5 亿美元海外 |

### T3：头部内容方（4 家）

- **酱油动漫**：从酱油文化转漫剧，《洪荒：代管截教》爆款
- **星火动漫**：多题材稳定输出
- **麦芽传媒**：生态合作计划
- **山海星辰**：StardustTV + NOVA AI 平台

### T3：海外双雄

- **ReelShort**（枫叶互动）：1.3 亿美元/季（Q1 2025）
- **DramaBox**（九州文化）：1.2 亿美元/季（Q1 2025）

### T4：万家中长尾

- 3-5 人作坊为主
- 90% 亏损
- 30% 在 6 个月内倒闭
- 不到 5% 能稳定输出

## 关键判断

1. **"两超多强 + 万家作坊"** 的格局
2. **没有"康师傅 vs 统一"这种品牌效应**——AI 漫剧行业最大缺口是"品牌"
3. 三巨头（字节/阅文/快手）正在吃掉中游利润空间
4. 中小团队"被 AI 卷死"是必然——只能靠"垂类题材 + 海外本土化"求生
