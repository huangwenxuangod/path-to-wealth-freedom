## 0. 开场定调（00:00–02:08）

Greg 的核心观察：**今天做 startup 最难的不是做产品——vibe coding 已经让做东西变得极其简单——最难的是获客、是把客户带到产品面前产生收入。**

很多人都在谈"营销 Agent"，但没人真正讲透它是什么、怎么搭。这期 Cody Schneider 端到端讲清楚两件事：

1. 一个他真心看好的创业点子（AI for WordPress）
2. 营销 Agent 是什么、怎么部署、需要哪些工具，如何成为一个"Agent 管理者"

Cody 承诺的交付：不是 Zapier 那种线性自动化流程，而是**"跑在云端的代码，基于你实时业务数据做决策"**的真 Agent；外加具体的公司类型示例，让你看清 Agent 在真实业务里长什么样。

## 1. 什么是真正的营销 Agent（02:08–04:03）

Cody 直言：网上把"营销 Agent"喊得震天响的人，一深聊就露馅。他给出的严格定义——营销 Agent 必须满足三件事：

1. **解决数据问题**：给 Agent 一个统一的数据视图，让它看得到整条 pipeline（从广告到收入）。
2. **自主决策**：Agent 按某种节奏（cadence）自主做决策，内部有一个"思考循环"（thinking loop）。
3. **基础设施**：需要数据管道（data pipeline）+ 数据仓库（data warehouse）+ 云端托管 Agent 的能力。

关键祛魅：**Agent 不需要是那种"AGI 级自主思考"的东西——Cody 明确说他根本不想要那个。** 他要的是：执行一个流程 → 看数据 → 根据回流的数据自我改进。就这么朴素。

但另一面也别低估：**现在完全可以让一个 Agent 独立跑整个 Facebook 广告**——研究目标客户的痛点和期望结果、生成符合品牌规范的素材（静态图 + AI 数字人 UGC 视频）、发布进广告账户、关掉失败的、加码赢的、再进入反馈循环分析什么在起作用、照着最佳表现者做更多素材。

## 2. 创业点子：AI for WordPress（04:03–09:44）

### 为什么是 WordPress

- **Google 索引的所有网站里约 43% 是 WordPress**（Greg 说 50%+，Cody 现场查证是 43%）。
- 但**几乎没人在给 WordPress 生态做 AI 产品**——一个体量巨大却无人执行的蓝海。Cody 说他把这个点子 pitch 给过 3 个进了 YC、不知道往哪 pivot 的创始人，全被拒了。

### 产品形态：Lovable for WordPress

- 让用户能在 WordPress 平台上"vibe code"自己的网站（对话式改设计）。
- **打包策略**：把用户原本要东拼西凑的十几个插件（表单、CRM 等）捆成一个套餐。
- **收费模式**：卖 token。比如 $29/月基础档给 X 量 token，用 token 驱动建站/改design。
- 价值主张：原来要付 10 个插件的钱，现在付 1/10 或 1/5 的价格全都有，还能对话改设计。

### Greg 的延伸：比 Lovable for WordPress 更大的机会

Greg 19 岁时是一家代理公司的合伙人，官方与 WordPress 合作，专做"把大网站从自有 CMS 迁到 WordPress"（做过 time.com、techcrunch.com）。他见过 WordPress/Automattic 插件生态里"荒谬级"的钱。

他的打法总结：**找到有验证需求、但没有 AI 化的插件，做每一个的 AI-first 版本。** 需求已被验证、用户已在付费，你只是用 Agent 把它做好 10 倍：

| 老插件 | AI-first 版本 |
|---|---|
| Yoast SEO | 不再给你红绿点让你自己改——Agent 直接写 meta、重构内容、加内链 |
| WPForms | 静态表单 → 会对话的表单 Agent，能筛选线索（qualify lead）、答疑 |
| WooCommerce | AI 店长：自动写商品描述、弃购挽回流程 |
| Akismet（反垃圾） | AI 化 |
| Wordfence（安全） | AI 化，让用户"再也不用想插件安全"，网站不会被挂赌博广告然后被 Google 除名 |

难点两个：把产品做好 + 找到能真正获客的分发渠道。——这就引出下半场：怎么用 Agent 做分发。

## 3. Facebook 广告的新玩法：Andromeda 时代（10:17–12:56）

### Andromeda 是什么

Facebook 的新广告算法。**兴趣定向（interest targeting）已死**——以前你会定向"对 WordPress 感兴趣的人"，现在不需要了。

Andromeda 的工作方式：AI 直接**理解你的广告素材本身**——静态图里有什么、文案是什么、视频脚本讲什么，再理解你落地页的内容——然后据此决定把广告投给谁。

### 实操含义

你只需要做一件事：**让素材直接对目标客户的痛点/期望结果说话**，然后指向一个说清产品的落地页，Facebook 自己会找到人。

Cody 的暴论（但他是认真的）：**Facebook 已经变成当今最好的 B2B 广告渠道。** 他们做过极其小众的广告——全美可能只有 10 个人正面临那个问题——Facebook 能找到那些人，给他们看广告，拿回高质量 B2B 线索。

### WordPress 产品的广告脚本长什么样（可直接抄的结构）

> "有点离谱。我以前每月付 $1000 给代理公司维护我的 WordPress 网站，他们响应慢、设计也做不出我要的。但我刚发现一个 WordPress 插件，让我能直接和 AI 对话改网站，还内置了所有我原来要额外付费的插件，免费包含。点链接了解。"

跑这样的广告，Facebook 会自动识别出"这些人是 WordPress 站长、有这个痛点"，然后你在漏斗深处设置转化事件（注册、付费）。

## 4. Agent 生产素材的完整流水线（13:14–17:45）

### 第一步：痛点调研（用 Perplexity 扒 Reddit）

Prompt 思路：`扒 Reddit，找 WordPress 站长的痛点和期望结果——他们为什么会买一个"解决所有插件问题+能 vibe code 网站设计"的 AI WordPress 工具`

**为什么选 Reddit**：那里是真人在真实抱怨（Greg 补充）。Cody 自嘲：Reddit 正在被像他这样为了 LLM 排名而操纵内容的人侵蚀（"我就是死互联网问题本身"），但目前依然是挖痛点的最好来源。

第二步 prompt：`按被提及次数排序（rank stack），给我 top 3 痛点`。示例结果：
1. 插件层混乱（被提及最多）→ 广告主打这个
2. 性能和速度 → 产品侧考虑用 Astro 这类轻量方案伺服内容
3. 安全与维护 → "让他们再也不用想插件安全"

**这份调研产出物 = 后续所有 creative 的种子。**

### 第二步：批量生成静态素材

- 工具：Kai AI（聚合所有图像/视频模型的平台），底层用 **Google Nano Banana** 生图。
- 方法：给模型一个参照——竞品或相邻行业正在跑的真实广告——让它照着结构生成。
- **品牌一致性控制**：定义 brand style guide（字体、颜色、品牌规范），生成后**再压一个视觉模型（vision model）做质检**：文字是否可读？字体是否 on-brand？不合格的过滤掉。

### 第三步：视频素材（AI 数字人 UGC）

- 现在效果最好的还是 **HeyGen**（Cody 自己都惊讶，因为它并不是技术最强的）。
- 正在实验 **Seedance**（字节），这是未来方向；瓶颈是单段只能生成 ~9 秒以内，30 秒广告需要跨片段拼接（stitching），一致性是挑战。
- 内容 = AI 数字人口播你在第一步扒出来的痛点/期望结果。

**以上每一步都是 Agent 在做**：调研是 Agent 做的、API 调用生成素材是 Agent 做的。

### 第四步：发布进 Facebook——Marketing API 的正确用法

关于"用 Agent 跑广告被封号"的真相：**封号不是因为用了 Agent，是因为违反 TOS**——那些人拿 API 疯狂拉取几亿行数据，把 API 当数据抽取管道刷爆了。

**正确姿势：Facebook Marketing API 只用来"写"**——发布广告、关停广告、加码广告。**读数据走另一条路**（见下节的数据仓库）。

## 5. 数据基础设施：管道 + 仓库（18:50–23:12）

### 开源方案（人人可用）

- **数据管道：Airbyte**（开源、自托管，有大量预建 connector，把各数据源的数据泵进仓库；可以直接让 Claude Code 帮你搭）
- **数据仓库：ClickHouse**（开源、自托管）

### 数据仓库是什么（Cody 的白话解释）

把所有数据源统一到一个地方，让 Agent 能**在全渠道上下文里**理解数据。具体到"怎么把 Facebook 广告跑有效"，你需要至少四类数据进同一个仓库：

1. Facebook Ads 数据
2. Google Analytics 数据
3. Posthog（产品行为）/ CRM（如 HubSpot）数据
4. **Stripe 数据**——这是关键：只有它能回答"我投了广告，最后到底有没有客户和收入从另一头出来"，并把**具体哪条广告在给公司挣钱**追溯出来。

### 闭环结构（Cody 现场画的图，文字版）

```
多个数据源（FB Ads / GA / Stripe...）
        ↓ Airbyte 管道
    数据仓库（ClickHouse）
        ↕ 读
   Facebook Ads Agent
        ↓ 写（Marketing API）
     Facebook Ads 账户
        ↓ 产生新数据
     回流进数据仓库 → 循环学习
```

### 附赠能力：对话式分析

仓库搭好后，你和团队可以在 Claude Code / Codex 里**直接和自己的业务数据对话**、搭自定义看板。Cody 举例：一家商用 HVAC 公司问"这个月工资快发不出来了，哪里出问题了？"——答案可能是"你的应收账款堵了"。营销数据、业务数据，全都能这么聊。

### Agent 托管

不需要 Mac mini 在家当服务器（虽然很多人真这么干）。部署到任何云：Heroku、Railway 等都行。**Agent 本质就是代码**：一个决策树 + 实时数据流 + LLM 思考循环 + 一个优化目标（对多数公司就是"怎么让业务多挣钱"）。

## 6. 实战运行数据：全自动广告循环（24:11–26:07）

Cody 团队正在给客户跑的真实配置：

- **每天 2 个 ad set × 每组 5 条广告 = 日产 10 条广告**，基于调研 + 仓库里"什么曾经有效"的数据自动生成并上传。
- **学习循环**：发布 10 条 → 跑 2–3 天拿初始信号 → Agent 从仓库拉数据，**关掉最差的，赢家存活**。
- **赢家池（winners pool）**：胜出的 ad set 进池子，互相竞争可用预算。
- **素材基因库**：他们建了一个数据库，存所有发给 Nano Banana 的 JSON prompt、发给 HeyGen/Seedance 的广告脚本，让 Agent 分析"到底什么在起作用"，从而越做越准。

## 7. 熵问题（Entropy）：Agent 的最大暗坑（26:07–27:09）

**问题**：Agent 会陷入同一种思维定势，生成的素材越来越同质化（熵增/近亲繁殖）。Greg 强调没人谈这个："那些说'搭好就一劳永逸'的人，从来没真正搭过——第一天感觉很好，第二天差一点，第三四五天持续劣化。"

**两个已验证的解法（往系统里注入新 DNA）**：

1. **Facebook Ads Library**：拉竞品广告库的素材喂给 Agent 当新的源文本。
2. **YouTube / 播客转写文本**：有几百个专门讲 WordPress（或任何垂类）的 YouTube 频道，把 insight 提取出来，基于这些聚合洞察做广告。

**终态形容**：这就是一个"虚拟员工"——只专注 Facebook 广告这一个渠道，因为它拥有思考"什么在驱动业务收入"所需的全部数据。

## 8. 为什么是付费广告（28:06–31:13）

### Greg：Facebook 是最划算的获客方式

- Vibe code 出产品后最大的问题永远是"客户从哪来"。内容当然要做，但内容起量需要时间；Facebook 是**成本效率最高**的路径。
- **新手最大错误**：试了几条广告没效果就放弃。正确做法是**同一条广告换 10/15/20 种 positioning**。Greg 自己经常被结果吓到——"我根本没想到这个定位能跑通"。例子：做 Yoast 竞品，可能最能跑的定位是"anti-Yoast"（Yoast 让你自己干活，我们替你干活）。

### Cody：别当 Don Draper

- 很多人进营销的心态是"我知道市场要什么，我要把我的想法强加给市场"——**完全反了**。我们不是《广告狂人》，我们是把 creative 扔进市场做测试。
- **付费广告是史上最强营销渠道的原因**：可以测 1000 条素材，48 小时内清晰知道市场对什么最买账。
- "只做 organic / 只靠口碑"是菜鸟视角。付费广告是唯一"投 1 美元、可能出来 5 美元、并且可以持续往里喂钱维持同样倍数"的 ATM 系统。

### 为什么现在时机成熟了

以前想这么玩，得雇每月几万美元的代理公司。**现在一个创始人自己搭这套系统就行**——当然需要调优、需要解决熵问题，但门槛从"几万美元/月"降到了"会用 Claude Code"。

## 9. 营销的新范式：Campaign 已死，持续流才是常态（31:50–34:37）

- 老思维：营销 = campaign（启动一件事，然后停止）。**新现实：营销是持续不断的循环**，因为反馈回路已经快到没有"停"的概念。
- 类比：时尚行业的趋势更替速度是 20 年前的 10 倍。一切趋势都发源于**短视频社交**，再向下渗透。你必须对市场有持续的 observability，随趋势实时调整广告、定位、整个 GTM。
- **趋势探测工具**：Viral Loop（有 API），扒全 TikTok（可能还有 Instagram Reels）——"给我看美妆品类过去一周最爆的帖子"→ 有什么趋势/概念格式 → 反哺 creative 产出。这也是解熵的第三条路。
- **规模对比**：过去做 100 条广告投进 Facebook ≈ 2 周工作量。现在一个创始人**一个半小时**就能把整套系统搭起来，规模化发布，且知道什么在起作用。可以先 human in the loop，跑明白了再把 Agent 部署到云端全自动。

### 营销人的职业未来

Cody 每周都被营销人问"我的工作安全吗"。他的回答："不知道，你会做这个吗？" **营销人的新职业 = Agent 骑师（agent jockey）**：把你的领域知识编码进 Agent。Cody 强调自己"不是技术出身"——现在模型聪明到半技术人员 + Claude Code 就能搭出来。他甚至说：**把这期播客的转写文本直接扔给 Claude Code，说"我要搭这套系统，带我走一遍"，就能开始。**

## 10. 预告清单：其他可部署的营销 Agent（35:15–37:15）

Cody 快速列了一串（观众点播决定下期讲哪个）：

1. **Google Ads Agent**——完整接管 Google 广告账户
2. **网红外联 Agent**——调研垂类 KOL → 冷邮件 → 谈价 → 合适人选时举手叫人
3. **冷邮件 Agent**——找到目标客户 + 邮箱 → 发信 → **Agent 管理收件箱**、回复约会议
4. **TikTok 矩阵农场**——云端开 10 个 TikTok 账号，规模化做产品相关图文轮播（slideshows），排程发布、聚合流量数据
5. **SEO Agent**——关键词调研 → 文章调研 → 写作 → 保持品牌语气 → 注入独特观点让内容既好读又能排名
6. **AI 搜索/引用建设 Agent**——冷外联把品牌塞进你所在品类已被 AI 引用的 citation 列表
7. **社媒管理 Agent**——代运营 LinkedIn / Twitter 账号
8. **播客+Newsletter Agent**——调研播客 → 写脚本 → ElevenLabs 配音 → 做 lead magnet → 在播客之上为某个行业（如电商）建 email list
