## 模板 6：Chrome Web Store 上架清单

```
## 上架前检查清单

### 技术准备
- [ ] manifest.json 中 version 编号正确
- [ ] permissions 声明最小化（只声明实际使用的权限）
- [ ] 所有外部资源使用 HTTPS
- [ ] 代码无 console.log 调试信息
- [ ] Content Security Policy 配置正确
- [ ] 在 chrome://extensions 本地加载测试通过
- [ ] 无明显 bug 和报错

### 视觉素材
- [ ] 插件图标 128×128 (.png)
- [ ] 商店截图 1280×800（至少 1 张，建议 3-5 张）
- [ ] 宣传小图 440×280
- [ ] 宣传大图 920×680 或 1400×560

### 文字素材
- [ ] 插件名称（≤45 字符）
- [ ] 简短描述（≤132 字符，显示在搜索结果）
- [ ] 详细描述（支持 HTML 格式）
- [ ] 隐私政策链接（如果处理用户数据）

### 提交
- [ ] 支付 $5 注册费（一次性）
- [ ] 提交审核
- [ ] 等待 1-3 个工作日

### 审核通过后
- [ ] 确认插件在 Web Store 可以搜索到
- [ ] 准备推广内容
- [ ] 设置 Google Analytics 追踪（可选）
```

## 模板 7：AI 插件 Prompts 调教模板

```
## 电商产品描述生成 Prompt

ROLE: 你是亚马逊资深产品文案专家，擅长撰写高转化的英文产品描述。

TASK: 根据用户提供的产品参数，生成一段电商产品描述。

REQUIREMENTS:
- 开头用一句话抓住注意力
- 列出 3-5 个核心卖点（Bullet Points 格式）
- 结尾包含购买号召
- 语气：专业但不生硬，像真人卖家而非机器
- 字数：80-150 词
- SEO：自然包含产品核心关键词

产品参数：
- 产品名：{product_name}
- 品类：{category}
- 材质：{material}
- 尺寸：{dimensions}
- 颜色：{color}
- 使用场景：{use_case}
- 目标客户：{target_customer}

---

## 小红书文案生成 Prompt

ROLE: 你是一个资深小红书博主，擅长写高互动的种草文案。

TASK: 根据网页内容/产品信息，生成一篇小红书笔记。

REQUIREMENTS:

- 注意：不要写「家人们」「绝绝子」等过气用语

参考网页/产品信息：
```
