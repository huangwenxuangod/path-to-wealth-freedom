#### 项目类型

AI Coding / Coding Agent

#### 为什么值得看

Reasonix 是市面上少数**专门为 DeepSeek 模型深度优化**的终端 AI 编程助手。它不是又一个 Claude Code 包装器——它的核心设计围绕 DeepSeek 的 Prefix Cache 机制，让长会话的 Token 成本保持在极低水平。v1.0 用 Go 重写，编译为单个静态二进制文件（CGO_ENABLED=0），跨平台一键分发。

关键技术亮点：支持 executor + planner 双模型协作模式（如 flash 执行 + pro 规划），插件系统兼容 MCP 协议（外部工具通过 stdio JSON-RPC 接入），精细的权限控制（ask/allow/deny 三级 + 命令白名单/黑名单）。

信号意义：DeepSeek 生态正在形成自己的工具链闭环——不只是模型厂商，而是围绕模型构建完整的开发者工具生态。

- **一句话说明**：AI 驱动的跨平台全能自动化助手，像 J.A.R.V.I.S 一样操控你的电脑——浏览器自动化、桌面控制、屏幕理解、定时任务、记忆系统一站搞定。

#### 项目类型

AI Agent / 桌面自动化

#### 为什么值得看

NutBot 不是又一个"聊天 AI"。它的核心能力是**直接操控你的电脑**——打开浏览器填表单、操控微信/QQ 等桌面应用、截图分析屏幕内容、执行系统命令、定时自动执行任务。本质上，它把一个完整的 AI Agent 循环（感知→思考→行动）封装成了一个 Web UI + MCP 插件系统。

它的架构很有意思：Gateway 统一入口 → Agent 决策层 → Tools 执行层（Browser/Computer/Screenshot/Exec）→ Memory 记忆系统 → Cron 定时调度。同时原生支持 MCP 协议，可以通过配置接入任何 MCP Server（如 filesystem、web 等），扩展能力极强。

更关键的是，它支持自定义 Skills——在 `skills/` 目录放 `.md` 文件即可自动注入到 Agent 的 system prompt。

#### 为什么适合黄文轩

1. **AI 产品实验者**：NutBot 本身就是一个"AI 个人助手"产品的完整实现，可学习其架构设计
2. **AI Coding 实操者**：TypeScript + Vue 3 技术栈，前端/全栈方向大学生友好
3. **内容创作自动化**：用它来自动化内容发布流程——定时截图、自动填表单、批量操作
4. **"文轩拆 AI 项目"栏目**：一个完整的 AI Agent 项目拆解案例
5. **个人效率工具**：真的可以部署到自己电脑上，日常使用

#### 可执行边界判断

- **个人能跑**：✅ 本地部署，yarn install + yarn dev 即可启动
- **企业权限**：❌ 不需要
- **昂贵 API**：❌ 支持任意 OpenAI 兼容 API（包括 DeepSeek/Minimax 等低成本方案）
- **复杂部署**：⚠️ 需要 Node.js 18+ 和 yarn，Chrome 扩展需要手动安装
- **适合时间**：1 天可跑通，3 天可深度改造
- **最大风险**：桌面控制能力涉及模拟键盘鼠标，可能被安全软件拦截；个人项目，部分功能可能不稳定
