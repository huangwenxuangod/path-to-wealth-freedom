#### 项目类型

AI Coding / Coding Agent

#### 为什么值得看

DeepSeek 第一次为一个社区 Agent 项目写进了官方文档推荐位。Reasonix 不是又一个 Claude Code 克隆——它有意不支持多后端，只绑定 DeepSeek，这不是限制而是策略：DeepSeek API 有独特的字节级前缀缓存机制（prefix-cache），当请求的 prompt 前缀与历史请求一致时，缓存命中部分的 Token 几乎免费。Reasonix 的 append-only 运行循环专门为此设计，让代理在整个长会话中持续命中缓存。

结果：一份晒账单显示 4.35 亿 Token 仅花了 12 美元。对比 Claude Code 在同等长会话下的成本，这是降维打击。

v1.0 用 Go 从头重写，编译成单一静态二进制，零依赖分发。同时支持 MCP 协议、Skills 系统、Web 搜索（8 种引擎）、QQ 远程通道、Tauri 桌面端。

信号意义：国产模型 + 国产开发工具 + 极致成本优化，这是「AI 编程工具的 DeepSeek 时刻」。

#### 为什么适合黄文轩

1. **AI Coding 实操者**：直接在自己的项目里使用，npm 一行命令装好即用
2. **大学生 AI 实战家**：DeepSeek API 价格极低（Flash 版输入 1 元/百万 Token），学生完全负担得起
3. **科技 AI 自媒体**：「DeepSeek 官方推荐 + 4.35 亿 Token 只花 12 美元 + 中国开发者的 AI Coding Agent」天然是爆款话题
4. **对比测评价值**：可以做 Reasonix vs Claude Code 的实操对比，这正是公众号读者想看的内容

#### 可执行边界判断

- **个人能跑**：✅ Node.js >= 22，`npm install -g reasonix`，5 分钟跑通

7. **额外验证**：输入 `/pro` 切换 V4-Pro 模型体验增强推理，输入 `reasonix doctor` 检查环境

Local Deep Research 用 7,800+ Star 和 MIT 协议回答了一个问题：「能不能在我自己的电脑上跑深度研究？」答案是可以，而且效果不差。它用 LangGraph Agent 做自主决策（搜索策略、引擎切换、信息合成），支持 10+ 搜索引擎（SearXNG、arXiv、PubMed、Semantic Scholar、Google、Bing 等），可以用 Ollama 本地模型完全离线运行，也可以用 OpenAI/Claude API 获得更强效果。

最惊艳的数据：用 Qwen3.6-27B + SearXNG，在 RTX 3090 单卡上 SimpleQA 达到 95% 准确率。这意味着隐私和性能不再对立。

#### 项目类型

内容自动化 / 信息聚合 / AI 工具

#### 为什么值得看

Horizon 解决的是内容创作者的经典痛点：信息源太多，值得看的内容太少。它不是又一个 RSS 阅读器，而是一个完整的信息处理流水线：信息源 → 抓取 → 去重 → AI 评分 → 过滤 → 背景补充 → 摘要生成 → 多渠道分发。

最重要的设计理念：「AI 帮你降噪，但信息品味仍然由人决定」。Horizon 不强制你用哪种信源、打多少分算通过、用什么语言输出——全部可配置。它提供框架，你定规则。

对于正在做 AI 自媒体的黄文轩，Horizon 可以直接作为内容生产链路的前端——自动监控技术动态，筛选出值得写的内容，生成结构化的选题简报。而且支持 GitHub Pages 免费发布，不需要服务器。

#### 项目信息

#### 项目类型

Browser Agent / 社交媒体自动化 / AI Agent

#### 为什么值得看

LocoAgent 解决了社交媒体自动化的核心难题：平台封 API、封无头浏览器、封异常登录。它的方案简单而聪明：不碰 API，不搞无头浏览器，直接用你已经在 Chrome 里登录好的真实会话，通过 CDP（Chrome DevTools Protocol）像真人一样操作。

它的架构值得学习：平台技能系统（32+ X.com 操作手册注入 Agent）、工作流引擎（纯浏览器自动化流水线，不需要 LLM 参与也能跑）、操作日志（跨会话去重，避免重复操作）。创始人马诗剑的背景也值得关注——从市场营销到数据科学，再到 UCL 机器人感知实验室，这个跨界路径本身就是一个好故事。

提供的示例工作流非常实用：抓取 Hugging Face Daily Papers → AI 挑选论文 → 读取论文 → 发到 X → 自动回复。整个流程一句命令完成。

#### 为什么适合黄文轩

1. **AI Coding 实操者**：代码量不大但架构清晰，是很好的「Agent 代码学习样本」
2. **科技 AI 自媒体**：社交媒体自动化 + AI Agent + 真实浏览器操作，写教程的素材非常丰富
3. **实操价值**：可以直接用来管理自己的社交媒体账号（批量发内容、自动回复、信息聚合）

#### 可执行边界判断
