# 示例：SEO 是啥？

## 问题
SEO 是啥？

## 正确路由

### Step 1：先分类
- `question_type`: `concept_explainer`
- `needs_code_evidence`: no
- `needs_user_feedback`: no
- `needs_freshness`: low
- `needs_authority`: high
- `geo_bias`: mixed
- `local_first`: yes

### Step 2：先查本地知识
当前仓库已有：
- `内容/AI牛马/概念深度学习-示范-SEO.md`

这说明这个问题不该直接 GitHub first。

### Step 3：再补权威解释
如需外部校准，再查：
- 官方/权威 SEO 定义
- 搜索引擎抓取、索引、排名机制

### Step 4：如果用户继续追问工具和实操
再补：
- GitHub 上的 SEO audit / crawler / site analyzer / indexing tooling 项目

## 为什么这样路由

因为这个问题本质上在问：
> SEO 的概念、机制和本质是什么？

它首先需要的是：
- 定义
- 机制
- 权威解释

而不是：
- 某个 GitHub repo
- 某个社交平台的二手观点

## 错误路由示范

错误做法：
1. 直接 Tavily/Google 搜一圈
2. 顺手带几个 GitHub repo
3. 没有先看本地已有深度内容

这样会导致：
- 忽略仓库里的高质量资产
- 回答更像拼接结果，而不是基于认知沉淀

## 正确输出应该长什么样

至少包含：
- SEO 的朴素定义
- 它和抓取/索引/排名的关系
- 为什么人们容易误把 SEO 理解成“堆关键词”
- 如果继续深挖，下一步应该看哪些工具或案例
