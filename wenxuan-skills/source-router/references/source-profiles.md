# source-profiles

## 目标

这个文档定义每种信息源的：
- 最擅长回答什么问题
- 最不擅长回答什么问题
- 应该怎么用
- 检索失败时如何回退

---

## 1. 本地知识库 / 跨会话记忆

### 最擅长
- 你已经研究过的问题
- 仓库内已有文档、方法论、热点报告
- 长期沉淀的个人判断

### 不擅长
- 最新发布且还未写入知识库的内容
- 强时效性新闻

### 使用方式
优先先查：
- `mem-search`
- `knowledge-agent`
- 仓库内相关 Markdown

### 代表场景
- SEO 是啥？
- 之前有没有写过精准搜索方法论？
- 最近 3 天有没有做过类似热点分析？

### 回退
如果本地已有内容不够，再补：
- 官方资料
- GitHub
- 社区讨论

---

## 2. GitHub

### 最擅长
- 开源项目
- 代码实现
- README / example
- issue / discussion / PR
- 维护状态与生态成熟度

### 不擅长
- 权威概念解释
- 非技术人群的需求语言
- 封闭平台里的真实内容生态

### 使用方式
不只看 repo 名字，要看：
- README
- stars / forks
- recent activity
- issues / discussions
- releases / docs

### 代表场景
- 有没有现成项目？
- 哪个库更适合个人开发者？
- 这个方案是不是只是 demo？

### 回退
如果 GitHub 不够：
- Reddit 看真实体验
- 官方文档看规格
- 视频内容看上手实操

---

## 3. Reddit

### 最擅长
- 用户真实反馈
- 踩坑
- 替代方案
- 争议点
- 社区口碑

### 不擅长
- 官方口径
- 结构化参数说明
- 中文平台玩法

### 使用方式
优先提炼：
- 大家最常抱怨什么
- 留下来的人为什么留下
- 不同工具的替代关系

### 代表场景
- 社区怎么评价 Firecrawl？
- 真实用起来有哪些坑？
- 大家为什么换工具？

### 回退
如果 Reddit 信息太少：
- issue / discussion
- X
- YouTube/B站评测

---

## 4. Web / 官方文档

### 最擅长
- 定义
- 规范
- 公告
- 参数
- 文档站点知识

### 不擅长
- 真正的用户体验
- 实战坑点
- 社交传播语言

### 使用方式
优先级：
1. 官方原文
2. 权威站点
3. 普通教程

### 代表场景
- 产品发布了什么？
- API 参数怎么填？
- 这个概念到底是什么？

### 回退
如果定义拿到了，但缺实践感：
- GitHub
- Reddit
- 视频演示

---

## 5. YouTube / B站 / X 视频内容

### 最擅长
- walkthrough
- 实操演示
- 产品上手
- KOL 观点
- 教程拆解

### 不擅长
- 最权威定义
- 完整参数文档
- 可重复验证的结构化数据

### 使用方式
优先从：
- 标题
- 描述
- 发布时间
- 章节
- 字幕 / transcript
入手。

### 代表场景
- 有没有人实测过？
- 有没有视频手把手教程？
- 谁讲得最清楚？

### 回退
如果视频信息不够：
- 回 GitHub 看代码
- 回官方文档看参数
- 回社区看真实反馈

---

## 6. X / 开发者社媒

### 最擅长
- 趋势热议
- 开发者即时观点
- 新产品第一波扩散
- 链接分发

### 不擅长
- 深度结构化解释
- 长期可追溯性
- 全量覆盖

### 使用方式
适合作为：
- 新消息雷达
- 开发者圈子情绪层
- 指向更原始来源的入口

### 代表场景
- 最近圈里在热议什么？
- 哪个新项目突然火了？
- 大家转发的原始链接是什么？

### 回退
- GitHub 查项目本体
- Reddit 看长期反馈
- 官方文档看事实细节

---

## 7. XHS / 抖音 / 封闭平台

### 最擅长
- 需求侧信号
- 博主内容句式
- 平台玩法
- 用户情绪与转化语言
- 中文内容消费场景

### 不擅长
- 稳定开放访问
- 结构化批量抓取
- 完整可验证榜单

### 使用方式
第一版按保守合规策略：
1. 公开索引和公开页面
2. 已登录浏览器会话读取公开可见内容
3. TikHub API / OpenClaw / browser automation 增强
4. 站外镜像 / 复盘 / 字幕 / snippet

### 代表场景
- 小红书上都怎么讲 AI 副业？
- 抖音上相关账号都在用什么标题句式？
- 封闭平台有没有明确的需求信号？

### 回退
如果平台本身拿不到足够多信息：
- B站 / YouTube / 公众号复盘
- 搜索引擎 `site:` 和 snippet
- 明确说明“当前检索受限”

---

## 8. 选源的一句话准则

- **要定义**：先本地知识和官方文档
- **要代码**：先 GitHub
- **要真实评价**：先 Reddit / issue / discussion
- **要实操演示**：先视频
- **要趋势热议**：先 X / Reddit / GitHub Trending
- **要中文平台需求和博主语言**：先 XHS / 抖音，但要诚实承认限制
