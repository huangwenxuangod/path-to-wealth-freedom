## 一、Codex App 是什么？它和chatgpt有什么区别？

Codex App 是 OpenAI 推出的 AI Agent 桌面应用。如果说过去的 AI 只是一个问答机器，那么 Codex App 就是一个能真正坐在电脑前帮你干活的数字员工。

它拥有极强的自主性，能够将你的一句话目标拆解为具体的行动路线。在依序执行每一步时，它会像真人一样调用电脑的各项功能，直到把事情做完并向你交付结果。

具体来说，它可以做到：

- **深度读写本地文件：** 直接查看、修改、整理你电脑里的文件夹与项目目录。
- **联网搜索实时信息：** 拥有内置的全功能浏览器，无需切出应用，就能在 App 内部搜索、浏览、汇总网页信息。
- **像人一样操控软件：** 拥有视觉感知能力，能实时识别复杂的软件界面，操作电脑上的各类 App。
- **生成多维工作成果：** 自动生成文档、图片、网页、代码等各类结果，并支持实时预览。
- **无缝连接外部工具：** 通过插件直接连接你的 Gmail 邮箱、Notion 笔记、Google Drive 网盘等应用。
- **后台自动化：** 设置好定时任务后，可以在电脑后台自动帮你执行重复性工作。

相较于我们熟知的 ChatGPT，Codex App 带来了两个颠覆性的改变：

1、**本地化：**Codex App 运行在你的本地电脑上，可以直接读写本地文件；ChatGPT 是运行在云端的AI聊天应用，想让它处理文件必须手动上传。

2、**执行能力：**Codex App能完美执行任何工作，根据需求直接在你的电脑上采取行动、交付结果；ChatGPT只能把答案停留在聊天框，执行这一步必须交给你来。

总结来说，Codex 是真正住在你电脑里的超级助手，能做到 ChatGPT 不能做到的一切。

## 三、核心功能解析

**1、全局概览**

进入Codex App后，界面布局如下图所示，主要包含左侧导航栏和中间工作区

![](https://pbs.twimg.com/media/HI0uZxQa8AAL4gx.jpg)

左侧导航栏包括的重要功能有：

- 顶部栏：Plugins（插件）中包括了 plugin 以及 skill，主要用于扩展 Codex 的能力边界，Automations（自动化）用于执行定时任务
- 中间对话区：项目区域用于管理与本地文件夹绑定的项目级会话，普通对话区域用于存放零散的临时性日常对话历史
- 底部设置：用于全局基础配置

中间主工作区则核心工作台，你的所有聊天都会从这里开始。

下面我们来具体拆解Codex App的核心功能，让你看完了就能够快速上手。

**2、项目&对话**

项目和对话区域位于左侧栏，是你进入Codex App后必须掌握的两个概念，它们代表两种开启会话的方式。

**项目：对应本地的一个文件夹，Codex 在项目会话中可以直接读写该文件夹内的文件。因此项目更适合有明确目标的任务，比如开发一个网站。**

开启方式：点击projects右侧的新建项目图标，支持新建文件夹和选择现有文件夹两种方式来建立项目

![](https://pbs.twimg.com/media/HI0y82EaMAA8KEx.jpg)

建议保持会话结构清晰，主要包括以下两点：

- 本地文件夹清晰，不同文件夹对应不同主题。
- 同个项目下一个会话只推进一个方向。比如开发一个网站，不同的功能设计各开一个会话，不要混在一起，执行效果更好，也方便后期回溯查看。

**普通对话：不绑定任何本地文件夹，更适合零散的问答和聊天需求。**

开启方式：在chats区域点击下图的新建对话图标

![](https://pbs.twimg.com/media/HI0zKZ0bEAAMk_w.jpg)

**3、plugins 和skills**

点击左侧栏的 Plugins，你可以为 Codex 安装 Plugins和 Skills，扩展它的能力边界。

**plugins 是给Codex 接外部工具的安装包。**比如：

- Gmail插件：让 Codex 读取和管理你的邮件
- Google Drive 插件：让 Codex 读取和编辑你的 Docs、Sheets、Slides
- Vercel 插件：让 Codex 直接将你的项目部署上线
![](https://pbs.twimg.com/media/HIqtzkFbAAAFDnZ.jpg)

**Skills是可复用的任务指令，告诉 Codex 遇到某类任务时该怎么做。**比如内置的Image Gen skill让 Codex 可以直接生成或编辑图片

![](https://pbs.twimg.com/media/HIquQXza4AACodM.jpg)

**4、自动化**

自动化让 Codex 按照你设定的时间在后台自动执行任务，适合需要定期执行的重复性任务，比如每日邮箱汇总、定时信息监控、股票日报等。

![](https://pbs.twimg.com/media/HIq21K1bgAA9p7j.jpg)

设置方式很简单，例如直接在对话里跟Codex说：

新建一个自动化，每天早上 9 点查看我的 Gmail 邮箱，把重要邮件总结到目前的聊天会话里

**5、聊天区对话相关功能**

1️⃣ plan mode：先制定详细方案再执行，适合在任务较复杂的情况下开启。

![](https://pbs.twimg.com/media/HIq30IXasAAmZC1.jpg)

2️⃣ 权限模式：每次发起对话前，可以在输入框左下角选择权限级别，共三档。

- Default 默认模式：仅限当前工作区，Codex 需要越界（访问网络或工作区外的文件）时，暂停询问你确认。
- Auto-review：边界与默认模式相同，但越界请求由 AI 自动审查决策，无需你手动确认，不打断工作流。
- Full access：移除所有边界限制，Codex 可访问任意文件和网络，直接执行，不做任何中断。

日常使用推荐选择Auto-review，安全相对可控，也不会频繁打断工作进度。

3️⃣ 模型和推理程度选择：支持不同模型和推理程度的选择。

推荐日常任务用GPT 5.5 Medium，复杂任务用GPT 5.5 Extra High。

![](https://pbs.twimg.com/media/HIq6fMlaUAAuZXF.jpg)

4️⃣ 输入框快捷符号：在对话输入框中，有三个符号可以快速触发不同功能

- “@”：支持选择调用已安装的插件或引用具体文件作为上下文
![](https://pbs.twimg.com/media/HIq97zyakAAKSdA.jpg)

- “/”：唤出命令菜单，可执行内置命令，已安装的 Skills 也会出现在列表中
![](https://pbs.twimg.com/media/HIq-Yo0bQAACdjV.jpg)

- “$”：显式调用某个 Skill，比如输入 $imagegen 直接触发图片生成
![](https://pbs.twimg.com/media/HIq-tV1bgAA5NoE.jpg)

## **四、推荐设置**

正式开始使用前，推荐你们把下面4个基础设置配置好，之后才能用得顺

点击左下角的设置进入配置页面

![](https://pbs.twimg.com/media/HIq79EibAAAkFJd.jpg)

1、权限设置里勾选auto-review和full access，方便随时调整权限模式

![](https://pbs.twimg.com/media/HIq9FuKaIAAsJXx.jpg)

2、开启「防止电脑在codex运行时睡眠」选项，这样Codex的任务就不会被无故中断

![](https://pbs.twimg.com/media/HIq-zvKa0AA-Kla.jpg)

3、配置全局指令（Agents.md）

在个性化设置的自定义指令里，写下你希望 Codex 长期遵守的背景信息和规则。

建议包括：

- 你的身份与偏好： 比如你的日常工作角色、常用的软件工具。
- 输出内容的格式要求： 比如“回答一律使用中文”、“文风保持简洁克制”。
- 行事准则： 比如“避免过度设计，只做必要改动”。
![](https://pbs.twimg.com/media/HI01NIAacAA-0a0.jpg)

4、个性化设置里开启记忆功能，Codex会自动从对话中学习你的偏好，在使用过程中越来越懂你

![](https://pbs.twimg.com/media/HItDNL4aMAAnhtI.jpg)

## 五、超级实用技巧推荐

**1、学会用好plan mode**

任务越复杂，越值得先开 Plan Mode 确认方案再执行。非常适合以下场景：

\- 任务涉及多个文件的改动

\- 需求本身还没想清楚

\- 从零开发某个功能或 Skill

![](https://pbs.twimg.com/media/HItD07LaMAAX7sT.jpg)

**2、多任务并行执行**

Codex 支持同时开启多个任务，甚至跨项目并行推进。每个对话的状态都会在侧边栏实时显示，任务完成后会出现蓝点提示

![](https://pbs.twimg.com/media/HIq_1K5boAAHp0S.jpg)

**3、4个宝藏命令**

- /side：在项目级会话的主线程正在运行时，开启一个临时的侧边对话，用于快速提问或确认某个细节
![](https://pbs.twimg.com/media/HIz3r2ebsAAq7cw.jpg)

- /pet：在电脑屏幕上开启一个桌面宠物，实时显示当前任务的执行状态，让你在做其他事的同时也能随时掌握进展
![](https://pbs.twimg.com/media/HIrBDIXasAAQBeV.jpg)

- /status：在会话里掌握你的上下文和额度的使用情况
![](https://pbs.twimg.com/media/HIrBXDYa8AA_Def.jpg)

- /goal ：设定一个明确的目标，让 agent 自己朝着目标不断努力

一个好的 /goal 提示词是这样的：

/goal 达成 <你希望 Codex 最终完成的目标>，并通过 <具体可验证的证据> 来确认结果有效，同时保持 <必须遵守的限制条件> 不被破坏。只能使用 <允许使用的输入、工具、文件范围或操作边界>。在每一轮迭代之间，Codex 需要根据 <如何判断下一步最优行动> 来选择下一步。如果遇到阻塞，或者已经没有有效路径可以继续尝试，Codex 必须停止，并报告 <已经尝试过的方法、已获得的证据、当前阻塞点，以及还需要什么信息或权限才能继续推进>。

**4、steer插入机制**

Codex 正在执行任务时，输入新指令后点击 Steer（或Mac快捷键 Cmd + Enter），指令会立即插入当前任务的上下文，而无需中断正在进行的工作。适合运行途中发现需要微调时使用。

![](https://pbs.twimg.com/media/HIrBg0fa0AA9J-5.jpg)
