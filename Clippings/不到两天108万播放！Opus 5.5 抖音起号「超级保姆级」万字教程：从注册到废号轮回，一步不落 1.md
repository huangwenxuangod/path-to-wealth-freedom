先上结果。

10 月 16 号下午两点，我发了一条用 Opus 5.5 做的知识视频《队友报点，你咋听不见？》。不到两天，**播放 108 万，点赞 2.7 万，评论 2383 条，分享 6 万次，收藏 3400 多**，光这一条就涨了 462 个粉。

它不是孤例。同一个号上，13.9 万、9.6 万、3.9 万、3.1 万、2.1 万……主页上留着的 10 条，基本都在万播以上。

抖音后台给这条视频的诊断是「流量上涨较多」，完播率和 2 秒跳出率「数据表现很棒」。2 秒跳出率只有 22.29%，作为对比，我之前做 AI 科普口播，2 秒跳出在 50% 到 70%。

还有一个细节：这条视频我只投了 30 块抖加，投放目标是 1500 播放，实际跑出 9175，超额 512%。

这些数字背后，是一整套能反复跑的流程。这篇教程将是你会在 X 上看到的最全面的教程！！！

> 这是一篇「超级保姆级」的抖音起号教程。从注册一个账号开始，到设置头像简介、养号、找爆款、用 Opus 5.5 复刻、发布、看数据、日常运维、投抖加，一直讲到账号废了怎么注销重来。一个号完整的生命周期，全部在这里。

> 能想到的细节我都写进去了，每一步都配了截图，没有一点水分。

> 本篇教程以抖音为例，但同样适用于视频号、小红书等主流社交媒体平台，采用的都是同样的方法。

最近 X 和抖音上，很多人在教怎么用 Opus 5.5 做那种知识科普动画。教程不少，但大多数只讲了一件事：怎么让 Claude 把视频做出来。

可是视频做出来，只是起号里很小的一环。号怎么注册、头像简介怎么设、发之前要不要养、对标找哪一条、发完 6 小时数据不好该怎么办、什么时候该投抖加、号废了要不要换……这些不搞清楚，给你 Opus 5.5 也发挥不出它真正的价值。做得再好看的视频，发在一个权重很低的号上，照样几十个播放。

这几年我在抖音上做过小程序、小说推文、AI 漫剧，平台规则吃过不少亏，也摸到了一些门道。这次做 Opus 5.5 知识视频，我把这些经验和新工具串成了一整套 SOP。

也先说句实在话：不是条条都爆。这个号到现在发了 29 条，播放低的 19 条我都隐藏了，你在主页上看到的，是留下来的那 10 条。怎么判断哪条该留、哪条该藏，第七章会讲。

为了方便你对照，我先把整个生命周期列出来，后面每一章对应其中一段：

1. 准备：一部手机，一台装好 Claude Code 的电脑
2. 账号包装：名字、头像、简介
3. 养号：先当一个正常人
4. 找爆款：只找最新的
5. 复刻制作：蒸馏风格，做一个比原片更好的版本，再压成一锅出的 Skill
6. 发布与诊断：看 6 小时的播放量，再看后台的几个「率」
7. 运维：把低播放的视频隐藏掉
8. 投抖加：火上浇油，别雪中送炭
9. 废号处理：注销，然后再来一轮

## 一、准备：一部手机，一台电脑

手机：你平时正常在用的那部

需要准备的东西很简单：**一部你平时正常在用的手机**。

唯一的要求是，这部手机最好之前没在抖音上违规过、没因为违规被封过号。手机本身有过前科，新号也容易跟着受影响。

然后就是正常注册抖音，按它的流程走，手机号验证完就行，这一步没有任何技巧。别为了「起号」专门去买什么号、刷什么机，正常人怎么注册，你就怎么注册。

电脑：做视频用

视频是在电脑上做的。你需要：

- 一个 Claude 会员，能用 Opus 5.5（会员档位和产能的关系，第五章最后会讲）
- Claude Code，在电脑上装好
- Node.js、ffmpeg、uv 这几个工具。Node 用来跑视频工程，ffmpeg 用来导出视频、测音量，uv 用来跑几个 Python 小脚本
- 我开源的视频工程，第五章会讲怎么拉下来

这些工具如果你没装过，直接把这一段丢给 Claude Code，让它帮你检查和安装就行，不用自己一个个去查。

```text
复现时可以这样说：
帮我检查这台电脑有没有装 Node.js、ffmpeg、uv 和 git，缺哪个就帮我装上，装完告诉我各自的版本号。
```

## 二、账号包装：名字、头像、简介

注册好以后，有很核心的一步：先把账号包装好。

定位先别划死

你去刷 Opus 5.5 做的那些爆款就会发现，题材非常杂：博弈论、拓扑学、游戏科普、历史冷知识……什么都有。所以前期没必要把自己限定在某一个细分领域，用一个比较泛的「知识分享」定位就够了。

这样做还有一个好处：后面你找爆款对标的时候，可以哪个题材正在爆就做哪个，不会被自己的定位卡住。等某一类题材在你的号上反复跑出数据了，再慢慢往那个方向收。

但标签一定要有。就跟我们玩 X 一样，先告诉系统「我是专门做知识分享的」，它才知道把你的视频推给谁。名字、头像、简介这三样，就是你给系统的第一份标签。

不会设置，就去抄作业

具体怎么设，直接看已经跑出来的号：

1. 抖音搜索「Vibe知识大赏」
2. 点右上角的筛选，选「最多点赞」，发布时间选「一周内」
3. 点开结果里的爆款，进他们的主页，看名字、头像、背景、简介都是怎么写的

![Image](https://pbs.twimg.com/media/HU4J6xeaMAAIUbC?format=jpg&name=large)

看多了你会发现，这些号的设置有很明显的共性。

**名字**：都和知识、思考有关。比如我自己的一个号叫「抽丝剥茧」，同类的号还有「厚黑文学」「万有引言」这种。两到四个字，读起来有点像一本书的名字。

**头像**：风景图，或者让 AI 生成一张看起来深奥一点的图，比如宇宙、星空、一只眼睛。头像在推荐流里只有很小一个圆，所以画面要简单，一眼能看清主体。

**背景图**：和头像同一个调性就行，深色、安静，别放花里胡哨的拼图。

**简介**：写一两句和哲学思考、知识有关的话。我的是「让知识可见，让思想有形」这样的句子。

![Image](https://pbs.twimg.com/media/HU4KHp5acAAB_tv?format=jpg&name=large)

如果你懒得自己想，可以把这几个号的截图丢给 AI，让它照着这个调性帮你起几个名字、写几版简介、生成几张头像，挑一个顺眼的就行。

```text
复现时可以这样说：
这是抖音上几个做知识科普的账号主页截图。请参考它们的调性，帮我：
1. 起 10 个账号名，2–4 个字，和知识、思考有关
2. 写 5 版简介，每版不超过 20 字
3. 写 3 个头像图片的生成提示词，风格偏深邃，比如宇宙、星空、眼睛
不要和截图里的账号重名。
```

起名的时候顺手在抖音里搜一下，确认没有重名的大号，免得别人搜你的时候搜到别人。

## 三、养号：先当一个正常人

头像、简介都弄好以后，**别马上发视频**。

很多人账号一注册好、资料一设好，就迫不及待地发第一条。最好别这样。新号一上来就发，系统很容易把你判断成矩阵号，单纯为了发视频拿流量，第一批流量会给得很低。

正确的做法是，先像平时一样刷抖音：

- 刷一两个小时左右
- 看到喜欢的点个赞
- 偶尔评论几句

目的只有一个：**让系统认为你是一个正常人**。

刷的内容也可以有点讲究。多刷一些知识类、科普类的视频，在「Vibe知识大赏」这类内容下面停留、点赞、评论。系统会根据你看什么、给什么点赞来判断你是谁，你刷得越像一个喜欢知识内容的人，后面你发的知识视频就越容易被推给同样喜欢这类内容的人。

![Image](https://pbs.twimg.com/media/HU4KW48b0AALEB_?format=jpg&name=large)

当然，也有号一上来第一条就爆的，但那是运气。为了稳妥，我建议你先养一下。养完一两个小时，基本就可以准备发第一条了。

养号的这一两个小时也不用干等，正好拿来做下一章的事：找爆款。

## 四、找爆款：只找最新的

入口：Vibe知识大赏话题页

![Image](https://pbs.twimg.com/media/HU4KlMqaAAAydas?format=jpg&name=large)

抖音现在有一个很火的标签，叫「Vibe知识大赏」。在搜索框搜它，结果页滑到「话题」，点进去。

这里面的视频，基本全部都是用 Opus 5.5 做出来的。

选「最新」，不选「最热」

话题页里有「最热」和「最新」两个排序。**我们要看的是最新。**

最热里面的视频，很多已经发了一个星期左右，数据一直在那里滚。它们吃的是已经验证过的流量池，你新号进去跟它们抢，没有竞争力。

![Image](https://pbs.twimg.com/media/HU4KTObacAAcRXR?format=jpg&name=large)

一句很核心的话：抖音爆过的东西，会一直爆

为什么要找爆款来对标？因为爆过的东西，已经经过了整个市场的验证。大众喜欢它，所以抖音才会持续给它流量。同样的选题和节奏，过一段时间换个号再做一遍，大概率还能爆。

所以在「最新」里，我们找的是这种视频：

- **发布几个小时以内**
- **播放量已经超过三四千，甚至已经上万**

几个小时就跑到这个量，说明这个选题此刻正在被推，跟上就能吃到这一波。

挑的时候，除了看播放量，还可以顺手看三样东西：

1. **评论区在吵什么**。评论多、大家在争论的选题，说明它戳中了人，后面你做的时候可以把这个争论点放大
2. **这个号是不是新号**。如果一个粉丝很少的号也能把这条做爆，说明爆的是选题本身，不是账号的老粉在撑，这种最值得对标
3. **能不能画出来**。Opus 5.5 做的是动画，选题里得有一个能画出来的东西：一张图表、一个天平、一个小世界。纯抽象、画不出来的选题，复刻起来很难做出冲击力

我这篇拿来演示的是一条「人生容错率」的视频，一天前发的，当时已经跑了 70万点赞了，属于超级爆款了！！！想都不要想，直接抄！

![Image](https://pbs.twimg.com/media/HU4Kf9tbgAA9mog?format=jpg&name=large)

把视频下载下来

下载很简单：

1. 在视频上点「分享」→「复制链接」
2. 谷歌搜「抖音视频解析」，随便找一个解析网站
3. 把链接粘进去，下载无水印的视频

![Image](https://pbs.twimg.com/media/HU4KhU6bAAAi00t?format=jpg&name=large)

下载好以后，把它放进工程里的 template/ 文件夹，后面蒸馏就从这里读。这个文件夹默认不会被提交到 git，因为这是别人的作品。

下载下来的视频只用来拆解学习，后面会讲到，**原片本身不能拿去直接发**。

## 五、复刻制作：让 Claude 蒸馏，再做一个更好的版本

这一章是整篇最核心的部分，也是最长的部分。

准备：拉我的开源项目

做这类视频，我自己搭了一个工程脚手架，开源在 GitHub 上：weilanx-claude-videos（链接放在评论区）。

它是一个 Remotion 工程，画面、配乐、音效全部用代码生成。简单说，一个视频就是一段 React 代码，每一帧画面都由帧号算出来。这样做的好处是，AI 写代码比操作剪辑软件准得多，改一个字、挪一个位置只要改一行，而且画面里每个数字、每句字幕的时间都能写成测试，AI 改完自己跑一遍就知道哪里对不上。

里面有两样东西对你最有用：

- **一堆现成的风格素材包**：暗金文献风、黑金光影风、战术屏科普风、灯火史话风……每种风格都有配色、字体、转场、招牌画面的现成组件
- **一个视频蒸馏 Skill**（weilanx-creator-distill-video）：你丢一个参考视频给它，它能把这个视频的画面语法拆出来，写成一套新的风格素材包

拉下来的步骤：

```sh
git clone https://github.com/Azure12355/weilanx-claude-videos.git
cd weilanx-claude-videos
npm install
npm run studio
```

最后一条会打开一个预览界面（Remotion Studio，地址是 http://localhost:3000），左边按风格分好了文件夹，里面是我做过的 50 多期视频的源码，点开任何一期都能直接看。先点开 ep00-demo 看一眼，能正常播放，环境就没问题了。

然后在这个文件夹里打开 Claude Code，它会自动读到工程说明和 .claude/skills/ 里的 8 个 Skill，就可以开始了。

第 1 步：蒸馏

先别急着让 Opus 5.5 自己生成视频。它自由发挥做出来的东西，大概率不是市场验证过的样子。

第一件事，是把你下载的那条爆款丢给蒸馏 Skill：

```text
复现时可以这样说：
用 weilanx-creator-distill-video 蒸馏这个视频的风格：template/人生容错率.mp4
重点拆：镜头节奏和硬切频率、画面布局、配色和强调色、字体层级、入场和转场方式、配乐卡点。
```

它会分两步拆。

![Image](https://pbs.twimg.com/media/HU4Km9Xa4AAH8Qf?format=jpg&name=large)

**先是机器拆一遍。** Skill 里带了一个拆解脚本，跑完会产出一份拆解报告：

- 哪一秒硬切、每个镜头多长（镜头表）
- 每秒的运动强度，画面哪里动得最猛
- 主色板，以及强调色。强调色是按有颜色的像素单独算的，背景面积再大也不会把它淹掉，所以那种「黑底上一点金」的风格也能准确取到金色
- 每个镜头的关键帧，以及每 3 秒一格的联系表，一张图就能看完整条视频
- 配乐的响度和卡点：节奏多快、重拍落在第几秒

**然后是「人眼」再拆一遍。** 机器只能告诉你哪里变了，不能告诉你为什么好看。所以它会像人一样去看：先把联系表通看一遍，把画面分成几类（标题卡、图表、实物、大字……）；再逐张看关键帧，把局部放大看字体、描边、发光；然后把入场、转场、招牌动作各切一小段，一帧一帧地数：几帧完成、先快后慢还是匀速、有没有模糊和缩放。

![Image](https://pbs.twimg.com/media/HU4KoZvbQAAsJvi?format=jpg&name=large)

拆完以后，它会把这套风格写进工程的素材库（Library）：

- 一套能复用的组件：配色和字体、背景和质感、标题卡、字幕、道具、图表
- 一个预览作品，把每个组件都演一遍
- 一张风格配方卡，把配色、字体、版式、转场、节奏、招牌画面全写清楚，最后还有一节「没有搬的东西」

做完它还会自己对照检查至少两轮：把它做的预览画面和原片同类的关键帧左右拼在一起，逐项比底色、主色、强调色、字体气质、字号层级、版式位置、留白；动效也一样，同一类入场比帧数和缓动。哪里不像就改，改完再比。

![Image](https://pbs.twimg.com/media/HU4KrR4aMAAQSt5?format=jpg&name=large)

工程里现在的几种风格，大部分就是这么来的：战术屏科普风是从同一个 FPS 科普系列的 4 支视频蒸馏的，灯火史话风和黑金光影风各是从 2 支视频蒸馏的。蒸馏的视频越多，它越能分清哪些是这个风格的共性、哪些只是某一条的偶然。

第 2 步：复刻，但要做得比原片更好

风格蒸馏好以后，就开始复刻。

这里要先说清楚「复刻」复刻的是什么。抖音有同质化检测，原片换个水印再发，或者原封不动照抄，轻则限流，重则判搬运。所以我们学的是：

- **选题**：同一个选题，市场已经验证过
- **结构和节奏**：开头怎么抛问题、几秒一个信息点、哪里给爆点
- **画面语法**：配色、版式、转场
- **音乐调性**：什么情绪的配乐、怎么卡点

文案用自己的话重新写，画面用素材包重新做。蒸馏 Skill 本身就是这么设计的：**风格一比一，内容不搬**。原片的字幕、标题、创作者名字和水印，一样都不会进你的素材包。

配乐要单独说一句：调性学原片，但曲子要用你自己有授权的。原片的配乐不会被写进素材包。我工程里的样片用的是一首我已经拿到授权的曲子，这个音频文件不在开源仓库里，你需要自己准备一首，放进工程的音乐库，Skill 里带了一个测拍子的脚本，能把这首曲子的节奏和重拍测出来。

最好就是直接让 Cluade 帮你帮样片的BGM提取出来，作为你自己的BGM。

然后，在这个基础上跟原片田忌赛马。原片已经证明这个选题和节奏能爆，我们要在下面三个地方做得比它更好：

1. **画面冲击力**：同样一个概念，画得更直观、更有视觉张力
2. **视觉感染力**：质感、光影、细节比原片更足
3. **音频节奏卡点**：这是最核心的一点。画面切换和配乐重拍卡得越准，看起来越爽，越容易被看完

第 3 点我多讲一些，因为这是我做了几十期以后最确定的一件事。

做卡点的顺序是**先测音乐，再写画面**。用脚本测出整首曲子的小节网格和重拍位置以后，整条视频的时间表就是从音乐里长出来的：每句字幕挂在第几拍，每个镜头从第几拍切到第几拍，全部对着拍子排。我用的那首曲子，17.45 秒有一个大重拍，102.52 秒配乐换气后整段重新进来，又是一个大重拍。一条 2 分多钟的视频，两个高潮就放在这两个位置。

每个高潮前后的处理是固定的：

- 重拍前大约 0.75 秒，整个画面开始收暗
- 重拍前最后 3 帧，画面静止不动
- 重拍那一帧，标题或核心的那个词「砸」出来，配一个冲击音效

这一收、一停、一放，观众会很明显地感觉到「到了」。

除了两个大高潮，配乐里还有很多小重音，我会让画面「一拍一个动作」。比如开场那几下重音，每一下画面里就发生一件事；中段配乐回落的地方有一串很响的硬拍，每一下就让画面里的模型跑一遍、计数牌跳一次数。观众未必说得出为什么，但会觉得这条视频「很顺」。

文案上，我也有几个固定的做法，都是从爆款里学来的：

- **找一个锚词**。两到四个字，是这个知识落在普通人生活里的处境，不是术语。比如讲智猪博弈，锚词是「等」。这个词在开头出现，在第二个高潮砸出来，结尾再重新定义一次（「等不是懒，是算出来的」）
- **高潮前那句话只说一半**。比如「你猜，最后是谁吃亏了——」，话停在破折号上，下一拍画面砸出答案
- **结尾抛一个人人都有答案的问题**，放进评论区，大号字一直挂到片尾

```text
复现时可以这样说：
用刚蒸馏出来的 <风格名> 做一期，选题是「人生容错率」。
参考原片的结构和节奏：<贴上蒸馏报告里的镜头表>
要求：
1. 文案用自己的话重写，不要照搬原片的句子
2. 先找一个锚词，开头出现、高潮砸出、结尾重新定义
3. 每个画面的冲击力要比原片强，关键数字和结论做成大号发光字
4. 先测配乐的拍子，画面切换卡在重拍上，高潮前收暗、静止 3 帧再爆发
5. 结尾抛一个人人都能回答的问题
做完先给我看几帧关键画面。
```

![Image](https://pbs.twimg.com/media/HU4KscmaQAAmMlc?format=jpg&name=large)

第 3 步：不满意就继续聊着改

第一版成片出来，不满意的地方直接跟它说。说的时候尽量具体，别只说「再高级一点」，它听不懂你心里的「高级」是什么样。一条好的修改意见要包含位置、问题、目标和边界：

```text
复现时可以这样说：
位置：第 12 秒那个天平画面
问题：天平太小，挤在画面中间，左右两边空了一大块
目标：天平放大到占画面宽度的 60%，两边托盘的字号加大
边界：配乐和字幕的时间不要动
```

「边界」这一行很重要。不写的话，它改天平的时候可能顺手把时间也挪了，好不容易卡准的点又对不上了。

改的时候不用每次都导出整条视频。让它只渲染你说的那一帧给你看，几秒钟就出来，确认了再继续改下一个地方。

第 4 步：把这套风格压成一个「一锅出」的 Skill

改到满意以后，最关键的一步来了：**把这一整套流程压缩成一个 Skill**。

压成 Skill 以后，后面你只需要给它一个相关的选题，它就会按这套 SOP 从头跑到尾：

- 查资料、写文案和分镜
- 做配乐和音效，按拍子排时间表
- 一帧一帧做画面，自己抽帧检查、自己修
- 导出成片
- 做一张 3:4 的封面
- 写好抖音的标题和发布描述

一条龙全部交付，中间不用你管。

做这个 Skill 也很简单，把上面这一整套流程发给它就行：

```text
复现时可以这样说：
把我们刚才做这一期的完整流程，整理成一个 Skill，叫 <风格名>-video。
以后我只给一个选题，就按这个流程一路做完：资料 → 文案分镜 → 配乐卡点 → 画面 → 自检 → 导出成片 → 3:4 封面 → 抖音标题和描述。
中间不要停下来问我，做完一起交付。
```

我工程里的黑金光影风、战术屏科普风，都是这样一锅出的 Skill。你可以直接打开它们的 SKILL.md 参考，我把这两个 Skill 实际在做的事情拆开讲一下，你做自己的 Skill 时照着补：

1. **一开始就授权到底**。Skill 第一段写明：调用它就等于授权从头做到交付，中途不问确认。只有两种情况才停下来问你：选题查不到任何一手资料，或者工具连续失败两次
2. **查一手资料**。论文至少读到摘要，书读到原段落，搜索结果的摘要不算数。每个上画面的数字都写进代码，用测试核对。知识视频翻车，一般都翻在事实上
3. **自己检查画面**。工程里有一个自查脚本，会把每个镜头切走前的那一帧抽出来拼成一张大图，再把两个高潮前后的几帧单独拼一张，AI 用眼睛一张张看：字有没有重叠、出画，该出现的东西有没有出现，高潮那一帧标题是不是已经亮了。最多改三轮，剩下的小问题写进报告，不无限打磨
4. **自己测音量**。整条视频的响度、峰值有固定标准，被配乐盖住的音效会被单独列出来
5. **交付一整套东西**。成片 mp4、3:4 封面、发布文案、字幕稿，全部放进同一个文件夹
6. **最后写一份交付报告**。说清楚用了哪些资料来源、哪些是自己算的、替你做了哪些决定、还剩什么小瑕疵

还有一条我特意写进了每个 Skill：AI 听不到声音。所以它只报响度的数字，听起来好不好，最后要你自己戴上耳机听一遍。

![Image](https://pbs.twimg.com/media/HU4KtifaEAAZpz3?format=jpg&name=large)

效率

这套 SOP 做好以后，我实测下来，做一条视频大概 15 分钟左右。

- 用 Pro 会员，一天能做 20 多条
- 用 Max 5x，一天能做上百条

视频做得快，意味着你可以不停地拿新爆款去验证。哪个选题不行就换，哪个号不行就换，这是后面整套打法的基础。

## 六、发布与诊断：看 6 小时的播放量

视频做好，就可以发了。新号直接发没关系。

发布时的几个细节

一锅出的 Skill 已经帮你准备好了封面和文案，发的时候注意几点：

- **封面用 3:4 的那张**，上面的标题要和视频里的标题一致
- **标题不超过 20 个字，留悬念，不说答案**。「躲进掩体，为什么还被打死？」比「掩体为什么挡不住子弹」好，前者观众想不通，后者观众觉得自己知道
- **描述里第一句写钩子**，然后是这期的要点，最后一行带话题
- **话题一定带上** [#Vibe知识大赏](https://x.com/search?q=%23Vibe%E7%9F%A5%E8%AF%86%E5%A4%A7%E8%B5%8F&src=hashtag_click)，再加两三个和选题相关的话题

![Image](https://pbs.twimg.com/media/HU4KuubbsAAFaCj?format=jpg&name=large)

先看 6 小时的播放量

发完别一直盯着刷新，**等 6 个小时再看播放量**。6 小时后，播放量基本会落在下面几个层级，每一层的处理方式不一样。

![Image](https://pbs.twimg.com/media/HU4LBtUb0AAk1tN?format=jpg&name=large)

**个位数：账号权重太低。**

只有几个播放，说明系统觉得你这个号权重太低，还不像个真人。这时候：

- 继续刷抖音，点赞、评论，把权重养上来
- 把之前发的视频先隐藏掉
- 发几条自拍，让抖音认为是一个真人在用这个号，而不是机器人

**几百之间波动：再发几条看看。**

再发几条。如果一直都卡在几百，就把这几条全部隐藏，然后发一条真人实拍的内容，露个脸，或者拍拍身边的生活。

然后接着发知识视频，看能不能起来。这个过程可能要来回轮几次，耐心养。

**几千：账号是正常的。**

到了几千，说明这是一个非常正常的号了，可以持续发下去。

再看后台的几个「率」

播放量告诉你账号正不正常，但要判断一条视频本身做得好不好，下一期该往哪改，得去创作者后台看几个比率。新视频发布时间短，播放量天然少，比率受发布天数的影响小得多，更适合横向比较：

- **5 秒完播率**：开头有没有留住人
- **2 秒跳出率**：封面和第一帧是不是让人一眼就想划走
- **平均播放时长**：大部分人看到第几秒走的
- **点赞率、收藏率、分享率**：点赞数、收藏数、分享数分别除以播放量

我拿自己做的一个 FPS 游戏科普系列举个例子，这是 10 月中旬导出的后台数据（部分）：

![Image](https://pbs.twimg.com/media/HU4LHVgaEAAaQPu?format=jpg&name=large)

![Image](https://pbs.twimg.com/media/HU4LLh3bsAAj9DH?format=jpg&name=large)

从这张表里，我得出了几个结论，后来全部写回了那个一锅出的 Skill：

1. **分享率决定推荐量**。「被冤枉 → 翻案」这类选题，分享率大约是讲机制的 5 倍。观众转发是为了替自己说话：「你看，不是我菜。」所以选题里最好有一个被冤枉的人，视频替他翻案
2. **答案显而易见的标题会被跳过**。「跑着开枪为什么打不准」，大家心里早有答案，开头跳出最多。好标题说的是观众想不通的事
3. **标题用第二人称加痛点**。前几期用「你为什么老是……」，后面换成中性的问句后数据往下走。样本不多，只能说相关，但没有理由放弃第二人称
4. **前 17 秒就要告诉观众这期讲什么**。观众平均只看 10 到 17 秒，而我的标题卡要到第 17.5 秒才出来，很多人没看到标题就走了。后来我在开头加了一条从第一帧就挂着的标题条，把「这期讲的就是你」一直放在画面顶部

作为对比，我之前做 AI 科普口播的时候，5 秒完播只有 12% 到 33%，2 秒跳出在 50% 到 70%。所以方向选对了，数据会差很多。

你自己的号跑了十几条以后，也可以把后台数据导出来，交给 Claude 一起分析，把结论写进你的 Skill 里。这样下一期它就会按新的结论去选题、写标题。

```text
复现时可以这样说：
这是我抖音后台导出的作品数据（附件）。不要看播放量，按 5 秒完播、2 秒跳出、平均播放时长、点赞率、收藏率、分享率，把这些视频分成几类比较，告诉我哪类选题和标题表现更好。
然后把结论写进 <风格名>-video 这个 Skill 的参考文档里，以后选题和写标题都按它来。
```

发布节奏

号正常以后，也别一口气发太多：

- **一天 3–5 条就够了**
- **间隔三四个小时**，早中晚各发一条，是比较合理的节奏
- 周末流量好，可以多发一两条
- 千万别一天发十几二十条

视频一天能做上百条，不代表要发上百条。做得多的那部分，可以拿来挑：同一个选题做两三个版本，挑最好的那一条发。

## 七、运维：把低播放的视频隐藏掉

号跑起来，发到 10 条左右的时候，回头看一眼整个账号的数据。

如果大部分是万播，中间夹着几条只有几十、几百播放的，**把这几条全部隐藏掉**。

![Image](https://pbs.twimg.com/media/HU4Lis8bMAAQiwQ?format=jpg&name=large)

这么做有两个好处。

**第一，给其他视频带尾流。** 用户刷到你的一条万播视频，觉得不错，会点进你的主页。主页上条条都是好内容，他就会在不同作品之间一条条看下去，这些视频之间就会互相导流，长尾流量就起来了。主页上挂着几条几十播放的，人家点进来一看就走了。

**第二，做好账号的数据面板。** 以后有品牌方或者想找你合作的人点进主页，看到条条都是爆款，信任感会强很多，你的号也显得更有分量。

隐藏不是删除。隐藏掉的那几条，选题和视频都还在，过一段时间换个标题、换张封面，或者用新学到的手法重新做一版，还可以再发一次。

## 八、投抖加：火上浇油，别雪中送炭

抖加投不投、什么时候投，是有策略的。

1 小时内破万：想都别想，立刻投

如果你的视频**发出去 1 个小时之内，就跑到了万播，甚至 5 万**，什么都不用想，立刻投抖加。

这叫火上浇油。这时候自然流量正在往上冲，抖加跟着一起跑，会把爆款效应拉得很长。这个时候投的抖加，价值绝对超出你的想象。

拿我那条百万播放的视频来说：我只投了 30 块钱，目标是 1500 播放，实际跑出了 9175，超额 512%。8.7 个小时的投放，还带来了 3092 次互动：961 个点赞、65 条评论、2066 次分享，外加 13 个新粉丝。

![Image](https://pbs.twimg.com/media/HU4LjpCa0AE9778?format=jpg&name=large)

互动才是关键。抖音判断一条视频要不要继续推，很大程度看点赞、评论这些互动数据。30 块钱换来的这三千多次互动，会让系统觉得这条视频值得继续推，带动更多的自然流量，形成一个正向循环。

6 小时内到 3 万、5 万：可以试试

如果没有在 1 小时内爆，但 6 小时之内跑到了 3 万、5 万以上，也可以试着投一点，能提高它变成大爆款的几率。

一直跑得慢：别投

如果一条视频一直慢悠悠地涨，卡在一两万上不去，像涓涓细流一样，就没必要投了。让它自己跑就行，抖加救不了一条没被市场选中的视频。

总结成一句话：**抖加只给已经在爆的视频加速，不给没爆的视频续命**。

## 九、废号处理：注销，然后再来一轮

最后讲号废了怎么办。

什么情况算废号

你发了 5–10 条，全部只有几十、几百个播放。前提是：这些视频都是用 Opus 5.5 认真做的，而且都是对标最新爆款复刻的。

内容没问题，数据还是起不来，说明这个号可能天生体质就不行。这时候就别硬耗了，直接注销。

反过来，如果这 5–10 条里有几千甚至上万播放的，那这个号就值得继续发下去。

判断之前，先对着前面几章自查一遍，确认问题真的出在账号上，而不是出在视频上：

- 对标的爆款是不是最新的，发布几个小时内就跑出了数据
- 是不是认真复刻了选题、结构、节奏和音乐调性，画面和卡点有没有比原片更好
- 养号、发布节奏有没有照着做，有没有一天发十几条
- 6 小时诊断以后，该隐藏的有没有隐藏，该发真人实拍的有没有发

这几样都做到了，数据还是起不来，再注销。

怎么注销

抖音的设置里就有注销账号的入口，按流程点下去就行。

![Image](https://pbs.twimg.com/media/HU4Lj8kbYAAfbSZ?format=jpg&name=large)

注销以后，别马上注册新号

这一点很重要。注销完立刻重新注册，新号会被抖音的风控盯上，流量依旧低迷，权重依旧很低，等于白注销。

**停一两天，再重新注册一个号**，然后把上面这整套 SOP 从头再跑一遍。

这个过程可以不断往返轮回。视频做得快，换号的成本就很低。而且每轮一次，你手里的东西都会变多：素材库里多了几套风格，Skill 里多了几条从数据里得来的结论，下一个号起步就比上一个号快。

## 写在最后

这套打法能跑通，靠的是下面这几点：

1. **对标的爆款一定要新**：发布时间离现在越近、数据越好，你复刻出来的数据就越不会差
2. **选题、结构、节奏、音乐调性完整学过来**，文案和画面自己做
3. **在爆款的基础上锦上添花**：画面更有冲击力，卡点更准
4. **不要自己去探索一条没人走过的路**：站在前人的肩膀上，用好数据
5. **把流程压成 Skill，把数据的结论写回 Skill**：做得越多，它越懂你的号

我自己就是完全按这套 SOP 来的：发了 29 条，隐藏了 19 条，主页上留下的 10 条基本都过万，最高的一条 108 万。你看，也不是条条都爆，但留下来的这些，已经足够撑起一个号了。

如果你稳定按这一整套流程走，起 3 个号，我觉得起码有 2 个能起来。我自己就是这样。
