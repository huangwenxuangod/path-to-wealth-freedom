> 我想，或许只有持续的学习新知识新工具才是正确的道路

清明节后的第一天。

Hermes 火爆的第三天。

我在 Twitter 上看到有人问，OpenClaw 还有人用吗。

下面两条回复。

一条说，早不用了。

另一条说，现在都用 Hermes agent。

我盯着屏幕看了三分钟。手指悬在键盘上，没打字。

**两个月前不是这样的。**

那时候我的时间线里，每天都有人发 OpenClaw 的截图。

早报推送到飞书。股票提醒。周报自动生成。

有人晒自己的配置。说用了两个月，省了多少时间。

有人在问怎么写 Prompt。怎么防止龙虾失忆。怎么让它记得自己的习惯。

那时候大家还在讨论。

现在这些帖子都沉下去了。

像水里的石头。

我下载了 Hermes agent。

花了十分钟。跑通了一个任务。让它每天早上给我发邮件。汇总昨天的新闻。

确实快。

不用写 Prompt。不用调参数。点三下就搞定。

我把截图发到群里。

有人问，这是什么。

我说，新出的。挺方便的。

有人说，那 OpenClaw 还装吗。

我说，先不装了吧。

那天晚上我删掉了 OpenClaw 的容器。

**不是因为它不好。**

**是因为新的更好。**

那天刷推

看到Claude Code 更新了。

我打开 Release Note。看到一条新功能。

支持定时任务调度。

我的心跳停了一下。

这行字我太熟悉了。

三个月前，我在 OpenClaw 里写过一模一样的功能。定时任务。Cron Jobs。让 AI 每天早上自动跑。

那时候 Claude Code 还没有这个。

它只能聊天。不能定时。

**我写了六篇教程。**

**教别人怎么用 OpenClaw 做自动早报。怎么做周报提醒。怎么防止龙虾失忆。**

那时候有人私信我。说谢谢，跑通了。

我说，不客气。

现在 Anthropic 把它做进去了。

名字不一样。界面不一样。但做的事情是一样的。

而且他们做得更好。

不用配置服务器。不用管 Token 消耗。不用怕龙虾失忆。

**我在 Twitter 上发了一句。**

**说，Claude Code 的新功能，看着眼熟。**

下面有人回，工具的事，能算抄吗。

另一个人说，OpenClaw 也是抄别人的吧。

我删了那条推文。

那天晚上我喝了三杯咖啡。

凌晨两点，打开 Claude Code。

输入命令。设置了一个定时任务。每天早上八点，让它读我的邮件，写个摘要。

跑通了。

比 OpenClaw 那时候顺。不用配置服务器。不用管 Token 消耗。不用怕龙虾失忆。

我坐在椅子上，看着终端里的绿色光标。

一闪一闪。

像呼吸。

昨天我又搜了 OpenClaw。

GitHub 上的star增长停滞了

没人回复。

Discord 频道里，最后一条消息是十天前的。有人问怎么配置 Slack。没得到答案。

我想起那些教程。

**我写的六篇。从新手村到进阶玩法。每一步都配了图。**

那时候有人说，谢谢，跑通了。

我说，不客气。

**现在那些链接还挂在那里。点进去，图片能打开。步骤还是对的。**

**只是没人点了。**

我想起自己用 OpenClaw 做的第一个自动化。

一月底，我让它每天早上爬取AI科技新闻，发到飞书。

第一天跑通的时候，我在房间里喊了一声。

对象问我怎么了。

我说，你看，它自己动了。

那时候我觉得自己掌握了什么秘密。

一个能让电脑替我干活的秘密。

现在 Claude Code 把这个秘密做进去了。

更简单。更直接。

几百万人用。

**我不用再教别人怎么配置openclaw。怎么调 Cron 表达式。**

**他们不需要了。**

晚上九点。

我坐在电脑前，没开灯。

手机屏幕亮了。是 Claude Code 的推送。

今天的邮件摘要。

我扫了一眼。没什么重要的。

想起以前用 OpenClaw 的时候。每天早上八点，飞书机器人准时发消息。有时候是新闻。有时候是股票。有时候只是天气。

我会看完。然后回一句，谢谢。

其实它不会回我。但我会回。

现在我不用回了。

Claude Code 把摘要写好了，存在文件里。不会问我好不好。不会等我说谢谢。

它只是在执行。

像一个好的员工。不打扰。不抱怨。

**我想起那些写过 OpenClaw 教程的人。**

**我们都在教别人怎么用这个工具。怎么让它更聪明。怎么让它记得更多。**

现在 Anthropic 做了。Hermes 做了。OpenAI 也要做 Operator。

我们教的东西，变得不重要了。

或者说，变得简单了。简单到不需要教程。

今天早上，我重新打开了 OpenClaw 的 GitHub 页面。

Star 数已经停滞了。

但 Hermes agent还是涨。Claude Code 闭源，但用户数以百万计。

**我在 Star 按钮旁边，点了一下。**

**变成 Unstar。**

又点了一下。

还是 Star。

我留下了那个 Star。

不是为了用它。

只是想记住。曾经有一只龙虾，每天早上八点，给我发过天气预报。

窗外在下雨。

我想起那个做同房提醒的人。

不知道他现在还在用 OpenClaw 吗。

还是说，他也换了。换成 Hermes，或者 Claude Code 的新功能。

可能他都忘了。

自己曾经用一只龙虾，给自己做过同房提醒。

工具就是这样。

来的时候很快。

走的时候，连再见都不说。

**你开始用Hermes agent了么？还是其他的你都还没用上？**

**我把openclaw+Claude code+Hermes agent的资料都放到评论区了**

有需要的话你们自取吧
