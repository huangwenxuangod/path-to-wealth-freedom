Codex 远程操作正式推出，现在可以使用手机丝滑的操作电脑

我第一时间进行了尝试，但发现如果用手机 Vibe coding，有一个致命问题：手机无法打开本地网站

这意味着你改完了代码，却没法在手机上直接看到效果。但如果你能把网站自动部署到线上，不就可以在手机上打开了？

**所以我特此做了一个能让你在手机端打开本地网站的skill，并命名为：Go-Live.skill**

**GitHub仓库：[https://github.com/Sac-Y/go-live](https://github.com/Sac-Y/go-live)**

## 1、Skill 技能展示：

如果没有安装这个skill，你遇到的问题会是这样：

![](https://pbs.twimg.com/media/HIW-A-cbcAAraCv.jpg)

安装了这个skill，手机上就能直接打开部署好的网站了（我用手机制作了一个 github 信息聚合网站）：

![](https://pbs.twimg.com/media/HIWvxGDbkAERS_9.png)

## 2、安装方法：

**1、终端输入命令：**

```bash
npx skills add Sac-Y/go-live
```

**2、在Codex输入框输入下述指令：**

请帮我安装这个 skill：[https://github.com/Sac-Y/go-live](https://github.com/Sac-Y/go-live)

![](https://pbs.twimg.com/media/HIWzsC1aAAAnikQ.jpg)

## **3、实际测评效果**

非常的夯，完美解决了远程 vibe coding 无法打开本地网页的问题，大家速速安装，以后在哪里都可以 vibe coding 了
