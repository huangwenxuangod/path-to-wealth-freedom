我把这份 13 页文档完整梳理了一遍。它本质上不是“X 算法技巧教程”，而是一篇 **Rob Hallam 讲自己如何从 900 粉涨到 6 万粉，并总结什么样的 X 增长才是真正可持续增长** 的视频逐字稿，后半段还穿插了他自己产品 **Super-X** 的演示和推广。

整篇最核心的一句话其实是：

> **不要把 X 当成一个算法游戏，而要把它当成世界上最大的社交聚会。**

他认为真正能建立“改变人生的受众”的关键，不是 hack 算法，而是 **成为一个值得被别人注意的人 + 持续参与真实关系 + 用故事表达自己 + 借势大家正在关心的话题** 。

---

## 一、他先用自己的结果证明这套方法

Rob 说自己 2019 年就注册了 X，但真正开始认真发内容大概是在 2024 年，当时只有 **900 个关注者** 。两年之后变成了 **6 万粉丝** 。

他强调，这个结果对他最大的价值不只是“涨粉”。

它给他带来的东西包括：

业务增长、可以搬去越南生活、认识了大量高质量朋友，甚至他说现在现实生活里很多朋友，要么直接来自 X，要么是通过 X 上认识的人介绍认识的。

所以他真正定义的“增长”不是：

> 粉丝数增长。

而是：

> **社交资本 + 商业机会 + 个人影响力 + 人际关系网络增长。**

这也是整篇最重要的价值观。

---

## 二、他明确反对“算法增长思维”

这里他其实是在批判很多社媒增长教程。

他说他不想讲：

> 怎么 hack 算法  
> 怎么 game people  
> 怎么骗别人关注

因为如果你只追求这些东西，最后可能得到的是：

> “an audience full of bots”

而不是一群真正的人。

所以这篇内容的定位不是：

**Growth Hack**

而更接近：

**Audience Building**

两者差别非常大。

Growth Hack 的问题是：

```
曝光
↓
点击
↓
关注
```

而 Rob 想做的是：

```
被发现
↓
觉得你有意思
↓
持续看你
↓
认识你
↓
信任你
↓
与你互动
↓
成为朋友 / 用户 / 客户
```

这也是为什么他说：

> 如果增长得非常快，人们也可能同样快地忘记你。

如果想做真正 sustainable 的东西，就得像做生意一样每天投入。

## 三、整篇最重要的比喻：X 是一个巨大的 Party

这是这份文档里面我认为最值得记住的部分。

Rob 说：

当你开始在 X 发帖的时候，不要把自己想象成：

> 一个账号正在向算法上传内容。

而是：

> **你走进了世界上最大的社交聚会。**

这里面有几百万人。

人们自然会形成一个个小群体。

而每个群体里，总会有几个人：

> 大家愿意听他们说话。

为什么？

Rob 的答案非常简单：

> Because those people are interesting.

**因为他们有意思。**

于是内容创作的问题就变成了：

不是：

> 怎么写爆款？

而是：

> **为什么大家愿意在一群人里面停下来听你说话？**

这个问题一下就把社交媒体内容讲透了。

---

## 四、那怎么成为“有意思的人”？

Rob 给出的答案其实只有两个。

1. **会讲故事**
2. **理解大家现在在关心什么**

文档中他说得非常直接：让一个人“有趣”和“无聊”的差别，在于这两个能力。

这里第二个能力，他用了一个词：

## Zeitgeist

也就是：

> **时代精神 / 当下大家共同关注的东西。**

他说：

你需要理解：

> 大家现在正在想什么？  
> 大家现在对什么感兴趣？

然后围绕这些东西创作内容。

例如某个领域突然出现：

GPT 新模型、AI Agent、OpenAI 新产品、创业浪潮……

这就是：

```
Attention wave
```

你要做的不是凭空创造所有注意力，而是：

> **ride that wave**

借这个浪。

但这里有一个非常关键的细节。

Rob 后面特意强调：

> **Ride the wave，但同时要 original enough。**

也就是：

不能只是：

> “GPT-6 发布了！”

因为所有人都在说。

应该是：

```
热点
+
你自己的经历
+
你自己的观点
+
你自己的故事
```

这才会变成你的内容。

## 五、整篇的第二个大核心：Storytelling

Rob 对 Storytelling 的理解也比较简单，但非常实用。

他说，人类从小听父母讲故事，到远古时代围着火堆讲故事，本质上一直都是靠故事交流。

所以：

> X 和其他社交媒体一样，本质上也是 storytelling。

而且他说自己表现最好的帖子，很多其实都是：

> **讲自己的故事。**

目的不是单纯卖惨或者晒成绩，而是：

> 让别人知道我是谁、我在做什么、我为什么做。

于是以后他发别的东西：

> people care about it.

别人就会在意。

这个逻辑其实非常重要：

```
内容
不是建立在主题之上

而是：

主题
+
人物
```

如果只有主题：

> AI Agent 很厉害。

用户关注的是：

**AI Agent。**

如果是：

> 我为了搞明白这个 Agent，花了一天把它拆了……

用户慢慢开始关注：

**你。**

这两个增长完全不是一个东西。

## 六、他给出了一个非常简单的故事公式

Rob 自己有一系列内容：

> 我辞掉工作  
> 离开家  
> 靠积蓄生活  
> 我要做到 $10,000/月

他说这为什么是故事？

因为里面存在：

**Setup + Conflict。**

后来他进一步把公式展开成：

```
Context
↓
Goal
↓
Conflict
↓
Resolution
```

具体来说：

### Context

我是谁？

我来自哪里？

我现在在干什么？

### Goal

我要做到什么？

例如：

> $10,000/月

### Conflict

最大的问题：

> 我到底能不能做到？

### Resolution

最后：

> 做到了。

而且他说真正让故事成立的关键就是：

**Conflict。**

如果没有冲突：

> story is boring.

## 七、为什么“Build in Public”特别容易成立？

虽然 Rob 没有把它直接理论化成 Build in Public，但他的整个故事其实就是典型的公开构建。

因为：

```
Goal
↓
uncertainty
↓
progress
↓
failure
↓
progress
↓
result
```

天然拥有故事张力。

他说自己当时并不是“写剧本”。

而是：

> 有意识地思考这些元素，然后把自己的 journey 分享出来，让别人一起参与。

这个区别很重要。

不是：

> 编一个故事。

而是：

> **把真实生活整理成故事。**

所以他说：

> Posting on X is not a game. It's real life.

核心是：

> 用真实的方式表现自己，同时让别人愿意听。

## 八、这里其实形成了一个很完整的内容公式

我把 Rob 整篇压成一个公式：

## Zeitgeist × Story × Person

也就是：

```
大家关心什么
        ×
你自己的故事
        ×
你是谁
```

不是：

```
热点 × 热点 × 热点
```

因为那样最后大家记住的是热点。

也不是：

```
我 × 我 × 我
```

因为别人一开始根本不认识你。

而是：

```
外部注意力
+
内部故事
```

这可能是整篇最值得拿走的框架。

## 九、Rob 对“互动”的理解也和普通运营教程不一样

后半段他重新回到 Party analogy。

他说：

如果你在一个 Party 里面：

> 有人主动开始和你说话。

你会怎么办？

正常情况下：

> 继续聊天。

所以 X 也是一样。

如果有人：

回复你、跟你交流、频繁出现在你的评论区……

那不是：

> “engagement 数据”。

而是：

> **一个人在和你说话。**

他的建议非常直接：

> maintain that conversation  
> make friends

也就是：

**继续聊，交朋友。**

这其实和很多：

> 每天评论 50 个大 V

完全不同。

因为一个是：

**增长技巧**

另一个是：

**社交行为。**

## 十、为什么 Super-X 会记录 90 天互动？

这就是后半部分他产品 Super-X 的核心思路。

Super-X 会分析：

> 最近 90 天谁与你互动最多。

因为按照他的 Party 模型：

这些人就是：

> 最近一直和你说话的人。

例如文档里他展示一个叫 Arthur 的人：

系统发现：

> Arthur 是过去 90 天回复他最多的人之一。

于是他可以看到 Arthur 所有回复。

这本质上就是：

```
Content CRM
```

不是单纯 Analytics。

更接近：

> **Relationship CRM。**

从文档来看，它不是一个纯粹“写推文”的工具。

Rob 说自己最初做 Super-X，是因为自己在发展 agency，需要：

文档展示的功能大致包括：

趋势发现、每周增长总结、Thread 写作、Lead Generation、Growth Planning、联系人互动追踪、历史推文表现分析，以及基于分析帮你起草内容。

```
X Growth OS
```


## 十二、其中一个非常有意思的观点：Views ≠ Followers

这一段非常值得注意。

Super-X 会分析：

> 哪些帖子有效。

例如：

某类内容获得大量 traction。

于是系统会建议：

> 可以继续做。

但是他提到：

## Meme

Meme 可能：

> views 很高。

甚至：

> 可以赚广告分成。

但是：

> **doesn't get followers**

所以他说：

> 不一定值得继续 double down。

这个其实是在强调：

### 不同内容对应不同目标。

```
Views
≠
Followers

Followers
≠
Trust

Trust
≠
Customers
```

如果你的目标是：

> 建立长期 audience

那么：

**播放量最高的内容，不一定是最好的内容。**

## 十六、我认为这篇最值钱的不是“趋势 + 故事”

表面上 Rob 最后总结就是：

> Trends + Storytelling。

但我认为更深的一层其实是：

## 不要做“内容账号”，要做“人物账号”。

因为他整个方法都在不断把：

```
Topic
```

转换成：

```
Person
```

热点只是入口。

故事让别人认识你。

互动让别人和你建立关系。

视频让别人记住你的脸。

长期公开 Journey 让别人有理由继续追。

最终：

> **Follower 不是订阅一个主题，而是在 follow 一个人。**

我认为这是整份文档最值得吸收的思想。

## 如果把 Rob 的方法变成一个可执行模板

你以后发一条 X，可以先问自己 5 个问题：

1. **这是不是现在有人关心的东西？** —— Zeitgeist
2. **我的独特信息是什么？** —— Experience / Insight
3. **这里有没有故事？** —— Context → Goal → Conflict → Resolution
4. **别人看完是记住这个新闻，还是记住我？** —— Person
5. **这条内容会带来真实的人，还是只是 Views？** —— Audience Quality

如果这五个都成立，才比较符合 Rob 这篇里所谓的：

> **real, sustainable audience。**
