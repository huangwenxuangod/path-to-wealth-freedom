# 02 - 创意方向

## 目标

避免 PPT 感。

视频必须像一套“正在运行的系统”，不是一页一页切换的幻灯片。

## 推荐方向：AI 工作流系统片

关键词：

- 流水线
- 节点
- 轨道
- token 汇聚
- 信息流
- 工具栈
- 进度条
- 数字目标
- 系统启动

## 画面设计

### 1. 开场：身份被系统识别

画面不是大字“文轩”静态出现，而是：

- 背景网格扫描。
- 字符碎片从不同方向汇聚。
- “文轩”被锁定。
- 三个标签动态贴上：05 后、大学生、AI 实战者。

### 2. 工具不是收藏夹

画面先出现大量工具 token：

- Codex
- Claude Code
- Obsidian
- 飞书
- Prompt
- 自媒体
- 知识库

这些 token 一开始散乱漂浮，然后被系统吸入一条 pipeline。

### 3. 认知生产流水线

主画面变成流程：

```text
选题 -> 研究 -> 写作 -> 知识库 -> 分发 -> 反馈
```

每个节点被激活时：

- 节点发光。
- 线条流动。
- 下方出现具体工具。
- 字幕跟随节点，而不是只在底部。

### 4. 工具轨道

Obsidian、飞书、Codex、Claude Code 不再只是文字，而是围绕“AI Native Workflow”轨道运动。

视觉含义：

> 工具不是一个个孤立 App，而是被文轩组合进同一个系统。

### 5. 加速器段落

三个能力动词出现：

- 理解行业
- 做出产品
- 验证机会

表现方式：

- 三条数据线从慢到快。
- 节点响应速度变快。
- token 从混乱变得结构化。

### 6. 100 万目标

不做简单大字。

做成：

- 进度刻度。
- 数字计数。
- 路径终点。
- “毕业前”作为时间约束。

### 7. 收尾

前面所有线条、节点、工具轨道收束成一句话：

> 关注我，看我怎么用 AI 把路跑通。

## 风格

基底：

- 米白、浅灰、黑字。
- 低饱和蓝/绿作为系统色。
- 细线、网格、留白。
- 不使用大面积霓虹、不使用花哨渐变球。

动效：

- 快慢结合。
- 线条流动和节点激活是主角。
- 字体运动要干净，不乱飞。
- 过渡尽量是“系统状态变化”，不是 PPT 翻页。
