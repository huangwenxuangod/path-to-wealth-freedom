# 02 - 创意方向

## 目标

避免 PPT 感。

视频必须像一套“正在运行的系统”，不是一页一页切换的幻灯片。

当前确认有效的方向是：

> 用 Swiss 极简高级风的秩序，去承载 AI 工作流系统片的动态表达。

## 推荐方向：AI 工作流系统片

关键词：

- 流水线
- 节点
- 系统面板
- 网格
- 信息块
- 信息流
- 工具栈
- 进度条
- 数字目标
- 系统启动

## 画面设计

### 1. 开场：身份被系统识别

画面不是大字“文轩”静态出现，而是：

- 背景网格扫描。
- 字符碎片从不同方向汇聚。
- “文轩”被锁定。
- 三个标签动态贴上：05 后、大学生、AI 实战者。

### 2. 工具不是收藏夹

画面先出现大量工具 token：

- Codex
- Claude Code
- Obsidian
- 飞书
- Prompt
- 自媒体
- 知识库

这些工具不应该像贴纸一样乱飘。

更好的做法是：

- 先以模块列表出现
- 再进入流水线结构
- 最后进入统一系统面板

### 3. 认知生产流水线

主画面变成流程：

```text
选题 -> 研究 -> 写作 -> 知识库 -> 分发 -> 反馈
```

每个节点被激活时：

- 节点发光。
- 线条流动。
- 下方出现具体工具。
- 字幕跟随节点，而不是只在底部。

### 4. 工具系统面板

Obsidian、飞书、Codex、Claude Code 不再只是文字，也不再做漂浮轨道。

更推荐：

- 中间是 `AI Native Workflow`
- 四周是结构化工具模块
- 用细连接线表达关系
- 整体像系统总览图，而不是“工具围着圆圈转”

视觉含义：

> 工具不是一个个孤立 App，而是被文轩接进同一个工作系统。

### 5. 加速器段落

三个能力动词出现：

- 理解行业
- 做出产品
- 验证机会

表现方式：

- 三条数据线从慢到快。
- 节点响应速度变快。
- token 从混乱变得结构化。

### 6. 100 万目标

不做简单大字。

做成：

- 进度刻度。
- 数字计数。
- 路径终点。
- “毕业前”作为时间约束。

### 7. 收尾

前面所有线条、节点、工具轨道收束成一句话：

> 关注我，看我怎么用 AI 把路跑通。

## 风格

基底：

- 米白、浅灰、黑字。
- 单一 IKB 蓝作为系统色。
- 细线、网格、留白。
- 轻字重大标题。
- 直角结构化模块。

不做：

- 多高亮色混搭
- 大面积花哨渐变
- 漂浮贴纸式标签
- 过度装饰性的圆轨道

动效：

- 快慢结合。
- 线条流动和节点激活是主角。
- 字体运动要干净，不乱飞。
- 过渡尽量是“系统状态变化”，不是 PPT 翻页。
- 优先做结构变化，不优先做夸张表演。

## 已验证的高级感规则

来自 `guizang-ppt-skill` 的有效提炼：

1. 一条视频只保留一个 accent 色
2. 标题必须有明确左上内容轴
3. 装饰必须后退，不能抢主信息
4. 中文大标题要更克制，优先手动断行
5. 网格和面板要真实存在，不能只靠“感觉对齐”
6. 动效要表达秩序，不要表达热闹
