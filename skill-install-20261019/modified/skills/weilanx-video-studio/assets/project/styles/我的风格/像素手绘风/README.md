# 像素手绘风

## 画面特征

- 角色已经换成像素风：`<CharStyle.Provider value="pixel">`

- 横屏演播室 `Host` 做 A-roll，B-roll 主持人 `PiP` 站右下角；ep04 加入了真实图片素材（`Photo`）
