## 为什么会爆：七个价值叠在一起

1. **痛点标题，第二人称**：每个题目都是玩家骂过的那句话（「越玩越菜」「总是我先死」），观众一看就觉得是在说自己。
2. **前 3 秒复现挫败**：开场直接在射击场里重演那一刻（被击杀的红屏裂纹、打空的子弹），第 6 秒标题卡才出来。先有情绪，再给问题。
3. **反直觉答案 + 科学模型**：不说「多练」，而是给一个能「看见」的模型：钟形曲线、50 发散布图、角速度公式、视野三角。模型让「玄学手感」变成可解释的东西，观众获得「原来如此」的认知爽感。
4. **生活类比降门槛**：夹菜、坐车看风景 vs 站路边看车、闭眼摸鼻子。一个类比顶十句解释，也给不玩游戏的人留了门。
5. **模拟即证明**：每个论点都在 3D 射击场或俯视图里「演」出来（慢放 ×0.25、两个视角并排对比），观众是亲眼看到，而不是被告知。
6. **给方法（实用价值）**：结尾前有一章「怎么办」：分步骤、可执行（先接受 → 看一组不看一次 → 找坏在哪一步 → 固定流程）。看完能马上去试，愿意收藏。
7. **情绪翻转 + 评论钩子（情绪价值 + 互动）**：最后一句替观众卸下包袱（「你没有变菜」），或者抛一个人人能答的二选一（「架点还是拉枪？」）。

## 结构公式（2 分 18 秒）

```
0–6 秒    重演挫败瞬间（3D 场景 + 一句话说一半）
6–10 秒   标题卡：系列标 + 痛点问题 + 胶囊关键词
10–20 秒  先否定直觉（「你是真的退步了吗？」）
20–100 秒 4–5 个章节，每章：一个模型 → 一个模拟 → 一句结论（关键词高亮）
100–125 秒「怎么办」：3–4 步方法，每步一个画面
125–138 秒 情绪翻转一句 + 评论区问题
```

每章开头右上角章节号跳一格（「03 / 07 大脑」），底部进度条走一段，观众始终知道还剩多少，完播率更稳。

## 画面语法（详见 README.md）

深蓝黑底 + HUD 角标框；三类画面轮换：低多边形 3D 射击场（冷青线框 / 暖橙「以前」两种色调）、发光图表（钟形曲线、折线、散布、循环环）、黑底大字卡；字幕白色粗黑体，关键词青 / 红 / 橙变色加发光下划线，逐字模糊浮现；镜头之间硬切，死亡用红屏裂纹，揭晓答案用「黑场 → 白闪 → 橙色大字 + 圆环」。

## 新选题：结合《无畏契约》的 12 个角度（原片没碰过的方向）

每个都按「挫败感 → 科学模型 → 模拟画面 → 方法 → 情绪翻转 / 评论钩子」来做。⚠ 数字发布前逐条核对。

| # | 挫败感（标题） | 科学模型 | 模拟画面 | 情绪 / 评论钩子 |
|---|---|---|---|---|
| 1 | 明明躲进掩体了，还是被打死？ | 网络延迟与服务器回溯（lag compensation）：服务器按对方看到的「过去」判命中；128 tick 每帧约 7.8 ms | 时间轴：你的屏幕 / 服务器 / 对手屏幕三条轨道错开 | 「你没躲慢，是你们活在不同的时间里」 |
| 2 | 脚步声听不出在前还是在后？ | 混淆锥（cone of confusion）：前后对称位置到两耳的时间差一样；耳廓靠频谱区分前后，可尝试游戏里的 HRTF 选项 | 俯视图：头 + 两耳 + 一圈对称的声源 | 「你左耳右耳都好，是声音太对称」；评论：你开不开 HRTF？ |
| 3 | 敌人就在眼前，为什么我没看见？ | 中央凹只有约 2°（伸直手臂一个拇指盖），其余是余光；不注意视盲（Simons & Chabris 1999） | 画面只有准星周围一小圈清晰，其余模糊 | 「你不是瞎，你的清晰区只有一枚硬币大」 |
| 4 | 一紧张就压不住枪？ | 倒 U 曲线（Yerkes–Dodson 1908）：唤醒太低太高都掉表现；生理震颤放大 | 倒 U 曲线 + 准星抖动幅度随心率变化 | 「紧张不是坏事，太紧张才是」；方法：残局前呼吸 4 秒 |
| 5 | 掉分比上分难受十倍？ | 损失厌恶（Kahneman & Tversky 1979）：输的痛约是赢的快乐两倍 | 天平：一场输 = 两场赢 | 「你不是心态差，是人脑天生这样算账」；评论：你连败几把会停？ |
| 6 | 队友一死我就慌，连死三把？ | 赌徒谬误 / 热手效应：上一局不改变这一局的概率，但会改变你的决策 | 硬币序列 + 你的「感觉」曲线 | 「下一把是新的一把」 |
| 7 | 高刷屏和低延迟真有用吗？ | 系统延迟链：鼠标 → CPU → GPU → 显示；NVIDIA 2022 研究：更低的延迟提升瞄准表现 | 一条延迟流水线，每段毫秒数 | 「设备不能替你瞄，但能少拖你后腿」；评论：你多少 Hz？ |
| 8 | 为什么开镜后反而打不中？ | 视场缩小 → 同样的手移动，画面角速度放大；倍率越大越难跟 | 同一手势在两个 FOV 下的位移对比 | 方法：开镜前先把准星放到位 |
| 9 | 高手开枪前为什么像「停了一下」？ | 安静眼（Quiet Eye, Vickers）：高手开枪前的最后一次注视更早、更久（篮球研究里约 972 ms vs 400 ms） | 两条注视时间轴对比 | 「慢一点的眼，换快一点的枪」 |
| 10 | 我觉得瞄准了，回放却打在后面？ | 闪光滞后错觉（flash-lag，Nijhawan 1994）：大脑会把运动物体「往前预测」 | 移动靶 + 闪光点的错位 | 「你的眼睛在骗你，而且一直在帮你」 |
| 11 | 选择越多，反应越慢？ | 希克定律：可选项每翻一倍，决策时间多一截；道具、站位、技能越多越卡 | 选项树 + 反应时间台阶 | 方法：残局前把选项砍到 2 个 |
| 12 | 输了总觉得是队友的锅？ | 基本归因错误：自己的失误归环境，别人的失误归人 | 两个镜头：你死 vs 队友死，同一个原因两种解释 | 评论：上一把你怪过谁？ |

推荐先做：**#1 掩体后被打死**（最高频的挫败，Riot 官方讲过 netcode，画面是三条时间线，新）、**#3 一枚硬币大的清晰区**（视觉冲击强，适用所有 FPS）、**#5 掉分比上分难受**（情绪价值最强，评论区最好接）。
