## Overview

weilanx-claude-videos is a Remotion project for making short explainer videos (mostly in Chinese) about AI, tech history, science, game theory, FPS games and ancient China. Nothing is drawn in an editor: characters, props, backgrounds, charts, subtitles and sound effects are all generated by code. Voice-over episodes need a voice recording and its subtitles; music-only episodes need just a music track.

The repository contains a reusable component library with eight style kits, a style library, an audio synthesis pipeline, eight Claude Code workflow skills, and the full source of 50+ episodes as worked examples.

## Features

- **Frame-pure animation** — every component computes its look from the frame number; randomness uses a seeded `rand(seed)`, so renders are deterministic.
- **Subtitle-driven timing** — `makeCues` turns an SRT into helpers like `cf(n)` (frame where sentence *n* starts) and `cw(n, 'word')` (frame where a word is spoken). Re-record the voice-over, re-import the SRT, and every animation re-aligns.
- **Character library** — vector or pixel-art buddy (`Char`), with skins, accessories, expressions and walking/arm animations, switched via a `CharStyle` context.
- **Multiple looks** — black-gold glow, tactical HUD, lamplight history, warm-paper desk, gilded archive, halftone, editor room, pixel sticker, pixel hand-drawn, vector hand-drawn, and a Vox-style collage/timeline kit. See the [Style Gallery](#style-gallery).
- **Beat-locked music-only shorts** — one `timeline.ts` per episode holds the bar grid, hit frames, bilingual captions, shots and SFX; climaxes land on the track's measured downbeats.
- **One-shot workflow skills** — from a topic to an exported video, cover, post copy and subtitle documents, with automated frame and loudness QA.
- **Procedural audio** — 14 synthesized sound effects plus per-episode background music that automatically ducks under the voice.
- **Music library** — `audio/music.mjs` cuts a section of any track in `public/music/`, fades it and normalizes loudness; music-only shorts align their climax to the track's measured downbeat.
- **Clean export** — renders voice / music / SFX stems separately and remixes them with a limiter to avoid Remotion's internal clipping.
- **Style library** — 35 art styles and 9 explainer grammars (recipes and scene code) for picking a look before building an episode.

## Quick Start

Requires Node.js (developed on v24) and, for exporting, `ffmpeg`.

```sh
git clone https://github.com/Azure12355/weilanx-claude-videos.git
cd weilanx-claude-videos
npm install
npm run audio      # generates shared SFX and the ep00 demo music into public/audio/
npm run studio     # opens Remotion Studio at http://localhost:3000
```

Open the `ep00-demo` composition first: it is a self-contained 30-second demo that needs no external assets.

Other useful commands:

```sh
npm test                       # vitest
npm run typecheck              # tsc --noUnusedLocals
npx remotion still src/index.ts ep06-context out.jpg --frame=200 --scale=0.4   # render one frame
npm run export -- ep00-demo    # render into the folder printed by: bash scripts/ep-dir.sh ep00-demo out
```

> `npm run audio` prints errors for episodes whose voice track or music file is missing (see [What Is Not Included](#what-is-not-included)); the shared SFX and the ep00 music are still generated. To build one episode's audio, run `node audio/episodes/<episode-id>.mjs`.

## Workflow Skills

`.claude/skills/` contains eight Claude Code skills. Open the project in Claude Code and describe what you want; the matching skill is picked up automatically.

| Skill | What it does | Delivery | Sample |
|---|---|---|---|
| `weilanx-creator-distill-video` | Breaks reference videos down shot by shot (cuts, keyframes, palette, motion strips, beats) and distills their visual grammar into a new reusable style kit under `src/library/`, with a preview composition and a recipe card | Kit + preview + recipe card | `gilded/`, `tactical/`, `lamplight/`, `blackgold/` |
| `weilanx-creator-blackgold-video` | Black-gold glow short on a game-theory or counter-intuitive model, no voice-over, bilingual captions | **One-shot**: video, 3:4 cover, post copy, bilingual subtitles | `ep36` |
| `weilanx-creator-fps-video` | Tactical-HUD explainer on why something feels bad in FPS games, no voice-over | **One-shot**: video, 3:4 cover, post copy, subtitle doc | `ep25`, `ep29`… |
| `weilanx-creator-lamplight-video` | Lamplight history short on an ancient Chinese rule or custom, no voice-over | Script and beat sheet first, then one run to the video | `ep28`, `ep30`… |
| `weilanx-creator-gilded-video` | Music-only knowledge short in the gilded style: anchor word, climax on the track's measured downbeat | Studio preview, export after approval | `ep23`, `ep24` |
| `weilanx-creator-desk-video` | Warm-paper desk explainer for a talking-head "how I did X in N steps" video | Studio preview, export after approval | `ep26`, `ep27` |
| `weilanx-creator-vox-video` | Vox-style collage explainer: research, licensed real footage, expressive voice-over, hard cuts | Studio preview, export after approval | `ep21` |
| `weilanx-creator-pixel-video` | One keyword → a pixel-art talking-head explainer (3:4 portrait) | Studio preview, export after approval | `ep05`–`ep17` |

Bundled scripts include `analyze.py` and `strip.py` (video breakdown), `beats.py` (tempo, bar grid and downbeat detection), `qa.mjs` (frame and loudness self-check for the one-shot skills), subtitle-document generators and `commons.py` (Wikimedia Commons search with license info).

Some steps originally used the author's private tools (voice clone, speech recognition, text-to-image cover, title formula library). Every skill has a **依赖（开源版说明）** section saying exactly what to swap in; the one-shot black-gold workflow needs nothing private except a music track.

## Using the Skills

### Prerequisites

- Node.js (developed on v24), `npm install` done
- `ffmpeg` for export and loudness checks
- [`uv`](https://docs.astral.sh/uv/) for the Python helper scripts (they run as `uv run --with numpy --with pillow python …`)
- [Claude Code](https://claude.com/claude-code) opened at the repository root, so it loads `CLAUDE.md` → `AGENTS.md` and the skills in `.claude/skills/`
- Fonts: the newer styles use system CJK fonts (`Songti SC`, `PingFang SC` on macOS, falling back to `Noto Serif SC` / `Noto Sans SC`). They render best on macOS.

### Distill a style from reference videos

The rule is **match the style one-to-one, never copy the content**: components are rewritten from scratch, example content is made up, and no frame, caption, title or watermark of the original goes into the repository.

1. Put one or more reference videos in `template/` (git-ignored; they are someone else's work).
2. In Claude Code, say something like: *"Distill the style of `template/ref.mp4` into a new kit."*
3. The skill runs a machine breakdown per video (shots, keyframes, contact sheets, palette and accent colors, motion intensity, beats), writing a report to `materials/00-公共/风格蒸馏/<style-id>/`.
4. It then cuts motion strips around key moments, writes a recipe card under `styles/我的风格/<name>/`, builds `src/library/<style-id>/`, a `library-<style-id>` preview composition, and registers everything in `src/library/README.md` and `styles/README.md`.
5. It compares the preview with the reference for at least two rounds before handing over. Open `http://localhost:3000/library-<style-id>` in Studio to review.

You can also run the breakdown by hand:

```sh
uv run --with numpy --with pillow python .claude/skills/weilanx-creator-distill-video/scripts/analyze.py \
  template/ref.mp4 --out materials/00-公共/风格蒸馏/<style-id>/<video-name>
```

### Make an episode in one shot

The one-shot skills (`blackgold`, `fps`) take a topic and deliver a finished episode without stopping for confirmation: research → anchor word and storyboard → `timeline.ts` locked to the music's beats → sound effects → scenes → tests → automatic frame and loudness self-check (fixing issues for up to three rounds) → export → 3:4 cover, post copy and subtitle documents.

1. **Provide a music track.** The samples are cut to `we-never`, a track the author is licensed to use; the mp3 is not distributed. Put your own licensed track in `public/music/`, register it in `TRACKS` in `audio/music.mjs`, and measure it:

   ```sh
   uv run --with numpy python .claude/skills/weilanx-creator-gilded-video/scripts/beats.py public/music/<track>.mp3 --to 40
   ```

   Then point the episode's `timeline.ts` grid and hit frames at the measured beats (the skill does this if you tell it which track to use).
2. **Give a topic** in Claude Code, e.g. *"Make a black-gold episode on the boxed pigs game"* or *"Make an FPS episode: why do I always lose the first duel"*. Give the topic explicitly: the author's topic pools live in `materials/` and are not in the repository.
3. The skill picks the next episode ID, creates the material and output folders with `scripts/ep-dir.sh`, and starts from the sample episode's code (`ep36-boxed-pigs` for black-gold, the latest tactical episode for FPS) instead of a blank file.
4. Find the deliverables in the output folder (`bash scripts/ep-dir.sh <episode-id> out`): `<episode-id>.mp4`, `封面-3x4.png`, `发布文案.md`, `字幕稿.md` and, for black-gold, `字幕.srt`.

The cover for black-gold is rendered by code (`CoverTall.tsx`); the FPS skill generates its cover with a text-to-image model, which you can replace with any image tool or a rendered frame.

## What Is Not Included

To protect the author's privacy and third-party rights, the following are intentionally **not** in this repository:

| Path | What it was | Effect |
|---|---|---|
| `public/audio/<episode>/voice.wav` | Original voice-over recordings | Voice-over episodes play silently in Studio; their music cannot be generated |
| `public/footage/<episode>/` | Real-world photos and video clips, host camera recordings | Those panels are empty in ep03, ep07, ep21, ep22, ep26, ep27 |
| `public/images/ep04-opus55/` | Screenshots used in ep04 | ep04 image panels are empty |
| `public/music/*.mp3` | Music library tracks (only the catalog `public/music/README.md` is included). `we-never`, used by every music-only episode from ep23 on, is licensed to the author for their own use and is not redistributed | Music-only episodes play silently and their audio scripts fail until you add your own licensed track |
| `template/` | Reference videos used for style distillation (other people's work) | — |
| `materials/`, `out/` | Raw recordings, scripts, topic pools, breakdown reports, rendered videos | Created on demand by `scripts/ep-dir.sh` |

The visuals, captions, timelines and scene code of every episode are included, so you can study or adapt them and plug in your own voice and music.

## Making a New Episode

Prefer the [workflow skills](#using-the-skills). To do it by hand for a voice-over episode:

1. Create the folders: `bash scripts/ep-dir.sh epXX-topic materials --new <style-folder> <short-title>`, transcribe your voice-over into an SRT file and put it there.
2. Normalize the voice to about −16 LUFS and save it as `public/audio/epXX-topic/voice.wav` (48 kHz, stereo, 16-bit).
3. Import subtitles: `npm run cues -- <materials-folder>/字幕.srt src/episodes/epXX-topic/cues.json`.
4. Add `audio/episodes/epXX-topic.mjs` (music sections) and run `node audio/episodes/epXX-topic.mjs`.
5. Create `src/episodes/epXX-topic/` — use `ep02-llm` (portrait) or `ep03-cc` (landscape) as a template — register it in `src/Root.tsx`, and add `tests/episodes/epXX-topic.test.ts`.
6. Check frames with `npx remotion still`, preview in Studio, then `npm run export -- epXX-topic`.

Music-only episodes use a single `timeline.ts` per episode instead of subtitles; see the black-gold, FPS, lamplight and gilded skills.

## Agent Quickstart

### Objective

Produce deterministic explainer videos where every visual is a pure function of the frame number and is anchored to subtitle timing. Non-goals: a general video editor, or hosting the author's voice recordings and footage.

### Sources of truth

- Engineering conventions and pipeline: [`AGENTS.md`](AGENTS.md)
- Component catalogue: [`src/library/README.md`](src/library/README.md)
- Compositions: `src/Root.tsx`
- Tests: `tests/`

### Safe workflow

1. Read `AGENTS.md` and the library README.
2. Change scenes or library components; never import `src/episodes/` from `src/library/`.
3. Run `npm test` and `npm run typecheck`.
4. Verify visuals with `npx remotion still ... --scale=0.4` instead of rendering the full video.

### Commands

```sh
npm install
npm test
npm run typecheck
npm run studio
```

### Boundaries

- Never commit voice recordings, rendered videos, real footage, music files, reference videos, `.env` files or secrets.
- No `Math.random()`, CSS animations or wall-clock time in components.
- Only add third-party media whose license allows redistribution, and record its source.
