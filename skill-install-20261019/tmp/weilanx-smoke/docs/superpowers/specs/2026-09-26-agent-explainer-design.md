# 「什么是 Agent」口播动画 — 设计文档

日期：2026-09-26（方案已获确认，实施细节自由发挥）

## 输入
- `AI-Agent-2.0-最终粗剪纯人声-1.15x.wav`：人声 166.67s，已标准化为 `public/audio/voice.wav`（−16 LUFS / −1.4 dBTP）
- `AI-Agent-2.0-最终粗剪字幕.srt`：88 句，与人声对齐

## 输出
- `out/agent-explainer.mp4`：1080×1920，30fps，5000 帧，烧录字幕
- `out/stems/{voice,bgm,sfx}.wav`：分轨

## 原则
- 画风沿用 demo：米白纸张、深色粗描边、扁平色块
- 角色：灰色无手小人 = 普通 AI（只会说）；橙色伸缩手臂小人 = Agent（能动手）
- 一切动画挂在「第 N 句字幕开始帧」上（`cf(n)`），换 SRT 重新渲染即可重新对齐
- 版式：顶部章节标签（y≈150）、中部舞台（y 280–1330）、字幕条（y≈1400）、底部与右侧留平台 UI 安全区
- 中文字体：ZCOOL KuaiLe（本地 TTF，OFL）
- BGM 按段落编排并根据人声包络自动 ducking
