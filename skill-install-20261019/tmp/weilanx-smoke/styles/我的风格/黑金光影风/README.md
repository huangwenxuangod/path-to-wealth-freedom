# 黑金光影风

![预览](预览.jpg)

讲博弈论、经济学、认知、冷知识、AI 原理这类「一个模型解释一种现象」的横屏 16:9 风格：近黑底上一层缓慢翻涌的暖色烟雾，所有东西都在发光——金色粒子聚成标题，霓虹细线画出收益矩阵和曲线，聚光灯打在发光的小人身上，底部中英双语字幕。画面语法是从两支参考视频里拆出来的（参考视频不进 git），组件和示例都是重写的，没有沿用原片的内容、文案、创作者名字和水印。

**一键成片**：给一个选题，用 skill `weilanx-creator-blackgold-video`（`.claude/skills/weilanx-creator-blackgold-video/`）从查资料一路做到成片 + 3:4 封面 + 发布文案 + 双语字幕稿，样片 ep36。

和 [暗金文献风](../暗金文献风/README.md) 的区别：暗金是「烛光下翻古籍」，金线 + 衬线 + 羊皮纸、偏历史；黑金光影是「暗房里做实验」，烟雾 + 霓虹描边 + 聚光灯、偏模型和数据，颜色有三种固定语义。

## 画面特征

- **底色与质感**：近黑 #050302，上面一层缓慢漂移的暖褐烟雾（#17110c～#3a2b22，左下或右下一团），四周暗角；需要「警报 / 背叛」氛围时整片烟雾转暗红（#2a0d0c 左右）。不加纸纹，只加极轻的颗粒
- **配色**（一切都发光）：
  - 米白 #fffaf0：正文、大字（带 12～18px 白色外发光）
  - 金 #edd287 / 暖金 #e5c991：标题、箭头、数字、聚光灯
  - **青 #6fe0d2 = 合作 / 更好 / 本可以**（描边 + 发光）
  - **珊瑚红 #ff7a63 = 背叛 / 均衡 / 陷阱**（描边 + 发光）
  - 一个画面里青和红各最多一处高亮，金做连接
- **字体**：中文宋体 Black（`Songti SC` 900），英文 / 小标用 Garamond（大写字母宽字距 0.35em），英文字幕 Garamond 斜体
- **固定版式**：
  - 底部字幕：y≈930 居中，中文 60px 宋体 Black 米白 + 一行 34px 英文斜体灰；换句时旧句先淡到 25% 再换（不是硬切）
  - 左上章节签：小号中文章节名 + 一行宽字距英文（如「一报还一报 / TIT FOR TAT」）
  - 顶部中间引用行：宽字距大写「年份 · 人名 · 机构」灰金小字，下一行「NAMED BY …」更小
  - 居中大字：需要强调的一句话直接压在画面中央，白色强发光，模糊柔入
- **出场方式**：文字模糊 + 透明一起收（14～18 帧）；线条从一端画出（箭头 8～10 帧一根，依次）；高亮框「先描边后发光」再弹出旁边的标签；标题由金色粒子聚拢成字（约 13 帧）再浮出英文和副标题
- **转场**：多数是同一画面里元素进出（矩阵、图表、小人一直在，换高亮和字幕）；段落之间暗场交叉淡化 12～15 帧；章节开头用标题卡
- **镜头**：极慢推近；剧场类场景用镜头整体后拉
- **节奏**：平均 9～18 秒一个镜头，字幕 3～5 秒一句，卡音乐的小节但不强卡点
- **招牌画面**：①金粒子聚成的大标题 + 背景漂浮的公式碎片（p=⅔、Nash、T>R>P>S）；②霓虹收益矩阵：金箭头一根根画出，均衡格亮红框、最优格亮青框；③两间审讯室：聚光灯从上打下，发光的小人一亮一暗；④一排青红方块（C/D 序列）逐个亮起；⑤青红金三色的细胞网格，合作团块慢慢长出来；⑥一圈金色光点连成网络

## 出彩的手法（ep36 沉淀，下次照着想）

- **一个舞台贯穿全片**：把模型变成一个会动的小世界（ep36 的猪圈），开场、回落段、结尾都回到它，抽象推导段落只是「离开一会儿」。
- **角色要有生命感**：呼吸、眨眼、跑起来甩汗带尘、躺着打呼——观众先对角色有情绪，才会在意模型的结论。
- **硬拍上对账**：配乐回落段的连续硬拍不要只闪光，每一下都推动一个数（`Ledger`），让观众亲眼看到结论（大猪吃得多、跑得也多，净得始终和小猪一样）。
- **把推理变成实物**：「比较两个选项」用天平往一边沉（`BalanceScale`），「减法」用食粒变成汗珠飞走（`PelletStack`）。
- **连续长镜头转场**：推理收尾时镜头推进结论那一格（纳什均衡），直接落回舞台；爆点的锚词背后放一个和锚词同义的图形（「等」配一圈一根根点亮的表盘刻度）。
- **反面情况要有感官**：0 : 0 不只是数字——灯接触不良地闪、两只猪肚子「咕……」。
- **能算就真的算**：ep38 的洛伦兹吸引子、两条轨迹和差距表是用原论文的方程在 timeline 里算出来的，画面、字幕、测试用同一份数据；第 128 拍正好落在算出来的「分开那一步」。
- **把原始文献变成道具**：ep38 的打印纸带（0.506 那一行）和「127」从数字上掉下去，比直接写「四舍五入」更有画面。
